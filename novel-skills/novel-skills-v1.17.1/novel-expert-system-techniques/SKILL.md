# 经典技法补全

> **触发条件**：涉及选题评估、素材积累、防崩策略时激活。
> **加载来源**：novel-expert-system 子模块。

## 经典技法补全

> 本章节补充可直接套用的经典技法模板，供创作者在实际写作中参考。

### 10.1 选题阶段检查点

选题是整个创作流程的"地基"——选题错了，后面所有努力都是在错误方向上加速。选题阶段的核心问题是"这个题材+这个平台+这个时机，能不能成"。

**选题四维评估模型：**
```
维度一：市场热度（权重30%）
  → 该题材在目标平台当前的热度如何？
  → 查看方法：平台排行榜/新书榜/完本榜
  → 评分标准：
    S = 平台前3题材（如番茄年代文/起点仙侠）
    A = 平台前10题材
    B = 有稳定受众但非热门
    C = 小众题材（风险高但竞争小）

维度二：个人匹配度（权重30%）
  → 你是否擅长/喜欢这个题材？
  → 你是否有足够的知识储备？
  → 评分标准：
    S = 擅长+热爱+有储备
    A = 擅长或热爱+有一定储备
    B = 不太擅长但愿意学习
    C = 完全不擅长也不喜欢

维度三：差异化空间（权重20%）
  → 该题材的头部作品已经写到了什么程度？
  → 你能否写出差异化？
  → 评分标准：
    S = 有独特的切入点/金手指
    A = 常见套路但执行更好
    B = 纯跟风
    C = 完全没有新意

维度四：变现路径（权重20%）
  → 该题材在目标平台的变现模式是否清晰？
  → 签约/推荐/付费/IP改编前景
  → 评分标准：
    S = 多重变现路径
    A = 主要变现路径清晰
    B = 单一变现路径
    C = 变现路径不明确
```

**选题阶段Checklist：**
- [ ] 是否完成了四维评估，总分 ≥ A？
- [ ] 是否研究了目标平台最近30天的排行榜？
- [ ] 是否阅读了3本以上同题材头部作品？
- [ ] 是否明确了自己的差异化卖点？
- [ ] 是否确认了目标读者画像？
- [ ] 是否设定了可量化的第一阶段目标？

### 10.2 大纲阶段检查点

大纲是创作的"蓝图"——没有大纲就开写，相当于没有图纸就盖楼。大纲不一定要详细到每章内容，但必须包含"故事的整体骨架"。

**大纲三层结构：**
```
第一层：一句话故事（Logline）
  → 格式：当[主角]遇到[冲突]时，他必须[行动]，
          否则[后果]。
  → 例："当一个废柴少年意外获得上古功法时，
         他必须在宗门覆灭前修炼到足够强大，
         否则整个家族将被灭门。"

第二层：故事弧大纲（每20-30万字一个弧）
  → 每个弧：起始状态 → 触发事件 → 高潮 → 新状态
  → 弧与弧之间的衔接关系
  → 总字数预估和节奏分配

第三层：章节大纲（每卷/每10章为单位）
  → 每章的核心事件（1-2句话）
  → 每章的情感目标（爽/虐/悬念）
  → 每章的伏笔/回收
```

**大纲阶段Checklist：**
- [ ] 是否写出了一句话故事（Logline）？
- [ ] 是否规划了完整的故事弧（从开始到结局）？
- [ ] 是否为每个弧设定了独立的目标和冲突？
- [ ] 是否规划了主角的成长路径（实力/感情/地位）？
- [ ] 是否标注了关键伏笔的埋设和回收节点？
- [ ] 大纲是否经过"逻辑自洽"检查？
- [ ] 是否设定了每个阶段的字数目标？

### 10.3 初稿与修改阶段检查点

初稿的目标是"把故事写完"，而不是"写好"。很多作者的错误是在初稿阶段追求完美，导致迟迟无法推进。修改阶段才是"变好"的阶段。

**初稿阶段原则：**
```
原则一：先写完，再写好
  → 初稿允许有瑕疵，重要的是完成
  → 不要反复修改前几章
  → 设定每日最低字数目标（如3000字/天）

原则二：遇到卡壳跳过去
  → 写不出来的章节先跳过，标记为[TBD]
  → 先写能写的部分，保持推进
  → 回头再补[TBD]部分

原则三：不要回头看
  → 写今天的章节时不要看昨天的
  → 初稿全部完成后再统一回顾
  → 避免"改着改着就不想写了"
```

**修改阶段四轮检查法：**
```
第一轮：结构检查（全局）
  → 整体节奏是否合理？
  → 有没有"塌陷段"（连续3章以上无冲突）？
  → 伏笔是否全部回收？

第二轮：角色检查（全局）
  → 主角性格是否前后一致？
  → 配角是否有独立动机（而非纯工具人）？
  → 角色行为是否符合其性格？

第三轮：文字检查（逐章）
  → 是否有"废话"（不推动剧情的内容）？
  → 对话是否自然？
  → 描写是否过度或不足？

第四轮：平台适配（针对性）
  → 章节长度是否符合平台要求？
  → 格式是否适配听读场景？
  → 敏感词/违规内容是否已清除？
```

**初稿与修改阶段Checklist：**
- [ ] 初稿是否在预设时间内完成？
- [ ] 是否进行了四轮修改？
- [ ] 结构层面是否有"塌陷段"？
- [ ] 角色行为是否前后一致？
- [ ] 是否删除了不推动剧情的内容？
- [ ] 是否进行了平台适配检查？
- [ ] 最终版本是否经过至少一次完整通读？

### 10.4 自检清单
- [ ] 选题四维评估是否总分 ≥ A？
- [ ] 大纲是否包含三层结构（Logline/弧/章节）？
- [ ] 初稿是否遵循"先写完再写好"原则？
- [ ] 修改是否完成了四轮检查？
- [ ] 每个阶段是否都有明确的Checklist？
- [ ] 是否有"卡壳应对预案"（跳过/TBD标记）？
- [ ] 最终版本是否经过完整通读？
- [ ] 是否保留了初稿和修改版的对照记录？
