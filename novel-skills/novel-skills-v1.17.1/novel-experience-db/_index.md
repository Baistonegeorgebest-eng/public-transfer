## 🛠️ 每次项目结束的标准流程

```
1. 在对应题材目录下创建 {项目名}/ 目录
2. 写入 project-review.md（用模板）
3. 提炼1-3条可执行规则 → 注入到相关skill的SKILL.md
4. 有重大踩坑 → 更新 cross-project/anti-patterns.md
5. 有验证有效技法 → 更新 cross-project/high-retention-patterns.md
6. 有平台参数变化 → 更新 cross-project/platform-params.md
7. 更新本索引表格
```
