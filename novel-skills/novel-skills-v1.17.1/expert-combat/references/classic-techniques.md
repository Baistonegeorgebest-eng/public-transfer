# 经典技法补全（动作链+五感战场+节奏变速器）

## 动作链构建法

好的动作链让读者像看武打片一样有画面感。

### 单回合动作链 = 起手 → 交锋 → 结果

**起手（1-2句）：** 交代双方的初始状态和意图
> "他微微弓身，右手按在剑柄上——这是拔刀术的起手式。"

**交锋（3-5句）：** 双方的动作交替描写
- 对称结构："A动→B应→B反→A应"
- 节奏控制：短句=快速，长句=慢镜头
> "剑光一闪（短句）。他侧身避开，长剑擦着耳际掠过（中句）。趁对方招式用老，他反手一掌拍在对手后心（长句）。"

**结果（1-2句）：** 交代这一回合的胜负/状态
> "那人踉跄后退三步，嘴角溢出一缕鲜血。"

### 组合链 = 多个回合的递进

```
回合1：试探（双方使用常规招式）
回合2：加码（一方认真，另一方被迫提升实力）
回合3：底牌（双方亮出关键招式/技能）
回合4：决胜（一方找到破绽/爆发决定胜负）
→ 每回合的激烈程度递增，不能在同一水平反复
```

## 五感战场法

只用视觉写战斗是通病。五感战场法要求调动读者的全部感官。

| 感官 | 占比 | 描写内容 | 升级技巧 |
|------|------|----------|----------|
| 视觉 | 40% | 刀光剑影、招式形态、角色表情 | 用色彩词增强画面感 |
| 听觉 | 25% | 兵器碰撞声、脚步声、喘息声 | 用声音"远近"表现距离 |
| 触觉 | 15% | 疼痛感、武器重量和温度、汗水 | 通过触觉表现身体状态 |
| 嗅觉 | 10% | 血腥味、焦糊味、花草香 | 嗅觉常用于"暗示" |
| 空间感 | 10% | 地形利用、距离变化、位置关系 | 空间感是写智斗的关键 |

**原则：每段战斗至少激活2种感官。**

### 声音描写词库

**动作音效：** 嗖（快速移动）/ 铮（武器相撞）/ 轰（爆炸）/ 噗（刺入身体）/ 咔嚓（骨骼断裂）

**力量感音效：** 轰隆隆（持续轰鸣）/ 嗡（能量蓄积）/ 嘶（能量消散）/ 噼里啪啦（电光雷电）

**刀剑：** 金属撞击"铛——" / 刀刃摩擦"嘶——" / 刀刃入肉"噗嗤——"

**拳脚：** 重拳撞击"砰——" / 骨头断裂"咔嚓——"

**魔法/技能：** 火焰"呼呼——噼啪——" / 雷电"咔嚓——嗤——" / 水流"哗——汩汩——"

**使用原则：**
- 每场战斗至少用2~3个声音词
- 声音词要配合战斗节奏
- 最重要的时刻用最响的声音词

## 节奏变速器

战斗场景的阅读节奏应该是变速的——有快有慢，有紧张有喘息。

### 四速档位

**超速档（5-10字短句，用于爆发瞬间）**
> "剑落。血溅。人倒。"
> 适用：主角爆发、秒杀、大招释放

**高速档（10-20字短中句，用于激烈交锋）**
> 动作+简单反应
> 适用：常规战斗的主要部分

**中速档（20-30字中长句，用于战术/对话穿插）**
> 动作+心理+对话
> 适用：智斗、谈判、战术调整

**低速档（30字以上长句慢镜头，用于关键时刻）**
> "那一剑从斜上方劈下，剑身上的光芒在空气中拖出一道弧线，像流星划过夜空。他看到了剑刃上映出的自己的脸——平静得不像一个即将死去的人。"
> 适用：关键时刻的慢镜头、角色心理转折

### 变速规则

- 超速→低速 = 大招释放后的慢镜头回放（爽感放大）
- 低速→超速 = 酝酿后的突然爆发（冲击力加倍）
- 连续超速不超过3段（读者来不及感受）
- 连续低速不超过2段（节奏太慢）

---

## 战斗情绪节奏公式

```
短战斗（500-1500字）：紧张→爆发→悬念→反击→决胜

长战斗（2000-5000字）：紧张→试探→压制→绝望→反转→爆发→代价→决胜

超长战斗（5000字+，BOSS战）：期待→压制→希望→压制→绝望→援军/觉醒→爆发→惨胜
```
