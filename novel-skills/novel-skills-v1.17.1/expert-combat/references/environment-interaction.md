# 战斗环境互动设计

## 环境描写三层次

| 层次 | 功能 | 示例 |
|------|------|------|
| 背景层 | 简单交代环境 | "荒山野岭，月黑风高" |
| 互动层 | 环境成为战斗一部分 | "他退入密林，对方追击速度被迫降低" |
| 转折层 | 环境成为决定性因素 | "一道雷电从天而降，正中两人之间" |

## 四种环境互动类型

### 类型一：地形利用型

常见地形：悬崖/密林/室内/城墙

```
模板：
"他忽然转身，一头扎进了密林之中。
对方紧随其后，却在三棵巨树之后失去了他的踪迹。
就在对方四处张望时，他从树冠中骤然跃下——"
```

### 类型二：天气借势型

常见天气：暴雨/雷电/大风/浓雾/沙尘暴

```
"暴雨倾盆而下，两人的视线都受到了极大干扰。
但他早有准备——在这片雨中战斗过无数次。
而对方，第一次。"
```

### 类型三：空间限制型

空间类型：封闭房间/桥梁/山谷/传送阵范围

```
"传送阵的光芒一闪，周围的景象骤然改变——
一片荒芜的石殿，四面高墙，无处可逃。
他心中一沉：对方早就布置好了战场。"
```

### 类型四：环境破坏型

破坏方式：建筑倒塌/地裂/引燃/决堤

```
"他猛然出掌，灵力灌入地下——
轰隆隆！大地裂开一道十丈宽的裂缝，
数十敌人惨叫着坠入深渊。"
```

## 环境+战斗+反转组合模板

```
"这是一片悬崖之上的平台，三面环崖，只有一条石桥通向外界。（环境铺垫）
他故意退到崖边，引对方步步紧逼。（环境利用）
就在对方以为胜券在握时——
他忽然暴起，一脚踢断身后的石桥！（环境转折）
敌人惊叫着坠入万丈深渊。
但他也被冲击波震退，脚下一空——
关键转折：援军的手抓住了他的手腕。
战斗，进入第二回合。"
```

## 战斗后写法（常被忽视的重要部分）

### 战斗后三必要元素

1. **伤势处理** —— 主角的伤势如何？
2. **战利品分配** —— 得到了什么？
3. **心理变化** —— 战斗对角色有什么影响？

### 战斗后心理变化

- 主角变强了，有没有变得自大？
- 主角变强了，有没有变得更谨慎？
- 配角对主角的态度有什么变化？
