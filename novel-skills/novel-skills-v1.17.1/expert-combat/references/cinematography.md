# 战斗分镜技术

## 战斗分镜的概念

将战斗场景拆分成多个"镜头"，每个镜头有不同角度/距离/重点。

### 镜头类型

- **近景：** 招式细节/表情特写
- **远景：** 战场全貌/战术布局
- **特写：** 关键一击/致命伤
- **俯拍：** 力量对比/劣势方
- **主观镜头：** 主角视角的紧张感

**核心原则：** 不要在同一个距离/角度停留太久；每次切换要有意义；高潮时刻用最密集的切换。

## 1v1 战斗分镜模板

```
镜头1【拉开序幕】（远景→中景）
"两人相距十丈，对视而立。风卷起地上的落叶。"

镜头2【试探出招】（中景→近景）
"他率先出手，剑光一闪，直刺对方咽喉。"

镜头3【对方反应】（近景→特写）
"对手侧身，剑锋贴着他的耳际划过，带起一缕碎发。"

镜头4【回合制推进】（中景交替）
"你攻我守，我进你退。二十招过去，未分胜负。"

镜头5【危机降临】（特写→远景）
"对手忽然后撤，双手结印，天地灵气疯狂涌动。"

镜头6【极限应对】（近景）
"他咬牙，将全身灵力注入剑中，迎了上去。"

镜头7【胜负揭晓】（特写）
"轰然巨响中，对手被震退三步，口角溢血。"

镜头8【战后余波】（远景）
"尘埃落定，他单手撑剑，大口喘息。"
```

## 群战分镜模板

```
第一层【宏观全景】（航拍视角）
"十万大军在荒原上对峙，旌旗遮天，战鼓震耳欲聋。"

第二层【中观战场】（战术视角）
"第三大队开始向左翼迂回，弓箭手压上，箭雨倾泻而下。"

第三层【小队焦点】（聚焦视角）
"林逸带着小队五人在敌阵中穿梭，直取敌方主帅。"

第四层【单挑特写】（特写视角）
"他与敌方将领刀剑相交，每一击都是生死之争。"

第五层【战场收束】（宏观视角）
"主帅落马，敌军阵型大乱，溃败如潮水般蔓延。"

第六层【主角近景】（人物视角）
"他浑身浴血，看着满目疮痍的战场，眼神复杂。"
```

## 分镜切换信号词库

### 由远及近
- 远眺/俯瞰/远远望去 → 镜头拉远
- 定睛一看/仔细一看/注目 → 镜头拉近

### 关键切换
- 就在这时/就在此时 → 关键时刻切入特写
- 与此同时/另一边/再看 → 平行镜头切换
- 刹那间/倏忽/电光火石间 → 快切，制造紧迫感
- 良久/许久之后/战况焦灼之际 → 减速镜头
- 他注意到/忽然/余光瞥见 → 主观视角切入

## 战斗中的"时间膨胀"写法

关键时刻放慢时间描写，让读者感受"这一刻的每一个细节"。

**正常速度：**
> "他拔剑，反派后退，他一剑刺穿了反派的肩膀。"

**时间膨胀版：**
> "他握住剑柄。反派的脸，在这一瞬间定格——他看到了反派眼里的恐惧。剑身出鞘。空气划破的声音，像撕裂绸缎。剑尖触碰到反派的肩胛。他感受到了阻力——那是血肉的质感。然后，剑刺穿了。"

**应用场景：** 主角的关键一击 / 反派的致命一击 / 逆转的一刻

## 战斗的"气"设计

**描写要素：** 颜色（红/蓝/金/黑）→ 形态（光/雾/龙/剑）→ 范围（点/线/面）→ 强度（微光/耀眼/毁灭性）

**使用原则：**
- 每个角色有自己独特的气（颜色/形态固定）
- 气是实力的外化，越强的人气越盛
- 气的变化代表战局的变化

## 多对多混战处理

**核心技法：**
1. 先锁定"核心对决"（2~3人）
2. 其他人的战斗作为背景
3. 核心对决分出结果时，再描写其他结果
4. 最后统一收尾

**指挥视角（大型战争）：**
- 主角作为指挥者，在后方指挥战斗
- 同时穿插主角的亲自参战
- 配角的战斗作为背景
