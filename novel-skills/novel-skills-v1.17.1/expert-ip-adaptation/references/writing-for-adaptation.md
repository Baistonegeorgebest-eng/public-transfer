# 从写作端为IP改编做准备

## IP价值最大化的写作策略

```
写作阶段（创作IP种子）
├─ 建立独特世界观标识
├─ 塑造3-5个高辨识度角色
├─ 埋下系列化/衍生化的种子
└─ 培养核心粉丝社群

连载阶段（培育IP价值）
├─ 维持更新稳定性（算法+口碑）
├─ 鼓励二创（同人/Cosplay/讨论）
├─ 积累"名场面"和"金句"
└─ 建立角色CP话题度

完结阶段（IP变现准备）
├─ 完结质量不崩（口碑保障）
├─ 留下衍生空间（前传/续作/外传潜力）
├─ 番外维护热度
└─ 主动/被动接触版权方
```

## 改编友好的格式规范

- 对话占比≥50%（适配有声书/影视）
- 每段≤3行（适配听读/短剧）
- 场景明确、可视觉化（适配影视/动漫）
- 角色有标志特征（适配所有改编）

## 版权谈判要点

```
❌ 为了改编牺牲文学性 → 改编来找你是结果，不是目的
❌ 版权谈判不谨慎 → 一定要保留影视改编权
❌ 改编授权太早 → 数据起来后再谈，筹码更大
❌ 不了解改编市场 → 要研究什么样的作品容易被改编
```

## 改编优先级详细排序

**短剧改编（门槛最低，收益最快）：**
- 平台：番茄/快手/抖音短剧
- 字数要求：3-10万字
- 改编周期：1-2个月
- 收益：保底+分成

**有声书改编（门槛中等，长尾收益）：**
- 平台：喜马拉雅/番茄畅听
- 字数要求：20万字+
- 改编周期：2-4个月
- 收益：播放量分成

**动漫改编（门槛高，IP价值大）：**
- 平台：B站/腾讯动漫
- 字数要求：50万字+
- 改编周期：6-12个月
- 收益：版权买断+分成

## IP改编终极检查清单

- [ ] 作品有"可改编基因"（场景可视化/对话驱动/情绪曲线/角色记忆点）
- [ ] 版权条款已审查（保留影视改编权/改编审核权）
- [ ] 了解目标改编赛道（短剧/有声/动漫/影视）
- [ ] 有改编友好的格式（对话占比≥50%/每段≤3行/场景明确）
- [ ] 作品数据已达到改编门槛（收藏/追读/订阅）
