# IP价值评估体系详解

## 五维模型各维度详解

### 维度一：粉丝基数（30%权重）

| 指标 | 优秀 | 良好 | 一般 | 较弱 |
|------|------|------|------|------|
| 总收藏/订阅 | 50万+ | 10-50万 | 1-10万 | <1万 |
| 均订（起点） | 3万+ | 1-3万 | 3000-1万 | <3000 |
| 完读率（番茄） | 25%+ | 15-25% | 8-15% | <8% |
| 同人创作量 | 1000+ | 100-1000 | 10-100 | <10 |
| 二创视频数 | 500+ | 50-500 | 5-50 | <5 |

**粉丝基数的真正价值**：不是数字本身，而是**可迁移性**——粉丝愿不愿意为改编作品买单。

### 维度二：世界观独特性（20%权重）

**高价值世界观特征：**
- 有独特的规则体系（修炼体系/社会制度/物理法则）
- 有可扩展性（同一世界观可支撑多条故事线）
- 有视觉识别度（能用一句话/一张图概括世界特色）
- 有跨文化潜力（核心设定不依赖特定文化背景）

**低价值世界观特征：**
- 与大量作品雷同（"又一个修仙世界"）
- 过于依赖文字表达（心理描写密集型）
- 场景不可视化（缺乏具象化的空间想象）

### 维度三：角色IP化潜力（20%权重）

**角色IP化评估清单：**
- [ ] 主角是否有标志性特征（外貌/口头禅/习惯动作）？
- [ ] 是否有3个以上有辨识度的配角？
- [ ] 角色之间的关系是否有话题性（CP/对手/阵营）？
- [ ] 角色是否有衍生价值（手办/表情包/Cosplay潜力）？
- [ ] 是否有"名场面"可被独立传播？

### 维度四：情感共鸣力（15%权重）

**情感共鸣的层次：**
```
表层：爽感（逆袭、打脸、升级）→ 传播力强，但留存弱
中层：情感（爱情、友情、亲情）→ 留存强，适合长剧
深层：共鸣（命运、选择、成长）→ 口碑好，适合精品化
```

**评估方法：** 书评/长评中的情感关键词密度。如果读者评论大量出现"哭了""心疼""意难平""回味无穷"，说明情感共鸣力强。

### 维度五：商业延展性（15%权重）

**高延展性IP特征：**
- 世界观可授权做游戏
- 角色形象可做周边/手办
- 有美食/服饰/建筑等可实体化的文化元素
- 有系列化潜力（前传/续作/外传/番外）
