# 粉丝社群管理详解

> 社群是连载运营的"后花园"，是从"读者"到"粉丝"的转化器。

## 1. QQ群管理

### 群分级制度

- **公开群**：门槛低（订阅/收藏截图即可加入），容纳普通读者
- **核心群**：高门槛（全订+长评/高活跃度），给予更多特权
- **VIP群**：付费入群或消费达标，提供提前看章等独家内容

### 群规模板

```
1. 禁止剧透（含暗示性剧透）
2. 禁止人身攻击作者/其他读者
3. 禁止发广告、外链
4. 禁止传播盗版
5. 讨论其他作品请@对方群或另开话题
违规3次移出群聊
```

### 群活跃度维护

- 每日定时话题（"今天这章你最想吐槽什么？"）
- 定期投票（"下一个番外写谁？"）
- 节日活动（红包、抽奖、定制头像）
- 偶尔"剧透碎片"（不剧透核心剧情，给一些边角料）

## 2. 微信群管理

微信群相比QQ群更私密，适合核心读者：
- 群上限500人，保持质量而非数量
- 作者亲自维护，定期分享创作心得
- 适合讨论更深度的内容（角色分析、世界观探讨）

## 3. Discord/Telegram（海外或年轻读者群）

**适用场景**：面向海外华人群体、Z世代读者、二次元/游戏题材

### Discord优势

- 频道分区清晰（讨论区/投票区/资源区/闲聊区）
- Bot自动化管理（自动验证、自动分组）
- 支持角色权限管理

### Telegram优势

- 群组容量大（最高20万人）
- 支持频道单向推送（适合通知更新）
- 匿名性好，读者更敢表达

## 4. 社群管理的红线

1. **不要在群里暴露未公开剧情**——泄露=事故
2. **不要在群里与读者发生冲突**——截图传播速度极快
3. **不要让社群成为"吐槽集中营"**——适度管理负面情绪
4. **不要过度依赖单一社群平台**——QQ被封号就全丢了
