# 多平台运营策略详解

> 多平台运营可以最大化曝光和收益，但需要策略性地管理。

## 1. 多平台分发模式

| 模式 | 说明 | 优劣 |
|------|------|------|
| 独家首发 | 只在一个平台发布 | 分成高，但风险集中 |
| 主平台+分发 | 主平台首发，其他平台延迟发布 | 平衡曝光和收益 |
| 全平台同步 | 所有平台同步更新 | 曝光最大化，但可能触发独家条款冲突 |
| 免费+付费分离 | 番茄免费版+起点付费版 | 需注意版权归属 |

## 2. 平台选择矩阵

| 你的作品特点 | 推荐首选平台 | 次选平台 |
|------|------|------|
| 男频玄幻/仙侠 | 起点 | 番茄、七猫 |
| 女频言情 | 晋江 | 长佩、番茄 |
| 都市/现实题材 | 番茄 | 起点、七猫 |
| 二次元/同人 | 刺猬猫 | LOFTER、AO3 |
| 悬疑/推理 | 起点 | 番茄 |
| 短篇/微小说 | 番茄 | 知乎、豆瓣阅读 |

## 3. 跨平台引流

- **微博**：发布更新通知、角色插图、创作日常
- **小红书**：书评推荐、角色分析（吸引女性读者）
- **B站**：同人视频、角色配音、创作Vlog（吸引年轻读者）
- **抖音/快手**：小说解说、名场面剪辑（吸引泛用户）
- **知乎**：专业领域回答中植入作品推荐

## 4. 多平台的注意事项

1. 检查各平台的**独家条款**，避免违约
2. 统一笔名和品牌识别度
3. 不同平台的读者偏好不同，章末引导语需调整
4. 数据分散管理，建议建立统一的数据追踪表
