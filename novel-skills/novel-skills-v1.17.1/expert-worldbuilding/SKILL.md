## 一、世界观架构金字塔

```
【顶层：哲学/信仰体系】→ 这个世界相信什么？什么是正义？什么值得追求？
【中层：社会/政治体系】→ 这个世界如何运作？政治/经济/文化/军事如何运转？
【底层：地理/物理规则】→ 这个世界的物质基础是什么？灵气/资源/种族/历史？
```

**核心原则：三层互相制约。** 底层决定中层的可能，中层决定顶层的形态，顶层反过来影响底层的演化。

## 二、地理与物理规则层

### 2.1 地理设计七要素

**要素一【灵气/资源分布】**
→ 灵气充沛→大宗门聚集→资源争夺 / 灵气匮乏→凡人国度→稳定但弱
→ 资源分布不均 → 势力分布不均

**要素二【禁忌区域】**
→ 开局绝对不可进入，需要特定境界/钥匙/机缘
→ 例：仙魔战场/天道禁地/远古遗迹
→ 作用：设定最终目标，制造悬念

**要素三【交界地带】**
→ 两个势力的交界/缓冲区，势力真空地带，冲突高发
→ 主角冒险的天然舞台

**要素四【独立势力/中立区】**
→ 商会联盟/中立城市/散修聚集地
→ 作用：情报交换/任务发布/第三方视角

**要素五【历史遗留区】**
→ 上古战场/宗门遗址 → 探险/传承/宝物发现地

**要素六【特殊环境】**
→ 火山水泽/雷渊/风暴之海 → 修炼特殊体质/获取特殊材料

**要素七【世界终极秘密】**
→ 世界是怎么来的？为什么有修炼体系？
→ 主线剧情的最终悬念，故事中后期逐步揭示

### 2.2 世界物理规则设计

```
规则一【能量体系】这个世界用什么能量？（灵气/斗气/魔力/原力）
规则二【力量上限】先设定世界最高战力，主角上限=世界最高-1~2个境界
规则三【力量边界】什么力量存在？什么力量不存在？（例：不能时间倒流）
规则四【特殊法则】世界级的特殊规则（例：每万年一次大劫/天道意志存在）
```

## 三、社会与政治体系层

### 3.1 社会结构四层

```
第一层【统治层】王朝/帝国/宗门联盟 → 制定规则，最强武力
第二层【精英层】贵族/大宗门弟子/富商 → 统治执行者，主角主要竞争对手
第三层【中间层】小宗门/中产/工匠 → 社会稳定基础，主角早期可接触
第四层【底层】散修/凡人/奴隶 → 数量最多，主角最可能出身
```

### 3.2 规则体系五维度

```
维度一【修炼规则】谁能修炼？代价是什么？修炼者社会地位？
维度二【资源规则】资源如何分配？（宗门传承/商会交易/国家统购）
维度三【信息规则】信息如何传递？（无互联网→信息极不对称→阴谋土壤）
维度四【时间规则】时间流逝如何？（秘境一年=外界一天）
维度五【生死规则】死亡是否可逆？（轮回/夺舍/消亡 → 决定世界观氛围）
```

## 四、信仰与哲学体系层

### 4.1 信仰体系四种模式

```
模式一【多神教】多个神祇各司其职 → 神祇关系→神战→影响凡间
模式二【天道意志】没有具体神祇，天道/因果/轮回作为规则运行
模式三【无神论/唯物论】修炼是对自然法则的掌握 → 科学修炼/技术修仙
模式四【神即是规则】最强大存在=规则本身（雷帝掌控雷霆法则）
```

### 4.2 世界观底层逻辑

```
示例一【玄幻·强者为尊】强者决定弱者命运 → 主角变强=掌握命运 → 丛林法则
示例二【奇幻·秩序代价】维持秩序需要代价 → 主角使命=维护秩序 → 等级森严
示例三【科幻·资源至上】资源决定一切 → 主角使命=获取资源 → 资本主义/殖民
```

## 五、世界观展现技巧

### 5.1 分层展示原则

```
第1章：只展示主角生活相关的1-2个设定（信息量最小化）
第5-10章：随主角行动逐步引入新区域/新规则
重要章节：设定配合剧情高潮（揭示=爆点催化剂）
大后期：揭示世界终极秘密（铺垫越久越震撼）
```

### 5.2 展示 vs 陈述

```
❌ 陈述："这个宗门是天下第一大宗，历史三万年，弟子十万。"
✅ 展示："踏入宗门的那一刻，他感受到了铺面而来的灵气压力——
   三万年的积累，让这里的每一寸土地都浸透了强者的气息。
   宗门深处，一道若有若无的神识扫过，他双腿一软，几乎跪下。"
→ 让读者自己感受，比直接告诉更震撼
```

### 5.3 世界观服务于剧情三原则

```
原则一【设定即冲突】设定要制造冲突不是装饰
  例：灵气匮乏之地 → 争夺灵脉 → 势力冲突

原则二【规则即困境】规则要限制主角不是让主角随意发挥
  例：不能杀人夺宝（天道不允许）→ 必须另想办法

原则三【秘密即悬念】留有未揭示的世界秘密，每个揭示=一个小高潮
```

## 六、世界观的差异化设计

### 6.1 差异化四步法

```
第一步：找到原型 → 参考一个已有的世界观体系
第二步：找到独特切入点 → 和别人的区别在哪？
第三步：设计独特规则 → 这个世界有什么独特规则？
第四步：规则衍生社会 → 独特规则 → 独特社会结构
```

**示例：** 灵气不是均匀分布而是随时间流动 → 灵气潮汐 → 随之迁徙的宗门 → 流动的国家

### 6.2 世界观缺陷设计法

```
类型一【历史遗憾】过去的错误决策留下创伤（传承断代）
类型二【系统性不公】世界规则本身存在不公（只有贵族能修炼）
类型三【隐藏真相】世界真相与表面不符（正道领袖是幕后黑手）
类型四【即将崩溃】世界面临即将到来的危机（大劫将至）
```

## 七、世界观bug自检清单

### 地理/物理层
□ 世界最高战力有明确描述？（不能是"最强"这种模糊词）
□ 资源总量是有限/稀缺的？（无限资源=无冲突）
□ 地理隔离是否造成文化差异？
□ 距离和时间是否合理？（不能瞬移随意穿越）
□ 信息传递有速度限制？

### 社会/政治层
□ 顶级强者数量合理？（不能满天飞也不能没存在感）
□ 势力分布与资源分布一致？
□ 弱势群体如何生存？
□ 势力之间有制衡关系？

### 信仰/哲学层
□ 这个世界的"正确"和"错误"标准是什么？
□ 有没有被这个世界认为"不可为"的事？（禁忌）
□ 世界的终极问题是什么？

### 逻辑一致性
□ 所有设定之间没有矛盾？
□ 前文伏笔在世界规则下能自洽？
□ 主角利用设定获得优势时，别人为什么不能复制？
□ 地理/历史/社会三者之间有内在逻辑联系？

## 八、创作前世界观构建流程

```
第一步：回答三个核心问题（30分钟）
  → 这个世界的核心魅力是什么？
  → 主角在这个世界里想追求什么？
  → 这个世界的核心冲突是什么？

第二步：构建三层框架（2小时）
  → 底层：地理+物理规则
  → 中层：社会+政治规则
  → 顶层：信仰+哲学规则

第三步：填充关键设定（2小时）
  → 至少3个势力 / 至少1个禁忌区域
  → 至少1个历史遗留问题 / 至少1个隐藏秘密

第四步：设定服务于剧情（1小时）
  → 每个设定是否能制造冲突？
  → 每个势力是否与主角有关联？

第五步：写"世界观大纲"（1小时）
  → 500字描述整个世界
  → 让别人读后能说"这是个什么样的世界"
```
