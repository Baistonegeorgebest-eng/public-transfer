# 世界观与主角互动设计

## 主角在世界中的位置

主角与世界的关系决定故事类型。

### 关系类型一【挑战者】
```
→ 主角不满现有秩序，试图改变世界
→ 例：陈踏凌驾于天道之外
→ 核心冲突：主角 vs 世界规则
```

### 关系类型二【适应者】
```
→ 主角在现有世界中寻求立足之地
→ 例：韩立的稳健修仙路
→ 核心冲突：主角 vs 更高位者
```

### 关系类型三【见证者】
```
→ 主角被动卷入世界大事
→ 例：普通人见证王朝兴衰
→ 核心冲突：世界 vs 主角（主角只是棋子）
```

### 关系类型四【守护者】
```
→ 主角有责任保护某物/某人/某秩序
→ 例：守护人类免受外敌入侵
→ 核心冲突：守护 vs 破坏力量
```

## 世界观缺陷与主角使命

每个好故事都有一个与世界缺陷对应的主角使命。

### 缺陷→使命对应表

```
缺陷一【系统性不公】→ 使命【打破不公】
  表现：揭露真相/推翻压迫/建立新秩序
  爽点：打脸既得利益者

缺陷二【即将到来的灾难】→ 使命【阻止灾难】
  表现：寻找解决方案/团结各方力量
  爽点：力挽狂澜，拯救世界

缺陷三【隐藏的历史真相】→ 使命【揭示真相】
  表现：调查/推理/冒险
  爽点：真相大白，反转震撼

缺陷四【失衡的世界规则】→ 使命【重建平衡】
  表现：修炼新体系/挑战旧规则
  爽点：以弱胜强，重塑秩序
```

## 信仰体系与角色弧线

### 信仰体系三层次
```
哲学基础：世界的根本规律
主流价值观：社会崇尚什么和禁忌什么
角色信仰变化：主角从相信什么 → 经历事件后相信什么
```

### 使用方法
```
→ 主角初始信仰 = 读者的默认认知
→ 故事中的事件挑战主角信仰 = 读者也被挑战
→ 主角信仰变化 → 读者认知升级
→ 这就是"角色弧线"的核心
```

## 世界观限制=爽点来源

```
核心公式：世界观限制主角 → 制造冲突 → 突破限制 → 爽点

例：
  限制：只有贵族能修炼
  冲突：主角是平民
  突破：主角发现了自己的特殊血脉
  爽点：以平民之身碾压贵族天才

→ 好的世界观允许阶层流动，流动性本身就是爽点
```
