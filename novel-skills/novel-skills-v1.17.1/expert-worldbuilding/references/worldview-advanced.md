# 世界观进阶技法

## 冰山理论（海明威）

```
展示给读者的 = 冰山一角（10%）
作者自己知道的 = 完整冰山（100%）

作用：
  读者能感受到世界观的"深度"，即使没有完全展示
  写作时不会"写空"，因为背后有完整的体系

实践：
  世界观文档应该比小说正文多3-5倍
  小说中直接展示的不超过世界观文档的20%
```

### 冰山三层分层

```
水面之上（读者直接看到，占15-20%）
  - 角色日常接触的世界规则
  - 当前剧情直接涉及的设定
  - 角色已经理解并能解释的信息
  → 展示方式：通过角色的行动自然呈现

水面之中（读者能推断，占30-40%）
  - 通过场景描写暗示的设定
  - 角色对话中侧面提及的信息
  - 环境细节中隐藏的逻辑
  → 展示方式：通过细节暗示，让细心读者自己发现

水面之下（读者不知道但作者必须知道，占40-50%）
  - 世界的完整历史和演化过程
  - 各势力的深层动机和秘密
  - 设定之间的底层逻辑关联
  → 作用：保证水面之上的一切都是自洽的
```

## 渐进揭示三阶法

```
第一阶段：体验期（第1-30章）
  目标：让读者"感受"世界，而非"理解"世界
  方法：通过角色行动展示，只展示主角目力所及的设定
  规则：新增术语 ≤ 10个

第二阶段：探索期（第31-100章）
  目标：读者开始主动"想了解"深层规则
  方法：通过导师/秘籍/奇遇揭示更深层设定
  规则：每章新增术语 ≤ 3个

第三阶段：掌控期（第100章以后）
  目标：读者期待看到世界规则的"极限"
  方法：揭示最高层/隐藏规则，角色开始"利用"甚至"改变"规则
  规则：可以引入颠覆性设定（但必须与已有设定兼容）
```

## 文化分层

### 三层文化架构
```
物质文化层（最外层，最容易变化）
  → 饮食、服饰、建筑、工具
  → 不同区域有明显差异
  → 例：东方饮茶论道，西方饮酒决斗

制度文化层（中间层，较稳定）
  → 社会结构、权力体系、婚姻制度、等级制度
  → 例：有的以武力论等级，有的以财力论等级

精神文化层（最深层，最稳定）
  → 信仰体系、价值观念、审美标准、禁忌
  → 这一层的冲突 = 最有戏剧张力的冲突
  → 例：一方信奉"弱肉强食"，另一方信奉"众生平等"
```

## 地理叙事

```
地理 → 经济 → 文化 → 性格

例：沿海城市 → 贸易发达 → 开放包容 → 居民见多识广、善于谈判
例：深山宗门 → 资源封闭 → 等级森严 → 弟子保守排外、尊师重道

→ 逻辑链：地理决定了经济模式，经济模式塑造了文化，文化影响了人的性格
```

## 世界观七要素（完整清单）

```
① 地理：大陆/海洋/山脉/气候/资源分布
② 政治：国家/势力/政权形式/外交关系
③ 经济：货币/贸易/产业/贫富差距
④ 文化：宗教/节日/艺术/社会风俗
⑤ 军事：军队编制/战争方式/武器水平
⑥ 科技/魔法：技术水平/魔法体系/禁忌领域
⑦ 历史：重大事件/战争/王朝更替/英雄传说
```

## 社会结构三层次

```
层次一：宏观（世界格局）→ 有几个大陆/国家/势力？关系如何？
层次二：中观（社会阶层）→ 贵族/平民/奴隶的分层
层次三：微观（日常生活）→ 普通人一天怎么过的？吃什么/住什么？

铁律：微观细节决定世界的"真实感"。
  读者不会被宏大设定打动，会被"普通人早餐吃什么"打动。
```

## 语言文字设定

```
→ 不同种族有不同的语言体系
→ 文字是文化传承的载体，有独特的设计风格
→ 翻译人才在跨种族交流中起到关键作用
→ 语言中的禁忌和礼仪是文化的重要组成部分
```

---

## 法律与秩序体系

```
→ 成文法典是社会秩序的基石
→ 执法者的权威来自制度也来自个人能力
→ 法律的漏洞是剧情推进的重要素材
→ 不同势力对法律有不同的解释权
```

---

## 2026年世界观创新趋势

```
→ 多维宇宙观成为主流，单一世界设定已不能满足读者期待
→ 科技与修炼的融合世界观开始兴起
→ 历史与架空世界的交织创造新的叙事空间
```
