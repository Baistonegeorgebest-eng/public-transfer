# 历史时间线构建

## 三层历史结构

```
├─ 远古时代（距今X万年）
│   └─ 世界的起源，神祇活跃，规则定型
├─ 上古时代（距今X千年）
│   └─ 文明兴起，大势力建立，历史被书写
└─ 近古时代（距今X百年）
    └─ 当前故事发生的时代背景
```

### 历史的作用
```
├─ 解释当前格局的成因
├─ 为秘境/宝物提供来历
├─ 为势力冲突提供历史根源
└─ 为伏笔提供时间跨度
```

### 展示节奏
```
→ 不要一次性讲完所有历史
→ 随剧情推进逐步揭示 = 持续的新鲜感
→ 例：第一章只知道"上古大战"，第50章才知道大战的真相
```

---

## 历史事件设计公式

每个重要历史事件必须有：

```
├─ 导火索：什么引发了这件事？
├─ 主要参与者：谁在这件事中扮演角色？
├─ 核心冲突：各方势力的利益诉求是什么？
├─ 结局：对当今世界造成了什么影响？
└─ 隐藏真相：官方叙事与真实情况是否一致？
```

### 设计示例【上古大战】
```
→ 导火索：两大圣地争夺起源之物
→ 参与者：正道联盟 vs 魔道宗门
→ 核心冲突：谁掌控修炼体系的源头
→ 结局：魔道被封印，正道元气大伤
→ 隐藏真相：正道领袖其实借刀杀人，消灭了潜在对手
→ 剧情作用：封印松动 → 魔道复出 → 新的大战
```

## 资源分布对势力的影响

```
→ 铁矿分布在北方 → 北方势力擅长锻造和战争
→ 肥沃平原在中部 → 中部势力擅长农业和人口
→ 贸易港口在南方 → 南方势力擅长商业和海运
→ 资源是势力争夺的核心
```

---

## 气候对战争形态的影响

```
→ 草原民族擅长骑兵（草原平坦辽阔）
→ 农耕民族擅长步兵（需要防守城池）
→ 海岸地区擅长水军（有海洋资源）
→ 气候也影响修炼体系（热带火属性多，寒带水属性多）
```
