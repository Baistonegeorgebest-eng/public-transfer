# 势力体系深度设计

## 势力关系动态图谱

### 核心原则
势力关系不是静态的，必须随剧情发展而变化。

### 势力关系三角模型
```
         【主角势力】
        ↗       ↖
  【势力A】  ←→  【势力B】
       ↖       ↗
        【势力C】
```

### 关系类型
```
├─ 敌对关系：直接冲突 → 制造高潮
├─ 竞争关系：资源争夺 → 制造张力
├─ 合作关系：共同敌人 → 临时联盟
├─ 依附关系：强弱分明 → 社会结构
└─ 隐藏关系：表面和平 → 制造反转
```

### 设计技巧
```
→ 每个势力必须有独立利益诉求
→ 势力之间有利益交叉点 = 冲突爆发点
→ 主角周旋于多个势力之间 = 权谋剧情
```

## 势力分布设计

### 核心规范
```
→ 核心势力≤3个，利益关系要清晰
→ 附庸势力若干
→ 每个势力有独特文化和价值观
→ 势力之间的冲突是故事的重要推动力
→ 势力首领要有鲜明的性格和目标（不能只是"强大的存在"）
```

## 势力内部结构设计

### 三层结构
```
最高层：领袖/宗主/皇帝
  └─ 决策层：核心长老会/内阁
中间层：精英成员/中层管理
  └─ 承上启下：政策的执行者
底层：普通成员/信徒/民众
  └─ 被统治层：数量最多，声音最少
```

### 内部矛盾
```
├─ 派系斗争：继承人之争/路线之争
├─ 新旧冲突：改革派 vs 保守派
├─ 利益分配：谁拿大头，谁喝汤
└─ 忠诚考验：关键时刻谁会背叛？

→ 大势力的内部矛盾 = 主角可利用的突破口
→ 例：大宗门内斗 = 主角浑水摸鱼的机会
```

---

## 势力兴衰周期律

```
崛起期：英雄出世 → 建立秩序 → 吸引追随者
鼎盛期：最强实力 → 制定规则 → 扩张领土
僵化期：利益固化 → 创新停滞 → 内部腐败
衰落期：外敌入侵/内部分裂 → 领土收缩
崩溃期：彻底瓦解 → 新的势力崛起
```

### 使用技巧
```
→ 把势力放在不同生命周期 = 增加世界动态感
→ 例：三大势力，一个鼎盛期，一个衰落期，一个崛起期
→ 这就是天然的矛盾来源

→ 没有永恒强大的势力（除非有特殊规则保护）
→ 没有永恒弱小的势力（主角可以从底层崛起）
```
