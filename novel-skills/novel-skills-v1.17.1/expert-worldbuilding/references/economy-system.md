# 经济体系设计

## 世界经济基础三要素

```
要素一【核心资源】
  → 这个世界的核心资源是什么？
  → 例：灵气晶石/魔兽晶核/魔法矿石/能源
  → 核心资源 = 争夺的焦点

要素二【流通体系】
  → 资源如何从产出地到使用者手中？
  → 例：宗门垄断/商会自由贸易/国家统购统销
  → 流通体系决定商业剧情

要素三【价值标准】
  → 用什么来衡量价值？
  → 例：灵石/金币/贡献点/功勋值
  → 价值标准影响社会结构
```

## 修仙/魔法世界经济体系

### 标准配置
```
├─ 灵石体系：下品/中品/上品/极品灵石
├─ 兑换比例：1:10:100:1000
├─ 日常消费：吃饭/住宿/武器/丹药
```

### 特殊经济机制
```
├─ 以物易物：高阶物品无法用灵石定价
├─ 拍卖行：稀有物品竞价机制
├─ 黑市：灰色交易，规则之外
├─ 悬赏任务：情报/猎杀/护送
```

### 经济设定与剧情联动
```
├─ 经济崩溃 → 社会动荡 → 战争爆发
├─ 资源垄断 → 强者更强 → 阶级固化
├─ 通货膨胀 → 民生疾苦 → 革命萌芽
```

## 货币体系设计

```
→ 通用货币减少交易成本但也存在汇率问题
→ 奢侈品和必需品的价格体系不同
→ 走私贸易是边境地区的重要经济形式
→ 货币发行权是政治权力的象征
```
