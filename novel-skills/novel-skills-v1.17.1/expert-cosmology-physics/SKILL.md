# 世界观科学锚点专家
> 读者能接受"唯心"（战锤40K用Warp解释一切），但不能接受"没有规则"。
> 没有规则 = 编剧可以随便改 = 没有张力 = "气体人在气体大陆打架"。

## 〇、本Expert的定位

```
【做什么】
→ 为虚构世界建立"底层物理规则"，让世界观有锚点
→ 不负责剧情/角色/文笔，只负责"这个世界能不能站住脚"
→ 在步骤①②③（世界观构建阶段）加载，不参与每章写作

【不做什么】
→ 不写小说正文
→ 不设计具体角色
→ 不决定剧情走向

【核心价值】
→ 防止"气体大陆"类世界观硬伤
→ 让战力体系有物理锚点（不是"我说强就强"）
→ 让地理环境有真实感（沙漠/海洋不会凭空出现）
→ 让力量体系有代价约束（能量守恒，不能无限膨胀）
```

## 一、物理约束层（防止战力崩坏）

### 1.1 能量守恒检查

任何力量体系必须回答以下问题，否则读者会发现漏洞：

```
□ 能量从哪来？
  → 灵气/魔力/斗气的来源是什么？
  → 是宇宙背景辐射？还是星球核心散发？
  → 还是生命体自身产生？
  ⚠️ 如果来源是"无限的"，战力膨胀不可避免

□ 能量到哪去？
  → 使用技能后能量去哪了？
  → 是消耗掉（热能散发）？还是转移了？
  → 还是凭空消失？
  ⚠️ 如果能量用完就消失，物理系读者会不买账

□ 能量转换效率？
  → 吸收100单位灵气，能释放多少战斗力？
  → 损耗去哪了？（热量？声波？光？）
  → 高境界转换效率更高？（合理，是升级的动力之一）

□ 能量存储上限？
  → 人体/丹田/灵魂能存储多少？
  → 为什么有人存储上限高有人低？
  → 升级=扩大存储+提高转换效率？（双轨制比单轨制合理）
```

**气功示例验证：**
```
气血之力来源 = 前世"叛道"遗留的生命本源（有限，有消耗）
转换方式 = 通过功法修炼激活，消耗后需要恢复期
存储方式 = 身体细胞层面（非丹田），解释了治愈能力
克制原理 = 本质是"起源之力"，对"被赐予"的力量有天然压制
→ 有来源、有代价、有上限、有克制逻辑 ✅
```

### 1.2 作用力与反作用力

```
□ 使用力量的代价是什么？
  → 施放强力攻击后自身会受伤/消耗？
  → 越级战斗的代价是什么？（不只是"打不赢"）
  → 无限使用能力的后果是什么？
  ⚠️ 没有代价的力量 = 无张力

□ 力量对环境的影响
  → 圣域级战斗能毁一座城？
  → 如果能，城市为什么还能存在？
  → 战斗频繁的区域环境应该是什么样？
  ⚠️ "世界大战1000年但城市完好"= 气体人

□ 重量/速度/距离的物理锚点
  → 一个黄金级战士能跳多高？
  → 一个圣域级法师的法术射程是多少？
  → 主角奔跑速度是多少？
  ⚠️ 不需要精确数字，但需要相对一致（不能一会跳10米一会跳100米）
```

### 1.3 热力学/熵增检查

```
□ 如果存在"永动机"式能力，如何解释？
  → 完全禁止？还是用特殊规则绕过？
  → 如："血脉觉醒后身体与天地灵气形成循环"= 合理
  → 如："主角就是无限能量"= 不合理（除非是最终形态/有极高代价）

□ 大规模破坏后的环境恢复
  → 城市被毁后多久重建？
  → 生态系统如何恢复？
  → 有没有"修复系"能力/职业存在？
  ⚠️ 战斗毁天灭地但下一章城市完好 = 严重bug
```

## 二、地理锚点层（防止环境硬伤）

### 2.1 地理逻辑检查

```
□ 地形的成因
  → 山脉 = 板块碰撞？还是魔法造物？
  → 沙漠 = 气候带决定？还是被诅咒？
  → 如果有魔法造物，谁造的？为什么？代价是什么？
  ⚠️ "沙漠旁边是雪山旁边是热带雨林"= 地理bug（除非有魔法解释）

□ 气候带的一致性
  → 同一纬度的气候应该相似（除非有特殊原因）
  → 大陆形状决定了洋流 → 决定了气候
  → 简单方法：画一张大陆草图，标注主要气候带
  ⚠️ 不需要地球级精度，但需要内部一致性

□ 资源分布与势力分布的因果链
  → 灵气充裕 = 宗门/势力聚集 = 冲突热点
  → 矿脉分布 = 经济中心 = 贸易路线
  → 水源分布 = 人口聚集 = 城市位置
  → 势力为什么会在这里？地理应该给出答案

□ 距离与旅行时间
  → 从A城到B城需要多久？
  → 不同交通方式（步行/骑马/飞行/传送）的时间差？
  ⚠️ "昨天还在北方今天就在南方"= 距离bug
```

### 2.2 气功地理锚点示例

```
大陆设定：
→ 红龙领（北方寒冷山区）→ 莱昂·红龙的领地，适合龙族栖息
→ 商业联盟（中南部平原）→ 经济中心，资源集散
→ 教会总部（西方圣山）→ 灵气充裕区，神术修炼地
→ 精灵森林（东北密林）→ 元素能量充沛，精灵族栖息

地理逻辑检查：
□ 北方寒冷+山区 → 龙族选择此地的原因？
  → 冷血动物需要温暖，但"龙"可以设定为不惧寒冷
  → 山区人烟稀少 = 不被干扰 = 合理 ✅
□ 精灵森林在东北 → 气候带？
  → 如果是温带大陆 → 东北可以是寒温带针叶林 → 合理 ✅
  → 如果是魔法维持的森林 → 需要说明能量来源 ⚠️
□ 商业联盟在平原 → 经济逻辑？
  → 平原适合农业+贸易 → 合理 ✅
  → 但需要说明为什么教会没有控制这里 → 需要在设定中解释
```

## 三、天文与维度层（世界观底层规则）

### 3.1 世界基础架构

```
□ 这个世界是什么形状？
  → 平面大陆？星球？浮空群岛？
  → 有没有"边缘"或"尽头"？
  → 边缘之外是什么？

□ 日月星辰是真实的还是魔法造物？
  → 如果是真实的天体 → 引力/潮汐/季节变化
  → 如果是魔法造物 → 谁造的？目的？
  → 读者对"假太阳"很敏感，需要有合理解释

□ 是否存在多维空间/位面？
  → 如果有，维度之间的物理规则是否一致？
  → 位面之间如何通行？
  → 不同位面的时间流速是否一致？
  ⚠️ "深渊是另一个宇宙"→ 需要解释两个宇宙的物理规则差异
```

### 3.2 气功维度锚点

```
世界架构 → 单大陆+隐藏位面（裂缝/深渊）
→ 大陆 = 已知世界，物理规则与现实相似
→ 裂缝 = "本体"的背面，非宇宙另一边，而是地表之下的深层空间
→ 深渊 = 恶魔栖息的维度，与主世界有物理屏障

物理规则一致性：
□ 裂缝中的物理规则是否与大陆一致？
  → 如果不同，需要说明差异和原因
  → 建议：裂缝中"灵气密度"更高但"物理规则"基本一致
  → 差异在于能量浓度，不在物理定律 → 合理 ✅
□ 主神级力量能"覆盖整个大陆"→ 这个大陆多大？
  → 需要定义大陆的尺度（面积/人口）
  → 覆盖"整个大陆"意味着能量投射距离需要合理
  → 如果大陆 = 欧洲大小，主神级 = 核武级能量 → 合理
  → 如果大陆 = 地球大小，主神级 = 行星级能量 → 需要更详细解释
```

## 四、生物生态层（物种合理性）

### 4.1 物种设定检查

```
□ 食物链完整性
  → 龙吃什么？食物链顶端生物需要足够的猎物
  → 魔兽的食物来源是什么？
  → 人类社会的农业/畜牧业如何运转？
  ⚠️ "森林里有100种魔兽但没有猎物"= 生态bug

□ 物种的繁殖与存续
  → 龙族为什么快灭绝了？（繁殖率低？寿命长但生育难？）
  → 精灵为什么人少？（寿命长=生育率低？）
  → 恶魔如何繁殖？（如果无限繁殖，为什么不淹没世界？）
  → 人类为什么最多？（繁殖快+适应力强 → 合理）

□ 物种的生态位
  → 每个物种在生态系统中的角色是什么？
  → 精灵 = 森林守护者？元素亲和者？
  → 龙 = 食物链顶端/领地型/独居？
  → 魔兽 = 外来入侵物种？还是本土生态的一部分？

□ 特殊物种的合理性
  → 不死族的能量来源？（违反热力学？需要解释）
  → 变形兽的物质来源？（改变体型需要大量物质）
  → 元素生物的组成？（纯能量体？还是有物质基础？）
```

### 4.2 气功生态锚点

```
物种体系：
→ 人类（主流，繁殖快，适应力强）
→ 龙族（稀有，强大，繁殖率极低，领地型）→ 解释了为什么龙族不统治世界
→ 精灵（半元素生物，寿命长，与自然共生）→ 解释了为什么精灵不扩张
→ 恶魔（深渊位面，非本土物种）→ 解释了为什么要入侵而不是原生共存
→ 魔兽（灵气变异的本土动物）→ 解释了魔兽的来源和食物链位置

检查：
□ 龙族不统治世界的原因？
  → 繁殖率极低 + 个体强大但数量少 → 合理 ✅
  → 但如果红龙大公是圣域级，为什么不直接征服？
  → 需要：龙族性格/文化/约束（如"不屑于统治蝼蚁"）✅
□ 恶魔为什么不直接淹没世界？
  → 深渊位面有物理屏障 → 需要"裂缝"才能通过 → 合理 ✅
  → 裂缝有限 = 入侵通道有限 = 入侵是间歇性的 → 合理 ✅
```

## 五、化学与炼金层（材料/丹药规则）

### 5.1 能量物质化检查

```
□ 修炼用的"丹药/灵石/魔晶"是什么？
  → 是能量的固态存储形式？
  → 还是化学反应的催化剂？
  → 还是纯粹的魔法造物？
  ⚠️ "吃一颗丹药升一级"= 需要解释丹药的能量从哪来

□ 炼金/炼丹的物理基础
  → 炼金是化学反应还是魔法操作？
  → 如果是化学反应 → 遵守物质守恒
  → 如果是魔法操作 → 需要能量来源
  → 最佳方案：两者结合（物理反应+能量催化）

□ 材料的稀缺性逻辑
  → 为什么某种材料稀缺？
  → 地理分布？采集难度？加工复杂度？
  → 稀缺材料的价值 = 收集难度 × 效果强度
  ⚠️ "传说级材料满地都是但大家都当垃圾"= 逻辑bug
```

### 5.2 气功炼金锚点

```
→ 气功世界的丹药体系以"草药+气血引导"为核心
→ 不是纯魔法炼金，而是"用气血之力催化草药的天然成分"
→ 能量守恒：草药中的活性成分 + 气血催化 = 丹药效果
→ 这个设定合理，且与"气血之力是生命本源"的设定一致 ✅

需要检查：
□ 丹药效果的能量来源？
  → 草药本身的天然成分（有限）
  → 气血之力催化（消耗主角的能量）
  → 不能"凭空产生效果" ✅
□ 高级丹药为什么稀缺？
  → 需要高境界的气血引导（低境界炼不出高级丹）
  → 稀有草药 + 高境界 = 自然稀缺 → 合理 ✅
```

## 六、世界物理审计（World Physics Audit）

> 当你审查一个世界观时，用以下检查表逐项验证。每项通过打✅，不通过打❌并写明问题。

### 6.1 审计检查表

```
【能量系统】
□ 能量来源明确且有限/有代价
□ 能量转换有损耗（非100%效率）
□ 能量存储有上限
□ 大规模战斗对环境有可追踪的影响
□ 力量使用有代价（不只是"用完就没了"）

【地理系统】
□ 大陆有草图或明确描述
□ 气候带内部一致
□ 资源分布与势力分布有因果关系
□ 距离与旅行时间合理

【生物系统】
□ 主要物种有食物链位置
□ 物种繁殖率与种群数量匹配
□ 物种有合理的生态位
□ 外来物种（如恶魔）有入侵逻辑

【化学/炼金系统】
□ 丹药/材料效果有能量来源解释
□ 炼金过程遵守物质/能量守恒
□ 材料稀缺性有合理成因

【物理一致性】
□ 境界提升有物理锚点（不只是"实力变强了"）
□ 越级战斗有合理解释
□ 力量克制关系有物理/能量层面的解释
□ 时间线与角色移动距离匹配
```

### 6.2 常见"气体人"类bug速查

| Bug类型 | 典型表现 | 修复方向 |
|---------|---------|---------|
| 无限能量 | "主角永远不累" | 加入能量恢复机制/使用代价 |
| 环境失忆 | 大战毁天灭地，下章城市完好 | 追踪破坏→重建时间线 |
| 距离失真 | "昨天在北方今天在南方" | 建立距离-时间换算表 |
| 生态真空 | "森林有魔兽但没有食物" | 补充食物链/生态系统 |
| 能力通胀 | "前期最强技能后期是杂兵技能" | 建立绝对战力锚点 |
| 克制随意 | "这次克制下次不克制" | 锁定克制关系表 |
| 繁殖悖论 | "强大种族无限繁殖但不统治世界" | 限制繁殖率/加文化约束 |
| 炼金万能 | "丹药能解决一切问题" | 限制丹药效果/加副作用 |

## 八、气功项目专项检查清单

> 以下为气功砍穿神魔项目的世界物理审计，可作为其他项目的模板。

### 8.1 气功能量系统审计

```
✅ 气血之力 = 前世"叛道"遗留的生命本源（来源明确·有限）
✅ 转换方式 = 功法修炼激活（有消耗·需要恢复）
✅ 存储方式 = 身体细胞层面（非丹田·解释了治愈能力）
✅ 克制原理 = "起源之力"对"被赐予"力量的天然压制（有能量层面解释）
✅ 气血神域 = 域内"被赐予"的力量全部失效（有物理规则支撑）

⚠️ 待确认：
□ 气血之力使用后的"恢复期"具体多久？
  → 如果没有明确时间，可能会出现"打完立刻又满血"的问题
  → 建议：随境界提升恢复速度加快，但有明确的上限
□ 气血之力消耗后是"消失"还是"回归天地"？
  → 建议：部分回归天地（能量循环），部分消耗不可逆（衰老/寿命）
  → 这样解释了为什么主角不无限使用
```

### 8.2 气功地理审计

```
✅ 红龙领（北方山区）→ 龙族栖息·人烟稀少 → 合理
✅ 商业联盟（中南部平原）→ 经济中心 → 合理
✅ 教会总部（西方圣山）→ 灵气充裕 → 合理
✅ 精灵森林（东北密林）→ 元素能量充沛 → 合理

⚠️ 待确认：
□ 大陆整体尺度？
```
