# 悬疑推理 · 平台适配指南

> 配合 [SKILL.md](../SKILL.md) 使用

---

## 一、番茄小说

| 维度 | 要求 |
|------|------|
| **字数** | 长篇连载为主，单章 1500-2500字，总字数 50万+ 为佳 |
| **节奏** | 前3章必须有爆点；每 3-5 章一个小高潮；每 20-30 章一个大高潮 |
| **类型偏好** | 规则怪谈、系统悬疑、无限流、都市灵异 |
| **读者画像** | 18-35岁男性为主，追求"爽感+烧脑"的结合 |
| **标题技巧** | 悬念式标题："我被困在规则怪谈里，发现所有规则都是假的" |
| **付费点设计** | 免费部分到第一个大悬念揭晓前 1-2 章处切断 |
| **注意** | 番茄用户对"注水"极其敏感——每一章必须有信息增量 |

**番茄悬疑公式**：
```
开篇即高能（怪谈/系统/危机） → 快速建立规则 → 初步胜利（建立爽感）
→ 遭遇更强挑战 → 推理+升级并行 → 阶段性大揭秘 → 进入下一个副本
```

## 二、起点中文网

| 维度 | 要求 |
|------|------|
| **字数** | 超长篇连载，总字数 100万+；单章 2000-3000字 |
| **节奏** | 可以慢热但不能太慢——前 30 章必须有明确的"追读动力" |
| **类型偏好** | 本格推理、刑侦推理、科幻悬疑、历史推理 |
| **读者画像** | 核心男性读者群，对逻辑自洽和世界观深度要求高 |
| **互动模式** | 本章说文化——读者逐段评论；伏笔/诡计会被实时讨论 |
| **付费设计** | 公众版 30-50 章后上架VIP；VIP章节密度要有保障 |
| **注意** | 起点读者对"诡计公平性"极其在意——不合理的诡计会被本章说拆穿 |

**起点悬疑公式**：
```
完整的世界观铺垫（3-5章） → 核心谜题建立 → 慢热型调查过程（穿插日常/支线）
→ 阶段性推理高潮 → 真相揭示 → 开启更大的谜题（如果写系列）
```

## 三、知乎盐选

| 维度 | 要求 |
|------|------|
| **字数** | 中短篇为主，1万-5万字最佳；单篇 3000-8000字 |
| **节奏** | 开头 300 字决定生死；全程高密度信息，无冗余 |
| **类型偏好** | 叙述性诡计、反转悬疑、社会推理、都市心理悬疑 |
| **读者画像** | 25-40岁，高学历，追求"看完讨论三天"的深度体验 |
| **叙事风格** | 第一人称为主，"知乎体"叙事（像在讲一个真实经历） |
| **付费设计** | 会员免费阅读；靠"盐选推荐"流量——质量>数量 |
| **注意** | 知乎读者对"合理性"和"文字质量"要求最高——文笔不能拉胯 |

**知乎悬疑公式**：
```
"我来说一个真实经历"式开头 → 快速进入核心异常 → 信息密度极高（每段都有新线索）
→ 第一次反转 → 第二次反转（颠覆第一次反转的解读） → 留白式结局
```

## 四、跨平台通用原则

1. **前三章是生死线**——所有平台的留存率都由前三章决定
2. **每章结尾必须有钩子**——程度不同，但"想看下一章"是最低要求
3. **悬念不能拖太久**——超过 10 章不给任何线索释放，读者会流失
4. **角色比诡计重要**——读者追的是"人"不是"谜"，角色立不住，诡计再精妙也没用
