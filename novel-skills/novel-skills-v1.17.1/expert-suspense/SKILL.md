## 一、本格推理三要素

本格推理（Honkaku）的核心是"公平游戏"——作者向读者提供所有必要线索，挑战读者与侦探一同解谜。

### 1.1 三要素详解

| 要素 | 定义 | 写作要点 |
|------|------|----------|
| **谜题（Puzzle）** | 一个或多个看似不可能的事件 | 谜面必须清晰、惊人、逻辑自洽；读者在揭晓前应能独立推理 |
| **线索（Clue）** | 解谜所需的全部信息 | 明线（显性描写）与暗线（隐性埋伏）比例建议 4:6；关键线索不能藏在读者无法获取的视角中 |
| **解答（Solution）** | 合乎逻辑且令人信服的真相 | 解答必须"意外但合理"——读者恍然大悟后应觉得"早该想到" |

### 1.2 公平推理十诫（ Knox's Commandments 精选 + 本土化改良）

1. 凶手必须在故事前半段登场
2. 超自然解释不可用于核心诡计（除非是奇幻推理子类型）
3. 不可使用未在文中出现的秘密通道/房间
4. 不可依赖"偶然"或"巧合"作为关键推理环节
5. 侦探不能是凶手
6. 读者必须与侦探拥有同等信息量
7. 笨蛋搭档不能靠无意中的暗示直接点破真相
8. 动机必须在人性范围内可理解
9. "双重解答"需在情感上也有呼应（不能纯粹为反转而反转）
10. 真相揭示后，回读全文应产生"二次阅读乐趣"

## 二、五种经典诡计

### 2.1 密室诡计（Locked Room）

**核心问题**：如何在一个从内部锁死的房间里完成谋杀，且凶手消失？

| 子类型 | 原理 | 经典案例 | 现代变体 |
|--------|------|----------|----------|
| 假密室 | 门其实没锁/有人从外锁上 | 《三口棺材》 | 智能门锁篡改、远程操控 |
| 机械陷阱 | 延时装置、冰块融化、绳索机关 | 《犹大之窗》 | 程序定时触发、IoT设备操控 |
| 视觉欺骗 | 房间结构异常、镜子/投影 | 《黄色房间的秘密》 | VR/AR环境伪造 |
| 时间差 | 死亡时间被误导，凶手在"不可能时间"前作案 | 《Y的悲剧》 | 药物改变尸温、监控时间戳篡改 |
| 心理密室 | 受害者其实活着走出去/凶手伪装成受害者 | 《螺旋馆事件》 | 换脸技术、身份伪造 |

**写作模板**：建立不可能→展示封闭性→侦探勘查→误导线索→突破发现→逻辑还原→密室解体
- 密室的"不可能感"要花 2-3 章充分渲染
- 至少设置 2 条以上的红色鲱鱼（误导线索）
- 解答不能依赖"读者不知道的专业知识"——要么在前文铺垫，要么属于常识

### 2.2 不在场证明诡计（Alibi）

**核心问题**：凶手如何在有铁证的情况下，同时出现在两个地点？

**七种经典手法**：

1. **时间伪造**：篡改时钟/手表/监控时间戳
2. **身份替换**：找人伪装成自己出现在公共场合
3. **提前/延后作案**：实际死亡时间与表象不符
4. **远程操控**：利用机关、动物、定时装置远程杀人
5. **交通工具诡计**：飞机/列车时刻表的利用（暴风雪山庄模式）
6. **证人共谋**：所有目击者串通或被统一误导
7. **"在场"本身是诡计**：凶手从未离开，但通过某种方式制造了"离开"的证据

**节奏模板**：完美证明→发现裂缝→证明崩塌→更深层真相浮现

### 2.3 身份替换诡计（Identity Swap）

**核心问题**：谁才是真正的受害者/凶手/关键人物？

**应用模式**：

- **凶手替换**：读者以为的受害者其实是凶手，真正的受害者另有其人
- **侦探替换**：侦探本身就是案件核心人物（需极高技巧，否则引起反感）
- **双重身份**：关键角色拥有两个互相矛盾的身份
- **群体替换**：暴风雪山庄模式中，有一个人从一开始就不属于这个群体

**设计红线**：
- 不能用"从未提及的双胞胎"来解释（除非双胞胎是核心悬念的前半段就埋下的线索）
- 身份替换的动机必须充分——为什么这个人要冒充？代价是什么？

### 2.4 叙述性诡计（Narrative Trick / Unreliable Narrator）

**核心问题**：作者如何利用叙事本身来误导读者？

**八种技法**：

| 技法 | 原理 | 示例 |
|------|------|------|
| **性别误导** | 全文不提叙述者性别，利用刻板印象引导 | 叙述者是护士→读者默认女性→实为男性 |
| **时间误导** | 叙述的时间线被打乱/压缩/延伸 | "那天晚上"实际是三年前的那天晚上 |
| **人称切换** | 第一人称"我"实际是不同的人 | 不同章节的"我"是不同角色 |
| **空间误导** | 描述的地点不是读者以为的地方 | "学校"实际是一所监狱的代称 |
| **身份误导** | 叙述者就是凶手/受害者但读者不知 | 叙述者从未承认自己做了某事 |
| **感知误导** | 叙述者感官异常但未明说 | 叙述者是色盲/失聪/有精神疾病 |
| **称谓误导** | 使用昵称/代号让读者误判人物关系 | "爸爸"实际是孩子的养父/绑匪 |
| **省略误导** | 关键信息被刻意省略而非说谎 | 从不提叙述者的左手——因为没有左手 |

**伦理准则**：
- 叙述性诡计的本质是"读者用自己的偏见填补空白"——作者没有说谎，只是没有纠正
- 揭晓后读者应该产生"啊，所有线索都对得上"的感受，而非"作者骗了我"的愤怒
- **绝对禁止**：让叙述者直接说谎（"我没杀他"→其实杀了）——这是欺骗而非诡计

### 2.5 动机隐藏诡计（Hidden Motive）

**核心问题**：真正的杀人动机被完美伪装，即使找到凶手也猜不到为什么。

**动机层次模型**：

```
表层动机（读者/侦探初步推理）
  ↓ 被推翻
中层动机（看起来合理但仍有疑点）
  ↓ 被推翻
深层动机（触及人性幽暗面的真实原因）
```

**经典动机隐藏手法**：①伪装成激情犯罪 ②嫁祸式动机 ③连锁式动机（杀A掩盖杀B） ④保护式动机 ⑤时间差动机（动机已消失但凶手不知） ⑥集体动机（《东方快车》模式）

## 三、悬疑惊悚恐惧递进五层次

悬疑惊悚的核心不是"突然吓人"（那是恐怖小说），而是"持续升级的不安感"。

### 3.1 恐惧递进模型

```
L1 日常裂缝 → L2 异常确认 → L3 威胁逼近 → L4 无处可逃 → L5 超越恐惧
```

| 层次 | 名称 | 情绪 | 读者体验 | 章节占比建议 |
|------|------|------|----------|-------------|
| L1 | 日常裂缝 | 不安、疑惑 | "好像哪里不对" | 15-20% |
| L2 | 异常确认 | 恐惧萌芽 | "真的出问题了" | 20-25% |
| L3 | 威胁逼近 | 紧张、焦虑 | "危险正在靠近" | 25-30% |
| L4 | 无处可逃 | 绝望、窒息 | "所有退路都被切断" | 20-25% |
| L5 | 超越恐惧 | 震撼/释然/更深的恐惧 | "原来真相比想象更可怕" | 10-15% |

### 3.2 各层次写作技法

**L1 日常裂缝**
- 在完全正常的场景中植入一个"不和谐音"
- 不解释、不强调——让读者自己感受到"不对劲"
- 示例：每天准时回家的父亲，连续三天晚归，身上有陌生的香水味
- 技巧：裂缝必须足够小，以至于读者可能觉得自己多心了

**L2 异常确认**
- 角色试图合理化L1的裂缝，但发现解释不通
- 第二个、第三个裂缝出现，模式开始浮现
- 角色开始主动调查（或被迫面对）
- 技巧：确认过程要"半推半就"——角色不想相信，但证据在增加

**L3 威胁逼近**
- 威胁从抽象变为具体——有明确的目标指向主角
- 时间压力出现（deadline、倒计时、某个人的危险状态）
- 可以使用"平行剪辑"：威胁方的行动与主角的行动交叉推进
- 技巧：每章结尾设置一个"微型cliffhanger"，不一定是大悬念，但要让读者想翻页

**L4 无处可逃**
- 所有"安全选项"逐一被消灭
- 盟友变得可疑/背叛/死亡
- 主角被迫做出不可逆的选择
- 技巧：这一层的节奏可以适当放慢——让绝望感充分发酵比持续高强度更有效

**L5 超越恐惧**
- 真相揭示——但真相本身带来新的恐惧维度
- 三种结局取向：
  - **震撼型**：真相颠覆一切认知（适合短篇/中篇）
  - **释然型**：解决了表面恐惧，但深层不安留有余韵（适合系列作品）
  - **更深恐惧型**：你以为的恐惧只是冰山一角（适合系列开篇）

### 3.3 悬疑节奏控制原则

- **弹簧原则**：紧张→短暂释放→更紧张→更短暂释放→爆发。每次释放的时间要递减。
- **信息阶梯**：每3-5章揭示一个关键信息，同时埋下2-3个新悬念。
- **视角控制**：悬疑场景使用受限视角（只看到主角看到的），揭示场景使用全知视角。
- **时间操控**：在最紧张的时刻切换到另一条时间线——延迟满足感制造更高成瘾性。

## 四、规则怪谈设计模板

规则怪谈（Rule Horror / SCP-style）是2020年后中文网文崛起的新赛道，核心在于"遵守规则才能活，但规则本身可能是陷阱"。

### 4.1 核心机制

- 角色被置于一个封闭的"规则空间"（副本/异空间/特殊场所）
- 该空间有若干条"规则"，角色必须遵守才能存活
- **关键设计：规则的真假比为 7:3**——70%是真的，30%是假的/矛盾的
- 角色需要通过试错/推理来分辨真假规则

### 4.2 规则设计模板

```yaml
场景名称: "午夜图书馆"
规则总数: 8-12条（推荐）
真假比: 7:3（例如：7真3假，或8真3假1半真半假）

规则结构:
  - 编号: Rule #1
    内容: "图书馆在午夜12点关门。关门后请勿发出声音。"
    状态: 真
    功能: 建立基本世界观和恐惧基调

  - 编号: Rule #2
    内容: "如果你看到穿红色衣服的图书管理员，请立即低头假装阅读。"
    状态: 真
    功能: 增加具体威胁和应对方式

  - 编号: Rule #3
    内容: "第三排书架的书可以随意翻阅。"
    状态: 假（第三排书架的书是诱饵，翻开会被标记）
    功能: 第一个陷阱——测试角色是否会轻信

  - 编号: Rule #4
    内容: "如果你听到有人叫你的名字，不要回应。"
    状态: 真
    功能: 经典恐怖元素的规则化

  - 编号: Rule #5
    内容: "管理员会帮助你找到出口。"
    状态: 半真半假（只有穿蓝色衣服的管理员可信）
    功能: 高级陷阱——结合Rule #2制造矛盾，迫使角色推理

  - 编号: Rule #6
    内容: "每小时钟声响起时，所有人必须闭眼30秒。"
    状态: 真
    功能: 引入时间节奏和群体协作需求
```

### 4.3 规则怪谈叙事框架

```
阶段一：进入规则空间
  - 角色获得规则列表（纸条/墙上/手机消息）
  - 初步阅读：规则看起来简单但令人不安

阶段二：初步试探
  - 角色小心翼翼遵守规则
  - 第一个违反规则的人出现——惩罚展示（建立恐惧）
  - 角色安全度过初期，建立"遵守规则=安全"的信念

阶段三：矛盾浮现
  - 规则之间出现矛盾（Rule A说做X，Rule B说不做X）
  - 角色被迫做出选择——选错的代价是看到的
  - 开始推理哪些规则是假的

阶段四：深层真相
  - 规则本身不是"保护"而是"控制"
  - 制定规则的存在有自己的目的
  - "遵守规则"和"打破规则"之外出现第三条路

阶段五：逃脱/代价
  - 角色找到离开的方式
  - 但离开有代价——可能是记忆/同伴/某项能力
  - 暗示规则空间的更大存在（为续集铺路）
```

### 4.4 规则怪谈设计原则

1. **规则必须具体可执行**：不能写"小心危险"——要写"不要在红色地毯上跑步"
2. **违反规则的后果必须即时可见**：延迟惩罚会降低恐惧感
3. **假规则不能太假**：要让角色有充分理由相信它
4. **规则之间的矛盾要有逻辑**：不能随机矛盾——矛盾本身就是线索
5. **保持规则总量可控**：超过15条规则会让读者和角色都混乱
6. **规则来源要可疑**：谁写的？为什么留下规则？这本身就是悬念

## 五、悬疑开篇五公式

好的悬疑小说必须在前三章（或前3000字）抓住读者。

### 公式一：尸体开篇（Cold Open）

```
结构：发现尸体 → 一个反常细节 → 切入主角日常 → 主角被迫介入
示例："死者手里攥着一张照片。照片上的人，已经死了三年。"
```

- **优势**：直接建立谜题，零门槛进入
- **适用**：刑侦推理、本格推理
- **注意**：避免"流水线式开尸"——尸体要有故事性

### 公式二：异常日常（Uncanny Normalcy）

```
结构：极度正常的场景 → 一个细微到几乎被忽略的异常 → 角色试图忽略 → 异常升级
示例："每天早上7:15，楼下邻居准时出门。连续十三年，风雨无阻。今天7:15，门没有开。"
```

- **优势**：制造"细思极恐"的阅读体验
- **适用**：心理悬疑、都市怪谈
- **注意**：异常细节必须足够小——太大会失去"不确定感"

### 公式三：死亡预告（Death Notice）

```
结构：角色收到自己/他人的死亡预告 → 试图阻止 → 发现预告的细节过于精确
示例："你将于72小时后死亡。死因：溺水。地点：你从未去过的城市。"
```

- **优势**：直接建立倒计时压力
- **适用**：惊悚悬疑、规则怪谈
- **注意**：预告必须有来源悬念——谁发出的？怎么知道的？

### 公式四：记忆碎片（Broken Memory）

```
结构：角色醒来/恢复意识 → 发现记忆有缺失 → 身边有无法解释的物品/伤痕 → 被告知一个与自己认知矛盾的"事实"
示例："他醒来时，手机显示未接来电47个。通讯录里的名字他一个都不认识。手机是他自己的——后壳有他刻的 initials。"
```

- **优势**：天然悬念——读者和角色同步解谜
- **适用**：心理悬疑、身份诡计
- **注意**：记忆缺失的原因不能太敷衍（"撞到头了"是最低级的解释）

### 公式五：倒叙劫难（In Medias Res）

```
结构：从故事高潮/灾难中间切入 → 定格 → 回溯到N天/小时前 → 逐步逼近这个时刻
示例："炸弹还剩43秒。她看着数字跳动，想起三天前那个改变一切的电话。"
```

- **优势**：保证前30秒有高强度吸引力
- **适用**：动作悬疑、限时推理
- **注意**：倒叙回到"现在"时，读者的期待必须被满足或超越——不能虎头蛇尾

## 六、悬念三种类型

### 6.1 信息悬念（Information Suspense）

**定义**：读者和/或角色缺少某个关键信息。

| 亚型 | 机制 | 示例 |
|------|------|------|
| 谜题悬念 | "是什么？"——某个事实未知 | 凶手是谁？密室如何形成？ |
| 揭示悬念 | "为什么？"——动机/背景未知 | 他为什么杀她？她为什么隐瞒？ |
| 预知悬念 | "会怎样？"——结果未知 | 主角能否在时限内找到真相？ |

**写作要点**：
- 信息悬念的强度与"信息落差"成正比
- **Hitchcock原则**：让观众知道桌子下有炸弹，但角色不知道——这比双方都不知道更紧张
- 揭示时机：每 3-5 章释放一个关键信息，同时引入 1-2 个新悬念

### 6.2 角色悬念（Character Suspense）

**定义**：读者关心某个角色的命运，但不确定ta会怎样。

| 亚型 | 机制 | 示例 |
|------|------|------|
| 安全悬念 | 角色是否有危险？ | 她一个人走进了那栋楼…… |
| 道德悬念 | 角色会做出什么选择？ | 面对杀父仇人，他会开枪吗？ |
| 身份悬念 | 角色的真实身份是什么？ | 他真的是受害者家属吗？ |

**写作要点**：
- 角色悬念的基础是**共情**——读者必须先关心角色，才会对ta的命运产生悬念
- 共情构建三要素：弱点（vulnerability）、欲望（want）、困境（dilemma）
- 道德悬念是最高级的角色悬念——因为它没有"正确答案"

### 6.3 故事悬念（Story Suspense）

**定义**：读者对故事走向的整体期待与不确定。

| 亚型 | 机制 | 示例 |
|------|------|------|
| 结构悬念 | 故事会如何收束？ | 多条线索如何交汇？ |
| 主题悬念 | 作者想说什么？ | 这个案件会揭示什么社会真相？ |
| 情感悬念 | 最终的情感走向是什么？ | 正义会得到伸张吗？还是又一次无力？ |

### 6.4 三种悬念的协同使用

```
最佳悬疑体验 = 信息悬念（驱动推理）+ 角色悬念（驱动共情）+ 故事悬念（驱动追读）
```

- **短期吸引力**：主要靠信息悬念（每章都有新问题）
- **中期粘性**：主要靠角色悬念（关心角色命运）
- **长期追读**：主要靠故事悬念（想知道最终走向）

## 七、推理节奏控制（四阶段模型）

推理叙事的节奏不是匀速的——它应该像心跳一样有快有慢。

### 7.1 四阶段定义

| 阶段 | 占比 | 节奏 | 情绪 | 核心动作 |
|------|------|------|------|----------|
| **发现（Discovery）** | 15-20% | 快 | 震惊、好奇 | 案件发生，第一现场呈现 |
| **调查（Investigation）** | 30-35% | 中 | 紧张、困惑 | 收集线索，访谈嫌疑人 |
| **推理（Reasoning）** | 25-30% | 慢→快 | 思辨、兴奋 | 整合线索，推导真相 |
| **真相（Revelation）** | 15-20% | 快→慢 | 震撼、反思 | 揭示真相，情感收束 |

### 7.2 各阶段详细技法

**发现阶段**
- 前3000字必须建立至少一个核心谜题
- 谜面要"惊"但不"乱"——清晰地展示不可能性
- 可以使用"钩子嵌套"：在解释一个谜题的过程中引出另一个更大的谜题

**调查阶段**
- 信息释放节奏：每章至少获得一个新信息（线索/证词/发现）
- 同时每章至少埋下一个新问题
- **红鲱鱼管理**：全书红鲱鱼不超过 3 条主线级别的，避免读者感到"被骗"
- 嫌疑人画像渐进建立：第一印象 → 表层秘密 → 深层秘密 → 核心真相

**推理阶段**
- 侦探的推理过程必须对读者透明——不能"想了一夜，第二天说我知道了"
- 推理可以分步展示：先排除错误方向 → 发现关键线索 → 推导出惊人结论
- **推理高潮设计**：在推理快完成时设置一个"推理反转"——看似指向A的答案突然指向B

**真相阶段**
- 真相揭示场景要精心设计——它既是智力高潮也是情感高潮
- **双层揭示**：第一层真相解答"怎么做到的"，第二层真相解答"为什么"
- 结局的情感余韵比"爽"更重要——好的悬疑小说结局是"读完后三天还在想"

### 7.3 节奏调制技巧

- **加速器**：倒计时、新发现、盟友变嫌疑人——压缩时间感
- **减速器**：角色内心独白、背景回忆、社会观察——释放紧张感、增加深度
- **呼吸感**：每 2-3 章紧张章节后插入 1 章"呼吸章节"（角色日常、对话、情感线）
- **章节长度控制**：紧张场景用短章（1500-2000字），推理/反思场景用长章（3000-4000字）

## 八、社会推理核心技法（速查）

> 详见 [经典技法补全](references/classic-techniques.md) 获取暴风雪山庄、连环杀手、失踪者等叙事模式

社会推理区别于本格推理：谜题的答案不在于"谁做了什么"，而在于"社会结构如何制造了悲剧"。

**五大技法速查**：
1. **阶级/权力揭露**：谁有权力谁就是隐性凶手
2. **群像博弈**：每个角色都有秘密，侦探是系统内部的异类
3. **制度性暴力**：案件根源是制度缺陷而非个人恶意
4. **受害者解构**：打破"完美受害者"叙事
5. **侦探的局限性**：侦探无法解决"社会"这个最大的凶手

**叙事框架**：
```
案件发生 → 调查展开 → 真相浮现 → 道德困境 → 结局（个人正义 vs 系统性无力）
```

## 九、自检清单

### 诡计自检
- [ ] 诡计是否可以在全文线索基础上独立推理出来？
- [ ] 解答揭晓后，回读是否有"二次阅读乐趣"？
- [ ] 红鲱鱼是否有独立存在的理由（不能纯粹为误导而误导）？
- [ ] 诡计是否依赖"读者不可能知道的信息"？

### 节奏自检
- [ ] 前三章是否有明确的悬念钩子？
- [ ] 连续紧张章节后是否有"呼吸章节"？
- [ ] 每章结尾是否有"想看下一章"的动力？
- [ ] 悬念释放是否有节奏（不能全部堆在结尾）？

### 角色自检
- [ ] 读者是否能在3章内建立对主角的共情？
- [ ] 每个嫌疑人是否有独立的人格和秘密？
- [ ] 凶手的动机是否"可以理解"（即使不被认同）？
- [ ] 角色行为是否有前后一致性？

### 平台自检
- [ ] 是否符合目标平台的字数和节奏要求？
- [ ] 付费切断点是否在最佳悬念位置？
- [ ] 标题/简介是否有足够的吸引力？
- [ ] 是否避免了目标平台读者最反感的元素？
