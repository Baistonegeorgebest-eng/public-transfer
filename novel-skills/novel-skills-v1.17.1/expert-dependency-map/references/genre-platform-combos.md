## 第七章 场景触发指南

### 7.1 按创作场景找skill

**"我要开始写一本新小说"**
→ novel-writing-expert（总指南）→ expert-worldbuilding（世界观）→ expert-hook（开篇）

**"我的开头不够抓人"**
→ expert-hook → expert-pacing → expert-title-outro

**"读者说我的节奏拖沓"**
→ expert-pacing → expert-revision（删减方法）→ expert-plot-shuangdian（增加爽点密度）

**"我的人物写得不够立体"**
→ expert-character → expert-dialogue → expert-emotion

**"我的打斗场面不够精彩"**
→ expert-combat → expert-weapons → expert-pacing（动作节奏）

**"我不知道怎么写情感戏"**
→ expert-emotion → expert-dialogue → expert-character

**"我想写催泪场景"**
→ expert-emotion-death → expert-emotion → expert-pacing

**"我的逻辑有漏洞"**
→ expert-logic → expert-memory（确保前后一致）→ expert-revision

**"我写到一半卡文了"**
→ expert-endurance（写作体能）→ expert-memory（回顾设定找灵感）→ expert-pacing

**"我不知道怎么断章"**
→ expert-title-outro → expert-pacing → expert-hook

**"我想发番茄/起点"**
→ expert-platform-metrics → 对应平台skill

**"写完初稿要改稿"**
→ expert-revision → expert-logic → expert-anti-ai-taste（如果用了AI辅助）

**"我的文风前后不一致"**
→ expert-footprint → expert-memory → expert-revision

**"我想写系统流小说"**
→ expert-system-design → expert-skill-system → expert-xuanhuan

**"我想写种田文"**
→ expert-farming → expert-pacing → expert-worldbuilding

**"我想写同人小说"**
→ expert-fanfic-universal 或 expert-acg-fanfic → expert-character

**"我想把小说改编成剧本"**
→ expert-ip-adaptation → expert-character → expert-dialogue

**"我想学习大神的写法"**
→ expert-writing-style → expert-pacing → expert-hook

## 第九章 经典技法补全与自检清单

### 经典技法一：个人学习路径设计法

**核心公式：** 目标题材 × 目标平台 × 当前水平 = 个性化路径

**使用方法：**
1. 确定目标题材（玄幻/都市/科幻/女频/同人...）
2. 确定目标平台（番茄/起点/晋江...）
3. 评估当前水平（新手/进阶/高手）
4. 按以下公式生成路径：

**新手公式：** expert-quickstart → novel-writing-expert → expert-hook + expert-pacing + expert-dialogue + expert-character + platform适配skill + expert-revision

**进阶公式：** 新手路径全部 + expert-plot-shuangdian + expert-emotion + expert-logic + expert-memory + 题材核心skill

**高手公式：** 进阶路径全部 + expert-emotion-death + expert-writing-style + expert-footprint + expert-serialization-ops + expert-endurance

### 经典技法二：Skill组合效果评估矩阵

**核心公式：** 组合效果 = 覆盖度 × 协同度 × 实用度

评估标准：
- **覆盖度（1-5）：** 这个组合能覆盖你多大比例的创作需求？
- **协同度（1-5）：** 这些skill之间是否互相补充、形成体系？
- **实用度（1-5）：** 这些skill是否都能直接应用于你的实际创作？

**组合评估示例：**

| 组合方案 | 覆盖度 | 协同度 | 实用度 | 总分 |
|---------|--------|--------|--------|------|
| 玄幻8件套 | 5 | 5 | 5 | 15 |
| 都市7件套 | 4 | 4 | 5 | 13 |
| 只学技法不学平台 | 3 | 4 | 2 | 9 |
| 全部43个一起学 | 5 | 3 | 1 | 9 |

**关键洞察：** 不是学越多越好。一个协同度高的7-8个skill组合，效果远好于零散学20个skill。

### 经典技法三：渐进式Skill加载法

**核心原则：** 按需加载，不要预加载你用不到的skill。

**操作流程：**
1. **当前任务是什么？** → 确定需要哪个skill
2. **这个skill的前置依赖是什么？** → 先加载前置
3. **完成任务后** → 卸载skill，保持上下文清爽
4. **下一个任务** → 重新评估需要哪些skill

**什么时候需要加载额外skill：**
- 进入新的创作阶段（从大纲到初稿、从初稿到改稿）
- 遇到当前skill解决不了的问题
- 切换题材或平台
- 长篇连载到了需要记忆管理的阶段
