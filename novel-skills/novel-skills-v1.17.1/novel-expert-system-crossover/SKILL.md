# 联动创作规范

> **触发条件**：用户要求以具体已知的影视/动漫/游戏作品为题材进行创作时激活。
> **加载来源**：novel-expert-system 子模块。

## 【联动创作规范】（仅限联动已出版影视动漫游戏作品时启用）
> 触发条件：用户要求以具体已知的影视/动漫/游戏作品为题材进行创作时激活。
> 目的：确保AI对原著剧情范围、改编边界、进入/退出时机有清晰认知，避免OOC和时间线错乱。
> 核心原则：**先确认范围 → 再检索原著 → 再分级处理 → 最后才创作。**
### 规则一：先确认创作范围
| 类型 | 确认方式 |
|------|---------|
| 单部连贯作品（如《鬼灭之刃》《咒术回战》） | 用户明确指定涉及全本哪些具体剧情 |
| 多季/多卷作品（如《龙珠》《JoJo》） | **必须**向用户确认具体是哪一季/哪一卷/哪几卷 |
| 多平台跨界作品（如漫威/DC/生化危机） | **必须**向用户确认以哪个版本/哪部作品为主 |
| 游戏/动漫/影视同名的IP | **必须**向用户确认具体哪个版本（如《生化危机》电影 vs 游戏 vs 动画） |
**⚠️ 严禁在未确认范围前自行推测、假设或臆造剧情内容。**
### 规则二：联网检索官设底稿
- 范围确认后，**立即联网检索**涉及范围的官方剧情内容
- 下载/保存为`官设底稿.txt`，作为创作时的唯一官方依据
- 底稿必须包含：章节范围、关键情节点、主要角色状态、战斗结果
- **所有改编必须以底稿为基准，不得与底稿矛盾**
### 规则三：分级标注处理方式
每个剧情节点须明确标注处理类型：
| 标注 | 含义 | 操作方式 |
|------|------|---------|
| 📍 **进入** | AI正式进入该场景 | 直接描写，按底稿推进 |
| ⚔️ **参与** | AI/主角参与该节点 | 配合原著角色互动，按底稿推进 |
| ✏️ **有限改编** | 在不影响核心走向的前提下做适度调整 | 直接拟定方案，无需每次请示 |
| ⏭️ **跳过** | 该节点对主线无影响或可由上下文推断 | 一句话概述过渡，不展开描写 |
| 🔴 **需讨论** | 涉及核心剧情重大改编 | 暂停，**向用户详细说明方案**，获批后再写 |
**操作流程**：
每处理一个剧情节点前 → 先标注类型 → 再按类型执行
遇到"需讨论"节点 → 立即停笔，详细汇报方案 → 等待用户确认
### 违反本规范的严重后果
- 在未确认范围时臆造剧情 → **OOC风险极高**
- 未检索底稿就创作 → **剧情细节可能与原著矛盾**
- 将改编内容标注为"有限改编" → 实际上是重大改编 → **必须报用户确认**
