## 1. POV权重分配公式（实操版）

给定N个主要视角角色，按以下公式分配权重：

```
主角权重 = 100% × 0.35
配角i权重 = (100% - 主角权重) × (配角i重要度评分 / Σ所有配角重要度评分)
```

**重要度评分标准**（1-5分）：
- 5分：与主线核心冲突直接相关
- 4分：承载重要支线+与主线有交集
- 3分：有独立支线+与主线间接相关
- 2分：功能性角色（提供信息/工具）
- 1分：点缀性角色（丰富世界观）

**示例**（1主角+4配角）：
- 主角：35%
- 配角A（5分）：65% × 5/15 = 21.7%
- 配角B（4分）：65% × 4/15 = 17.3%
- 配角C（3分）：65% × 3/15 = 13%
- 配角D（3分）：65% × 3/15 = 13%

## 2. 角色记忆锚点速成法

**五分钟为每个角色建立锚点的步骤**：

1. **写下角色的一句话定义**（如"谨慎的军人型队长"）
2. **从定义推导三个锚点**：
   - 语言特征 → 说话简短、军事化用语
   - 行为特征 → 观察环境时先数人数、永远站高地
   - 思维特征 → 任何场景先评估威胁等级
3. **测试唯一性**：问自己"如果去掉角色名字，读者能分辨出这个角色吗？"
4. **如果不能**：修改锚点直到可以

**锚点唯一性检验表**：

| 角色 | 语言可区分？ | 行为可区分？ | 思维可区分？ | 总分 |
|------|-------------|-------------|-------------|------|
| 角色A | ✓ | ✓ | ✓ | 通过 |
| 角色B | ✓ | ✗（和D相似） | ✓ | 需修改行为特征 |
| 角C | ✗（和E相似） | ✓ | ✓ | 需修改语言特征 |

## 3. 五阶段节奏模型

```
阶段1：分散建立（各线独立推进，建立角色和支线）
   ↓  占总篇幅30%
阶段2：渐进交叉（支线开始与主线产生交集）
   ↓  占总篇幅20%
阶段3：全面交织（多条线在同一事件中碰撞）
   ↓  占总篇幅20%
阶段4：矛盾爆发（各线的矛盾在同一节点集中爆发）
   ↓  占总篇幅15%（高潮，节奏最快）
阶段5：收束与分流（高潮后各线收束，为下一弧做准备）
      占总篇幅15%
```
