## 战力上限原则（9×3境界）

严格遵守9大境界×3小层次=27等级上限。

### 27等级分配建议（以仙侠为例）

| 世界 | 境界 | 小层次 |
|------|------|--------|
| 凡界 | 炼气/筑基/金丹 | 各1~3层 |
| 灵界 | 元婴/化神/渡劫 | 各1~3层 |
| 仙界 | 大乘/飞升/真仙 | 各1~3层 |

## 战力展示三技巧

### 参照物展示法
> "那可是筑基期的强者，我们镇上最强的修士。"他一剑劈出，筑基期强者当场吐血。所有人都震惊了——他才炼气期。

### 对比展示法
> 半年前，他在这条路上被3个劫匪打得重伤垂死。今天，同样的路，同样的人。他轻轻抬了抬手，三个人当场跪下。

### 震惊展示法
> 配角："那个……传说中的剑圣……真的来了？"主角淡淡一笑。

## 升级节奏设计

| 升级类型 | 频率 | 特点 |
|---------|------|------|
| 小境界升级 | 每10~15章一次 | 突破带来实力提升，有代价（心魔/雷劫/资源消耗） |
| 大境界升级 | 每30~50章一次 | 伴随重大事件，全书重要里程碑，需足够铺垫 |
| 越境战斗 | 每50~80章一次 | 体现主角越级能力，需合理理由（金手指/秘技/特殊状态） |

## 百万字不崩架构

### 四层架构防崩模型

```
第一层：大世界观（贯穿全文）
  → 最终目标/终极敌人/世界真相
  → 从第一章开始暗示，最后30万字才揭晓

第二层：故事弧（每20-30万字一个）
  → 每个弧有独立的主线目标
  → 弧与弧之间有"过渡期"（3-5章轻松日常）
  → 每个弧结束时回收大部分伏笔，同时埋下新的

第三层：小剧情（每5-10万字一个）
  → 独立的小冲突/小冒险
  → 有明确的开始-发展-高潮-结束

第四层：章节钩子（每章）
  → 每章结尾有追读钩子
  → 保证基础追读率
```

### 防崩关键指标

- 每20万字至少一次"地图扩展"（新城市/新世界/新势力）
- 每10万字至少一次"实力跃升"（大境界突破/新能力觉醒）
- 连续5章不能全是"日常/练级"（至少有1章冲突）
- 主角的每个阶段实力要与该阶段对手匹配

## 战力膨胀控制

### 膨胀控制公式

```
每卷实力增长幅度 ≤ 一个大境界

卷1：练气期（1-20万字）
卷2：筑基期（20-40万字）
卷3：金丹期（40-60万字）
卷4：元婴期（60-80万字）
卷5：化神期（80-100万字）

每个大境界内分3-5个小等级
每个小等级需要3-5万字来成长
突破大境界 = 故事弧的高潮事件
```

### 设计四原则

1. **限制原则**：每个境界有明确上限（如"筑基期不可能飞行"）
2. **代价原则**：越级战斗必须有代价（消耗寿命/损伤根基/需要特殊条件）
3. **维度原则**：实力不只看境界，还有功法品质/战斗经验/法宝/阵法等维度
4. **克制原则**：五行/功法类型之间有克制关系，低境界可克制高境界

### 战力膨胀预警信号

- 主角在10万字内从底层升到顶层 → 膨胀过快
- 主角已经没有对手，需要不断"飞升"新世界 → 体系设计有问题
- 配角完全跟不上主角，变成纯观众 → 配角成长线缺失
