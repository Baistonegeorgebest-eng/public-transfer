## 细纲三种写法

### ① 事件流细纲（最适合新手）

格式：「时间/地点+角色+目标+阻碍+结果」

```
第3章：刘封在酒楼 → 遇到挑衅 → 展示实力 → 对方服软 → 结交新友
第4章：刘封回府 → 接到任务 → 发现阴谋 → 收集证据 → 埋下伏笔
第5章：刘封出城 → 遭遇埋伏 → 激活底牌 → 击退敌人 → 获得线索
```

### ② 情绪流细纲（最适合情感戏）

格式：「当前情绪+触发事件+情绪变化+行动+结果」

```
第8章：平静→被羞辱→愤怒但不发作→暗中收集情报→反转打脸
第9章：压抑→得知真相→悲痛转化为动力→做出决定→章节钩子
第10章：坚定→主动出击→获得阶段性胜利→情绪短暂满足→新危机出现
```

### ③ 世界观流细纲（最适合西幻/科幻）

格式：「地点+当前局势+势力变化+主角介入+结果」

```
第15章：北境战场 → 兽潮逼近 → 主角带领团队研究战术 → 关键性胜利 → 势力版图变化
第16章：回到主城 → 朝廷内斗 → 主角被卷入 → 借力打力 → 化解危机但引出新敌
```

## 细纲写到哪一步？

| 级别 | 标准 | 适用场景 |
|------|------|---------|
| 最低 | 每章3句话概括：「谁在哪里做了什么，遇到什么问题，最后结果如何」 | 日常赶稿 |
| 中级 | 每章100~200字，列出核心冲突、爽点、钩子 | 稳定连载 |
| 高级 | 每章300~500字，预埋本章说触发点、配角反应、金句 | 精品冲刺 |

## 防止卡文的细纲检查表

- [ ] 这个月内要写什么？（30章细纲）
- [ ] 今天要写哪几章？（3~5章细纲）
- [ ] 每章的核心事件是什么？
- [ ] 每章的核心爽点是什么？
- [ ] 每章结尾的钩子是什么？
- [ ] 这章和下章怎么衔接？
- [ ] 这章的配角谁出场？他们各自的目标是什么？
- [ ] 有没有哪段情节自己想不出来？（提前标记，留时间思考）

## 章节节奏卡点

### 起点爆款章节结构（按字数排布）

| 字数 | 内容 | 作用 |
|------|------|------|
| 0~100字 | 开篇冲突（本章钩子延续，或新冲突） | 抓住读者 |
| 100~500字 | 冲突展开（第一波压迫，主角被动） | 制造压力 |
| 500~1000字 | 转机出现（金手指/配角/计策） | 给出希望 |
| 1000~2000字 | 高潮对抗（反击/逆转） | 核心爽点 |
| 2000~2500字 | 结果确认（爽点爆发） | 情绪满足 |
| 2500~3000字 | 章节钩子（为下章埋悬念） | 驱动追读 |

## 钩子设置的三种类型

### ① 危机钩子（最常见）

> 就在他转身的瞬间。背后，传来了一声轻笑。「你要去哪里？」他的脸色瞬间变了。那是——不可能出现的声音。

### ② 反转钩子（强情绪）

> 长老宣布：测试结果，林尘——无属性。全场哄笑。林尘低着头，不说话。但他的手心里，藏着一枚从未展示过的玉佩。那玉佩上的纹路，和测试碑上的纹路——一模一样。

### ③ 悬念钩子（强期待）

> 任务完成了。但他发现，这次任务的奖励——不是金币。是一张地图。地图上标注的位置，是他自己家的坐标。

---

## 每章必须有明确"目标"

- [ ] 这章主角要做什么？（目标）
- [ ] 做这件事的障碍是什么？（阻碍）
- [ ] 最后做成没有？（结果）
- [ ] 下章接着会发生什么？（钩子）

> 没有目标的章节 = 流水账 = 读者弃书
