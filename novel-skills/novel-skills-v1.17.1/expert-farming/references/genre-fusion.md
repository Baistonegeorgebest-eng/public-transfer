## 3. 种田×各题材融合

### 3.1 修仙种田

**核心设定：灵田+炼丹+宗门经营**

修仙种田的本质是把修仙世界当作一个"特殊的农业/经营环境"来处理。

**灵田体系设计：**

| 灵田等级 | 灵气浓度 | 产出 | 对应凡间 |
|---------|---------|------|---------|
| 劣等灵田 | 微弱 | 普通灵草 | 贫瘠荒地 |
| 下等灵田 | 较弱 | 低阶灵药 | 普通农田 |
| 中等灵田 | 中等 | 中阶灵药/炼丹材料 | 良田 |
| 上等灵田 | 浓郁 | 高阶灵药/天材地宝 | 灵田福地 |
| 仙田 | 仙气 | 仙药/传说级材料 | 洞天福地 |

**修仙种田的三条路线：**
1. **灵植夫路线**：种植灵药→炼丹→提升修为→种植更高阶灵药（正向循环）
2. **宗门经营路线**：管理灵田分配、弟子培养、产业布局（模拟经营）
3. **资源大亨路线**：垄断某种稀缺灵药的供给→控制修仙界经济命脉

**修仙种田特有爽点：**
- 灵植变异的惊喜（普通灵草变异为天材地宝）
- 炼丹成功率的赌性（高风险高回报）
- 以种田实力碾压战斗型修士（你打我？我用丹药砸死你）

**节奏要点：**
- 修炼进度和种田进度交替推进，避免单线叙事疲劳
- 每个修为突破需要特定的灵药→驱动种田动机
- 定期引入新品种/新技术保持新鲜感

### 3.2 末日种田

**核心设定：安全屋+生存基地+资源争夺**

末日种田是2024-2025年的热门融合方向，本质是在极端稀缺环境下重建秩序。

**末日种田的三个阶段：**

```
阶段一：安全屋求生（1-30章）
  核心：在末日环境中活下来
  资源：搜刮废墟、旧世界遗留物资
  爽点：第一次在末世吃到热饭、安全屋升级

阶段二：据点建设（31-100章）
  核心：建立小型避难所/生存基地
  资源：改造建筑、开辟种植区、建立水净化系统
  爽点：种出第一棵菜、收留第一个幸存者、电力恢复

阶段三：秩序重建（101章+）
  核心：从小基地到小社区到聚居地
  资源：农业恢复、工坊重建、防御体系
  爽点：外面是末世，基地里有电有水有网络
```

**末日种田的"反差爽"：**
- 丧尸围城的夜晚，基地里灯火通明，众人围坐吃火锅
- 别人在啃压缩饼干，主角的温室里西红柿红了
- 外面为了半瓶水打生打死，基地已经实现水循环自给

**末日种田的特殊冲突来源：**
- 外部威胁：丧尸群、变异兽、敌对势力掠夺
- 内部矛盾：资源分配、人心浮动、权力争夺
- 环境压力：辐射区扩张、水源污染、季节变化

### 3.3 异世界种田

**核心设定：穿越+基建+文化碰撞**

异世界种田是种田文最大的融合类型，起点/番茄均有大量作品。

**异世界种田的四种开局：**

| 开局 | 起点 | 核心冲突 | 爽点 |
|------|------|---------|------|
| 贵族少爷 | 继承一块荒凉领地 | 财政赤字+内忧外患 | 用现代知识改造落后的领地 |
| 落魄商人 | 穿越后一穷二白 | 生存+原始积累 | 白手起家到商业帝国 |
| 平民农夫 | 最底层的穿越者 | 阶级壁垒+资源匮乏 | 从最底层一步步爬上来 |
| 神秘来客 | 带着特殊身份/能力 | 身份暴露风险 | 降维打击般的知识碾压 |

**异世界种田的"知识碾压"设计：**
- 现代农业技术：轮作/堆肥/嫁接/温室→产量暴增
- 基础工程：水车/风车/桥梁/道路→基建碾压
- 工业萌芽：水泥/玻璃/肥皂/酿酒→垄断产业
- 管理制度：科层制/标准化/记账法→效率碾压

**注意：知识碾压不能太离谱。**
- 合理版：主角是农业专业出身，会堆肥和轮作
- 离谱版：主角一个人搞出蒸汽机+电力+化工
- 原则：一个现代人在没有工业基础的异世界，能做的上限大约是"中世纪晚期水平"

### 3.4 都市种田

**核心设定：创业+经营+财富积累**

都市种田是种田文在现代背景下的变体，更侧重商业经营。

**都市种田的五条赛道：**

```
1. 农业创业：有机农场/特色种植/养殖基地
2. 餐饮经营：从路边摊到连锁餐厅
3. 科技创业：技术发明→产品化→市场扩张
4. 电商经营：网店→品牌→供应链整合
5. 地产开发：买地→建设→出租/出售
```

**都市种田的特有优势：**
- 读者共鸣度高（大家都有创业/赚钱的幻想）
- 现代背景的细节容易查证（降低写作门槛）
- 可以融入职场/商战元素增加冲突

**都市种田的节奏要点：**
- 前期重"第一桶金"的获取过程（这比什么都重要）
- 中期重扩张中的决策与取舍
- 后期重行业地位的确立和对手的碾压

### 3.5 历史种田

**核心设定：古代农业+水利+民生**

历史种田是种田文的"正统"起源，核心是穿越到古代搞建设。

**历史种田的经典模式：**

| 模式 | 核心内容 | 代表要素 |
|------|---------|---------|
| 农业改良 | 引入高产作物/改进农具/推广技术 | 土豆番薯玉米三件套 |
| 水利工程 | 修渠/治河/灌溉系统 | 都江堰模式 |
| 商业发展 | 打破重农抑商/建立贸易网 | 丝绸之路模式 |
| 政治路线 | 从基层到中枢的升迁 | 从县令到宰相 |

**历史种田的考据要求：**
- 历史种田对"时代感"要求最高
- 作物引入需要合理解释（不能上来就种玉米，要看穿越到哪个朝代）
- 技术改良不能太超前（在唐朝搞蒸汽机不太行）
- 税收/物价/度量衡需要基本准确

**历史种田的核心爽点：**
- 用现代知识改良古代民生
- 从被嘲笑到被认可的"先知"感
- 看到自己的政策改变千万人命运的成就感

### 3.6 西幻种田

**核心设定：领主+魔法+奇幻资源**

西幻种田结合了西方奇幻元素和种田经营。

**西幻种田的特殊资源体系：**
```
常规资源：土地/木材/矿石/粮食（与现实一致）
魔法资源：魔晶矿/魔法草药/魔兽/魔法材料
特殊建筑：魔法塔/附魔工坊/传送阵/结界
独特产业：炼金术/附魔/魔药/魔法道具制造
```

**西幻种田的独有爽点：**
- 魔法技术的"降维打击"效果（用魔法实现自动化灌溉）
- 魔兽养殖的趣味性（养一只龙=最顶级安保）
- 精灵/矮人/兽人等种族的产业合作（各族特长互补）

**西幻种田的注意点：**
- 魔法体系要有限制，不能太万能（否则不需要种田了）
- 魔法是放大器而非替代品——魔法能让种田更好，但不能替代种田本身
- 种族设定要服务于经营逻辑（精灵擅长植物→农业顾问，矮人擅长锻造→工业核心）
