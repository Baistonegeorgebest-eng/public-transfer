# 感官描写专家 · v1.0

> **定位：** 男频网文感官场景的核心引擎——从旁观到互动，从静态到动态。
> **来源：** 《太阳王之证》218万字全本技法提炼 + 通用男频技法研究

---

## 使用原则

- 所有技法本质上是**高级感官描写**，不局限于单一场景类型
- 适用任何需要"让读者感受到五感"的写作场景
- 亲密分级严格遵守平台合规红线（见第五层）

---

## 第一层：感官描写基础

### 核心原则：动作代替静态

```
❌ 她穿着黑色丝袜（静态陈述）
✅ 她低头整了整大腿上的丝袜，指尖从膝盖内侧轻轻抹过，将皱褶抚平（动态动作）

核心：不写"她很美"，只写手在做什么
```

### 动作链模板（从上到下顺序）

```
她低头整了整大腿上的[袜类] →
指尖从膝盖内侧轻轻抹过，将皱褶抚平 →
俯下身，掌心从大腿两侧滑向小腿 →
将[袜类]边缘仔细掖进裙摆/裤腿 →
确保完美贴合腿部的每一寸曲线 →
直身，满意地点头
```

### 触感词汇链（3-5个叠加）

| 感官 | 词汇 |
|------|------|
| 视觉 | 修长、纤细、光泽、若隐若现、透亮、莹白、匀称、笔直 |
| 触觉 | 柔软、光滑、细腻、温润、滑腻、弹性、紧致、温热、绵软 |
| 综合 | 玲珑、精致、白皙、粉嫩、圆润、纤巧、骨感 |

**使用规则：**
- 视觉词先铺（看到什么），触觉词跟进（触到什么）
- 同一类词不重复（不写"光滑又细腻又柔滑"，选两个即可）
- 最后一个词要有力度（弹性十足/温热可辨/细腻入微）

## 第二层：L1-L5 亲密分级

### L1 · 远观（描写存在感）

```
场景：角色出场/重点描写
要素：三件套（上装+下装+足部），每件有细节
模板：
  她身穿[颜色][材质][款式][上装]，
  [腰线/身材]描写，
  [腿部]裹着[颜色][材质][款式][袜类]，
  [足部]踩着一双[颜色][款式][鞋类]。
```

### L2 · 近距互动（肢体接近）

```
场景：两人近距离对视/擦肩/递东西
要素：呼吸感/距离感/体温感知
模板：
  他站在她身后一步远的地方。
  能闻到她身上淡淡的[气味]。
  她的[发丝/耳廓]在光线下近乎透明。
```

### L3 · 肢体接触（主动触碰）

```
场景：握手/搀扶/包扎伤口
要素：触觉感知 + 对方反应
模板：
  [男性]伸出手，轻轻握住/捏住[女性]的[部位]。
  那层薄薄的[材质]紧紧包裹着她的肌肤，
  指尖传来的触感[词1]而[词2]。

触碰分级：
  ★ 手腕/手背（触感词1-2个）
  ★★ 脚踝/小腿（触感词2-3个）
  ★★★ 脚底/脚掌（触感词3-4个）
  ★★★★ 大腿/膝弯（触感词4-5个）
```

### L4 · 情境暧昧（氛围拉满但不越界）

```
场景：更衣/疗伤/湿身/意外亲密
要素：环境压力 + 感官叠加 + 情绪张力
模板：
  水顺着她的[发丝/脖颈/锁骨]往下淌。
  [衣料]被打湿后紧贴着身体，勾勒出[曲线]。
  他移开视线。
  但余光还是扫到了。

关键：情绪最高峰用短句，越短越有力
```

### L5 · 留白（停在最痒的地方）

```
场景：关键时刻突然中断
要素：打断 + 未完成 + 读者脑补
模板：
  她转过身，[某个动作做到一半]。
  门响了。
  "有人来了。"她低声说。

核心技法：场景写到情绪最高点时切掉
→ 读者的想象力比任何描写都强
→ 留白 = 最强的挑逗
```

## 第四层：打断·克制·挑逗技法

### 4A 打断技法

```
场景写到L4高潮时，用以下方式切断：

· 环境打断：门响了/有人来了/窗外有声音
· 角色打断：她推开他/他移开视线/她突然站起来
· 内心打断：他想起了什么/她意识到了什么
· 时间打断：天亮了/灯灭了/该走了

效果：读者被迫中断阅读快感，但脑中会继续"补完"
→ 这就是"上瘾感"的来源
```

### 4B 克制技法

```
最有力的不是写了什么，而是"没写什么"：

· 他握住了她的脚踝。
· 然后松开了。
· 没有说为什么。

（读者会想知道为什么松开 → 情绪张力在"松开"这个动作上）
```

### 4C 递进技法

```
同一场景内，亲密程度逐步升级：

第一次触碰 → 手背（L3★）
第二次触碰 → 小臂（L3★★）
第三次触碰 → 没有第三次（被打断）→ 读者期待第三次

每次递进之间至少间隔2-3句对话/环境描写
不要连续触碰 → 会变成"油腻"
```

## 第五层：合规自检

### 平台红线清单

| 红线 | 番茄 | 起点 |
|------|------|------|
| 直接描写性行为 | ❌ 封书 | ❌ 封章 |
| 身体隐私部位描写 | ❌ 封书 | ❌ 封章 |
| 强迫/非自愿 | ❌ 封书 | ❌ 封章 |
| 未成年角色的感官描写 | ❌ 封书 | ❌ 封书 |
| 过度露骨的触感描写 | ⚠️ 限流 | ⚠️ 限流 |

### 安全线（可以写但需注意）

| 场景 | 注意事项 |
|------|---------|
| 擦边场景 | 停在L4，不进L5的行为描写 |
| 更衣/疗伤 | 视角限制在"看到的部分"，不描述全部 |
| 湿身/意外亲密 | 用环境描写代替身体描写 |
| 对话中的暗示 | 可以有，但不能是"明示" |

### 自检问题

```
□ 这段描写如果被编辑看到，我会觉得尴尬吗？
□ 这段描写的目的是"推动剧情/建立角色"还是"纯粹福利"？
  → 纯粹福利 = 需要至少一句剧情推进
□ 触碰场景中，对方是否有明确的"同意/默许"信号？
  → 没有 = 重写
□ 亲密程度是否与角色关系阶段匹配？
  → 初次见面就L4 = 不合理，重写
```
