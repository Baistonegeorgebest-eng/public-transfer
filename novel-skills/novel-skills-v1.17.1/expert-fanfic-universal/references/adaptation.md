## 4. 跨媒介改编适配

### 4.1 影视→小说：场景文字化

**核心挑战：** 影视靠画面和表演传达信息，小说需要纯文字重建这些信息。

**技法框架：**

**画面→环境描写：**
```
影视镜头：[广角] 长安城全景，灯火万家，远处宫殿的轮廓
小说化：  长安城的夜色如同一幅铺展开的画卷。万家灯火在脚下蔓延，
          像是银河落入人间。远处，太极宫的飞檐在月色下勾勒出沉默
          的轮廓，那是权力的象征，也是牢笼的形状。
```

**表演→内心描写：**
```
影视表演：[演员眼眶微红，嘴唇微动，但没有说话]
小说化：  他想说什么。嘴唇动了一下，像一条搁浅的鱼。但最终，
          什么都没有说。有些话一旦出口，就再也收不回去了。
          他只是转过身，让背影替他说了那句说不出口的再见。
```

**对白→小说化对白：**
```
影视对白：（语气+表情+肢体动作承载大量信息）
小说化：  需要把"表演信息"转化为"叙述信息"
          ❌ "你来了。"他说。
          ✅ "你来了。"他连头都没抬，语气平淡得像在说今天的天气。
             但握着茶杯的手指，关节已经泛白。
```

**蒙太奇→叙事节奏：**
```
影视：快速切换多个场景（蒙太奇）
小说：用简洁的段落过渡/时间跳跃标注/碎片化叙述来模拟
```

### 4.2 游戏→小说：机制叙事化

**核心挑战：** 游戏的互动性和系统性需要转化为小说的线性叙事。

**详细转换表：**

| 游戏元素 | 小说化策略 | 注意事项 |
|----------|------------|----------|
| 开放世界探索 | 选择性描写，突出标志性场景 | 不要写成"旅游指南" |
| 战斗系统 | 战斗中的感官+策略描写 | 避免数值化描述 |
| 角色培养 | 蒙太奇式训练+关键突破场景 | 不要写成流水账 |
| 对话选择 | 合并为角色性格驱动的自然对话 | 不要出现"选择了A选项" |
| 物品/装备 | 自然融入场景，不单独列举 | 避免"物品栏"感 |
| 存档/重生 | 时间循环/梦境/预知能力 | 需要提供合理的叙事内解释 |
| 多结局 | 选择一条线深入或写"if线"系列 | 不要在一个故事里强行融合所有结局 |
| NPC交互 | 自然的人物关系建立 | 避免"接任务→完成→交任务"的模式 |

**游戏叙事化的三个层次：**
```
Level 1（表层）：将游戏画面转化为文字描写
Level 2（中层）：将游戏系统转化为叙事逻辑
Level 3（深层）：将游戏的核心体验转化为小说的主题和情感
```

### 4.3 小说→同人：世界观扩展

**核心挑战：** 原作小说的世界观已经很完整，同人需要找到"缝隙"来扩展。

**扩展维度：**

1. **空间扩展：** 原作只写了A地，同人可以探索B地/C地
2. **时间扩展：** 原作之前/之后/之间的时间段
3. **视角扩展：** 配角/反派/路人视角
4. **体系扩展：** 原作中提到但没有展开的力量体系/社会结构
5. **日常扩展：** 原作中省略的日常生活细节

**扩展的前提——不与原作冲突：**
```
扩展内容不能与原作明确描述的事实矛盾
如果有矛盾 → 需要明确标注为AU
扩展内容应该让读者觉得"原作中就是这样，只是没有写出来"
```

### 4.4 动画→小说：分镜文字化

**核心挑战：** 动画的视觉冲击力和节奏感需要在文字中重现。

**分镜→文字的转换技法：**

```
动画分镜1：[特写] 角色的眼睛，瞳孔收缩
小说化：  他的瞳孔在那一瞬间缩成了针尖。

动画分镜2：[全景] 两军对峙，风卷起沙尘
小说化：  风卷着黄沙从两军之间的空地席卷而过。没有人说话。
          只有旗帜猎猎作响，像是在替千军万马呼吸。

动画分镜3：[快速剪辑] 战斗连续动作
小说化：  用短句和动词来模拟快节奏：
          拔刀。踏步。挥斩。血花飞溅。
          他没有停。第二个。第三个。
          动作连贯得像一条绷紧的线。
```

**动画独有元素的处理：**
- BGM/配乐 → 用氛围描写和节奏暗示来传递"音乐感"
- OP/ED → 不能直接写，但可以用类似的意象和主题呼应
- 声优表演 → 将声音特质转化为文字（"他的声音低沉得像夜晚的潮水"）
