## 3. 同人创作通用技法

### 3.1 OOC五层防控体系

**OOC (Out of Character)** 是同人创作最大的风险——读者进来的前提是"这是那个我爱的角色"，一旦角色行为超出合理范围，读者的信任瞬间崩塌。

#### 五层防控框架：

```
第一层：硬性底线（绝对不可触碰）
│  角色的核心身份标签/不可改变的经历/明确的性格底线
│  例：梅长苏不会为权力放弃原则/蜘蛛侠不会主动杀人
│
第二层：性格逻辑（行为必须可解释）
│  角色的每一个行动都必须能从其性格+经历中推导出来
│  可以让角色做"不像他会做的事"，但必须有充分的动机铺垫
│  例：一个内向角色在极端情况下爆发→合理；一个内向角色突然变得话痨→OOC
│
第三层：语言风格（说话方式的一致性）
│  角色的口头禅/用词习惯/句式特点/语言节奏
│  例：高启强的"风浪越大鱼越贵"式表达/钟离的古风措辞
│
第四层：关系动态（角色间互动的合理性）
│  角色对不同人的态度差异/权力关系/亲疏远近
│  例：一个对所有人都冷酷的角色只对特定人温柔→是特色
│       一个对所有人都温柔的角色突然对所有人冷酷→需要解释
│
第五层：成长轨迹（变化必须有弧度）
│  角色可以有成长和变化，但必须有清晰的转变过程
│  不允许"第一章还是这样，第五章突然变成那样"的跳跃
│  关键事件→内心动摇→逐步转变→最终蜕变（至少4个阶段）
```

**OOC自检清单：**
- [ ] 这个行为是否与角色的核心性格矛盾？
- [ ] 如果矛盾，是否有足够的动机和铺垫来解释？
- [ ] 角色的说话方式是否像他/她？
- [ ] 角色对其他人的态度是否符合原著关系？
- [ ] 角色的成长/变化是否有清晰的轨迹？
- [ ] 读者是否能在看到这个场景时说"没错，这就是他/她"？

### 3.2 AU设计六种类型

**AU (Alternate Universe)** 是同人创作最强大的工具之一——将原作角色放入一个全新的世界观，既保留了角色魅力，又获得了创作自由。

#### 六种AU类型详解：

**类型一：时代AU（Era AU）**
将角色放入不同的历史时代或未来世界。
- 古代→现代 / 现代→古代 / 现代→未来
- 例：《琅琊榜》角色在现代商战中/漫威角色在中世纪
- **设计要点：** 角色的"社会身份"需要重新设计，但"性格内核"不变

**类型二：职业AU（Profession AU）**
设定角色从事不同的职业。
- 咖啡店AU / 医院AU / 学校AU / 警局AU
- 例：高启强是正经鱼贩的日常生活/钟离是大学考古教授
- **设计要点：** 职业设定要合理，不能为了CP服务而强行安排不合理的职业组合

**类型三：种族/物种AU（Species AU）**
改变角色的种族或物种。
- 人类→狼人/吸血鬼/精灵/AI/人鱼
- 例：漫威角色全员是不同种族的奇幻生物
- **设计要点：** 种族特性要与角色性格有呼应

**类型四：关系AU（Relationship AU）**
改变角色间的关系设定。
- 陌生人→青梅竹马 / 仇人→恋人 / 上下级→平等伙伴
- 例：安欣和高启强从小一起长大/韦小宝是康熙的青梅竹马
- **设计要点：** 关系变了，但角色的互动模式应该有原著的影子

**类型五：剧情AU（Plot AU）**
改变原作的某个关键剧情节点，推导蝴蝶效应。
- "如果XX没有死""如果XX做了另一个选择"
- 例：如果梅长苏没有中火寒毒/如果灭霸的响指没成功
- **设计要点：** 蝴蝶效应要有逻辑链，不能改了一个点结果整个世界都变了却没有解释

**类型六：融合AU（Crossover AU）**
将不同作品的角色和世界观融合。
- 漫威×DC / 原神×崩铁 / 国产剧×韩剧
- 例：所有漫威英雄在同一所高中就读
- **设计要点：** 需要一个"合理性桥梁"来解释为什么不同世界观的角色会在一起

**AU设计自检清单：**
- [ ] AU设定是否服务于故事主题？（不是为了AU而AU）
- [ ] 角色的"感觉"在AU中是否保留？
- [ ] AU的世界规则是否自洽？
- [ ] 读者能否在第一章就理解AU的基本设定？
- [ ] AU设定是否有足够的"新鲜感"但又不过于陌生？

### 3.3 CP处理规范

#### 3.3.1 官配CP

原作中明确的恋人/夫妻关系。

**处理原则：**
- 官配是安全区，读者接受度最高
- 可以写官配的"日常向"/"婚后向"/"if线"
- 官配的深度挖掘（他们为什么相爱/他们的矛盾在哪里）比单纯发糖更有价值
- **常见误区：** 以为官配就只需要发糖→实际上官配的"暗流"和"冲突"才是好同人的核心

**官配CP深化公式：**
```
表面甜蜜 + 暗藏矛盾 + 外部压力 + 共同面对 + 关系升华
```

#### 3.3.2 拆官配（非官配CP）

将原作中没有恋爱关系（或有其他官配）的角色配对。

**处理原则：**
- 拆官配是同人创作的常态，但需要更强的说服力
- 必须提供两人"为什么会在一起"的合理逻辑
- 需要处理好与原作官配的关系（不能简单否定原作CP）
- **尊重原则：** 不要在以官配为主题的同人下讨论拆CP

**拆官配CP的说服力构建：**
1. 共同经历：两人一起经历了什么
2. 性格互补：为什么他们适合彼此
3. 转折事件：从什么关系变成了恋爱关系
4. 障碍与克服：他们在一起的阻力是什么

#### 3.3.3 多CP处理

一部同人中有多对CP同时发展。

**处理原则：**
- 主CP占据60-70%篇幅，副CP各占10-20%
- 多CP之间需要有互动和联系，不能完全独立
- 副CP的进展应与主CP形成对比或呼应
- **节奏技巧：** 主CP遇到障碍时，切到副CP的甜蜜期→反之亦然

### 3.4 时间线管理

#### 3.4.1 三种时间线模式

**原著线（Canon Timeline）：**
- 在原著的时间线内填补空白
- 原著没有详细描写的时段/场景/对话
- **优势：** 最容易获得读者认可
- **风险：** 容易与原作冲突

**偏离线（Divergence Timeline）：**
- 在原著的某个节点"偏离"，走向不同的发展
- "如果XX做出了不同的选择"
- **优势：** 创作自由度高，保留原著设定
- **关键：** 偏离点的选择至关重要，需要是"合理的分歧点"

**平行线（Parallel Timeline）：**
- 完全独立的时间线，只借用角色和设定
- AU同人的常见时间线模式
- **优势：** 最大的创作自由
- **风险：** 需要重新建立读者对世界观的理解

#### 3.4.2 时间线标注规范

```
[原著时间线锚点]：以原著中的关键事件为坐标
├── "XX事件前3年" / "XX事件后2个月"
├── "第X卷开始时" / "第X章结尾后"
└── 避免使用绝对日期（除非原著明确提及）
```

**时间线一致性检查清单：**
- [ ] 角色年龄在各场景中是否一致？
- [ ] 角色间的关系进展是否符合时间流逝？
- [ ] 季节/天气/节日是否与时间线匹配？
- [ ] 原著事件的发生顺序是否被正确引用？
- [ ] 角色的知识/能力在各时间点是否合理？

### 3.5 同人开篇公式

#### 公式一：名场面重演式
```
选取原作中最经典的场景 → 以不同视角/更详细的内心独白重新演绎 → 自然过渡到同人原创内容
```
**适合：** 还原向同人/角色深度挖掘

#### 公式二：日常切片式
```
角色的某个普通日常 → 细节描写建立角色氛围 → 某个微小的变化打破日常 → 引入故事主线
```
**适合：** 日常向同人/AU设定

#### 公式三：悬念前置式
```
故事高潮/结果的片段（倒叙）→ 跳回故事起点 → 读者带着"怎么会走到这一步"的好奇心继续阅读
```
**适合：** 悬疑向/虐心向同人

#### 公式四：对话驱动式
```
一段关键对话（不说明说话人/场景）→ 读者开始猜测 → 逐渐揭示对话的背景和含义
```
**适合：** CP向同人/关系探讨

#### 公式五：世界构建式
```
AU世界观的展示 → 角色在这个世界中的位置 → 角色的日常 → 引入冲突
```
**适合：** AU同人/架空设定

### 3.6 同人结尾公式

#### 公式一：原作呼应式
结尾回到原作的某个场景/台词，形成互文和闭环。
```
同人结尾场景 ≈ 原作某个场景 + 关键差异
```
**效果：** "一切变了，一切又好像没变"的感慨

#### 公式二：开放式余韵
不给出明确的"结局"，而是停在一个有余韵的场景。
```
角色完成了同人故事中的目标 → 展望未来/做出选择 → 故事在选择的瞬间结束
```
**效果：** 给读者留有想象空间

#### 公式三：情感收束式
以一段情感总结作为结尾，不需要大事件的收束。
```
角色的内心感悟/对关系的确认/对自身的认知 → 温暖/释然的氛围
```
**效果：** 适合短篇/日常向/CP向

#### 公式四：命运循环式
结尾与开头形成呼应，暗示某种宿命感。
```
开头的场景/台词/意象 → 经过整个故事 → 结尾重现，但意义已经不同
```
**效果：** 增强故事的整体感和深度
