## 1. 泛同人创作总论

### 1.1 同人创作的本质

同人创作的核心定义：**在已有世界观、角色体系、叙事框架的基础上，创作出原作未讲述或未深入的故事。**

同人不是"抄"，而是"对话"——与原作对话，与角色对话，与读者的既有认知对话。同人作者的角色类似爵士乐手：拿到一个已有的旋律（原作），即兴演奏出全新的变奏（同人故事）。

**同人创作的三层价值：**

| 层次 | 价值 | 说明 |
|------|------|------|
| 情感补完 | 弥补原作遗憾 | "如果他没有死""如果他们在一起了" |
| 视角拓展 | 展示原作未见之面 | 配角视角/反派视角/时间线空白处 |
| 设定延展 | 在原作基础上建造新世界 | AU世界观/时间线续写/跨界联动 |

### 1.2 同人vs原创的核心差异

```
原创：从零搭建世界观 → 设计角色 → 构建冲突 → 讲述故事
同人：继承世界观和角色 → 识别叙事空白 → 填补/重构 → 与原作形成互文
```

**关键差异对比：**

| 维度 | 原创 | 同人 |
|------|------|------|
| 世界观 | 完全自建 | 继承+微调/颠覆 |
| 角色 | 从零塑造 | 读者已有预期，需维持"感觉" |
| 读者门槛 | 需要完整建立 | 门槛低但天花板高 |
| 创作自由度 | 最高 | 受原作框架约束 |
| 爽点来源 | 角色成长+世界探索 | CP情感+OOC惊喜+设定深度挖掘 |
| 读者黏性 | 取决于质量 | 原作粉丝天然流量 |

**同人的独特优势：** 读者进来时已经"爱上"了角色，你不需要从零建立感情——你需要做的是让读者觉得"你懂这个角色"。

### 1.3 同人创作的法律边界

**合理使用原则（中国大陆）：**
- 同人属于"二次创作"，著作权法未明确禁止，但也未明确保护
- 核心原则：非商业/非商业宣传/不损害原作声誉
- 逐字搬运原作片段属于侵权，化用设定和角色属于灰色地带

**平台规则速查：**

| 平台 | 同人政策 | 注意事项 |
|------|----------|----------|
| 晋江 | 开放同人专区，鼓励创作 | 需标注"同人"标签，不得洗稿 |
| 番茄 | 允许同人，有专门分类 | 注意番茄的审核敏感词 |
| 起点 | 有同人分区 | 部分IP受版权方限制 |
| LOFTER | 同人主阵地 | 图文并茂，社区属性强 |
| AO3 | 国际标准 | 完全开放，tag体系成熟 |

**原作者态度光谱：**
- 🟢 支持型：鼓励同人创作（大部分网文作者/部分影视版权方）
- 🟡 中立型：不反对不鼓励（部分日系版权方）
- 🔴 抵制型：明确禁止+维权（极少数，如部分游戏公司早期态度）

**安全线：** 在国内平台发布同人时，务必标注"同人/衍生创作"，不冒充原创，不商业化盈利（除非获得授权）。

## 2. 四大源媒介同人详解

### 2.1 影视同人

影视同人是覆盖面最广的同人类型——从国产古装到好莱坞大片，从韩剧到日剧，影视作品天然提供了高辨识度的角色和强烈的戏剧冲突。

#### 2.1.1 国产剧同人

**热门IP分类与创作方向：**

**权谋/古装类：**
- 《琅琊榜》：梅长苏的复仇线之外，霓凰郡主视角/靖王视角/誉王翻盘if线
- 《庆余年》：范闲的现代知识在古代的降维打击/陈萍萍的暗线/五竹的AI视角
- 《长安十二时辰》：张小敬的前传/时间线限定推理同人

**悬疑/现实类：**
- 《狂飙》：高启盛重生线/安欣与高启强的另一种可能/2000年时间线续写
- 《漫长的季节》：王响的平行人生/龚彪if线

**古偶/言情类：**
- 《长相思》：相柳线深度展开/涂山璟视角/防风邶的前传故事
- 《苍兰诀》：东方青苍的魔界日常/长珩仙君的独立线
- 《星汉灿烂》：凌不疑的战场回忆/程少商的经商if线

**国产剧同人创作要点：**

1. **演员形象vs角色形象的区分**
   - 读者脑海中的角色往往与演员形象绑定，这是双刃剑
   - ✅ 利用：借用演员的气质特征丰富角色描写（"那双深邃的眼眸"）
   - ❌ 避免：将演员的现实经历/人设混入角色（"他私下其实很逗"）
   - ⚠️ 红线：绝不能写涉及演员本人的暧昧内容，只能写角色

2. **国产剧特有的叙事节奏**
   - 电视剧节奏偏慢，同人可以压缩节奏或反向延展
   - 大量"名场面"可以作为同人的锚点事件
   - 广电审核下的留白（感情线/权力暗线）是同人的天然金矿

3. **历史文化考据**
   - 古装剧同人需要基本的朝代常识
   - 不要用现代网络用语直接套入古装语境
   - 官职/礼仪/称谓要大致准确

**模板——国产古装剧同人开头：**
```
[季节+天气+场景] → [角色独处/两人场景] → [触及原著某个未解之谜或情感空白] → [引入本篇的核心what-if]
```

#### 2.1.2 韩剧同人

**热门韩剧同人方向：**

- 《鱿鱼游戏》：成奇勋的赛后人生/456号玩家的平行选择/幕后组织前传
- 《黑暗荣耀》：文东恩复仇后的重建生活/河道英视角/朴妍珍的崩塌侧写
- 《爱的迫降》：利正赫的首尔生活if线/两国关系的平行宇宙
- 《鬼怪》：鬼怪与新娘的千年之后/地狱使者的新任务

**韩剧同人特色：**
- 韩剧强于情感张力，同人应延续这种"含蓄而浓烈"的情感风格
- 韩剧常用"命运/宿命"母题，同人可以挑战或深化这个母题
- 注意韩国社会文化背景（财阀/军营/前后辈关系）

#### 2.1.3 美剧/西方影视同人

**热门IP与创作方向：**

- **漫威MCU**：最大影视同人池之一。钢铁侠死后时间线/洛基的TVA冒险/冬兵的意识恢复/黑寡妇的红房子前传
- **DC宇宙**：蝙蝠侠的哥谭日常/小丑的起源深度/超人的小镇回忆
- **权游**：剧终后的续写/小说未完结线的延伸/龙妈if线
- **指环王**：精灵视角/矮人冒险/第四纪元故事
- 《怪奇物语》：十一的大学生活/颠倒世界起源

**美剧同人创作要点：**
- 英文名+中文叙述是常见模式，但要保持一致性
- 西方文化背景需基本准确（称呼/社交习惯/法律体系）
- 漫威DC的"多元宇宙"概念为AU提供了天然的合法性

#### 2.1.4 影视同人通用技法

**"名场面再解读"法：**
选取原作中一个经典场景，从不同角度重新叙述——换一个角色视角、加入内心独白、延长场景的时间跨度。

**"时间线暗面"法：**
原作没有交代的时间段是同人的黄金矿脉。角色成长过程中的空白期、两个事件之间的日常、剧终后的生活。

**"演员-角色双层"处理原则：**
```
第一层：角色本身（性格/经历/关系）——同人的核心素材
第二层：演员气质（外形特征/表演风格）——可以借用来丰富描写
红  线：演员本人（现实经历/私人生活）——绝对不可触及
```

### 2.2 游戏同人

游戏同人的独特挑战在于：游戏是互动媒介，小说是线性叙事。如何把"玩家操控的角色"变成"有血有肉的角色"，是游戏同人的核心课题。

#### 2.2.1 二次元/手游同人

**原神同人：**
- 角色池极深，CP组合丰富（钟离×公子/甘雨×刻晴/散兵×草神等）
- 提瓦特大陆的"旅途"结构天然适合同人续写
- 每个国家的文化背景（璃璃=中华/稻妻=日本/枫丹=法国）提供了丰富的世界观素材
- **游戏机制转叙事技巧：**
  - ❌ "他切了一下角色就从甘雨变成了胡桃" → ✅ "风起时，她手中的弓化作了护摩之杖"
  - ❌ "他吃了一个甜甜花酿鸡回了5000血" → ✅ "他咬了一口温热的料理，伤口的灼痛感逐渐消退"
  - 元素反应可以转化为战斗中的协同/羁绊描写

**崩坏：星穹铁道同人：**
- 星际列车的旅途结构→公路片叙事
- 角色间的列车日常→轻喜剧同人
- 命途系统→哲学/命运主题的深度挖掘
- 不同星球的文化→丰富的AU素材

**明日方舟同人：**
- 泰拉大陆的世界观极其庞大（源石/感染者/各国政治）
- 博士身份的模糊性→极佳的"空白主角"同人素材
- 干员档案中的故事碎片→细节丰富的二创来源
- **注意：** 方舟的设定考据门槛较高，需要仔细阅读档案

**Fate系列同人：**
- 圣杯战争→多角色博弈的群像剧
- 英灵召唤→跨时代角色的梦幻联动
- 月球史观→极度硬核的世界观设定（需要大量考据）
- **经典方向：** 第四次圣杯战争的另一个Master/英灵的前世故事/迦勒底日常

#### 2.2.2 主机/PC游戏同人

**艾尔登法环同人：**
- 交界地的世界观碎片化叙事→需要同人来"串联"
- 褪色者的旅程→英雄叙事的经典模板
- Boss的故事线（玛莲妮亚/拉塔恩/菈妮）→独立短篇
- **关键技巧：** 魂系游戏的"留白"是同人最大的宝库，但考据必须严谨

**黑神话悟空同人：**
- 西游记原著+游戏改编的双重素材
- 天命人的"轮回"设定→时间循环同人
- 各妖王的前传故事→反派视角同人
- **文化考据：** 必须同时参考西游记原著和游戏设定，两者有差异时需声明

**其他热门游戏：**
- 《塞尔达》：林克×塞尔达的各时代版本/海拉鲁日常
- 《巫师》：杰洛特的猎魔人日常/叶奈法vs特莉丝
- 《只狼》：回生系统的叙事化/苇名国的落幕

#### 2.2.3 游戏机制转小说叙事的通用技巧

**核心原则：玩家操作 → 角色行动**

| 游戏机制 | 小说化的处理方式 | 示例 |
|----------|------------------|------|
| 切换角色 | 视角切换/队伍同行的不同位置 | 不写"切换"，写"她将弓收起，拔出了长枪" |
| 存档/读档 | 记忆/时间回溯/梦境 | 不写"读档"，写"他从噩梦中惊醒，发现一切还未发生" |
| 血条/状态栏 | 体感描述（疼痛/疲惫/恢复） | 不写"HP还剩30%"，写"每一次呼吸都带着肋骨的钝痛" |
| 抽卡/掉落 | 意外获得/机遇/命运 | 不写"他十连出了金"，写"那道光芒太过耀眼，他知道里面的东西非同寻常" |
| 任务系统 | 目标/使命/承诺 | 不写"接了支线任务"，写"酒馆里的老人用颤抖的声音请求他找回孙女" |
| 升级 | 突破/顿悟/修炼 | 不写"升到60级"，写"体内的力量像是突破了某层桎梏，奔涌而出" |

**游戏→同人的叙事公式：**
```
[游戏中的一个场景/机制] → [剥离UI和数值] → [转化为角色的感官体验] → [加入内心活动和环境描写] → [融入叙事流]
```

### 2.3 小说同人

小说同人是最"纯粹"的同人类型——源文本和目标文本都是文字，不存在媒介转换问题，但面临的挑战是：如何在另一个作者已经构建精良的文字世界中，写出不逊色于原作的文字。

#### 2.3.1 起点热门IP同人

**玄幻/仙侠类：**
- 《斗破苍穹》：药老前传/美杜莎if线/萧炎的另一条修炼路
- 《斗罗大陆》：唐三前世/武魂殿视角/不同武魂觉醒的平行线
- 《遮天》：叶凡离开后的北斗星域/黑暗动乱的另一面
- 《凡人修仙传》：韩立的凡人视角日常/配角的修仙传记
- 《完美世界》：石昊的另一种成长/仙古纪元的详细展开

**起点同人创作要点：**
- 起点读者对"爽感"要求极高，同人也不能例外
- 需要深读原作，掌握"力量体系"的完整逻辑
- 起点同人的"金手指叠加"很常见（给同人主角加系统/老爷爷）
- **注意：** 不能写崩原作主角的人气角色，容易被读者群攻

**起点热门IP的力量体系考据清单：**
```
斗破：斗之气→斗者→斗师→大斗师→斗灵→斗王→斗皇→斗宗→斗尊→半圣→斗圣→斗帝
斗罗：魂士→魂师→大魂师→魂尊→魂宗→魂王→魂帝→魂圣→魂斗罗→封号斗罗
遮天：苦海→命泉→天宫→四极→化龙→仙台→大圣→准帝→大帝
```

#### 2.3.2 番茄热门IP同人

**番茄平台热门同人方向：**
- 系统流小说的同人：给不同角色一个不同的系统
- 重生文同人：反派重生/配角重生/不同时间节点重生
- 赘婿文同人：反转身份/女主视角
- 神豪文同人：不同金手指的变体

**番茄同人的特点：**
- 节奏比起点更快，开篇3章内必须有爆点
- 读者容忍度较低，文字需要更直接
- 同人可以借用原作的"套路"但必须有差异化

#### 2.3.3 纵横/其他平台热门IP

- 《雪中悍刀行》：徐凤年的江湖日常/剑九黄的前传/北凉铁骑的群像
- 《剑来》：齐静春的来时路/陈平安的另一个人生/小镇的过去
- 《大奉打更人》：许七安的探案日常/不同朝代的打更人

#### 2.3.4 国外小说同人

**《魔戒》/托尔金世界：**
- 中土世界的历史跨度极大（数千年的编年史）→空白年表是同人金矿
- 精灵/矮人/人类的不同种族视角
- 第四纪元的故事（原著几乎没有涉及）
- **注意：** 托尔金遗产基金会对商业化同人管控严格

**《哈利·波特》：**
- 全球最大的同人社区之一（仅次于漫威）
- 经典方向：亲世代/下一代/黑魔王崛起时期/不同学院视角
- AU变体极其丰富（麻瓜AU/教授AU/食死徒AU）
- **近年来趋势：** 由于J.K.罗琳的争议言论，HP同人社区出现"去作者化"趋势

**《冰与火之歌》：**
- 马丁未完结→同人社区在"帮马丁写结局"
- 维斯特洛的家族政治→极其丰富的群像剧素材
- 电视剧结局争议→大量"修正"同人

#### 2.3.5 不同平台原作风格适配

| 原作平台 | 风格特点 | 同人文的适配要点 |
|----------|----------|------------------|
| 起点 | 爽文节奏/升级打怪/宏大叙事 | 保留爽感，补充情感线和日常 |
| 番茄 | 快节奏/直白/打脸逆袭 | 节奏可以稍缓但不能拖，保留"爽点密度" |
| 晋江 | 情感细腻/CP向/文笔讲究 | 文笔需要跟上原作水平，情感线是核心 |
| 纵横 | 偏传统/硬核/体系完整 | 世界观考据必须严谨，不能出现体系bug |
| 国外 | 设定丰富/叙事多元/文风各异 | 翻译腔需要统一，文化背景需考据 |

### 2.4 动漫同人

动漫同人是整个同人文化的"起源地"和最大阵地。由于已有专门的ACG同人创作技能（`expert-acg-fanfic`），本章节不做重复展开，而是提供与ACG技能的联动指引和补充内容。

#### 2.4.1 与expert-acg-fanfic的分工

```
expert-acg-fanfic：ACG领域（动画/漫画/轻小说/Galgame）的深度专项
├── 日系动画同人的详细技法
├── 漫画同人的分镜→文字转换
├── 轻小说同人的风格模仿
├── Galgame同人的多线叙事
└── ACG领域的CP处理专精

expert-fanfic-universal（本技能）：全媒介同人创作的通用框架
├── 跨媒介改编的通用技法
├── 非ACG源材料的同人创作
├── ACG同人与影视/游戏/小说同人的联动
├── 通用的OOC防控/AU设计/时间线管理
└── 各平台（国内为主）的同人适配
```

**使用建议：** 创作ACG同人时，先阅读`expert-acg-fanfic`获取领域专项知识，再参考本技能的通用技法章节补充跨媒介视角。

#### 2.4.2 ACG同人的跨媒介联动

许多热门ACG作品同时拥有动画、游戏、小说、影视改编版本。同人创作可以利用这种"多版本"优势：

**联动方向：**
- 动画版的角色设计 + 游戏版的战斗系统 + 小说版的内心描写 = 丰富立体的同人
- 不同改编版本之间的差异本身就是AU的素材
- 例：《鬼灭之刃》动画的华丽战斗 + 漫画的简洁叙事 + 游戏的招式设定

#### 2.4.3 ACG同人特别注意事项

1. **画风差异的处理：** 不同动画化公司的画风差异可能导致角色"感觉"不同，同人需要选择一个锚定版本
2. **声优效应：** 日本声优文化深入人心，角色的声音形象也是同人素材的一部分（但不能混入声优本人的内容）
3. **中日同人文化差异：** 日本同人以"社团→即卖会"模式为主，中国同人以"网络平台→订阅/打赏"模式为主
4. **翻译同人的二次创作：** 基于翻译作品的同人需要考虑翻译版本的差异
