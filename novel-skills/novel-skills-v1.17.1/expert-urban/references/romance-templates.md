# 都市言情五大模板

## 豪门恩怨（Family Dynasty）

**核心公式：** 身份差距 × 家族利益 × 真爱考验

**结构模板：**
```
身份揭示 → 豪门规则冲突 → 家族内部站队 → 商战/阴谋线 → 误会与分离 → 真相大白 → 共同面对
```

**必备元素：**
- 恶婆婆/恶公婆（读者情绪靶子）
- 门当户对压力（社会现实共鸣）
- 家产争夺战（多线冲突）
- 白月光/前女友搅局（情感波折）
- 身份反转（隐藏的豪门血脉）

**人物配置：**
| 角色 | 功能 | 塑造要点 |
|------|------|----------|
| 女主 | 观众代入体 | 不卑不亢，有底线有温度 |
| 男主 | 欲望投射体 | 霸道但不油腻，强势但懂尊重 |
| 恶婆婆 | 情绪催化剂 | 有合理动机，非纯恶 |
| 女二 | 竞争对手 | 让读者"又恨又理解" |
| 男二 | 暖心备胎 | 付出型人格，读者心疼但知道不会在一起 |

## 职场爱情（Office Romance）

**核心公式：** 能力认可 × 上下级禁忌 × 共同成长

**职场线与感情线交叉节奏：**
```
初入职场 → 工作交集（感情暗线启动）→ 职场危机（被迫合作）→ 感情升温 → 职场冲突（被发现/被阻挠）→ 职业选择与感情抉择 → 双线收束
```

**关键场景库：**
- 加班深夜独处（暧昧环境）
- 出差双人房（突破关系的催化剂）
- 项目竞争（亦敌亦友）
- 被甲方刁难时的互相维护
- 升职竞争中的克制与牺牲

**行业选择建议（2024-2026热门）：**
- 互联网/科技公司（读者群最大）
- 医疗/医院（生死场景天然戏剧性）
- 金融/投行（高端感+高压感）
- 娱乐圈/影视（自带话题性）
- 律所/法院（案件线+感情线双驱动）

## 青梅竹马（Childhood Sweethearts）

**核心公式：** 时间厚度 × 习惯性忽视 × 失去才懂珍惜

**三幕结构：**
```
第一幕·习惯：从小一起长大，对方的存在如同空气
第二幕·觉醒：第三方介入触发占有欲觉醒
第三幕·确认：经历分离/误会后确认心意
```

**虐点设计：**
- "我只把你当朋友/妹妹/哥哥" —— 经典杀伤力台词
- 青梅竹马的另一半出现 → 主角被迫退出
- 搬家/出国/转学导致分离 → 时间线跳转后重逢
- 一方暗恋多年另一方浑然不知 → 读者上帝视角的揪心感

**现代创新：** 从幼儿园到大学的超长线铺垫 / 双方父母是好友 / 童年约定被翻出

## 破镜重圆（Second Chance）

**核心公式：** 曾经深爱 × 不可抗力分手 × 再次相遇

**分手原因库：**
1. 现实压力（异地/家庭反对/经济差距）
2. 误会（第三方介入造成的误解）
3. 成长差异（人生规划不同步）
4. 外部阻挠（父母干预/工作调动）
5. 自身原因（年轻不成熟/逃避型人格）

**重逢后的心理博弈阶段：**
```
假装不在意 → 刻意回避 → 被迫接触 → 旧情复燃 → 回忆闪回 → 解开当年心结 → 重新在一起
```

**关键——"心结还原"：** 必须正面处理当年分手的真正原因，双方都要有成长/改变。

## 先婚后爱（Marriage First, Love After）

**核心公式：** 契约/利益婚姻 × 日久生情 × 假戏真做

**起因设置：** 家族联姻 / 冲喜冲运 / 假结婚骗家长 / 合同婚姻换利益 / 闪婚冲动

**感情发展四阶段：**
```
Phase 1 · 同居尴尬：各过各的，互不干涉
Phase 2 · 生活渗透：习惯对方的存在
Phase 3 · 嫉妒觉醒：对方被追求时占有欲爆发
Phase 4 · 假戏真做：一次契机打破界限
```

**高甜场景模板：**
- 生病照顾（日常关怀的心动瞬间）
- 被迫一起见家长（配合演出中的真情流露）
- 朋友圈互动暴露关系
- 睡觉时无意识的靠近
- 吃醋后的冷战与和好
