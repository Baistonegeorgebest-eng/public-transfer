# 都市题材经典技法补全

## 卡章术（Cliffhanger Mastery）

在每一章结尾制造悬念，迫使读者继续阅读。

| 编号 | 技法 | 示例 |
|------|------|------|
| 01 | 门卡 | "他推开门，看到了不该看到的人——" |
| 02 | 电话卡 | "手机响了，来电显示让他瞳孔一缩——" |
| 03 | 真相卡 | "她终于说出了那个秘密，他的世界在这一刻崩塌。" |
| 04 | 选择卡 | "他必须在三十秒内做出选择：左边是她，右边是整个公司。" |
| 05 | 反转卡 | "所有人都以为他输了。但他的嘴角，微微上扬。" |
| 06 | 回忆卡 | "这个场景，他在梦里见过无数次。每次都以同样的方式结束。" |
| 07 | 倒计时卡 | "距离炸弹引爆，还有最后十秒。" |
| 08 | 人物卡 | "来人走进会议室，全场起立。因为他是——" |
| 09 | 信息卡 | "邮件只有一行字：'我知道你重生了。'" |
| 10 | 情感卡 | "她转身离开的那一刻，他终于知道什么叫心如刀割。" |
| 11 | 战斗卡 | "对手亮出了底牌。他发现自己的能力在对方面前一文不值。" |
| 12 | 日常卡 | "下班回家，发现门口站着一个他以为这辈子再也见不到的人。" |

## 打脸节奏学

**打脸三要素：**
1. **铺垫压抑** —— 先让对手嚣张，读者积攒怒气值
2. **反转时机** —— 在读者忍耐极限时反转
3. **围观放大** —— 必须有第三方见证者

**打脸升级路径：**
```
Level 1: 语言打脸（一句话反驳）→ 快餐级爽感
Level 2: 能力打脸（用实力证明）→ 满足级爽感
Level 3: 格局打脸（用眼界碾压）→ 高级爽感
Level 4: 命运打脸（用结果说话）→ 封神级爽感
```

**频率控制：**
- 番茄文：每3-5章一次打脸
- 起点文：每10-15章一次大打脸
- 晋江文：打脸转化为"用魅力征服"

## 信息差叙事术

利用读者/角色之间的信息不对称制造悬念和戏剧效果。

**三种信息差：**
1. **读者全知，角色不知** —— 制造"快跑！"的紧张感
2. **角色全知，读者不知** —— 制造"原来如此"的揭秘感
3. **角色A知道，角色B不知道** —— 制造戏剧冲突和误会

**经典用法：**
- 重生者知道未来但不能说
- 主角隐藏真实身份（扮猪吃虎）
- 读者知道男主在吃醋但男主自己不承认

## 多线叙事编织术

**都市文至少需要两条线：**
- **主线：** 事业/能力成长线（驱动剧情前进）
- **感情线：** CP发展线（驱动情感投入）

**双线交织节奏：**
```
章节N: 主线推进（事业冲突）
章节N+1: 感情线推进（心动/误会/靠近）
章节N+2: 主线与感情线交汇
章节N+3: 感情线回响反作用于事业
```

**三线模式（进阶）：** 主线 + 感情线 + 家族/阴谋线，每隔3-5章交替推进，大高潮时三线汇合。

## 情绪节拍器

控制读者情绪起伏，确保阅读体验不单调。

**情绪波形设计：**
```
爽 → 爽 → 虐 → 爽 → 甜 → 虐 → 大爽 → 甜 → 虐 → 超大爽
```

| 情绪 | 功能 | 频率 |
|------|------|------|
| 爽（打脸/逆袭/升级） | 核心吸引力 | 50% |
| 甜（感情进展/温馨） | 情感粘合剂 | 20% |
| 虐（分离/误会/失去） | 情感深度 | 15% |
| 紧张（危机/对决） | 节奏推动 | 10% |
| 搞笑（日常/吐槽） | 调节呼吸 | 5% |

**铁律：** 虐完必须给甜，爽完可以给紧张，永远不要连续两章纯虐。

## 金句锻造术

**金句类型：**
1. **反差型：** "他说他只是个送外卖的。没人知道，他送的每一份外卖都在改变这个行业的格局。"
2. **哲理型：** "这座城市的每一盏灯背后，都有一个不敢回家的人。"
3. **情感型：** "她以为自己只是习惯了他的存在。直到他真的离开，她才发现，习惯是最可怕的深爱。"
4. **打脸型：** "三年前你说我不配。三年后，我让你高攀不起。"
5. **意境型：** "他站在天台边缘，看着这座曾让他一无所有的城市。风很大，但他的心前所未有的平静。"

**锻造公式：** `[对比/反转] + [具体意象] + [情感落点]`
