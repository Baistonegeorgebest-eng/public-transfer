## 核心分类速查

| 类型 | 核心恐惧源 | 读者体验 | 适合平台 |
|------|-----------|---------|---------|
| 规则怪谈 | 未知规则与逻辑陷阱 | "动脑子" | 番茄/知乎 |
| 无限流恐怖 | 死亡压力与副本探索 | "追着看" | 番茄/起点 |
| 民俗恐怖 | 传统文化中的禁忌 | "出冷汗" | 起点/番茄 |
| 克苏鲁 | 宇宙级的渺小与疯狂 | "想很多" | 起点 |

## 氛围营造核心

### 环境暗示四要素
恐怖不靠描写"有多可怕"，靠描写"有什么不对"。**异常藏在正常之中。**

1. **空间异常**：多了一扇门、少了一级台阶、走廊变长了
2. **时间异常**：表慢了/快了、天突然黑了、重复的日期
3. **感官异常**：闻到不该有的气味、听到不该有的声音
4. **记忆异常**：记不清某件事、记忆与现实矛盾

### 节奏模板
恐怖的节奏是"松→紧→松→更紧"，不是一直紧。

| 段落 | 占比 | 内容 |
|------|------|------|
| 铺垫段 | 60% | 正常生活+微小异常 |
| 攀升段 | 25% | 异常加剧+恐惧累积 |
| 爆发段 | 15% | 直面恐惧+情绪释放 |

**铁律：** 铺垫段要够长→读者越放松，爆发时冲击越大。章末必须留钩子。

## 规则怪谈速查

### 三层规则体系
1. **表面规则**：玩家直接获得的规则条目（可能是假的）
2. **隐藏规则**：需要通过观察和推理发现的规则
3. **底层规则**：世界运行的终极法则（通常到最后才揭示）

### 设计七步法
1. 确定核心恐惧 → 2. 设计违规后果 → 3. 写表面规则(6-10条) → 4. 埋隐藏规则 → 5. 设计规则陷阱(至少1条假的) → 6. 安排发现过程 → 7. 设计破解爽感

### 爽感三阶段
1. **困惑期**：规则太多记不住，主角处处碰壁
2. **顿悟期**：发现某条规则的真正含义，恍然大悟
3. **掌控期**：利用规则反杀/逃脱，智商碾压的快感

## 无限流速查

### 副本难度曲线
新手副本(建立规则) → 成长副本(逐步加难) → 困难副本(生死抉择) → 地狱副本(制造高潮)

### 死亡规则三原则
1. **规则明确**：读者需要知道什么会导致死亡
2. **不可逆性**：死亡是真的，不能随便复活
3. **可规避性**：遵守规则可以避免死亡

## 避坑指南

| 坑 | 解决 |
|----|------|
| 恐怖=恶心 | 用暗示和氛围制造恐惧，删除血腥描写后恐怖感应依然存在 |
| Jump Scare滥用 | 氛围铺垫3000字+一次jump scare=有效；连续=无效 |
| 主角降智 | 恐惧中做出看似不理性但有心理依据的决定 |
| 世界观前后矛盾 | 建立规则后严格遵守，例外需要有解释 |
| 全程高压 | 恐怖+日常交替，用日常对比放大恐怖 |

→ 详见 [references/cases-pitfalls.md](references/cases-pitfalls.md)（实战案例+节奏控制表+完整避坑指南）

## 恐怖创作终极检查清单

- [ ] 异常是否藏在正常之中（而非直白描写）？
- [ ] 铺垫篇幅是否足够（≥50%）？
- [ ] 每章末尾是否有钩子？
- [ ] 怪物是否保留了未知（不露全貌）？
- [ ] 规则是否有矛盾+有解？
- [ ] 节奏是否有松有紧（非全程高压）？
- [ ] 恐怖感是否来自氛围而非血腥？
- [ ] 平台适配是否正确？
