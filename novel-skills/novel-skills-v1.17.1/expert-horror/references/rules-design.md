# 规则怪谈专项设计

## 规则设计逻辑

规则怪谈的核心是"规则即世界"——规则就是这个世界运行的底层逻辑。

## 三层规则体系

1. **表面规则**：玩家直接获得的规则条目（可能是假的）
2. **隐藏规则**：需要通过观察和推理发现的规则
3. **底层规则**：世界运行的终极法则（通常到最后才揭示）

## 规则设计七步法

1. **确定核心恐惧**：这个怪谈要让读者怕什么？
2. **设计违规后果**：违反规则会怎样？要有层次感
3. **写表面规则**：6-10条，每条简短明确
4. **埋隐藏规则**：在规则之间制造矛盾
5. **设计规则陷阱**：至少1条规则是假的
6. **安排发现过程**：主角如何发现隐藏规则
7. **设计破解爽感**：弄懂规则→利用规则→掌控规则的升级感

## 规则矛盾陷阱设计

### 矛盾类型
- **直接矛盾**：规则A说"不要开灯"，规则B说"必须保持灯光"
- **隐含矛盾**：遵守规则A的过程中必然违反规则B
- **时间矛盾**：白天的规则和晚上的规则互相冲突
- **身份矛盾**：不同身份的人适用不同规则

### 设计技巧
- 矛盾不能太明显——要让读者和主角一起发现
- 矛盾要有解——不能是死局
- 解法要优雅——利用规则的字面意思钻空子
- 破解矛盾是最大的爽点

## 规则破解的爽感设计

### 爽感三阶段
1. **困惑期**：规则太多记不住，主角处处碰壁
2. **顿悟期**：发现某条规则的真正含义，恍然大悟
3. **掌控期**：利用规则反杀/逃脱，智商碾压的快感

## 规则怪谈设计模板

```
【怪谈名称】：
【场景设定】：
【进入条件】：
【离开条件】：

【表面规则】（7-10条）：
1. （明确的安全规则）
2. （明确的安全规则）
3. （看似安全实际有陷阱的规则）
4. （明确的安全规则）
5. （与其他规则矛盾的规则）
6. （明确的安全规则）
7. （隐藏真实含义的规则）

【隐藏规则】（2-3条，需要推理发现）：

【底层规则】（1条，核心法则）：

【矛盾点】：
- 规则X与规则Y矛盾，真实含义是...
- 违反了规则Z但没有受到惩罚，原因是...

【通关路径】：
主角如何发现矛盾→推理真相→利用规则逃脱
```

## 自检清单

- [ ] 表面规则是否有至少1条是假的？
- [ ] 规则之间是否有至少1处矛盾？
- [ ] 矛盾是否可以被推理发现（不是死局）？
- [ ] 底层规则是否能解释所有表面规则？
- [ ] 通关路径是否优雅（利用规则的字面意思）？
- [ ] 违规后果是否有层次感（警告→惩罚→死亡）？
