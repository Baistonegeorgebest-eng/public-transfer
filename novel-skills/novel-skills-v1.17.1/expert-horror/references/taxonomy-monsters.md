## 六大子类型定义

| 类型 | 核心恐惧源 | 代表作品 | 核心卖点 |
|------|-----------|---------|---------|
| 规则怪谈 | 未知规则与逻辑陷阱 | 《怪谈规则》《动物园怪谈》 | 规则破解的智力爽感 |
| 无限流恐怖 | 死亡压力与副本探索 | 《全球高武》恐怖向副本 | 副本新鲜感+队伍成长 |
| 民俗恐怖 | 传统文化中的禁忌 | 《茅山后裔》《我当道士那些年》 | 文化认同+未知恐惧 |
| 克苏鲁 | 宇宙级的渺小与疯狂 | 《诡秘之主》恐怖元素 | 认知颠覆+存在焦虑 |
| 都市怪谈 | 现代生活中的异常 | 《深夜书屋》《鬼吹灯》 | 就在身边的恐惧 |
| 末日恐怖 | 生存压力与人性黑暗 | 《末日蟑螂》 | 绝境求生+人性拷问 |

## 恐怖 vs 悬疑的核心差异

**恐怖靠情绪，悬疑靠逻辑。** 这是最根本的区别。

- **悬疑**：读者在推理——"凶手是谁？""动机是什么？"→ 满足感来自逻辑闭环
- **恐怖**：读者在恐惧——"那是什么？""它要过来了？"→ 满足感来自情绪释放

**关键区分：**
- 悬疑的高潮是"真相大白"——谜底揭开，读者恍然大悟
- 恐怖的高潮是"直面恐惧"——主角对抗未知，读者心跳加速
- 最好的作品是恐怖+悬疑融合：用悬疑的钩子拉着读者走，用恐怖的氛围裹住读者

## 选型决策树

```
你想写什么类型的恐怖？
├─ 想让读者"动脑子" → 规则怪谈 / 克苏鲁
├─ 想让读者"出冷汗" → 民俗恐怖 / 都市怪谈
├─ 想让读者"追着看" → 无限流恐怖
└─ 想让读者"想很多" → 末日恐怖 / 克苏鲁
```

## 怪物与异常实体设计

### 核心原则：未知 > 已知

**铁律：不露全貌 > 露全貌。** 读者想象力制造的恐惧，永远比你写出来的更恐怖。

**设计原则：**
1. **永远保留未知**：即使到结局，异常实体也不应该被完全解释
2. **局部描写**：只描写一部分——一双眼睛、一只手、一个影子
3. **反应描写**：通过角色的反应侧面烘托——比直接描写更有效
4. **声音和痕迹**：脚步声、抓痕、血迹——暗示存在而不直接出现

### 怪物类型学

| 类型 | 特征 | 恐怖机制 | 示例 |
|------|------|---------|------|
| 实体型 | 有物理形态 | 追逐恐惧、暴力威胁 | 丧尸、异形 |
| 规则型 | 以规则运作 | 逻辑恐惧、认知颠覆 | 鬼打墙、规则怪谈 |
| 认知型 | 知道即危险 | 知识恐惧、精神崩溃 | 克苏鲁旧日支配者 |
| 空间型 | 空间本身异常 | 环境恐惧、无处可逃 | 异次元、鬼域 |
| 时间型 | 时间异常 | 宿命恐惧、循环绝望 | 时间循环、预言 |
