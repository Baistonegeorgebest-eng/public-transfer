# 无限流恐怖专项设计

## 副本设计框架

### 副本四要素
1. **世界观**：每个副本有独立的规则和背景
2. **目标**：存活/通关/找到某物/击败BOSS
3. **限制**：时间限制、能力限制、人数限制
4. **奖励**：通关奖励是持续追读的动力

### 副本难度曲线
- 新手副本：建立规则认知，中等难度
- 成长副本：逐步加难，主角通过成长应对
- 困难副本：主角面临生死抉择
- 地狱副本：几乎不可能通关，制造高潮

## 死亡规则设计

### 三原则
1. **规则明确**：读者需要知道什么会导致死亡
2. **不可逆性**：死亡是真的，不能随便复活
3. **可规避性**：遵守规则可以避免死亡

### 常见死亡触发条件
- 违反副本规则
- 时间耗尽
- 被BOSS/怪物捕获
- 队友背叛
- 精神值归零

## 队伍配置模板

```
【核心配置】（3-5人）：
- 领队：决策力强，负责分析规则和制定策略
- 战力：武力担当，负责对抗实体威胁
- 智囊：逻辑推理，负责破解规则谜题
- 辅助：特殊能力（治疗/感知/沟通），负责支援
- 新人/隐藏大佬：制造反差和悬念

【队伍动态】：
- 信任危机：谁可能是内鬼/被控制
- 能力互补：没人能单独通关
- 牺牲抉择：必要时需要有人殿后
```

## BOSS设计

### BOSS类型
- **规则型BOSS**：本身就是一个规则的化身，需要用规则打败
- **实体型BOSS**：有物理形态，需要战斗或逃跑
- **认知型BOSS**：精神污染，需要意志力对抗
- **空间型BOSS**：BOSS就是这个空间本身
