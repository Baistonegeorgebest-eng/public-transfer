# 意象与氛围系统

## 留白技法详解

### 留白的五种类型

| 类型 | 做法 | 示例 |
|------|------|------|
| 省略结果 | 不写事件的结果 | "她问了他一个问题。他没有回答。" |
| 省略对话 | 不写说了什么 | "他在电话里说了很多话。挂了电话之后，她坐在沙发上，一直到天黑。" |
| 省略内心 | 不写角色怎么想 | "她把结婚戒指放在桌上，走了。" |
| 省略原因 | 不写为什么 | "那天之后，他再也没去过那家咖啡店。" |
| 省略结局 | 不写最终如何 | "他站在机场大厅里，看着那块显示屏上的航班信息。" |

### 半留白原则

> ❌ 全藏："他知道了。"（知道什么？）
> ❌ 全说："他知道她得癌症了，活不过三个月，但她一直瞒着他。"
> ✅ 半留白："他翻到了那张诊断书。日期是四个月前的。"

## 通感系统

### 使用频率
在文学性写作中，**每1000字使用1-2次通感**是舒适的密度。过多会让读者觉得你在"炫技"。

## 以景写情高级版

### 景物与情感对应系统

| 景物 | 可以承载的情感 | 用法注意事项 |
|------|--------------|------------|
| 雨 | 悲伤、告别、思念、洗刷 | 别每段悲伤都下雨 |
| 雪 | 孤寂、纯洁、死亡、掩埋 | 雪的"覆盖"意象适合写"遗忘" |
| 月亮 | 思念、孤独、永恒 | 非节日用月亮才有文学感 |
| 夕阳 | 终结、回忆、辉煌后的衰落 | 适合写关系/时代结束 |
| 花落 | 无常、美之易逝、青春 | 注意文化匹配 |
| 老屋/废墟 | 记忆、时间、衰败 | 写"回去"的场景必备 |
| 火 | 希望、毁灭、温暖、激情 | 小火=温暖，大火=毁灭 |
| 水/河/海 | 时间流逝、距离、分离 | "隔河相望"=永远无法到达 |

### "以景写情"的正确用法

> ✅ "雨把他的眼镜打花了。他索性摘掉眼镜，世界一下子模糊了。也好。"

景物的功能是**提供一个触发情感变化的物理事件**，而不是直接"象征"某种情感。

## 色彩与光线

### 文学性色彩词汇

| 基础色 | 文学性替代 | 情感暗示 |
|--------|-----------|---------|
| 红 | 绯红、殷红、绛红、朱砂色 | 少女面颊、血迹、深沉、记忆 |
| 蓝 | 靛蓝、藏蓝、灰蓝、月白 | 深沉、庄重、忧郁、清冷 |
| 绿 | 青绿、苍翠、墨绿、苔色 | 生机、远山、深沉、时间 |
| 白 | 霜白、银白、象牙、月白 | 寒冷、光泽、温暖、冷寂 |
| 黑 | 墨色、鸦青、玄色、炭灰 | 沉重、发色、尊贵、疲惫 |
| 黄 | 杏黄、枯黄、金色、昏黄 | 温暖、衰败、辉煌、暮年 |

### 光线的情感语法

| 光线类型 | 情感暗示 |
|---------|---------|
| 晨光 | 希望、开始 |
| 正午阳光 | 压迫、无所遁形 |
| 夕照 | 终结、回忆、温暖的消逝 |
| 月光 | 冷寂、思念、宁静 |
| 烛光 | 温暖、脆弱、时间 |

## 声音与寂静

### 寂静的高级写法

寂静不是"没有声音"，寂静是一种**有重量的存在**：

> "图书馆安静极了。翻书的声音像是一声惊雷。"

通过夸张"翻书"的声音来强调环境的安静。

> "他们坐在车里，谁也不说话。发动机的声音、轮胎碾过路面的声音、空调的嗡嗡声——这些平时根本注意不到的声音，在沉默中变得无比清晰。"
