## 〇、人味生成过程审计（核心·每次写章必执行）

### 核心理念

```
旧定位：写完 → 检查AI味 → 修改  ← 事后补救，效果有限
新定位：写时 → 审计人味注入 → 确认到位  ← 过程控制，从源头保证

人味 = 犹豫 + 浪废 + 缺陷 + 个性 + 噪音
```

### 审计执行时机

在 novel-volume-workflow Phase 3 的 Post-Write 链路中，本skill在 expert-writing-safety 之后执行，替代旧的事后去AI味检查。

### 人味指数五维度评估

每章写完后，从五个维度评估人味注入情况：

```
┌────────────────────────────────────────────────────┐
│ 人味审计报告 ChXX                                    │
├────────────────────────────────────────────────────┤
│                                                    │
│ ① 犹豫分（0-5）                                     │
│   □ 有没有碎片化表达/省略号/说一半没说完？            │
│   □ 有没有"不知道怎么说"类含糊地带？                  │
│   □ 有没有犹豫后放弃的表达？                          │
│   → 5分：至少3处    3分：1-2处    0分：无            │
│                                                    │
│ ② 浪废分（0-5）                                     │
│   □ 有没有不推动剧情的细节？（抠指甲/灯泡不亮/味道）   │
│   □ 有没有旁枝逸出的联想？                            │
│   □ 有没有"没用但有趣"的对话？                        │
│   → 5分：至少3处    3分：1-2处    0分：无            │
│                                                    │
│ ③ 缺陷分（0-5）                                     │
│   □ 有没有粗糙句子？（明显没打磨的、赶工的）           │
│   □ 有没有语言失败？（口误/打断/话没说完）             │
│   □ 有没有结尾无收束？                                │
│   → 5分：至少2处    3分：1处    0分：无              │
│                                                    │
│ ④ 个性分（0-5）                                     │
│   □ 不看说话人能分辨谁在说话？（语言DNA卡）            │
│   □ 有没有角色专属的口头禅/句式/禁区？                │
│   □ 有没有个人化的比喻？                              │
│   → 5分：全部角色有辨识度    3分：主要角色有    0分：无 │
│                                                    │
│ ⑤ 噪音分（0-5）                                     │
│   □ 有没有扰动注入？（novel-volume-workflow §3b）     │
│   □ 有没有节奏突变？（加速段/减速段/断裂点）           │
│   □ 有没有句式断裂？（不是每句都完整的主谓宾）         │
│   → 5分：扰动+节奏+断裂全有    3分：有1-2项    0分：无 │
│                                                    │
│ 总分：/25                                          │
│ 通过线：≥12分（≥4.8均分）                            │
│ 红线：任何单维度0分 → 立即重写该维度对应段落           │
└────────────────────────────────────────────────────┘
```

### 审计失败处理

```
总分 < 12分 或 任何维度0分：
1. 定位人味缺失的具体段落
2. 针对性补充（见下方补充指南）
3. 重新评估
4. 不通过不得输出给用户

补充指南：
- 犹豫不足 → 在对话中加省略号/打断/含糊表达
- 浪废不足 → 插入1-2个不推动剧情的细节（谁在干什么闲事）
- 缺陷不足 → 故意写一句粗糙的/让结尾无收束
- 个性不足 → 对照语言DNA卡重写角色对话
- 噪音不足 → 检查扰动注入是否执行，补入节奏变化
```

### 快速自检口诀

```
排比不过三，成语不连环。
不写"他感到"，改用动作演。
对话要带刺，说话不圆满。
环境写一感，别把五感全。
长句配短句，节奏要翻转。
角色各有嘴，一听能分辨。
比喻要接地气，别用"如诗如画"。
留白和跳跃，别把话说完。
```

## 一、AI味的本质（速查）

> 详细十大特征对比见 `references/ai-taste-10-features.md`

AI味是指AI生成文本中普遍存在的一种"过于正确、过于工整、过于干净"的质感。

**五大表现维度：**

| 维度 | 表现 | 比喻 |
|------|------|------|
| **结构工整** | 段落匀称、逻辑严密、起承转合一丝不苟 | 像教科书，不像小说 |
| **缺乏个性** | 没有作者的独特癖好、偏好、怪癖 | 像白开水，没有味道 |
| **句式单一** | 主谓宾结构反复出现，节奏平稳无波 | 像节拍器，没有音乐感 |
| **情感扁平** | 情绪描写模板化，愤怒=握拳+皱眉+大吼 | 像说明书，不像人话 |
| **逻辑过满** | 每件事都有交代，没有留白和暗示 | 像新闻报道，不像故事 |

## 二、去AI化检查清单（写完每章执行）

**段落级：**
- [ ] 有没有3句以上的排比？→ 打散
- [ ] 有没有"首先/其次/最后"结构？→ 改写
- [ ] 有没有"值得注意的是"等过渡词？→ 删除
- [ ] 有没有"他感到XX"？→ 改为动作描写
- [ ] 成语密度是否超过每段1个？→ 替换为大白话

**对话级：**
- [ ] 不看名字能不能分辨谁在说话？→ 不能则重写
- [ ] 有没有语气词和口头禅？→ 没有则添加
- [ ] 对话是否太完整太逻辑？→ 打断/留白

**全文级：**
- [ ] 句式是否有长短变化？
- [ ] 环境描写是否五感全写？→ 只留2-3种
- [ ] 是否有"不完美"的表达？→ 故意添加
- [ ] 不同章节的文风是否有变化？

## 三、核心信念

> **好的小说不是完美的小说，是让人忘记在读小说的小说。AI能写出"正确"的文字，但只有人能写出"对"的文字。去AI化的本质不是"降级"，而是"升级"——从机器的正确，升级为人的精彩。**

---

## 四、与 expert-literary-prose 的协作

本skill负责「去掉AI味」（移除机器感的表达、套路化句式），`expert-literary-prose` 负责「注入文学味」（注入人的感性、审美意识、意象直觉）。推荐工作流：先用本skill清理AI痕迹，再用literary-prose进行文学质感升级。两者顺序不可颠倒——先减后加。
