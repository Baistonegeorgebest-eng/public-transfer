## 三、配角塑造（避免工具人化）
### 3.1 知乎认证：配角为什么容易工具人化
"写网文，如果想赚钱，必须要进行结构化写作。
在结构化写作当中，所有角色，本质上都是工具人。"
### 3.2 给配角立住的技巧
❌ 最低级配角：反派 → 被打脸（没目标）
✅ 有点层次配角：反派 → 为了自己的利益针对主角（有自己的目标）
❌ 最低级配角：反派 → 只会说"你等着"
✅ 有点层次配角：反派 → 有自己的说话风格，有自己的行为逻辑
❌ 最低级配角：配角 → 永远围绕主角
✅ 有记忆点的配角：配角 → 有自己的过去/背景，和主角产生交集
### 3.3 男女主角的塑造
→ 他们之间要有冲突/张力/吸引力
→ 不是"主角强，CP也强"就完了
→ 不是工具人，不是"因为是女主所以出现"
→ 她/他有自己的目标/困境/成长线
→ 不是一成不变的"喜欢→在一起→甜蜜"
## 四、反派塑造（让打脸更爽）
### 4.1 反派合理动机设计
→ "你挡了我的路，所以我针对你"
→ "他误以为主角做了什么，所以针对"
→ "他嫉妒主角的才华/地位"
→ 嫉妒是人类情感，读者能理解
→ 反派有自己的悲哀，打脸有层次
### 4.2 反派降智的解决方案
→ 反派做愚蠢的决定，只为了送脸给主角打
→ 读者觉得不真实，打脸不成立
→ 反派做出"在当时情境下的合理决定"
→ 反派不是因为"傻"而输，而是因为遇到了更强的主角
→ 反派的下场是"技不如人"，不是"天生愚蠢"
→ 反派没有任何铺垫，读者不接受
然后主角亮出证据——原来反派的把柄早就被主角掌握了。
反派输在"他不知道主角手里有什么"，不是"他天生愚蠢"
→ 读者接受打脸，因为反派是"输给了更强的人"
OOC = Out Of Character（角色性格崩坏）
→ 角色在关键时刻做出不符合自己人设的行为
① 平时高冷的主角，突然变得话痨
② 平时"有仇必报"的主角，突然原谅了敌人
③ 平时"不信感情"的主角，突然无条件相信对方
