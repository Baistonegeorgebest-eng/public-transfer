## 一、核心原则：文风一致，不是逐字查重

### 1.1 逐字重复 vs 文风重复

```
❌ 逐字重复（严格禁止）：
  → 第3章："暮色降临，远山只剩剪影"
  → 第87章："暮色降临，远山只剩剪影"
  → 完全相同的句子，完全没有情节变化

✅ 文风重复（允许存在）：
  → 第3章："暮色降临，远山只剩剪影"
  → 第87章："黄昏的光线从天际消失，山脉的轮廓在暮色中变得模糊"
  → 同一氛围，不同的文字表达，文风一致

✅✅ 有意为之的风格标记（允许）：
  → 某个角色每次出现都有特定的描写手法
  → 某个重要场景每次出现都用相似的结构
  → 这些是风格，不是错误
```

### 1.2 判定标准：删掉这段，读者会发现吗？

```
好的重复（可接受）：
  → 这段描写建立了某种氛围/风格感
  → 删掉后，熟悉作品的读者会说"少了点什么"
  → 有叙事功能（建立基调/暗示情绪/固定角色形象）

坏的重复（必须修改）：
  → 删掉后，读者完全不会注意到
  → 这段没有任何只有本文才有的独特元素
  → 任何一本中世纪小说都能用这段凑字数
```

### 1.3 footprints的范围弹性

```
严格范围（1~30章）：同一段落/场景逐字重复 → 禁止
适度放宽（30~50章）：同一意象可再现，但必须有新叙事功能
宽松范围（50章以上）：可有意复用，但必须比前次更丰富
```

### 1.4 例外：hentai.md亲密场景描写（可灵活）

```
→ 允许更多的词汇密度和类似结构再现
→ 但必须满足：有情节推进 / 每次有新细节层次 / 相邻章节不重复
```

### 1.5 文风一致性三问

```
① 这段是否符合本文当前的叙事声音？
② 这段是否会因为太"标准化"而破坏了本文的独特性？
③ 如果这段出现在任何一本中世纪小说里，那它是本文独有的吗？

三问全"否" → 修改
三问有一个"是" → 可以保留
```

## 二、五类机械错误（图谱）

### A类：无功能时间转场
```
表现：用"天色暗了/天亮了/夜深了"标记时间流逝，但与情节毫无关联
正确用法：时间变化跟角色心理挂钩，服务于情节
```

### B类：静态环境描写（与情节脱节）
```
表现：描写房间/领地/城堡的物理环境，与本章核心事件无呼应
正确用法：烘托情绪 / 暗示事件 / 折射角色状态
```

### C类：万能章节收尾段落
```
表现：章节末尾插入固定"夜晚独处"段落作为万能结尾
典型：夜色渐深 → 灯火熄灭 → 角色独坐 → 回顾 → 需要变强
正确用法：章节结尾必须有叙事功能：悬念/反转/新信息/情感高潮
```

### D类：感官堆砌式描写
```
表现：视觉→听觉→嗅觉→触觉机械罗列，形成"五感清单"
正确用法：选择1-2种最能服务于情节的感官重点
```

### E类：通用意象复用
```
表现：反复使用"安全牌"意象——月光、烛火、壁炉、炊烟、薄雾
频率数据（红龙公爵家ch001-205）：月光197次/远山111次/壁炉118次/烛火79次
正确用法：替换为本世界独有的设定元素（龙焰荧光/源力尘埃/红土气息）
```

## 三、四问自检法

| # | 问题 | 答案"否"=修改 |
|---|------|-------------|
| 1 | 这段描写是否只在本章出现？（全文唯一性） | ❌ 逐字重复，删除或改写 |
| 2 | 删掉这段后，本章情节是否受损？（叙事必要性） | ❌ 冗余，删除 |
| 3 | 这段描写是否跟本章核心事件有直接关联？（情节绑定性） | ❌ 脱节，重写 |
| 4 | 这段描写中是否有本世界独有的元素？（独特性） | ❌ 通用，替换为设定元素 |

## 四、Footprints追踪分类体系

### 4.1 十大追踪类别

```
类别A【环境描写】：天气/光线/场景/气味
类别B【战斗描写】：力量爆发/技能/受伤/氛围
类别C【人物高光时刻】：表情/动作/名场面
类别D【器物描写】：武器/服装/建筑/地图
类别E【情感时刻】：哭/心动/愤怒/告别
类别F【对白手法】：标志性口头禅/特定情绪下的对白模式
类别G【情节装置】：反转/伏笔/揭露方式（用后标记"已耗尽"）
类别H【情绪渲染手法】：比喻/乐景写哀/沉默代替语言
类别I【力量体系专用】：境界突破感觉/能力视觉效果
类别J【转场手法】：时间转场/章节间过渡
```

### 4.2 freshness等级

```
🍃 Green（新）：本项目第1-30章使用过 → 可以用，但必须改变角度/感官
🟡 Amber（适中）：第31-100章使用过 → 必须换词汇/节奏/感官重点
🟠 Dated（老化）：100章以上使用过 → 必须翻新
🔴 Red（耗尽）：同写法出现≥3次 → 立即加入禁止列表
```

### 4.3 🚫禁止列表（逐字重复严禁）

```
通用网文（所有项目）：
1. 无情节绑定的"暮色降临"场景
2. 无情节绑定的"夜色渐深"万能章节结尾
3. 无情节绑定的"烛火摇曳"室内描写
4. 五感清单式描写（视觉/听觉/嗅觉逐项罗列）

hentai.md亲密场景例外：允许更高的词汇密度，允许同类结构再现
```

## 五、写作前检查流程

### 5.1 提示词强制指令（每次生成前必须加入）

```
1. 禁止逐字使用前文已出现的任何描写段落
2. 禁止用"天色/月光/烛火/炊烟"等通用意象做无功能填充
3. 章节结尾禁止使用"夜色渐深"类万能收尾
4. 字数不足时扩展优先级：对话 > 心理 > 行动 > 世界观 > 场景
5. 每段描写必须通过四问自检
6. 环境描写必须与本章核心事件有直接叙事关联
```

### 5.2 三步检查流程

```
写前（15分钟）：
① 读取本项目.footprint.md
② 对照freshness等级和禁止列表
③ 有⚠️警告 → 找替代方案

写后（15分钟）：
④ 登记本章新元素到.footprint.md
⑤ 对照🚫禁止列表检查本章是否有违规
⑥ 有新元素 → 立即登记

批量后：
⑦ 批生成3-5章后，立即运行重复段落扫描脚本
⑧ 发现A/B/C类机械错误段落 → 立即替换或删除
```

## 六、检测脚本（复制即用）

### 6.1 grep扫描（单文件）

```bash
# 扫描指定章节中的5种机械错误
echo "=== A类：无功能时间转场 ==="
grep -n "天色渐渐暗了下来\|薄雾还没散尽\|夜色渐深" "$1"

echo "=== C类：万能收尾 ==="
grep -n "夜色渐深.*灯火.*熄灭\|夜幕降临.*灯火.*熄\|夜已深.*只有" "$1"

echo "=== E类：通用意象频率 ==="
for word in "月光" "烛火" "炊烟" "薄雾" "壁炉"; do
  count=$(grep -o "$word" "$1" | wc -l)
  [ "$count" -gt 1 ] && echo "⚠️ $word 出现 $count 次"
done
```

### 6.2 Python批量扫描（整项目）

```python
import re, os
from collections import defaultdict, Counter

def scan_project(folder):
    files = sorted([f for f in os.listdir(folder) if f.endswith('.txt')])
    all_text = {}
    for fname in files:
        path = os.path.join(folder, fname)
        with open(path) as f:
            text = f.read()
        all_text[fname] = text

    # 扫描C类万能结尾
    print("=== C类万能结尾扫描 ===")
    patterns = [
        "夜色渐深", "夜幕降临", "夜已深",
        "灯火.*熄灭", "灯火阑珊", "夜深人静",
        "独坐窗前", "月色.*窗", "唯有.*陪伴"
    ]
    for fname, text in all_text.items():
        for p in patterns:
            if re.search(p, text):
                print(f"⚠️ {fname}: 发现C类变体「{p}」")

    # 扫描E类通用意象频率
    print("\n=== E类通用意象频率统计 ===")
    generic = {"月光":0,"烛火":0,"炊烟":0,"薄雾":0,"壁炉":0}
    for fname, text in all_text.items():
        for word in generic:
            cnt = len(re.findall(word, text))
            if cnt:
                generic[word] += cnt
    for word, cnt in sorted(generic.items(), key=lambda x:-x[1]):
        if cnt > 0:
            level = "🔴" if cnt>100 else "🟠" if cnt>30 else "🟡"
            print(f"{level} {word}: {cnt}次")

    # 扫描连续相同段落（≥3句）
    print("\n=== 逐字重复段落扫描 ===")
    all_paras = []
    for fname, text in all_text.items():
        paras = re.findall(r'(?:[^\n]{20,}\n){2,}[^\n]{20,}', text)
        for p in paras:
            all_paras.append((fname, p.strip()[:80]))
    counter = Counter([p for _,p in all_paras])
    for para, cnt in counter.most_common(10):
        if cnt > 1:
            print(f"🔴 出现{cnt}次: {para[:60]}...")

# 示例用法
# scan_project('/workspace/长篇小说及规划/项目名/卷一/')
```
