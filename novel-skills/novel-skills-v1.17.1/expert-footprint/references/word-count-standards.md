# 字数统计标准与扩充优先级

> 核心工作流见SKILL.md。

---

## 三套统计标准

| 标准 | 计算方式 | ch32字数 | 适用 |
|------|---------|---------|------|
| **窄口径（推荐）** | 中文+中文标点 | ~2072字 | 项目通用 |
| 宽口径 | 所有非空白字符 | ~2165字 | 快速估算 |
| 纯中文 | 仅中文 | ~1862字 | 精确字数 |

```
宽口径 vs 窄口径差异：全书约86章（42%）
→ 项目启动时必须锁定统计口径，建议用窄口径
```

## 字数警告触发规则

```
正常：≥2100字（窄口径）
⚠️  警告：1800-2099字
❌  不足：1500-1799字 → 必须扩充
🚨  异常：<1500字 → 人工检查正文是否损坏
🚨  疑似损坏：<500字 → 标记⚠️（ch112/ch121/ch133/ch144）
```

## 扩充优先级体系

| 优先级 | 手法 | 说明 |
|-------|------|------|
| 🥇 最高 | **扩展对话** | 直接增加互动，信息量大 |
| 🥈 次高 | **增加心理活动** | 深化代入感 |
| 🥉 第三 | **丰富战斗/行动细节** | 提升画面感 |
| 第四 | **补充世界观信息** | 增加厚度 |
| 第五 | **有功能的环境描写** | 仅在必要时候用 |
| ❌ 禁用 | **无功能的场景填充** | A/B/C类机械错误 |

```
❌ 错误：硬指标"每章≥2100字" → AI为达标而填充
✅ 正确：范围指标"2000-2800字" → 允许自然波动
```
