> 核心工作流见SKILL.md。

## 10.1 痕迹密度控制公式

"剧情痕迹"是指作者在文本中留下的、读者可以追踪的信息线索。

```
核心痕迹（高密度，1:3~1:5章）
  → 与当前卷/当前主线直接相关的信息
  → 每章至少有1-2个痕迹元素

支撑痕迹（中密度，1:10~1:15章）
  → 支撑世界观/角色背景的间接信息
  → 不需要每章出现，但要定期刷新

远景痕迹（低密度，1:30~1:50章）
  → 全书级的宏观线索/最终真相的碎片
  → 越到后期密度逐渐增加

密度递增法则：
  前期（1-30章）：远景痕迹每50章1次
  中期（30-100章）：远景痕迹每20章1次
  后期（100章+）：远景痕迹每5-10章1次
  → 前期稀疏是为了不让读者过早猜到结局
  → 后期密集是为了让回收有充足铺垫
```

## 10.2 读者预期管理四步法

```
① 建立预期（引导读者形成判断）
  手法：通过正常的情节发展让读者觉得"应该是这样"
  例：主角遇到了一个神秘的老人 → 读者预期"这是传授功法的NPC"

② 巩固预期（让读者确信自己的判断）
  手法：给出1-2个"印证"读者预期的线索
  例：老人确实展示了超凡实力 → 读者更加确信"果然是传功NPC"

③ 颠覆预期（给出超出预期的真相）
  手法：揭示读者判断中遗漏的关键信息
  例：老人其实是最终Boss的化身，传授功法是为了植入追踪印记
  → 颠覆不能是"凭空出现的新信息"，必须是"之前就存在但被忽略的线索"

④ 合理化颠覆（让读者接受新真相）
  手法：通过回溯/闪回展示"被忽略的线索"
  → 合理化要快（1-2段话），不能让读者觉得作者在补设定
```

## 10.3 信息差编排矩阵

```
                读者   主角   配角A   反派
真相A（Boss身份） 知道   不知道  不知道  知道
真相B（宝物位置） 不知道  知道   不知道  知道
真相C（身世之谜） 不知道  不知道  知道   知道

三种经典信息差模式：

模式1：读者 > 角色（上帝视角紧张感）
  → 适用于：悬疑、恐怖、灾难铺垫

模式2：角色 > 读者（揭秘快感）
  → 适用于：推理、智斗、反转

模式3：角色之间信息不对称（冲突根源）
  → 适用于：人际关系、势力博弈、多视角叙事

编排铁律：
  每5-8章必须有一次"信息差消除"（否则读者会烦躁）
  信息差消除的时机 = 情绪最高点
  信息差消除的方式 = 要有戏剧冲突（不是平静地"告诉"）
```

## 10.4 freshness评级系统（补充）

```
评级标准：
  S级（新鲜）= 完全原创，无重复模式
  A级（良好）= 基本原创，偶有相似
  B级（一般）= 部分模式化，但不影响阅读
  C级（需改）= 明显模板化，需要修改
  D级（重写）= 严重重复，需要重写

检查频率：
  每5章做一次freshness评级
  连续3章C级 → 需要暂停调整文风
  出现D级 → 立即重写该章节
```

## 10.5 强制禁止模式补充

```
禁止的写作模式：
❌ 同一章节内重复使用同一比喻
❌ 连续3章使用相同类型的开篇
❌ 所有战斗场景用同一套描写模板
❌ 所有角色使用相同的口头禅
❌ 章末钩子总是同一类型

例外：
  系列化写法中，固定的"仪式性重复"是允许的
  例：每章开头的经典台词（属于品牌标识）
```

- [ ] 读者预期管理是否完成了四步（建立→巩固→颠覆→合理化）？
- [ ] 信息差矩阵是否清晰标注了"谁知道什么"？
- [ ] 每5-8章是否安排了一次信息差消除？
