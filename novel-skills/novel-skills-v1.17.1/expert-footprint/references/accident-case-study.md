## 五种模板段落详情

```
模板A【暮色场景】：暮色降临/远山剪影/壁炉余烬 → 出现24次
模板B【室内光影】：房间暗/烛火摇曳/古老气味 → 出现23次
模板C【户外夜景】：领地夜晚安静/月光/犬吠 → 出现22次
模板D【清晨薄雾】：清晨薄雾/农夫劳作/炊烟 → 出现22次
模板E【清晨苏醒】：清晨苏醒/铁匠铺/农田（变体） → 出现1次
```

## 事故根因

```
问题本质：模型生成时，上下文窗口中不一定包含前文已写的具体段落
→ AI每次生成都是"重新开始"
→ 低温度参数会让AI选择训练数据中出现频率最高的意象
→ "月光/烛火/炊烟" = AI的"舒适区"
→ 没有外部记录，AI无法意识到"这个段落已经写过了"
```
