# C类万能结尾二次清理SOP

> 核心工作流见SKILL.md。

---

## 背景

发现：46处C类结尾首次清理漏删20处 → 必须二次扫描

## 标准流程

```
Step 1：初检（grep批量扫描）
Step 2：初检后立即人工抽查3-5章（章节首中尾三处）
Step 3：二检（24小时内用不同关键词再扫一次）
Step 4：标记确认（将已清理标记写入footprint）
```

## C类万能结尾常见变体关键词

```
夜色渐深/夜幕降临/夜已深/夜色笼罩
灯火.*熄灭/灯火阑珊/灯火渐熄
夜深人静/独坐窗前/月光洒在/月色.*窗
黑暗中.*只有/唯有.*陪伴
```
