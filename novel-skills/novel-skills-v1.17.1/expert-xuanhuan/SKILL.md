## 一、世界观分层设计（核心框架）

### 1.1 世界分层速查

**模式一【三层世界】**（最通用）：凡界 → 灵界/修真界 → 仙界

**模式二【两界+秘境】**：人界+妖界+魔界（并存）→ 共享上古遗迹

**模式三【单界无限地图】**：一个世界，地图随成长逐步开放

> 详细设计 → [references/world-layers.md](references/world-layers.md)

### 1.2 地理设计核心要点

- 灵气/资源分布不均 → 决定势力分布
- 禁忌区域 → 开局不可进入的最终目标
- 交界地带 → 冲突高发区
- 独立势力 → 第三方力量
- 历史遗留区域 → 探险/传承节点

## 二、势力与冲突设计（核心框架）

### 2.1 势力层级速查

```
霸主级(1-3) → 顶级(5-10) → 中层(数十) → 底层(数百) → 散修(无数)
```

### 2.2 冲突三模式

- **资源争夺战**：两势力争夺秘境/灵脉，主角渔翁得利
- **正邪大战**：正道 vs 魔道全面战争，主角在战争中成长
- **宗门内斗**：同门派系斗争，展现智谋和人性

## 四、配角与反派设计（核心框架）

### 4.1 反派四类型速查

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 利益型 | 立场不同，不是邪恶 | 增加故事深度 |
| 误解型 | 可洗白 | 有反转空间 |
| 宿命型 | 无法调和 | 适合最终Boss |
| 替代型 | 因故堕落，让人惋惜 | 最有深度 |

### 4.2 配角三原则

1. **师父非工具人**：有传承逻辑，关键时刻出手
2. **伙伴非附庸**：有自己故事线和成长弧光
3. **反派有智商**：有完整行为逻辑和充分动机

## 五、开局设计

### 5.1 五种经典公式

| 公式 | 开局 | 钩子 | 优势 |
|------|------|------|------|
| 废柴逆袭 | 出身低微被看不起 | 获得金手指 | 代入感强 |
| 天才陨落 | 曾是天才遭遇变故 | 找到原因决心复仇 | 有期待感 |
| 穿越者 | 穿越到异世界 | 带着现代知识 | 信息差有趣 |
| 稳健布局 | 重生知道未来 | 布局改变命运 | 智斗感强 |
| 系统面板 | 获得系统面板 | 完成任务获奖励 | 数据成长感 |

### 5.2 开头三章任务表

**第1章必须完成：**
- □ 建立主角身份（名字/出身/处境）
- □ 建立核心冲突（当前最大困境）
- □ 展示金手指的存在
- □ 制造第一个钩子

**第2章必须完成：**
- □ 让主角开始行动（不是被动等待）
- □ 展示主角的性格
- □ 第一个小胜利/小收获

**第3章必须完成：**
- □ 引入第一个有记忆点的配角
- □ 展示世界观的一角
- □ 为后续大冲突埋下伏笔

## 六、仙侠 vs 玄幻文体区分

### 6.1 核心差异

| 维度 | 仙侠文 | 玄幻文 |
|------|--------|--------|
| 文化根基 | 道教/佛教/神话体系 | 不一定有 |
| 终极目标 | 成仙 | 自由（力量/地位/自由） |
| 核心追求 | 心境/悟道/因果 | 力量升级/战斗爽感 |
| 文风 | 古典雅致，有诗意 | 白话，节奏更快 |
| 常见元素 | 飞剑/丹药/洞府 | 升级/打怪/夺宝 |

### 6.2 仙侠文三大魅力

1. **道法自然的哲学感**：修炼也是心境提升，"道"是终极追求
2. **因果轮回的命运感**：今生善恶影响来世，增加命运厚度
3. **飞剑与法宝的美学**：御剑飞行/法宝变化是独特视觉符号

### 6.3 仙侠文写作要点

- 修炼要有"悟"的过程（不能只靠资源堆砌）
- 要有"道心"设定（主角坚持的"道"）
- 因果要明确（做了什么事就承担什么后果）
- 每个境界有不同外在表现

## 七、修炼瓶颈与剧情高潮联动

### 7.1 瓶颈四种类型

| 类型 | 特征 | 解决方式 |
|------|------|---------|
| 资质瓶颈 | 资质不够无法突破 | 特殊机缘/洗髓丹/顿悟 |
| 心境瓶颈 | 力量够但心境不够 | 特定事件/道心提升 |
| 资源瓶颈 | 缺少关键资源 | 寻找/争夺/炼制 |
| 因果瓶颈 | 因诅咒/誓言/杀劫 | 化解因果/接受代价 |

### 7.2 瓶颈与高潮联动三模式

**模式一【瓶颈即是高潮】：** 铺垫→绝望→转机→突破

**模式二【突破触发新危机】：** 突破→高兴→更大危机

**模式三【多次尝试才突破】：** 第一次失败→第二次更绝望→第三次成功

### 7.3 瓶颈突破完整模板

```
第一步【绝望铺垫】（500-1000字）
  → 瓶颈的痛苦和绝望，周围人的质疑

第二步【意外转机】（500-800字）
  → 获得某个契机/信息/物品

第三步【顿悟过程】（300-500字）
  → 修炼中的顿悟/灵感

第四步【突破高潮】（500-800字）
  → 突破时的壮观场面，震惊周围人

第五步【代价与余韵】（300-500字）
  → 突破的代价和后续影响
```
