# 势力分布与冲突设计

## 五层势力金字塔

| 层级 | 类型 | 数量 | 功能 |
|------|------|------|------|
| 第一层 | 霸主级势力 | 1-3个 | 统治整个世界，通常在幕后 |
| 第二层 | 顶级势力 | 5-10个 | 大型宗门/王朝/妖族联盟，互相制衡 |
| 第三层 | 中层势力 | 数十个 | 中型宗门/中等王国，资源争夺主力 |
| 第四层 | 底层势力 | 数百个 | 小宗门/小家族/散修联盟，主角早期起点 |
| 第五层 | 个体/散修 | 无数 | 无势力依靠，最艰难也最自由 |

## 六层势力金字塔（长篇适配）

```
第一层：家族/村庄（1-10万字）
  → 主角出身的小势力
  → 冲突类型：家族内部争斗/村庄危机

第二层：城池/小宗门（10-30万字）
  → 主角崭露头角的舞台
  → 冲突类型：宗门内斗/城池争锋

第三层：区域/大宗门（30-60万字）
  → 更大的势力范围
  → 冲突类型：宗门大战/区域争霸

第四层：国家/联盟（60-80万字）
  → 国家级势力对抗
  → 冲突类型：国战/阵营对抗

第五层：大陆/位面（80-100万字）
  → 最高层级的势力
  → 冲突类型：种族大战/位面入侵

第六层：隐藏势力（贯穿全文）
  → 幕后操控者/上古遗族/天外势力
  → 最终Boss所在
```

## 势力冲突三模式

### 模式一：宗门争斗

- 各宗门争夺洞天福地/上古遗迹
- 宗门内部有派系斗争（传承派 vs 改革派）
- 主角在宗门斗争中崛起
- 派系斗争可作为感情线催化剂

### 模式二：王朝争霸

- 各大王朝争夺天下
- 王朝内部有忠奸之争
- 主角在王朝争霸中崛起

### 模式三：种族大战

- 人族/妖族/魔族等种族冲突
- 种族内部也有不同势力
- 主角在种族大战中崛起

## 宗门设计三要素

```
① 定位 → 正道/魔道/中立/隐藏
② 特色 → 独有的功法/阵法/丹药传承
③ 内部矛盾 → 不同派系的争斗
```

## 经典宗门结构

```
掌门 → 长老团 → 内门弟子 → 外门弟子 → 记名弟子
→ 每层有不同的资源分配和晋升规则
→ 内门/外门的矛盾 = 天然的冲突来源
```

## 势力设计检查清单

- 每层势力至少有3个互相竞争的单位
- 势力之间的矛盾要"合理"（利益/理念/历史恩怨）
- 主角在每个势力中都有"盟友+敌人"
- 势力之间的关系会随剧情发展变化

## 散修生存指南

- 散修没有宗门支持，需要自己寻找修炼资源
- 常用方法：赏金任务（猎杀妖兽获取内丹）、探索遗迹、交易
