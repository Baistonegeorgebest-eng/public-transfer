# 经典技法补全（升级节奏+地图扩展+势力架构）

## 升级爽点设计模板

```
突破前：被对手压制/遇到无法解决的困境
突破中：金光大作/天地异象/对手震惊
突破后：一招碾压之前打不过的对手/展现新能力
→ 三段式 = 最大化爽感
```

## 地图扩展法则

地图扩展是维持长篇新鲜感的关键手段。每扩展一次地图，主角就从"这个区域最强"变成"新区域最弱"，重新获得成长空间。

### 地图扩展节奏模板

```
初始地图（安全区）：
  → 主角的家乡/学院/宗门
  → 主角在这里从最底层成长到最强

第一次扩展（挑战区）：
  → 触发条件：主角在初始地图达到天花板
  → 扩展方式：升学/参赛/被招募/逃亡
  → 新地图规模：一个省/一个大洲

第二次扩展（冒险区）：
  → 触发条件：新地图的天花板
  → 扩展方式：飞升/传送/探索未知区域

最终地图（终局区）：
  → 最高层级的世界
  → 主角在这里达到巅峰
  → 最终Boss战
```

### 地图扩展注意事项

1. 旧地图不能完全抛弃（偶尔回顾/召回旧友/对比实力变化）
2. 新地图要有足够的"新意"（不同的修炼体系/文化/种族）
3. 扩展的理由要合理（不能为了扩展而扩展）
4. 每次扩展后给3-5章适应期（让读者了解新地图规则）

## 检查清单

- [ ] 升级节奏是否控制在"低阶2-3万字/中阶3-5万字/高阶5-6万字"？
- [ ] 是否为每个大境界突破设计了"蓄力-瓶颈-突破"三段式？
- [ ] 势力架构是否至少有5层金字塔结构？
- [ ] 每层势力是否有至少3个互相竞争的单位？
- [ ] 地图扩展是否有合理的故事触发条件？
- [ ] 每次地图扩展后是否有3-5章适应期？
- [ ] 旧地图是否没有被完全抛弃？
- [ ] 升级爽点是否设计为"突破前被压制→突破中异象→突破后碾压"三段式？
