# 世界观分层体系详解

## 三种经典分层模式

### 模式一：三层世界（最通用）

```
凡界（凡人可到达）
    ↓ 飞升
灵界/修真界（修士聚集，宗门林立）
仙界（仙人居住，主角终点或新开始）
```

### 模式二：两界+秘境的多元世界

```
人界 + 妖界 + 魔界（并存）
    ↓ 共享的上古遗迹/秘境
（不同界主角相遇，碰撞出火花）
```

### 模式三：单界无限地图

```
只有一个世界，但地图随主角成长逐步开放
→ 前期：局限在某个国家/宗门
→ 中期：开放其他国度/势力
→ 后期：开放禁区/上古遗迹/世界之外
```

## 四层世界详细设计

| 层级 | 定位 | 人群 | 核心冲突 |
|------|------|------|----------|
| 凡人界 | 主角起点 | 普通人+低级修士 | 生存+资源竞争 |
| 修士界 | 成长后到达 | 各宗门+家族 | 宗门争斗+天才竞争 |
| 仙界/神界 | 终极目标 | 真正的强者 | 神战+天道规则 |
| 终极世界 | 全书最终真相 | 极少数人能到达 | 世界终极秘密 |

## 地图设计核心原则

- 每层世界的实力上限不同
- 主角进入新地图时实力要匹配
- 不同地图有不同的规则、文化、冲突
- 换地图 = 进入新的战力区间 = 新的开始 = 新的爽点来源

## 地理设计七要素

1. **灵气/资源分布不均** → 资源分布决定势力分布
2. **禁忌区域** → 开局不可进入，需要特定条件
3. **交界地带** → 冲突高发区，故事主要舞台
4. **独立势力** → 第三方力量，增加变数
5. **历史遗留区域** → 上古战场/宗门遗址，探险节点
6. **特殊环境** → 火山/冰原/雷泽，修炼场所
7. **世界级设定** → 世界的形成原因和终极秘密

## 末法时代设定

末法时代 = 灵气稀缺 = 争夺资源的核心冲突

写作技巧：
- 修炼变难 → 每个境界突破都珍贵
- 资源稀缺 → 争夺成为核心冲突
- 普通人与修士差距加大 → 社会矛盾激化
