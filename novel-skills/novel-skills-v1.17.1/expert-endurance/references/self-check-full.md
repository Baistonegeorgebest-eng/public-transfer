# 完整自检清单

## 生理健康自检
- [ ] 我的桌椅高度合适（显示器上沿与眼睛平齐）
- [ ] 我每45-60分钟起来活动一次
- [ ] 我每天有30分钟以上的运动
- [ ] 我没有手腕/颈椎/腰椎的不适症状
- [ ] 我使用了20-20-20护眼法则

## 心理健康自检
- [ ] 我每周做一次倦怠自检
- [ ] 我没有每天反复刷后台看数据
- [ ] 我能接受差评而不影响创作情绪
- [ ] 我不会因为和别人比较而自我否定
- [ ] 我写作时的心态是"我想写"而不是"我必须写"

## 时间管理自检
- [ ] 我有固定的写作时间段
- [ ] 我使用计时器管理写作单元
- [ ] 我每天有输入（素材/阅读/观察生活）
- [ ] 我每周至少1天非强制写作日
- [ ] 我了解自己的最佳写作时间段

## 产量管理自检
- [ ] 我的产量目标是可持续的（能坚持一年以上）
- [ ] 我有存稿缓冲（至少3章）
- [ ] 我会在状态差时降低产量而不是硬撑
- [ ] 我会在状态好时存稿而不是全部发完
- [ ] 我的质量底线是明确的且不可突破的

## 灵感管理自检
- [ ] 我有持续建设素材库的习惯
- [ ] 我至少掌握了2种灵感枯竭应对方法
- [ ] 我知道什么时候该用"最低限度写作法"
- [ ] 我不会因为一天没灵感就焦虑

## 应急预案自检
- [ ] 我有请假通知的模板和流程
- [ ] 我的存稿足以覆盖3-5天的请假
- [ ] 我知道严重倦怠时该如何处理
- [ ] 我有可以倾诉的写作朋友或社群
- [ ] 我的回归节奏是"渐进恢复"而非"突然冲刺"
