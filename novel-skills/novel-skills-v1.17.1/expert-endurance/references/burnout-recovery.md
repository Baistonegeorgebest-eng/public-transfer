# 写作倦怠识别与恢复方案

## 倦怠自检量表

每周做一次自检，5个问题各打1-5分：

| 问题 | 1分（从不） | 3分（有时） | 5分（总是） |
|------|-----------|-----------|-----------|
| 我抗拒打开写作文档 | | | |
| 我写的时候很难集中注意力 | | | |
| 我对读者评论过度在意 | | | |
| 我觉得自己的作品没有价值 | | | |
| 我在考虑放弃这个故事 | | | |

**评分规则：**
- 5-10分：正常状态，继续当前节奏
- 11-15分：轻度疲劳，降低产量+增加休息
- 16-20分：中度倦怠，主动请假+改变写作方式
- 21-25分：严重倦怠，暂停连载+寻求支持

## 三阶段恢复方案

### 轻度疲劳恢复（3-5天）

- 每天产量降到正常的80%
- 增加一次户外活动
- 和写作朋友聊聊
- 翻翻素材库找灵感

### 中度倦怠恢复（1-2周）

- 请3-5天假（用存稿覆盖）
- 期间不写连载内容，但可以写短练笔/番外
- 换一个写作环境（咖啡馆、图书馆、公园）
- 回顾初心：当初为什么写这个故事
- 做一些和写作完全无关的事（运动、旅行、看电影）

### 严重倦怠恢复（2-4周）

1. **暂停连载**——和读者沟通，请假1-2周
2. **不要强迫自己写任何东西**——让创作系统完全休息
3. **寻求支持**——和信任的人聊聊（朋友、家人、必要时心理咨询）
4. **找到倦怠的根源**——是这个故事本身的问题？还是写作方式的问题？还是生活压力的外溢？
5. **制定回归计划**——不是"明天开始写"，而是"先做这些小步骤恢复"

## 可能的根源及对策

| 根源 | 对策 |
|------|------|
| 故事本身的问题 | 考虑提前完结、大改方向、或者真的放弃（放弃不可耻） |
| 写作方式的问题 | 改变写作节奏、降低产量、调整时间段 |
| 生活压力 | 先处理生活问题，写作问题会自行缓解 |
| 完美主义 | 接受"完成比完美重要" |

## 回归节奏

从请假回归后的注意事项：
- 不要一回来就冲量（容易再次倦怠）
- 用2-3天恢复正常产量
- 回归第一篇的质量要比平时更好（第一印象很重要）
- 如果是因为倦怠请假的，回归后要调整写作方式，避免再次倦怠
