## 一、2026年番茄平台最新态势

### 1.1 平台现状
- **用户体量**：全网最大免费阅读平台，日活过亿
- **内容生态**：免费为主+付费解锁，算法分发代替人工编辑
- **作者规模**：超50万作者（2024年数据）
- **2026年重大变化**：投入近十亿现金扶持创作者，全面转向"短剧友好型"内容

**2026年的机会：**
- 平台补贴力度加大，爆款作者最高单书收入破80万
- 算法相对公平，适合无背景新人
- 短故事（千字万金计划）新赛道出现

**2026年的挑战：**
- AI批量内容涌入，普通新人生存更难
- 中层福利（部分全勤奖励）被削减
- "短剧友好型"内容优先，长篇需要更强的开头钩子

### 1.2 番茄 vs 起点核心差异

| 维度 | 番茄小说 | 起点中文网 |
|------|---------|----------|
| 收入模式 | 全勤+广告分成 | 全勤+VIP订阅分成 |
| 推荐机制 | 算法为主，8万字验证期 | 4轮PK制 |
| 读者画像 | 下沉市场，中低收入读者为主 | 中高端，付费意识强 |
| 内容风格 | 快节奏、高爽点、无脑爽 | 深耕型、人物塑造、世界观 |
| 爆款周期 | 首秀决定一切（8万字前后） | 长线运营，追读决定推荐 |
| 字数规模 | 百万字+（完读率是核心） | 20-50万字单部 |
| 版权开发 | 短剧改编为主 | 影视/游戏版权为主 |

## 二、2026年推荐机制详解（全流程）

### 2.1 签约门槛
- **基本条件**：满2万字即可后台申请签约（约7个工作日）
- **审核难度**：全网最简单（远低于起点）
- **签约模式**：全勤+广告分成（无保底）
- **两种选择**：
  - ① 新人训练营：3万字申请，零门槛，前两个月无更新要求，编辑一对一指导
  - ② 常规保底签约：需2万字+质量达标

> 📁 签约三次机会详解 → [references/signing-contract.md](references/signing-contract.md)

### 2.2 推荐流程（五阶段）

**第一阶段：验证期（8万字前后，持续7天）**
- 点击"开始推荐"按钮后进入
- 平台用小规模流量测试，数据决定是否正式推荐
- 核心指标：完读率（建议满10万字再点推荐）

**第二阶段：正式推荐/首秀（8~15万字，持续3周）**
- 验证期数据合格 → 进入正式推荐
- 每天稳定更新6000字，严禁断更
- 完读率>10%就能推流

**第三阶段：追读稳定期（15~30万字）**
- 追读率>30%：稳定推荐
- 追读率>40%：快速放量
- 追读率>50%：爆款潜质

**第四阶段：冲击精品期（30~100万字）**
- 均订达到3000+ → 精品认证

**第五阶段：巅峰期（100万字以上）**
- 完读率>25% → 完结后长尾流量稳定

### 2.3 追读率合格线

| 追读率 | 级别 | 后果 |
|--------|------|------|
| <20% | 扑街 | 验证期后基本无量 |
| 20-30% | 一般 | 缓慢放量 |
| 30-40% | 良好 | 稳定推荐 |
| 40-50% | 优秀 | 快速放量 |
| >50% | 爆款 | 现象级，全网推量 |

## 三、番茄长篇黄金开篇（3000字五件套·2026版）

### 3.1 开篇结构
| 段落 | 字数 | 任务 |
|------|------|------|
| 第0~100字 | 黄金钩子 | 困境/异象/身份冲突（三选一，必须立刻抓住读者） |
| 第100~500字 | 身份确认 | 名字+处境+最核心困境（一句话讲清） |
| 第500~1500字 | 第一个冲突 | 建立读者期待 |
| 第1500~2500字 | 金手指展示 | 让读者看到主角有希望赢 |
| 第2500~3000字 | 爽点预告 | 章尾留钩子，下一章立刻打脸/突破 |

### 3.2 开篇禁忌（番茄特别严格）
❌ 不能开头写大段背景介绍
❌ 不能写超过500字的环境/世界观描写
❌ 不能写穿越前的"上辈子"回忆（番茄节奏快，容不下慢热）
❌ 不能写主角出身名门+天才设定（没有代入感）
❌ 不能写大段主角外貌/服饰描写

✅ 必须：开局即冲突，300字内出钩子
✅ 必须：主角有具体困境（读者能感同身受）
✅ 必须：金手指/系统/重生记忆，500字内展示
✅ 必须：章尾有悬念

### 3.3 番茄爆款开篇模板
```
「我重生了。」
他睁开眼睛的时候，发现自己躺在医院的病床上。
时间——回到了十年前。
高考前三个月。
那个他曾经发誓要改变一切、却最终失败的节点。
但这一次，他不会再犯同样的错误。
```
→ 300字内，重生+困境+悬念全部到位
→ 直接接第一章核心冲突，不要铺垫

## 四、百万字不崩的大纲设计

### 4.1 三幕五卷结构模型

| 卷 | 字数 | 目标 | 节奏 |
|----|------|------|------|
| 第一卷·逆袭 | 0~20万字 | 让读者爱上主角 | 1个核心困境→3次小高潮→1个BOSS |
| 第二卷·崛起 | 20~40万字 | 建立势力/团队/世界观 | 2个中等BOSS→1个大势力 |
| 第三卷·决战 | 40~60万字 | 解决核心悬念 | 1个核心决战→世界观全面展开 |
| 第四卷·新世界 | 60~80万字 | 升级/换地图/新挑战 | 新地图→新敌人→新目标 |
| 第五卷·结局 | 80~100万字 | 解决所有悬念 | 伏笔回收→终极BOSS→结局 |

> 📁 百万字架构进阶（地图设计、多线叙事、防崩检查节点） → [references/outline-design.md](references/outline-design.md)

### 4.2 战力体系设计（三层架构）

**第一层：境界设定**（9个境界，不要超过）
- 初境→小成→大成→圆满→王境→皇境→帝境→圣境→神境
- 每个境界分3个小层（初期/中期/后期）

**第二层：战斗力公式**
- 战斗力 = 境界等级 × 天赋系数 × 努力系数 × 机缘系数
- 主角的天赋系数要低（增加成长空间），机缘系数要高（增加爽点）

**第三层：克制关系**
- 每3个境界有一个小克制（避免单纯以境界压人）
- 允许低境界打败高境界（需要特殊手段/环境/策略）

### 4.3 长期伏笔设计

| 伏笔类型 | 埋设节奏 |
|---------|---------|
| 身世之谜 | 第1卷末尾埋入→第3卷线索→第5卷揭示 |
| 敌人真实身份 | 第1卷埋入→第3卷揭示 |
| 隐藏势力 | 第2卷埋入→第4卷揭示 |
| 金手指的来源/代价 | 第1卷埋入→第5卷揭示 |
| 世界真相 | 全程铺设→第5卷终极揭示 |

→ 每个大章节（20万字）至少有一个长期伏笔

### 4.4 阶段性BOSS排布
| 字数 | BOSS | 作用 |
|------|------|------|
| 10万字 | 第一小BOSS | 展示主角成长 |
| 20万字 | 阶段性BOSS | 解决第一卷核心冲突 |
| 30万字 | 势力BOSS | 扩大冲突规模 |
| 50万字 | 世界观级BOSS | 揭示世界真相 |
| 70万字+ | 终极BOSS | 最终决战 |

## 五、签约与变现策略

### 5.1 番茄收入构成

**① 全勤奖（最重要！）**
- 月更≥10万字：600元/月
- 月更≥15万字：1000元/月
- 月更≥20万字：1500元/月
- ⚠️ 必须稳定日更（每天4000-6000字），断更全勤全无

**② 广告分成**
- 平台广告收入×分成比例（约50%归作者）
- 完读率越高，单次阅读广告分成越高

**③ 爆款奖金**
- 平台活动奖金池（节日/主题活动）
- 爆款可瓜分500万奖金池

**④ 版权开发（头部作者）**
- 短剧改编权（最常见）、有声书版权、游戏版权

### 5.2 新人起步策略
1. 选赛道（见第六章）
2. 写2万字+申请签约（不要等到写很多字再签）
3. 签约后立刻建细纲（到50章）
4. 日更4000字，稳定更新
5. 8万字点击"开始推荐"，进入验证期
6. 首秀3周观察数据
   - 追读>30%：继续日更
   - 追读20-30%：调整写法，加快节奏
   - 追读<20%：分析原因，必要时切书重开

## 七、崩文预警与急救方案

### 7.1 崩文预警信号

**红色预警（必须立即行动）：**
- 追读率连续3天下跌
- 评论区出现大量"太水了""节奏慢"
- 均订连续下滑

**橙色预警（需要调整）：**
- 更新不稳定（断更超过2天）
- 读者开始讨论剧情bug
- 新增收藏明显减少

**黄色预警（观察即可）：**
- 涨收藏速度变慢
- 读者催更但不骂人
- 同期同赛道出现爆款（分流）

### 7.2 7天急救法
| 天数 | 行动 |
|------|------|
| Day 1-2 | 分析数据：找到掉追读的具体章节，找到读者骂得最多的点 |
| Day 3-4 | 制定方案：砍掉不受欢迎的支线，加快主线节奏，加入读者期待的角色 |
| Day 5-6 | 写改稿细纲：把要调整的10章全部写出细纲，确认不会产生新的逻辑漏洞 |
| Day 7 | 爆发更新：一次性更新3-5章，把前面拖拉的剧情全部推进，章尾留最强悬念 |

### 7.3 百万字后常见问题与解决

| 问题 | 解决方案 |
|------|---------|
| 战力崩了 | 重制战力表，增加"限制条件"（环境/体力/道具限制） |
| 配角变成工具人 | 给3个核心配角各写一段专属戏份，让他们有独立目标 |
| 重复套路审美疲劳 | 引入全新矛盾类型（如从"打怪升级"变成"内部分裂"） |
| 伏笔忘记埋了 | 建"伏笔清单"，每发现漏洞立刻补上 |
