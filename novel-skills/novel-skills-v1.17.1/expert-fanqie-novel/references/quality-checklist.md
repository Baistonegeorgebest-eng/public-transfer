## 一、开篇前三章检查
- [ ] 第1章前300字是否有钩子？
- [ ] 第1章主角身份是否明确？
- [ ] 第1章是否有冲突？
- [ ] 第2章是否有小爽点（打脸/突破/发现）？
- [ ] 第3章是否建立了核心世界观/规则？
- [ ] 前三章是否出现了主要配角（至少1个）？
- [ ] 章尾是否有悬念钩子？
- [ ] 对话是否超过60%？
- [ ] 每段是否不超过3行？
- [ ] 是否有系统/重生/特殊能力的展示（第500~1000字内）？

## 二、10万字自检
- [ ] 前10万字是否有3个阶段性爽点？
- [ ] 主角是否有明确的当前目标？
- [ ] 是否埋入了至少2个长期伏笔？
- [ ] 战力体系是否清晰（没有越级打败不应该能打败的人）？
- [ ] 是否有至少1个让读者喜欢的配角？
- [ ] 金手指的使用是否克制（不要一出现问题就靠金手指解决）？

## 三、30万字自检
- [ ] 第一个阶段性BOSS是否解决？
- [ ] 是否埋入了第二阶段的核心悬念？
- [ ] 主角的成长曲线是否呈上升趋势（不是原地踏步）？
- [ ] 配角是否有各自的成长弧线？
- [ ] 是否有至少3个让读者印象深刻的配角？
- [ ] 伏笔是否有回收（至少1个）？
- [ ] 世界观是否扩展了（地理/势力/历史至少一面）？

## 四、选材Checklist
- [ ] 这个故事的核心爽点是什么？（1句话内说清楚）
- [ ] 主角的困境是什么？（读者能感同身受吗？）
- [ ] 金手指够不够独特？（有没有让人眼前一亮的设计？）
- [ ] 我的差异化在哪里？（为什么读者要看你这本？）
- [ ] 我能写100万字吗？（故事有足够的剧情支撑吗？）
- [ ] 我的核心读者是谁？（男性/女性？年龄层？）
- [ ] 番茄的读者会喜欢这个题材吗？
- [ ] 我的更新时间够稳定吗？（每天4000-6000字能坚持吗？）

## 五、追读钩子自检
- [ ] 每章结尾是否有明确的追读钩子？
- [ ] 前三章完读率是否达到60%以上？
- [ ] 是否避免了连续3章以上的"平章"？
- [ ] 百万字架构是否拆分为20-30万字的小故事弧？
- [ ] 地图扩展是否与字数进度匹配？
- [ ] 章节字数是否控制在2000-2500字？

## 六、番茄创作自检
- [ ] 开篇3000字是否包含完整的五件套？
- [ ] 前300字是否有明确的钩子？
- [ ] 追读率是否在合格线以上？（推荐期≥10%，稳定期≥8%）
- [ ] 更新频率是否稳定？（番茄算法惩罚断更）
- [ ] 广告插入位置是否避开情感高潮？
- [ ] 书名是否包含"热门标签+情绪钩子"？
- [ ] 简介是否在3行内说清"主角是谁+要做什么+有什么爽点"？
- [ ] 百万字架构是否拆分为20-30万字的小故事弧？

### 终极检查清单
- [ ] 战力体系≤9×3境界
- [ ] 无超过30章无实质进展
- [ ] 伏笔回收>70%
- [ ] 感情戏每20章推进
- [ ] 书架率≥5%，追更率≥20%
