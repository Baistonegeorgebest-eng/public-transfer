## 一、追读率优化公式

追读率是番茄算法推荐的核心权重指标，2026年权重占比约40%。

追读率 = 次日回访读者数 / 总阅读读者数

优化追读率的本质是"每章结尾制造一个未完成的悬念"。

### 三段式追读钩子模板
```
章节前70%：推进主线剧情，解决上一章悬念
章节后20%：抛出新冲突/新信息/新危机
章节最后10%：用"但是/突然/然而"制造反转或悬念
```

### 追读率分档应对策略
| 追读率 | 状态 | 应对 |
|--------|------|------|
| >35% | 优秀 | 保持节奏，可适当放缓铺设伏笔 |
| 25-35% | 正常 | 检查最近5章是否有"平章"，增加冲突密度 |
| 15-25% | 偏低 | 立即安排一波高潮，连续3章高密度爽点 |
| <15% | 危险 | 考虑大反转/新地图/新角色入场 |

### 章节结尾钩子类型库
1. 悬念型："他打开门，看到了一个不可能出现的人"
2. 冲突型："你敢动她一下试试"
3. 信息型："原来，这一切都是他布的局"
4. 反转型："真正的敌人，一直在身边"
5. 情感型："她终于明白，自己一直在等的人是谁"

## 二、推荐流量撬动策略

番茄的推荐机制是"赛马制"——同一时段多个作品竞争有限的推荐位。

前三章完读率决定初始推荐量，追读率决定推荐是否持续。

### 流量撬动关键动作
- 首日更新3-5章，快速积累初始数据
- 每天固定时间更新（培养读者习惯）
- 避免断更（断更1天 = 推荐权重降30%）
- 章节字数控制在2000-2500字（太长完读率低，太短推荐效率低）

## 三、百万字连载节奏模板

百万字长篇的核心挑战是"如何在大篇幅内保持读者兴趣"。

解决方案：将百万字拆分为若干个"小故事弧"，每个弧20-30万字，有独立的起承转合。

### 自检清单
- [ ] 每章结尾是否有明确的追读钩子？
- [ ] 前三章完读率是否达到60%以上？
- [ ] 是否避免了连续3章以上的"平章"？
- [ ] 百万字架构是否拆分为20-30万字的小故事弧？
- [ ] 每个小故事弧是否有独立的起承转合？
- [ ] 地图扩展是否与字数进度匹配？
- [ ] 更新频率是否稳定（不断更）？
- [ ] 章节字数是否控制在2000-2500字？

| 2022 | 听书功能上线 | 听读适配成为新要求 |
| 2023 | 短剧改编扶持 | 短剧改编成为新增收渠道 |
| 2024 | 算法大改 | 前三章完读率成为核心 |
| 2025 | 听读权重拉满 | 格式要求更严（每段≤3行） |
| 2026 | 权重重排 | 追读率+听读双核心 |
