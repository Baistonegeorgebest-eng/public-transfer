## 平台定位

晋江 = 女频网文黄埔军校。核心特征：
- 精品化、情感向内容调性
- 付费阅读为主（区别于番茄免费模式）
- 人工编辑主导+算法辅助的推荐机制
- IP影视改编头部平台（《甄嬛传》《花千骨》《魔道祖师》等）

## 积分核心速查

**积分公式（2026年参考）：**
```
总积分 ≈ 收藏×3 + 点击×0.1 + 长评×50 + 短评×5 + 营养液×2
```

**高权重指标：**
- 长评（50分/条）：鼓励读者写分析性评论
- 收藏（3分/个）：核心忠诚度指标

**低权重但量大：**
- 点击（0.1分/次）：靠曝光量取胜
- 短评（5分/条）：靠互动频率取胜

## 签约入V快速参考

### 签约条件
- 通常需要1-3万字 + 数据表现（收藏等）
- 编辑审核稿件质量和市场潜力
- 签约类型：普通签约 / 独家签约 / 买断

### 入V门槛
| 频道 | 收藏门槛 | 入V字数 |
|------|---------|---------|
| 言情 | 200-500收藏 | 10-20万字 |
| 纯爱 | 150-400收藏 | 10-20万字 |
| 百合 | 较低 | 视编辑建议 |

### 收益
- 订阅收入分成：50%-70%（视签约类型）
- 霸王票分成：50%
- 全勤奖：日更达标有额外奖励

→ 详见 [references/genres-signing.md](references/genres-signing.md)（题材分区+签约流程+入V机制+防盗机制）

## 审核红线速查

### 绝对红线（零容忍）
- 涉政内容 / 涉毒涉赌 / 未成年色情 / 极端暴力 / 邪教恐怖主义

### 高风险区域
- 性描写（2021年后审核大幅收紧，用隐喻代替直白）
- 师生恋 / 强制非自愿 / 乱伦 / 军警题材负面描写

### 被锁章应对
1. 检查被锁内容，修改敏感部分
2. 提交申诉，说明修改情况
3. 联系编辑寻求帮助
4. 评论区安抚读者情绪

## 榜单冲榜速查

### 核心榜单
| 榜单 | 周期 | 核心策略 |
|------|------|---------|
| 新晋作者榜 | 6个月内 | 前3万字积分积累最关键 |
| 月榜 | 每月 | 月中冲刺+月末决胜 |
| 季榜 | 每季 | 持续高产 |
| 金榜 | 年度 | 综合积分+编辑审核+读者投票 |

### 月榜时间轴
```
月初（1-5号）：蓄力期 → 正常更新+准备存稿
月中（15-25号）：冲刺期 → 日更加更+高潮剧情
月末（25-31号）：决胜期 → 最大高潮+社群联动
```
