# 晋江积分/收藏/营养液/长评/霸王票机制

## 积分系统

晋江积分是衡量作品热度的核心指标，由多个维度构成：

- **点击积分**：每章节点击量贡献积分，同一IP每日仅计1次
- **收藏积分**：读者收藏作品产生的积分，权重较高
- **营养液积分**：读者赠送营养液，每瓶贡献固定积分
- **长评积分**：长评（200字以上）额外加分，权重最高
- **霸王票积分**：读者投雷/手榴弹/火箭炮/深水鱼雷等道具

**积分公式（2026年参考）**：
```
总积分 ≈ 收藏×3 + 点击×0.1 + 长评×50 + 短评×5 + 营养液×2
```

## 收藏

- 收藏是**最关键的指标之一**，直接影响入V门槛和排名
- 读者收藏后可在"收藏夹"中追踪更新
- 收藏数是编辑签约和入V审核的核心参考
- **入V门槛参考**：言情一般需数百收藏，纯爱/百合门槛略低

## 营养液

- 营养液是晋江独特的"打赏轻量级"道具
- 每日登录可领取免费营养液，也可购买
- 营养液数量直接反映读者粘性和作品口碑
- 营养液多的作品更容易进入各类榜单

## 长评

- **长评要求**：200字以上，且需有实质内容（不能水字数）
- 长评对积分贡献极大，一篇长评≈多条收藏的积分权重
- 优质长评会被作者置顶，形成社区互动氛围
- 长评数量也是衡量作品口碑的重要信号

## 收藏转化公式

收藏率 = 收藏数 / 点击数。晋江平均收藏率约3-5%，优秀作品可达8-12%。

**收藏转化漏斗：**
```
点击 → 阅读前3章 → 决定收藏 → 持续追读 → 入V付费

转化率参考：
  点击→前3章：60-80%
  前3章→收藏：3-12%
  收藏→追读：50-80%
  追读→入V：30-60%
```

**提升收藏率的五种手法：**
```
手法一：前三章"钩子密度"最大化
  → 第一章结尾必须有悬念
  → 第三章结尾必须有一个"大事件预告"
  → 让读者觉得"不收藏就忘了"

手法二：章末收藏引导
  → 不要只写"求收藏"
  → 要有创意："收藏的人下章都能看到男主告白"

手法三：入V前"蓄力"
  → 入V前3-5章安排高密度剧情
  → 入V第一章放最大爆点

手法四：简介与标签优化
  → 标签要精准（不要贪多）
  → 简介最后一句是"钩子"

手法五：封面质量
  → 晋江读者审美较高，封面要精致
  → 风格匹配题材
```

## 积分提升策略矩阵

```
短期提升（1-2周）：
  → 日更+固定时间更新，提升点击量
  → 章末引导收藏（"觉得好看请收藏~"）
  → 设置讨论话题，引导短评

中期提升（1-3月）：
  → 高质量剧情引发长评
  → 与读者互动，回复评论
  → 参与平台活动获取额外曝光

长期提升（3月+）：
  → 建立读者社群（微博超话/QQ群）
  → 完结后保持一定更新频率（番外/新文预告）
  → 多部作品形成"作者品牌效应"
```
