# 晋江榜单系统与冲榜技巧

## 榜单类型

### 新晋作者榜
- **对象**：注册时间不超过6个月的新作者
- **排名依据**：积分（综合点击、收藏、营养液等）
- **价值**：新作者最重要的曝光渠道，上榜后流量显著提升
- **策略**：新书前3万字的积分积累至关重要

### 月榜
- **周期**：每月更新
- **分区**：按频道（言情/纯爱/百合/衍生等）分别排名
- **排名依据**：当月积分增量
- **价值**：月榜前列作品曝光量大，是入V前的重要流量来源

### 季榜
- **周期**：每季度更新
- **排名依据**：当季积分总量
- **价值**：季度稳定表现的体现，适合长线连载作品

### 年榜
- **周期**：每年更新
- **排名依据**：年度积分总量
- **价值**：年度最具影响力作品的认定，对IP价值有加持

### 金榜
- **定位**：晋江最具含金量的榜单
- **产生方式**：综合积分+编辑审核+读者投票
- **分区**：各频道独立评榜
- **价值**：金榜作品通常是当年最热、质量最高的作品，影视改编概率大增

### 收藏夹榜/霸王票榜
- 反映读者直接支持度的榜单

### 各频道分区榜
- 按题材细分：现代言情、古代言情、仙侠、现代纯爱、古代纯爱、百合、衍生等

## 月榜冲榜时间轴

```
月初（1-5号）：蓄力期
  → 保持正常更新节奏
  → 观察竞争对手数据
  → 准备冲榜期间的存稿

月中（15-25号）：冲刺期
  → 日更或加更（每天2-3章）
  → 安排高潮剧情，引发讨论
  → 章末集中求收藏/营养液

月末（25-31号）：决胜期
  → 释放最大高潮章节
  → 社群联动，号召投票
  → 关注排名变化，必要时加码
```

## 频道榜冲榜差异化策略

- 言情榜：甜宠名场面+CP互动密度
- 耽美榜：人设苏感+剧情深度
- 古典仙侠榜：文笔质量+世界观完整度
- 现代都市榜：现实共鸣+节奏紧凑
- 无CP/剧情流榜：剧情反转+伏笔精妙

## 冲榜避坑

- 不要在月初就冲刺（后劲不足）
- 不要为了冲榜牺牲剧情质量
- 不要在冲榜期间断更
- 不要买数据（晋江检测严格，会封号）

## 推荐算法

### 人工+算法混合模式

晋江的推荐系统是**人工编辑主导+算法辅助**的混合模式：

- **编辑推荐**：编辑团队根据作品质量、题材趋势、市场反馈手动推荐
- **算法推荐**：基于读者阅读历史、收藏偏好、相似用户行为的协同过滤
- **首页轮播**：编辑精选+热度排序的混合展示

**核心推荐逻辑：**
```
推荐权重 ≈ 编辑评分×0.4 + 算法热度×0.3 + 读者互动×0.2 + 新鲜度×0.1
```

**推荐触发条件：**
- 上新推荐：新开文、有稳定更新的前3万字
- 入V推荐：入V后进入付费推荐池
- 完本推荐：完结作品的长效推荐位
- 节日/专题推荐：配合平台活动的主题推荐

### 编辑的重要性

晋江编辑对作品命运的影响远超其他平台：
- 编辑可以主动联系看中的作者签约
- 编辑推荐位是流量最大的入口
- 编辑对入V、上架时间有建议权
- 与编辑保持良好沟通是运营策略之一
