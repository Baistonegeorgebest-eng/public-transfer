## 附：2025-2026年平台安全红线升级版
### 1. 番茄小说AI审核机制（2026年新增）
番茄平台2026年引入AI内容检测：
→ 文风一致性检测：人类写作有随机性，AI没有
→ 情节重复率检测：AI容易重复相同桥段
→ 章节相似度检测：连续章节结构相似被标记
AI违规后果：
→ 轻微：限流警告
→ 中度：取消推荐资格
→ 严重：封号处理
如何避免AI违规：
✅ 使用AI辅助时，保留人工修改痕迹
✅ AI生成内容必须经过润色（改变句式/增加细节）
✅ 不要连续多章使用相同的开头句式
✅ 加入自己独有的写作风格（口头禅/叙事习惯）
### 2. 平台内容安全评分体系（2025年新标准）
各平台通用的内容安全评分：
评分维度：
→ 政治敏感度（0~100，越低越好）
→ 暴力描写度（0~100）
→ 色情暗示度（0~100）
→ 违法信息度（0~100）
合格标准：四个维度均低于40分
常见踩红线行为：
❌ 涉及真实政治人物的姓名/事件
❌ 描写吸毒/赌博的具体过程
❌ 亲密场景超过"点到为止"
❌ 教唆犯罪/传授犯罪方法
### 3. 2025年新出现的违规类型
① "软色情擦边"：边缘性暗示但未明确描写，2026年平台收紧管控
② "违规人设"：抹黑军人/警察/医生/教师等职业形象
③ "境外势力"相关：任何暗示境外势力干预的情节（虚构国家背景也不行）
### 4. AI写作的版权归属问题（2025年新议题）
当前法律状态：
→ AI生成内容的版权归属尚无明确法律
→ 多数平台要求"AI辅助必须标注"
→ 未来可能出台强制规定
建议做法：
→ AI辅助创作时，保留人工创作底稿
→ 标注"AI辅助创作"，避免版权纠纷
→ 重要情节人工撰写，AI仅做辅助
### 5. 写作安全自检表（升级版）
发布前必检：
- [ ] 无政治/涉黑/涉黄/涉赌内容
- [ ] 无抹黑军人/警察/医生/教师内容
- [ ] 无抄袭/融梗/洗稿
- [ ] AI辅助内容已标注
- [ ] 战力体系≤9×3境界
- [ ] 无教唆犯罪内容
- [ ] 文风非机械性（无连续相同句式）

### 7. 违规模糊地带（2025年新争议）
① 暧昧描写的边界
→ "点到为止"是行业惯例
→ 具体边界：不能描写身体接触过程
→ 可以写："他靠近她，心跳加速"（点到为止）
② 暴力描写的边界
→ 可以写打斗，但不能描写具体的解剖过程
→ 可以写流血，不能描写血腥细节
→ 仙侠/玄幻可以写"碎尸万段"（这是古代用语，不算违规）
③ 金钱描写的边界
→ 可以写具体金额（"他欠了一个亿"）
→ 不能写具体洗钱/贪污方法
→ 不能写如何非法转移资产
### 8. 审核申诉的正确姿势
被误判违规后：
① 不要立即重发（会加重处罚）
② 联系平台客服，说明具体情况
③ 提供"人工创作证明"（创作底稿/时间戳）
④ 申诉期间不要修改原文
申诉成功率高的情形：
→ 有明确的创作时间戳证明
→ 内容确实在模糊地带
→ 首次违规
### 9. 政治敏感度自检表
以下内容绝对禁止：
❌ 涉及中国政治制度/领导人
❌ 涉及台/港/疆/藏等领土问题
❌ 涉及真实历史事件（民国/文革/六四等）
❌ 涉及国际关系敏感话题
以下内容需要授权：
❌ 以真实人物为原型的创作
❌ 以真实企业为背景的商业故事
### 10. AI辅助创作的合规使用（2026年新标准）
番茄小说要求：
→ AI辅助创作必须标注（平台提供标注选项）
→ 不能使用AI进行"批量创作"（会被检测）
→ AI生成内容必须有人工润色痕迹
合规的AI辅助方式：
✅ 用AI生成参考对话，人工修改后使用
✅ 用AI生成场景描写，人工修改后使用
✅ 用AI检查逻辑漏洞，人工修改后使用
不合规的AI使用方式：
❌ 纯AI生成，不做任何修改直接发布
❌ 多账号用同一AI批量生成（会被检测为"同质内容"）
❌ 用AI改写他人作品（侵犯版权）
### 11. AI检测的人工规避技巧（内部经验）
平台AI检测的判断逻辑：
→ 文字的随机性（人类写作有随机性，AI没有）
→ 句式的多样性（人类句式变化多，AI变化少）
→ 章节开头的一致性（AI倾向于用相同的开头）
人工干预技巧：
① 每章开头的手动修改（加入不同的起始词）
② 句式的主动变化（长短句交替）
③ 加入角色口头禅（AI不会学口头禅）
④ 加入人工润色的"噪音"（typo/口语化）
## 附三：写作安全深度案例库
### 案例1：边缘擦边内容被限流
背景：都市言情文，亲密场景写到"他吻了她"
问题：被平台标记为"疑似色情"
结果：全书限流，收益下降60%
正确处理：
→ 亲密场景点到为止
→ 用"心跳加速"代替身体描写
→ 用情绪描写代替动作描写
### 案例2：涉政内容被封号
背景：历史穿越文，主角评价唐朝政治制度
问题：被AI检测为"涉政内容"
结果：全书封禁
→ 评价历史朝代时，不要与现实政治制度类比
→ 不要用"制度"等现代政治词汇
→ 可以写具体的"皇帝昏庸/忠臣被害"但不能评价制度
### 案例3：抄袭被封号
背景：作者用了其他作品的设定和人物
问题：被读者举报"融梗抄袭"
结果：全书封禁+全平台封禁
→ 设定和人物必须原创
→ 可以借鉴"套路"但不能借鉴"具体表达"
→ 借鉴比例不超过20%

## 附五：AI创作安全合规进阶（2026年最新）
### 12. AI检测的"指纹"规避法
平台AI检测的本质：
→ AI生成的内容有"指纹"
→ 这个指纹是AI模型的统计特征
→ 人类写作没有这个特征
如何规避AI指纹：
① 句式多样性：主动变化句式（长短交替）
② 段落开头多样性：不要每章开头都用同样的句式
③ 口头禅植入：给角色设计独特的口头禅（AI不会学）
④ 打字错误：适当留一两个typo（不是严重错误）
### 13. 多平台同步发布的合规策略
同一内容多平台发布注意事项：
→ 各平台的AI标注要求不同
→ 番茄：必须标注AI辅助
→ 起点：无强制要求，但建议标注
→ 晋江：无强制要求，但建议人工标注
不同平台的内容调整：
→ 同一内容，根据平台尺度调整
→ 尺度大的平台可以写得更详细
→ 尺度小的平台要精简描写
### 14. 创作安全的"预防-监测-补救"体系
预防：
→ 发布前做完整的合规检查
→ 使用AI辅助时保留创作底稿
→ 了解各平台最新规则
监测：
→ 关注平台通知和违规提示
→ 定期检查作品数据（异常下降可能是被限流）
→ 关注读者反馈（读者可能先于平台发现违规）
补救：
→ 收到通知后立即修改
→ 申诉时提供创作时间戳证明
→ 修改后观察数据恢复情况
### 15. 每日创作安全打卡表（养习惯）
每天发布前完成以下打卡：
- [ ] 无涉政/涉黑/涉黄内容

- [ ] 近期3章无逻辑漏洞
- [ ] 近期3章无OOC
