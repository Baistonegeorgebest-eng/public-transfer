## 一、签约策略矩阵

2026年起点签约体系分为三个档次：

### 签约三档对比

```
普通签约（入门）：
  → 门槛：3万字 + 投稿审核通过
  → 分成：订阅五五分成
  → 推荐：可参与PK，但优先级最低

保底签约（进阶）：
  → 门槛：编辑认可作品质量，给出保底价格
  → 分成：保底 + 超出部分分成
  → 推荐：PK优先级中等

大神约/买断（顶级）：
  → 门槛：前作有成绩 / 编辑主动邀约
  → 分成：固定稿费或高保底
  → 推荐：PK优先级最高，有额外资源倾斜
```

### 签约前优化清单
1. **书名**：6-10字，含核心卖点关键词（如"稳健""长生""从XX开始"）
2. **封面**：专业制作，风格匹配题材
3. **简介**：三段式——背景+金手指+悬念，不超过200字
4. **前三章**：必须在300字内出金手指，第一章结尾有钩子
5. **更新**：签约前保持每天2章，证明有持续产出能力

## 二、推荐位竞争法则

### 四轮PK详解

```
第一轮PK（新书期）：
  → 触发条件：收藏达到频道门槛
  → 核心指标：追读率
  → 策略：前30章必须章章有钩子，追读率目标 > 15%
  → 通过率：约50%

第二轮PK（小热门）：
  → 核心指标：追读率 + 月票增长
  → 策略：安排一波小高潮，拉高月票数据

第三轮PK（热门竞争）：
  → 核心指标：追读率 + 订阅均订
  → 策略：大高潮章节，配合求票/求订阅

第四轮PK（大推荐）：
  → 核心指标：全维度数据
  → 策略：保持节奏不崩，稳住数据
```

### PK期间关键操作
- 更新频率加倍（每天3-4章）
- 章末求票话术要真诚且有创意
- 本章说互动要积极回复
- 避免在PK期间写争议性内容

## 三、读者社群运营

### 本章说运营三原则

**原则一：制造讨论话题**
- 章节中故意留"可以争论的点"
- 本章说数量多 = 活跃度高 = 推荐权重加分

**原则二：适度互动**
- 精选回复，风格要"像作者不像客服"
- 偶尔剧透一点点

**原则三：引导情绪**
- 高潮章节后"求月票"
- 虐心章节后安抚读者
- 悬念章节后激发讨论

### 月票运营节奏
- 月初（1-5号）：发布"本月计划"
- 月中（15-20号）：安排大高潮，集中求票
- 月末（25-30号）：冲刺排名
