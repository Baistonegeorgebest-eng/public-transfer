# 锻造体系与东西方武器详解

> 锻造流核心设定、东西方武器体系对比、东方神兵与西式神器。

## 1. 锻造体系设计

### 1.1 锻造三要素

锻造三要素：材料+工艺+火候
→ **材料**：决定武器上限（寒铁/玄冰/星辰之精）
→ **工艺**：决定能发挥几分（锻造师水平）
→ **火候**：决定最终品质（文火/武火/三昧真火）

### 1.2 锻造师等级

徒弟（能锻造凡品）→ 匠师（能锻造极品）→ 大师（能锻造灵器）→ 宗师（能锻造仙器）→ 传说（能锻造神器）

### 1.3 锻造场景描写

"他将寒铁投入炉中，以三昧真火淬炼"
"九九八十一锤，每一锤都敲在剑胚的穴位上"
"最后一锤落下，剑身发出一声清越的龙吟——成了！"

### 1.4 锻造流核心爽点

- 爽点一：亲手打造神兵（主角是锻造师）
- 爽点二：发现废弃武器的隐藏潜力（修补/重铸）
- 爽点三：以普通材料锻造出超越仙器的奇迹
- 爽点四：锻造出唯一一件克制某敌人的专属武器
- 爽点五：锻造传承（为徒弟/后代锻造）

### 1.5 材料分级

| 等级 | 材料类型 | 来源 |
|------|---------|------|
| 凡品 | 普通铁/铜 | 挖矿 |
| 良品 | 寒铁/赤铜 | 稀有矿脉 |
| 极品 | 星辰之精/九天玄铁 | 天外陨石 |
| 神品 | 造化之气凝聚 | 天地唯一 |

### 1.6 铭文要素

铭文等级：初阶铭文（基础特效）→ 中阶铭文（高级特效）→ 高阶铭文（特殊效果）→ 神阶铭文（超自然效果）

铭文来源：自行铭刻（需要技艺）/ 传承获得（更强大）/ 天然形成（最强大）

### 1.7 注入仪式

- 血祭（以血激活）
- 灵魂契约（以灵魂绑定）
- 传承仪式（以传承激活）

## 2. 东方武器体系

### 2.1 东方武器性格

| 武器 | 性格 | 核心招式 | 标志场景 |
|------|------|---------|---------|
| 剑 | 百兵之君，君子之器 | 万剑归宗/一剑破天 | 剑出鞘，寒芒如雪 |
| 刀 | 百兵之帅，霸道之器 | 力劈华山/横扫千军 | 刀光如瀑，一刀断岳 |
| 枪/矛 | 百兵之王，沙场之器 | 霸王枪/回马枪 | 枪出如龙，洞穿一切 |
| 弓/弩 | 精准致命，远程猎杀 | 万箭齐发/一箭穿云 | 弦如满月，箭去似流星 |
| 扇/笛 | 风流潇洒，暗藏杀机 | 扇骨藏针/音波夺魄 | 扇开生面，针死无声 |
| 鼎 | 镇压气运，炼丹炼器 | 鼎镇山河 | 鼎立大地，气吞山河 |
| 琴 | 音律杀人，范围杀伤 | 十面埋伏/广陵散绝 | 琴音裂石，群敌授首 |

### 2.2 剑道六重境界

| 境界 | 名称 | 武器对应 |
|------|------|---------|
| 第一境 | 剑士 | 普通长剑（铁剑/钢剑） |
| 第二境 | 剑客 | 稀有材质（寒铁剑/赤铜剑） |
| 第三境 | 剑侠 | 器灵觉醒（灵器初成） |
| 第四境 | 剑宗 | 剑意解锁（剑气外放） |
| 第五境 | 剑圣 | 心剑合一（人剑合一） |
| 第六境 | 剑神 | 万剑归宗（万物皆可为剑） |

### 2.3 东方神兵

- 轩辕剑（黄帝传承，正道之剑）
- 盘古斧（开天辟地之力）
- 女娲石（补天之物，防御至宝）
- 东皇钟（镇压气运之器）

## 3. 西方武器体系

### 3.1 西方武器性格
- 剑：骑士的象征
- 斧：力量的代表
- 弓：远程的利器
- 法杖：魔法的媒介
- 盾牌：防御的核心

### 3.2 西式神器
- 石中剑（王者之剑）
- 雷神之锤（雷霆之力）
- 阿基琉斯之矛（无敌之矛）
