# 武器命名系统详解

> 好的武器名字要满足三个条件：好记（3个字以内最佳）、有画面感、有逼格。

## 1. 名字长度公式

- **2字名**：简洁有力，如"霜月""断魂""赤霄"——最常用
- **3字名**：增加逼格，如"鸣凤剑""焚天刀""碧波枪"——高级感
- **4字名**：史诗感，如"赤霄火鳞剑"——太长了慎用

## 2. 命名七种方法

### 方法一：颜色+意象
公式：颜色词 + 自然意象
- 玄黑（色）+ 霜（意象）= 玄霜剑
- 赤红（色）+ 霄（意象）= 赤霄剑
- 霜白（色）+ 月（意象）= 霜月刀
- 碧鳞（色）+ 龙（意象）= 碧鳞刀

颜色词库：玄黑/赤红/霜白/鸦青/鎏金/碧鳞/藕荷/松绿
意象词库：霜/月/霄/云/风/雷/火/龙/凤/魂/断/鸣/焚/碧/寒

### 方法二：材质+意象
公式：材质名 + 武器类型/意象
- 玄冰（材）+ 剑 = 玄冰剑
- 寒铁（材）+ 枪 = 寒铁枪
- 赤铜（材）+ 刀 = 赤铜刀

材质词库：玄冰/寒铁/赤铜/星辰金/九天玄铁/陨铁/紫电青霜

### 方法三：动词+意象
公式：动作词 + 武器意象
- 鸣（动）+ 凤（象）= 鸣凤剑
- 断（动）+ 魂（象）= 断魂刀
- 焚（动）+ 天（象）= 焚天刀
- 裂（动）+ 地（象）= 裂地枪

动作词库：鸣/断/焚/裂/啸/破/碎/灭/斩/屠
意象词库：魂/天/地/穹/苍/冥/虚/寂

### 方法四：阵法/道法意象
公式：阵法名 + 武器类型
- 八荒（阵）+ 剑 = 八荒剑
- 六合（阵）+ 枪 = 六合枪
- 周天（阵）+ 戟 = 周天戟

阵法词库：一元/两仪/三才/四象/五行/六合/七星/八卦/九宫/十方

### 方法五：古诗词化用
公式：古诗词中的意象词 + 武器类型
- 碧血（词）+ 剑 = 碧血剑
- 干将（古剑名）+ 莫邪 = 干将莫邪（双剑）

古风词库：碧血/干将/莫邪/吴钩/鱼肠/太阿/赤霄/纯钧

### 方法六：神兽/神话意象
公式：神兽名 + 武器类型
- 龙（兽）+ 剑 = 龙渊剑
- 凤（兽）+ 琴 = 凤鸣琴
- 玄武（兽）+ 甲 = 玄武甲

神兽词库：龙/凤/龟（玄武）/虎（白虎）/雀（朱雀）/麒麟/鲲鹏/饕餮

### 方法七：功能+意象
公式：武器核心功能 + 意象
- 镇魂（功能）+ 鼎 = 镇魂鼎
- 摄心（功能）+ 铃 = 摄心铃
- 裂空（功能）+ 刀 = 裂空刀

功能词库：镇/摄/控/灭/断/裂/焚/封/锁
意象词库：魂/心/空/魔/道/天/地/劫

## 3. 命名避坑

❌ 名字太常见 → "神剑""仙剑""宝刀"——读者记不住
❌ 名字太长 → 超过5个字的名字，读者记不住
❌ 名字和武器外形不符 → 叫"烈火刀"却是冰属性
❌ 名字太中二 → "宇宙毁灭者之剑"——读者会出戏

✅ 正确做法：名字要在脑海中形成画面；2-3字最佳；同书内不同武器要有区分度

## 4. 命名模板

### 模板一：主角专属武器
武器名：玄霜断魂剑
→ 颜色：玄黑+霜白（双色渐变）
→ 意象：断魂（霸气+杀气）
→ 武器类型：剑（百兵之君，符合主角性格）

### 模板二：女主专属武器
武器名：碧波鸣凤琴
→ 颜色：碧色（清新）
→ 意象：凤鸣（优雅）
→ 武器类型：琴（才情，符合女主气质）

### 模板三：反派专属武器
武器名：赤霄焚天刀
→ 颜色：赤红+金霄
→ 意象：焚天（霸气侧漏）
→ 武器类型：刀（霸道，与反派性格匹配）
