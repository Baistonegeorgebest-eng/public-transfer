## 1. 核心指标详解

### 1.1 六大核心指标

| 指标 | 定义 | 健康值 | 重要性 |
|------|------|--------|--------|
| 追读率 | 每章读者留存比例 | ≥60%（前30章） | ★★★★★ |
| 完读率 | 从头读到尾的比例 | ≥20%（全本） | ★★★★☆ |
| 收藏转化率 | 曝光→收藏 | ≥5% | ★★★★☆ |
| 订阅转化率 | 免费→付费 | ≥3%（起点） | ★★★★☆ |
| 均订 | 平均每章订阅人数 | 因平台而异 | ★★★☆☆ |
| 追订比 | 追读人数/总收藏 | ≥30% | ★★★★☆ |

### 1.2 追读率（最重要）

**定义：** 第N章阅读人数 / 第1章阅读人数 × 100%

**分级标准：**
- **S级** ≥70% — 神作级，平台重点推荐
- **A级** 60-70% — 优秀，稳定推荐
- **B级** 50-60% — 合格，有推荐但不稳定
- **C级** 40-50% — 堪忧，需要优化
- **D级** <40% — 危险，可能被砍推荐

### 1.3 完读率

**健康标准：** 30万字≥30% / 50万字≥20% / 100万字≥10%

**低完读率常见原因：** 中期节奏拖沓 / 世界观太复杂 / 核心矛盾解决后无新驱动力

### 1.4 收藏转化率

**影响因素：** 封面(40%) + 标题(30%) + 简介(20%) + 字数/更新(10%)

### 1.5 订阅转化率

**最佳付费节点：** 主角第一次重大升级/胜利之后
**付费前需要：** 足够角色羁绊 + 未完成悬念
**付费后需要：** 立即给爽感

### 1.6 追订比

**追订比 = 最新章订阅 / 总收藏 × 100%** — 反映"活读者"比例

## 2. 追读率曲线诊断

### 2.1 正常曲线

```
100%|*
    | **
    |   **
    |     ***
    |        ****
    |            ******
    ──────────────────────
     1  10  20  30  50  100
```

特征：前5章下降最快（筛选读者）→ 5-20章缓慢下降 → 20章后趋于稳定

### 2.2 三种异常曲线

**A. 悬崖式下跌** — 第X章有致命问题（主角做了读者无法接受的事/逻辑崩塌/核心卖点突变）
→ 立即回看第X章前后，找读者评论

**B. 中期崩塌** — 中期节奏拖沓/爽点密度下降/世界观太复杂
→ 加速中期剧情，增加爽点密度，简化设定

**C. 持续下滑无平台期** — 缺乏让读者"留下来"的钩子
→ 每个高潮后立即设置新的悬念/目标

### 2.3 章节级异常定位

```
1. 导出每章阅读量数据
2. 计算每章相对前一章的留存率
3. 找出留存率<85%的章节
4. 连续两章低留存 = 问题区域
5. 回看问题章节，分析原因
```

常见原因：大段说明/设定堆砌 / 主角OOC / 爽点延迟 / 配角戏份过多 / 突然换地图

## 3. 收藏转化漏斗

### 3.1 漏斗模型

```
曝光 → ×5-10% → 点击 → ×30-50% → 收藏 → ×50-70% → 阅读 → ×40-60% → 追读 → ×3-10% → 付费
```

### 3.2 每层优化

**曝光→点击（封面+标题+标签）：** 高对比度封面、含搜索热词的标题、精准标签
→ 从2%→5%=曝光效率提升150%

**点击→收藏（简介+前3章）：** 简介公式=身份+冲突+金手指+悬念；前3章=钩子→设定→高潮
→ 从20%→40%=收藏翻倍

**收藏→追读（更新+质量）：** 日更是底线、每章有信息增量、章末钩子
→ 从40%→60%=有效读者+50%

**追读→付费（情感+节点）：** 付费前足够情感投入、节点放在"不得不看"处
→ 从3%→6%=收入翻倍

### 3.3 漏斗诊断

```
收入下降？
├─ 曝光量下降 → 推荐位/标签/更新频率
├─ 点击率下降 → 封面/标题/简介
├─ 收藏率下降 → 简介/前3章
├─ 追读率下降 → 内容质量/节奏
└─ 付费率下降 → 付费节点/情感投入
```

## 4. 数据驱动选题

### 4.1 选题四维评估

| 维度 | 评估内容 | 数据来源 |
|------|---------|---------|
| 题材热度 | 排行榜题材分布、搜索热词趋势 | 平台榜单、百度指数 |
| 竞争饱和度 | 同题材作品数、头部vs腰部比例 | 分类统计 |
| 个人匹配度 | 擅长题材、知识储备、写作风格 | 自我评估 |
| 生命周期 | 题材在上升期还是衰退期 | 趋势分析 |

### 4.2 饱和度 vs 热度矩阵

```
热度高 ↑  蓝海机会（优先）  │  红海搏杀（需差异化）
         ──────────────────┤
         小众精品（细分突围）│  夕阳题材（不建议入场）
                          → 竞争饱和度高
```

### 4.3 选题实操步骤

```
1. 收集数据：各平台排行榜前50名
2. 分类统计：按题材/金手指/主角人设
3. 计算密度：每类题材作品数量占比
4. 分析头部：头部作品共同特征
5. 找缝隙：热度高但竞争少的细分领域
6. 交叉验证：结合个人优势确认可行性
```

## 5. 章节级数据复盘

### 5.1 每章复盘指标

| 指标 | 健康标准 | 异常信号 |
|------|---------|---------|
| 章节阅读量 | 相对稳定 | 突降>15% |
| 章节完读率 | ≥80% | <70%说明内容有问题 |
| 章节评论数 | 稳定或上升 | 连续3章无评论 |
| 章节点赞/打赏 | 与高潮对应 | 高潮章无反馈 |

### 5.2 问题章节定位法

```
Step 1 数据扫描：导出最近20章阅读量，计算留存率，标红<85%的章节
Step 2 问题分类：设定注水/节奏拖沓/爽点缺失/人设崩塌/逻辑漏洞
Step 3 针对修改：注水→删减分散 / 拖沓→砍对话加速 / 缺失→插入爽点 / 崩塌→加内心独白
```

### 5.3 数据复盘周报模板

```
【第X周数据复盘】统计周期：MM-DD ~ MM-DD
一、核心指标：新增收藏XXX（环比±X%）/ 平均追读率XX% / 总阅读量XXX
二、章节明细：第XX章留存率XX%（正常/异常+原因）
三、问题诊断：主要问题+影响范围
四、下周计划：修改计划+剧情预告+预期改善
```

## 6. A/B测试思维

### 6.1 可测试元素

封面 / 标题 / 简介 / 付费节点位置 / 更新时间

### 6.2 测试方法

```
1. 设计两个方案
2. A方案跑一周，记录数据
3. 换B方案跑一周，记录数据
4. 对比选择更好的

注意：其他条件保持一致 / 测试至少一周 / 每次只改一个变量
```

### 6.3 标题优化公式

```
[题材关键词] + [核心卖点] + [情绪钩子]

示例：
A：《规则怪谈：我在动物园生存的72小时》→ 信息最完整
B：《深夜动物园：所有人都遵守的七条规则》→ 有悬念
C：《规则动物园：第三条规则是假的》→ 悬念最强
```

### 6.4 简介结构公式

```
第一段：冲突钩子（读者被什么吸引）
第二段：核心设定（独特卖点是什么）
第三段：悬念留白（读者想知道什么）
```

## 7. 数据≠一切

### 7.1 什么时候该忽略数据

```
场景一：数据说题材不热，但你有独特视角 → 数据反映"过去"不是"未来"
场景二：数据说某章留存低，但那是必要铺垫 → 不能为了追读率跳过所有铺垫
场景三：你明确知道读者要什么，数据还没反映 → 数据有滞后性
```

### 7.2 数据+直觉的正确用法

```
数据定位问题（哪里出了问题）
  ↓
直觉分析原因（为什么出问题）
  ↓
数据验证方案（改了之后有没有改善）
```

### 7.3 数据陷阱

```
❌ 幸存者偏差 — 只看到成功作品的数据
❌ 短期波动误判 — 一天数据不能说明趋势
❌ 相关≠因果 — 追读率下降不一定是内容问题，也可能是推荐位变化
❌ 过度优化 — 为了数据牺牲创意，写出没有灵魂的流水线作品
```
