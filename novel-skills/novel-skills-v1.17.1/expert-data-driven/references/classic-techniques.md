# 经典技法补全

## 技法一：追读率诊断矩阵

### 诊断矩阵

| 追读率表现 | 可能原因 | 优先级 | 应对方案 |
|-----------|---------|--------|---------|
| 前5章骤降 | 开篇钩子不够/题材与预期不符 | P0 | 重写前3章或修改简介 |
| 5-15章缓降 | 爽点密度不足/配角戏份过多 | P1 | 增加主角爽点，砍配角戏份 |
| 15-30章崩塌 | 中期节奏拖沓/世界观太复杂 | P1 | 加速剧情，简化设定 |
| 30章后稳定低 | 核心卖点不够强/读者不匹配 | P2 | 调整方向或接受现状 |
| 某章突然下跌 | 该章有致命问题 | P0 | 立即回看该章 |
| 高潮章无提升 | 爽感设计不足/铺垫不够 | P1 | 重新设计高潮场景 |

### 使用流程
```
1. 导出每章追读数据
2. 描绘追读率曲线
3. 对照矩阵找到对应情况
4. 按优先级执行应对方案
5. 一周后复查数据变化
```

### 自检清单
- [ ] 是否每周至少做一次追读率曲线分析？
- [ ] 是否针对异常章节有具体的修改计划？
- [ ] 是否在修改后追踪了数据变化？
- [ ] 是否避免了"头痛医头"式的过度修改？

## 技法二：收藏转化优化公式

### 各要素优化标准

**封面优化（权重40%）：**
- 高对比度配色（深色背景+亮色文字）
- 标题字号≥画面的1/3
- 明确的题材标识
- 避免过度设计（简洁>复杂）

**标题优化（权重30%）：**
- 包含1-2个搜索热词
- 字数8-15字最佳
- 有信息量（不是纯抽象）

**简介优化（权重20%）：**
- 第一句话制造冲突
- 3句话内说清核心卖点
- 留悬念，不超过200字

**前3章优化（权重10%）：**
- 第1章出钩子
- 第2章出金手指/核心设定
- 第3章出第一个小高潮

### 自检清单
- [ ] 封面有明确题材标识？
- [ ] 标题包含搜索热词？
- [ ] 简介3句话内说清卖点？
- [ ] 前3章有完整钩子→设定→高潮链条？
- [ ] 做过封面/标题的A/B测试？
