# 各平台数据工具使用指南

## 番茄作家助手

### 核心功能
```
→ 实时阅读量统计
→ 收藏/追读数据
→ 读者画像（性别/年龄/地区）
→ 收入明细
```

### 数据维度
```
→ 今日数据 vs 历史数据
→ 章节级阅读量
→ 读者来源渠道
```

### 使用技巧
```
→ 每天固定时间查看，养成数据习惯
→ 重点关注追读率趋势而非单日数据
→ 结合评论区分析数据背后的原因
```

---

## 起点数据后台

### 核心功能
```
→ 订阅数据（均订/高订/追订）
→ 推荐票/月票数据
→ 收藏数据
→ 书评区管理
```

### 数据维度
```
→ 按卷/按章的订阅数据
→ 付费转化漏斗
→ 读者活跃度
```

### 使用技巧
```
→ 均订是核心指标——代表稳定收入
→ 追订/总收藏=追订比，反映读者粘性
→ 付费章首章订阅量是关键——代表付费转化率
```

---

## 晋江积分面板

### 核心功能
```
→ 积分排行
→ 收藏数据
→ 营养液/地雷数据
→ 评论互动数据
```

### 数据维度
```
→ 积分来源分析
→ 收藏增长曲线
→ 互动热度
```

### 使用技巧
```
→ 积分是综合指标，包含多种因素
→ 营养液反映读者付费意愿
→ 评论数反映读者参与度
```

---

## 第三方数据工具

```
→ 百度指数：搜索热词趋势
→ 微信指数：微信生态内的热度
→ 新榜/飞瓜：跨平台数据分析
→ 自建数据表：手动记录关键指标（Excel/Notion）
```
