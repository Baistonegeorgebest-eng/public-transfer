## 三、新手必学的10个核心能力

按优先级排列。前5个是"能写"的底线，后5个是"写好"的关键。

### 🔴 必须先学（能写的底线）

#### 1. 开篇钩子 — expert-hook（603行）

**50字速读：** 前300字决定读者走不走。第一句抛冲突，前3段给悬念，第一个场景必须有事件发生。不要从"天气很好"或"主角起床"开始。

**必读章节：**
- 第一章 开篇钩子的分类
- 开篇禁忌（千万别做的10件事）

**学到什么程度可以动笔：** 能写出一个让朋友愿意读完前500字的开头。

#### 2. 人物塑造 — expert-character（722行）

**50字速读：** 人物不是简历，是行为。不要告诉读者"他很聪明"，要让他做出聪明的事。配角不是工具人，每个配角要有自己的欲望。

**必读章节：**
- 性格弧线四阶段法
- 配角记忆点速成

**学到什么程度可以动笔：** 能用3句话描述主角的核心性格+一个鲜明特征。

#### 3. 爽点设计 — expert-plot-shuangdian（754行）

**50字速读：** 读者追读的本质是"期待被满足"。打脸是最基础的爽点：先压抑（被欺负/被嘲笑）→ 翻转（实力暴露）→ 释放（对方震惊/后悔）。每3-5章至少一个小爽点。

**必读章节：**
- 打脸三段式模板
- 升级爽感公式

**学到什么程度可以动笔：** 能设计出一个完整的"压抑→翻转→释放"小事件。

#### 4. 节奏控制 — expert-pacing（742行）

**50字速读：** 网文节奏 = 信息密度。每章必须有信息增量（新信息/新冲突/新进展）。断章是最强武器——在高潮前切断，读者会追到下一章。

**必读章节：**
- 断章公式
- 高潮三层递进

**学到什么程度可以动笔：** 能控制每章在2000-2500字，且每章结尾有悬念。

#### 5. 写作安全 — expert-writing-safety（760行）

**50字速读：** 平台会审核，被锁章=前功尽弃。暴力场景写结果不写过程，色情暗示用隐喻，涉政绝对不碰。和谐词替换表必须存一份。

**必读章节：**
- 和谐词替换表
- 安全描写框架

**学到什么程度可以动笔：** 知道哪些词不能写，哪些场景需要绕着写。

### 🟡 进阶必学（写好的关键）

#### 6. 对话设计 — expert-dialogue（828行）

**50字速读：** 每个角色说话方式要不同。语言 = 人设。暴躁的人说短句，学究的人说话绕弯，话痨的人说一半被打断。对话不只是传递信息，更是塑造角色。

**必读章节：**
- 角色语言差异化
- 对话的潜台词

#### 7. 开篇3000字模板 — expert-fanqie-novel（766行）

**50字速读：** 不管发哪个平台，番茄的"五件套"模板都适用：钩子→身份→冲突→反转→行动。3000字内讲清楚主角是谁、要做什么、有什么阻碍。

**必读章节：**
- 第三章 番茄长篇黄金开篇（3000字五件套）

#### 8. 情感描写 — expert-emotion（688行）

**50字速读：** 不要写"他很伤心"，要写他做了什么。情感 = 行为 + 细节 + 留白。让读者自己感受到情绪，而不是被告诉"这里应该感动"。

**必读章节：**
- 情感表达的行为化
- 共鸣制造技法

#### 9. 逻辑审查 — expert-logic（773行）

**50字速读：** 读者最不能忍的不是文笔差，是逻辑崩。写完后检查：因果关系是否成立？角色行为是否一致？时间线是否矛盾？战力是否溢出？

**必读章节：**
- 因果链五步验证
- 行为一致性矩阵

#### 10. 连载运营 — expert-serialization-ops（719行）

**50字速读：** 写得好不如运营好。更新频率稳定 > 偶尔爆更。不要断更超过3天。追读率是生死线，低于8%就要调整。数据异常48小时内必须响应。

**必读章节：**
- 更新节奏设计
- 数据监控日常

## 四、新手常见错误 Top 10

| 错误 | 后果 | 怎么避免 |
|------|------|---------|
| 开篇3000字全是背景介绍 | 读者直接划走 | 用"五件套"模板，事件先行 |
| 主角一上来就无敌 | 没有成长弧线，读者无聊 | 降低起点，给成长空间 |
| 配角全是工具人 | 世界不真实，读者不信 | 每个配角有独立动机 |
| 对话全是"他说""她说" | 无聊 | 用行为和语言风格区分角色 |
| 每章200字水过去 | 追读率暴跌 | 每章必须有信息增量 |
| 断更一周 | 算法惩罚，读者流失 | 日更有困难就隔日更，但绝不断 |
| 不看数据 | 不知道自己哪里写错了 | 每天看追读率，找到流失点 |
| 抄别人的设定 | 没有辨识度，还可能被举报 | 借鉴结构，自己填充细节 |
| 同时写3本 | 3本都写不好 | 先完本一本再说 |
| 追求完美初稿 | 永远写不完 | 先写完，再改好 |

## 七、一句话总结

**先写完一本，再写好一本，最后写爆一本。**

不要在准备阶段停留太久。最好的学习方式是写完第一本回头看，你会发现所有skill里的建议都变成了亲身经验。

## 八、2026年新增：一键推进工作流（必读）

> 2026年新增的自动化工作流，让创作从"手动调用每个skill"变成"一句话推进全卷"。

### 8.1 你需要知道的3个新skill

| Skill | 一句话说明 | 什么时候用 |
|-------|----------|-----------|
| **expert-bookstatus** | 项目状态文件（章节索引+进度追踪） | 每个项目必须有，每章写完自动更新 |
| **novel-volume-workflow** | 卷级全流程自动编排 | 说"推进第二卷"就自动走完全链路 |
| **expert-revise-loop** | 质检不过时的3轮自动修正 | quality-gate检测出问题后自动处理 |

### 8.2 新手创作流程（2026版）

```
旧流程（手动）：
  用户："帮我写第1章" -> agent写 -> 用户检查 -> 用户说"调用quality-gate检查" -> ...
  问题：每一步都需要用户手动调用skills

新流程（自动）：
  用户："推进第二卷" -> 自动走完全链路：
    1. 读取 bookstatus 恢复进度
    2. 加载前情/伏笔/世界观
    3. 卷级规划（10个expert自动调用）
    4. 逐章执行（每章自动质检+修正+更新）
    5. 输出正文 + 质检报告
  用户只需要说一句话
```

### 8.3 关键规则

- 不需要手动调用skills -> 全部自动执行
- 质检不过不会输出 -> 自动修正3轮，未通过才升级给你
- 章节索引自动维护 -> bookstatus每章自动更新
- 剧情节奏自动校验 -> 对照PLOT-FRAMEWORK检查是否过快/偏移
