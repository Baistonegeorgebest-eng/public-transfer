## 二、西幻政治体系设计

### 五种经典政体
```
① 王权制 → 国王+贵族+骑士 → 宫廷阴谋
② 帝国制 → 皇帝+行省+军团 → 军事政变
③ 共和制 → 议会+元老+公民 → 政治博弈
④ 神权制 → 教皇+教会+信徒 → 信仰冲突
⑤ 部落联盟 → 酋长+长老+战士 → 酋长之争
```

### 设计要点
政体决定了权力斗争的形式。选择政体时要先想好"主要冲突是什么"，然后选最合适的政体来承载这个冲突。

## 三、心动场景公式

言情小说的核心价值是"让读者心动"。心动的本质是"距离的突然拉近"。

### 五要素公式
```
心动值 = 意外性 × 亲密距离 × 情绪浓度 × 感官细节 × 克制感

意外性（0-3）：0=预料之中，3=完全出乎意料
亲密距离（0-3）：0=正常社交距离，3=呼吸可闻
情绪浓度（0-3）：取决于前文情感铺垫
感官细节（0-3）：不写"他很帅"，写"睫毛在脸上投下一小片阴影"
克制感（0-3）：越克制越心动
```

### 十种经典心动场景
① 英雄救美 → 救完之后的"确认安全"瞬间
② 不经意触碰 → 手指碰到手指，两人都假装没发生
③ 雨中共伞 → 物理距离被迫拉近
④ 醉后真言 → 平时不敢说的话醉后说了
⑤ 生病照顾 → 一方脆弱，一方温柔
⑥ 背后环抱 → 教做某事时的肢体接触
⑦ 吃醋现场 → 看到对方和异性亲近时的反应
⑧ 独处时刻 → 意外被困在某个空间
⑨ 专属称呼 → 第一次用非正式称呼
⑩ 送/收到礼物 → "我一直记得你说过的话"

## 四、感情线节奏模板

### 七阶段模板
```
阶段一：初遇（1-3万字）
  → 建立第一印象，制造"再次见面"的合理理由

阶段二：偏见/误解（3-8万字）
  → 双方对彼此有错误认知

阶段三：暗生情愫（8-15万字）
  → 用"行为"而非"心理描写"表现
  → ❌ "她发现自己好像喜欢上他了"
  → ✅ "她发现自己会不自觉地看向门口，等他出现"

阶段四：暧昧期（15-22万字）
  → 读者最享受的阶段，可以适当拉长

阶段五：误会/分离（22-28万字）
  → 必须有的"虐心期"，持续3-5万字即可

阶段六：和好/告白（28-32万字）
  → 告白场景要"封神级"

阶段七：在一起后的考验（32万字+）
  → 外部压力考验感情，最终大团圆
```

## 五、CP感强化术

### 四法则
**法则一：反差互补**
- 性格反差：一个外向一个内向
- 身份反差：总裁×小职员 / 学神×学渣

**法则二：专属记忆**
- 创造只有两个人知道的"梗"/"暗号"/"回忆"

**法则三：自然称呼演变**
- 全名→姓+职位→名字→昵称→专属称呼
- 每次称呼变化都是"小型告白"

**法则四：并肩作战**
- 两个人各自发挥所长，一起解决问题
- 并肩 = 平等 = 最高级的爱情

### CP感自测
- 读者能否用一句话描述这对CP的特点？
- 副CP是否同样有CP感但不喧宾夺主？
- 两人在一起的场景是否比单独场景更有吸引力？
