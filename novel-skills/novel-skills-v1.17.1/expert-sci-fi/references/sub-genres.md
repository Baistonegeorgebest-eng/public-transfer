## 2. 四大子赛道详解

### 2.1 赛博朋克（Cyberpunk）

#### 核心设定四要素

**霓虹（Neon）：**
- 视觉基调：永恒的夜色、霓虹灯光、酸雨、雾气、全息广告
- 空间结构：上层（巨企总部/精英区，干净整洁）vs 下层（贫民区/黑市，混乱肮脏）
- 色彩体系：主色调——深蓝/紫色/黑色为底，霓虹粉/青/橙为点缀
- 描写模板："霓虹灯在酸雨中模糊成一片光晕，全息广告上的笑脸女人无声地张合着嘴唇。脚下的积水倒映着天空中巨型企业的LOGO——那是这座城市唯一的星辰。"

**义体（Cyberware）：**
- 义体等级：基础义肢（替代功能）→ 增强义体（超人能力）→ 战斗义体（军用级）→ 禁忌义体（人体极限突破）
- 义体侵蚀值（人性值）：每次义体替换降低"人性值"，满替换=失去人类身份/情感/记忆
- 义体经济：黑市义体、走私义体军火、义体医生（地下手术室）
- 核心张力：**义体越强，离"人"越远**

**巨企（Megacorp）：**
- 巨企类型：科技垄断（芯片/AI）、生物制药（基因/义体）、军工复合体（安保/武器）、媒体娱乐（信息控制）
- 巨企结构：董事会（幕后）→ CEO（台前）→ 企业武士（私人武装）→ 普通员工（社畜）
- 巨企与国家：巨企权力>国家，城市由巨企管理，政府沦为傀儡
- 巨企内部冲突：派系斗争、商业间谍、技术泄露

**黑客（Netrunner）：**
- 网络空间设定：虚拟现实网络层，数据以可视化形态存在
- 黑客攻防：入侵（ICE突破）→ 数据窃取 → 安全反制（黑ICE=杀人的防火墙）
- 黑客社会角色：情报贩子、数据盗贼、网络幽灵、信息解放者
- 核心风险：精神反馈——在网络中死亡，现实中脑死亡

#### 核心冲突模型

**个人 vs 系统：**
```
小人物（义体佣兵/黑客/底层社工）→ 发现系统（巨企/政府/AI）的阴谋
→ 试图揭露/反抗 → 系统碾压 → 找到同盟 → 最终对决
→ 但系统不可摧毁，最多制造裂痕 → 开放式结局
```

**赛博朋克的"反乌托邦定律"：**
1. 没有彻底的胜利 —— 打倒一个巨企，另一个补位
2. 科技解决不了不平等 —— 义体越发达，贫富差距越大
3. 人性是最后的底线 —— 当一切都可以数字化，"你还是你吗？"
4. 信息即权力 —— 控制信息流的人控制一切

#### 赛博朋克视觉风格描写词库

| 场景 | 关键词 | 描写要素 |
|------|--------|----------|
| 街道 | 霓虹、酸雨、全息广告、涂鸦、电线蛛网 | 光污染+视觉过载 |
| 居住区 | 胶囊公寓、集装箱住宅、垂直贫民窟 | 空间压迫感 |
| 黑市 | 地下通道、改装车间、义体摊位、信息贩子 | 混乱但有序 |
| 巨企总部 | 玻璃幕墙、空中花园、无菌走廊、监控矩阵 | 冷漠+压迫 |
| 网络空间 | 数据流、防火墙(ICE)、数据节点、虚拟化身 | 抽象+危险 |

#### 赛博朋克升级体系

```
肉体极限 → 基础义体 → 战斗义体 → 神经改造 → 全义体化 → 超越人类
（普通佣兵）  （半机械化）  （企业武士）  （顶尖黑客）   （传奇人物）  （禁忌领域）
```

**每个阶段的核心冲突：**
- 基础义体：经济压力（义体贷款）+社会歧视（义体人≠人）
- 战斗义体：企业控制（企业买的义体=企业的人）+人性侵蚀
- 神经改造：记忆篡改风险+意识分裂+谁是"真正的你"
- 全义体化：失去人类身份+被排斥+力量巅峰但孤独

### 2.2 末日生存（Post-Apocalyptic Survival）

#### 灾难类型矩阵

| 灾难类型 | 触发方式 | 世界观基调 | 生存难度 | 适合题材 |
|----------|----------|------------|----------|----------|
| 病毒爆发 | 实验室泄漏/自然变异 | 恐慌+混乱 | 中 | 丧尸围城、变异生物 |
| 核战废土 | 大国冲突/误判 | 荒芜+辐射 | 高 | 拾荒者、重建文明 |
| 陨石撞击 | 天灾不可抗力 | 黑暗+寒冷 | 极高 | 地下避难所、冰封世界 |
| AI叛变 | 超级AI失控 | 人机对抗 | 高 | 机械猎杀、游击战 |
| 环境崩溃 | 气候极端变化 | 资源枯竭 | 中高 | 水战争、粮食危机 |
| 异界入侵 | 平行世界/外星生物 | 混合文明 | 中 | 融合系、异能觉醒 |

#### 生存法则体系

**资源四象限：**
```
         紧急
          ↑
  食物 | 医疗
  水源 | 武器
 --------→ 重要
  庇护所 | 弹药
  燃料   | 信息
          ↓
         不紧急
```

**生存优先级（前30章黄金法则）：**
1. **水** —— 脱水比饥饿死得快，水源争夺是最自然的早期冲突
2. **庇护所** —— 一个安全的据点是所有发展的基础
3. **食物** —— 独猎→团队→种植→养殖的生存升级线
4. **武器** —— 防御优先于攻击，"不被吃掉"比"吃掉别人"重要
5. **信息** —— 末日后的信息差价值倍增（哪里有避难所/哪里安全）
6. **同伴** —— 独狼生存上限有限，团队建设是中期主线

**末日生存"新社会形态"设计：**

| 阶段 | 时间跨度 | 社会形态 | 核心冲突 |
|------|----------|----------|----------|
| 混沌期 | 0-3个月 | 暴力为王、弱肉强食 | 活下来 |
| 整合期 | 3-12个月 | 帮派/部落形成 | 资源争夺 |
| 秩序期 | 1-3年 | 聚居地/小政权 | 规则建立 |
| 重建期 | 3-10年 | 城邦/联盟 | 文明冲突 |
| 新世界 | 10年+ | 新国家/新文明 | 新秩序vs旧记忆 |

#### 人性考验设计（核心卖点）

**七大经典人性考验场景：**

1. **分配困境** —— 食物只够一半人吃，谁活谁死？
   - 写法要点：不要让主角"大公无私"地解决，要让读者也纠结
2. **背叛与信任** —— 收留的陌生人是间谍/强盗？
   - 写法要点：前期铺垫信任建立，背叛才有杀伤力
3. **牺牲选择** —— 救一个人还是救一群人？
   - 写法要点：被牺牲的那个人要有名字、有故事、有温度
4. **暴力边界** —— 为了生存可以做到什么程度？
   - 写法要点：让读者理解（不一定认同）角色的选择
5. **文明底线** —— 吃人？奴隶制？这些"旧世界禁忌"在新世界还适用吗？
   - 写法要点：展示不同群体对此的不同选择
6. **希望vs现实** —— 救援到底会不会来？"希望"本身可能是毒药
   - 写法要点：希望和绝望交替出现
7. **旧世界身份** —— CEO和乞丐在末日中是否平等？
   - 写法要点：旧身份有时有用（技能），有时是负担（傲慢）

#### 末日生存升级体系

```
流亡者 → 据点居民 → 探索者 → 聚落首领 → 区域势力 → 文明重建者
（求生本能）（基础建设）（资源获取）（权力博弈）（文明冲突）（新世界缔造）
```

**末日题材的独特升级感：**
- 不是"变强"，而是"变安全"
- 从"一个人活着"到"一群人活着"到"一个文明活着"
- 每次升级感来源于"建设"而非"打怪"

#### 资源争夺叙事模板

```
发现资源点 → 侦查（发现竞争者）→ 准备阶段（布防/谈判/突袭选择）
→ 资源争夺战 → 获得资源（但有代价）→ 分配引发新矛盾
```

### 2.3 星际殖民（Interstellar Colonization）

#### 星际政治架构

**势力类型：**
| 势力类型 | 特征 | 叙事功能 |
|----------|------|----------|
| 星际联邦 | 多星系联合政府，官僚体系 | 规则制定者、反派来源 |
| 帝国 | 单一文明扩张，中央集权 | 权力斗争舞台 |
| 企业联盟 | 商业利益主导 | 资源冲突驱动力 |
| 独立殖民地 | 边疆星球、自给自足 | 主角主场、反抗基地 |
| 游牧舰队 | 无固定星球，太空为家 | 灰色势力、情报来源 |

**星际政治核心冲突线：**
1. 中心 vs 边疆 —— 核心星系对边缘殖民地的资源掠夺
2. 主流 vs 少数 —— 人类文明对其他种族的态度
3. 扩张 vs 保守 —— 是否继续殖民未知星系
4. 科技 vs 伦理 —— 基因改造/AI权利/意识上传的道德边界

#### 种族接触设计

**第一次接触（First Contact）模型：**

```
接触模式选择：
├── A. 对等接触 —— 双方文明等级相当 → 外交/贸易/冲突
├── B. 降维接触 —— 高等文明观察低等文明 → "动物园假说"
├── C. 意外接触 —— 考古发现/信号截获 → 揭示远古真相
└── D. 敌对接触 —— 资源竞争/领土重叠 → 战争不可避免
```

**外星种族设计模板：**
1. **生理差异** —— 硅基生命？气态生物？集体意识？外形越不像人，越有趣
2. **文化差异** —— 没有"隐私"概念的种族？以"死亡"为最高荣誉的种族？
3. **沟通障碍** —— 语言不通是基本设定，真正的问题是思维方式不通
4. **共同敌人** —— 最快的结盟方式是出现更大的威胁

**注意事项：**
- 避免"穿皮套的人类"——外星人不应该只是"长得不一样的人"
- 避免"全善全恶"——最好的外星种族设定是"他们有自己的逻辑，人类觉得疯狂但他们内部自洽"
- 避免"翻译机万能"——真正的文化冲突不在语言，而在价值观

#### 文明冲突叙事框架

**卡尔达舍夫文明等级在叙事中的应用：**

| 等级 | 能力 | 与低等文明互动模式 |
|------|------|---------------------|
| Type I | 行星能源利用 | 殖民/保护/忽视 |
| Type II | 恒星能源利用（戴森球） | 赏赐/实验/观察 |
| Type III | 银河系能源利用 | 神级存在/不可理解 |

**文明冲突叙事模板：**
```
低等文明发现高等文明遗迹 → 科技跳跃 → 引起高等文明注意
→ 高等文明的回应（好奇/恐惧/利用）→ 文明间博弈
→ 揭示宇宙真相 → 文明选择（融入/抵抗/超越）
```

#### 太空歌剧框架

**太空歌剧 = 星际尺度的史诗叙事**

**必备元素：**
1. **宏大舞台** —— 多个星系、多个文明、多个势力
2. **英雄旅程** —— 从边缘到中心的崛起之路
3. **势力博弈** —— 不是一个反派，而是多方势力的动态平衡
4. **科技奇迹** —— 超空间跳跃、巨型星舰、行星毁灭武器
5. **浪漫与悲壮** —— 太空歌剧需要"歌"的成分——情感浓度要高

**太空歌剧节奏模板（200章连载）：**
- Ch1-30: 行星故事（建立角色、本土冲突）
- Ch31-80: 星系故事（接触外星文明、势力博弈）
- Ch81-150: 银河故事（大规模战争、文明存亡）
- Ch151-200: 宇宙故事（终极真相、超越文明）

### 2.4 时间旅行（Time Travel）

#### 四大悖论处理方案

**1. 祖父悖论（Grandfather Paradox）**
- 问题：回到过去杀死祖父，自己就不会出生，但不出生就无法回到过去杀死祖父
- 处理方案：

| 方案 | 机制 | 叙事效果 | 代表作品 |
|------|------|----------|----------|
| 自洽时间线 | 过去不可改变，任何"改变"行为都是历史的一部分 | 宿命感+悲剧性 | 《前目的地》《哈利·波特3》 |
| 平行宇宙 | 改变过去=创造新分支，原时间线不受影响 | 自由度高但情感连接弱 | 《蜘蛛侠：纵横宇宙》 |
| 时间保护 | 自然力量阻止悖论发生（巧合/意外） | 喜剧感+命运不可抗 | 《回到未来》 |
| 信息闭环 | 不存在"回到过去杀死祖父"的可能性 | 悖论被逻辑消解 | 《降临》 |

**2. 平行时间线（Branching Timeline）**
```
主时间线 A ───────────────────────────→
                ↘
                  分支 B ───────────→
                ↘
                  分支 C ──╳ （崩塌/合流）
```

**设计规则：**
- 每次重大改变产生一条新分支
- 分支之间可以有"量子纠缠"——影响另一条线的自己
- 分支越多，宇宙越不稳定——制造"修复时间线"的紧迫感
- 主角的困境：回到哪条时间线？哪条是"真正的"现实？

**3. 固定循环（Bootstrap Paradox / Closed Loop）**

**经典循环结构：**
```
A → B → C → A（无始无终）
```

**循环设计要领：**
- 循环中的每个"选择"看似自由，实则必然
- 打破循环是终极目标（或终极悲剧）
- 信息/物品在循环中"无中生有"——制造悬念
- 循环的"第一次"永远不可知——保留神秘感

**4. 蝴蝶效应（Butterfly Effect）**

**效应层级设计：**
| 改变规模 | 影响范围 | 叙事用途 |
|----------|----------|----------|
| 微小改变 | 个人命运改变 | 情感线、选择困境 |
| 中等改变 | 历史事件偏移 | 世界线变动、身份危机 |
| 巨大改变 | 文明走向逆转 | 史诗叙事、末日危机 |
| 奇点改变 | 宇宙结构崩塌 | 终极危机、自我牺牲 |

**蝴蝶效应叙事模板：**
```
主角穿越到过去 → 做了一个"微小"改变 → 回到"现在"发现一切不同
→ 追溯改变路径 → 发现影响比预想大得多 → 尝试修复 → 修复引发新问题
→ 最终选择：接受新现实 / 再次改变 / 自我抹除
```

#### 时间旅行的"代价体系"

**时间旅行不是免费的，必须有代价：**

| 代价类型 | 具体表现 | 戏剧张力 |
|----------|----------|----------|
| 物理代价 | 每次穿越消耗寿命/生命力 | 不能无限穿越 |
| 记忆代价 | 穿越越多，记忆越混乱 | "我到底经历了什么？" |
| 存在代价 | 每次改变削弱自己的存在 | 存在危机 |
| 道德代价 | 知道未来却不干预 = 共犯 | 内心冲突 |
| 因果代价 | 改变过去导致身边人消失 | 情感重击 |

#### 时间旅行升级体系

```
被动穿越者 → 意识穿越者 → 主动穿越者 → 时间管理者 → 时间守护者 → 时间本身
（意外穿越）  （可控意识）  （可控肉体）  （修改历史）   （保护时间线） （超越因果）
```
