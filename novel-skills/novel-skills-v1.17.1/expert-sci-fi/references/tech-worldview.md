## 3. 科技树设计

### 3.1 科技树vs修仙体系对比

| 维度 | 修仙体系 | 科技树体系 |
|------|----------|------------|
| 升级逻辑 | 天赋+悟性+资源（主观性强） | 研发+实验+积累（客观性强） |
| 升级感知 | "感觉要突破了" | "实验证明了理论" |
| 阶段跳跃 | 可以顿悟、奇遇跳跃 | 必须有前置科技，不能跳 |
| 群体vs个体 | 以个人修炼为核心 | 以团队/文明发展为核心 |
| 升级爽感 | 突破时的天地异象 | 新科技的震撼展示 |
| 失败风险 | 走火入魔 | 实验失败/爆炸/变异 |

**核心差异：科技树比修仙更需要逻辑自洽。**

读者可以接受"主角顿悟突破"，但很难接受"主角突然发明了曲率引擎却没有前置理论"。科技树必须有清晰的因果链。

### 3.2 科技树分支设计

**标准科技树结构：**
```
                        [超空间技术]
                       /
        [量子通信] → [量子计算] → [AI觉醒]
       /                      \
[基础物理] → [能源革命] → [材料科学] → [纳米技术]
       \                      /
        [生物工程] → [基因编辑] → [意识上传]
                       \
                        [克隆技术] → [生命延续]
```

**每个科技节点的必备属性：**
```
科技名称：曲率驱动引擎
前置科技：量子引力理论 + 高能材料学
研发周期：50-100年（文明级别）/ 1-5年（主角金手指）
社会影响：星际旅行成为可能 → 殖民时代开启
军事影响：超光速打击 → 战争形态彻底改变
经济影响：星际贸易 → 新的经济中心
风险/副作用：空间涟漪 → 可能被其他文明探测到
```

### 3.3 科技锁（Tech Lock）

**定义：** 特定科技必须满足条件才能解锁，用于控制剧情节奏。

**科技锁类型：**
| 锁类型 | 解锁条件 | 叙事功能 |
|--------|----------|----------|
| 资源锁 | 需要稀有材料（外星矿石/暗物质） | 探索驱动力 |
| 知识锁 | 需要特定理论突破 | 科学家角色价值 |
| 设施锁 | 需要大型实验设备（粒子对撞机） | 基建叙事 |
| 伦理锁 | 社会共识允许才能研发 | 道德冲突 |
| 敌对锁 | 敌对势力封锁技术 | 对抗叙事 |
| 事件锁 | 特定剧情事件触发 | 主线推进 |

**科技锁在网文中的运用：**
```
主角需要X科技 → 发现需要Y前置 → 发现Y需要Z资源
→ Z资源在危险区域/敌对势力手中 → 冒险获取 → 解锁Y → 解锁X
→ 展示X科技的震撼效果 → 引出新需求（下一循环）
```

### 3.4 科技与社会互动模型

**科技革命 → 社会变革 → 新矛盾 → 新科技需求（循环）**

| 科技阶段 | 社会形态 | 核心矛盾 |
|----------|----------|----------|
| 化石能源 | 工业社会 | 阶级分化、环境污染 |
| 核能 | 冷战格局 | 核威慑、能源安全 |
| 信息技术 | 全球化 | 数据隐私、信息鸿沟 |
| AI时代 | 后工作社会 | 人类价值、就业危机 |
| 太空时代 | 星际文明 | 文明冲突、资源分配 |
| 后人类 | 后稀缺社会 | 人类定义、存在意义 |

**写作技巧：** 不要只写科技发展，要写科技如何改变普通人的生活。一个"AI替代了所有工作"的世界，早餐摊还存在吗？婚姻还必要吗？这些细节比"发明了量子计算机"更能打动人。

## 4. 科幻世界观构建

### 4.1 与 expert-worldbuilding 联动指引

科幻世界观是 worldbuilding 的子集，但有特殊要求：

| Worldbuilding 通用模块 | 科幻特殊化处理 |
|------------------------|----------------|
| 地理设定 | 替换为：星系/行星/太空站 |
| 历史设定 | 替换为：文明史/科技发展史/星际事件 |
| 政治设定 | 替换为：星际政治/企业政府/AI治理 |
| 经济设定 | 替换为：星际贸易/数字货币/资源经济 |
| 文化设定 | 替换为：后人类文化/多元种族文化 |
| 种族设定 | 替换为：外星种族/改造人/AI种族 |

**联动方式：** 先用 worldbuilding 通用框架构建基础设定，再用本模块的科幻特殊化处理填充细节。

### 4.2 尺度选择

| 尺度 | 舞台大小 | 叙事重心 | 适合题材 |
|------|----------|----------|----------|
| 行星级 | 一个星球 | 社会结构、地面冲突 | 末日生存、赛博朋克 |
| 星系级 | 太阳系/邻近星系 | 殖民扩张、资源争夺 | 太空殖民 |
| 银河级 | 整个银河系 | 文明博弈、史诗战争 | 太空歌剧 |
| 宇宙级 | 多元宇宙 | 存在意义、终极真理 | 哲学性科幻 |

**选择原则：**
- **新手推荐：行星级** —— 场景有限，更容易掌控
- **进阶推荐：星系级** —— 有足够空间又不至于失控
- **挑战级：银河级** —— 需要强大的架构能力
- **慎选：宇宙级** —— 极容易写崩

### 4.3 文明等级（卡尔达舍夫等级）

**卡尔达舍夫等级在小说中的实用化改造：**

| 等级 | 原始定义 | 小说化定义 | 能力表现 |
|------|----------|------------|----------|
| Type 0 | 行星部分能源 | 起步文明 | 化石能源、初步太空探索 |
| Type I | 整颗行星能源 | 行星文明 | 控制天气、全球能源网络、初步太空殖民 |
| Type II | 恒星全部能源 | 恒星文明 | 戴森球、恒星际旅行、基因完美化 |
| Type III | 银河系能源 | 银河文明 | 银河统治、空间折叠、时间操控 |
| Type IV+ | 宇宙级 | 超越文明 | 改写物理定律、维度旅行、创世 |

**等级差距的叙事技巧：**
- 高等级文明对低等级文明 = 人类对蚂蚁（不是仇恨，是不在同一维度）
- 主角的核心价值 = 用低等级文明的"意外"打破高等级文明的"算计"
- 最佳张力 = 等级差距2级以内（Type I vs Type III 太悬殊，没有对抗可能）

### 4.4 物理规则设定

**可以修改的物理规则（读者接受度高）：**
- 超光速旅行（曲率引擎/虫洞/超空间）
- 人工重力（几乎所有太空题材都默认存在）
- 能量护盾（科幻版"金钟罩"）
- 即时通讯（超光速通信，否则星际叙事太慢）

**不建议修改的物理规则（读者不买账）：**
- 能量守恒（"无限能源"会让所有冲突失去意义）
- 热力学第二定律（违反=让一切努力变得无意义）
- 因果律（除非专门做时间旅行题材）

**物理规则设定黄金法则：**
> "如果你要打破一个物理规则，用一整章来建立这个新规则，让读者理解它的代价和限制。不要在第50章突然冒出一个第1章没有的物理例外。"
