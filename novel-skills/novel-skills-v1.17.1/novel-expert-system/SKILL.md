# 网文创作全流程六步体系（2026校正版·扩充版）

> 已整合为「六步制作体系 × 专家团队调度 × 质量门禁」三层架构。六步体系是创作地基，专家团队是执行工具，质量门禁是输出保障，三者协同覆盖从构思到发布的全链路。
>
> **版本核心升级**：新增第三层"质量门禁体系"，让每个创作环节都有可量化的质量标准；深化专家调度规则，增加异常处理机制；新增系列书协同创作流程；新增expert-emotion-death联动调度规则。

## 第一层：六步全流程制作体系（地基）

### 第一步：世界观轻量化构建

**核心原则**：先定核心冲突与主角目标 → 再做适配剧情的轻量化世界观 → 最后补全细节。设定必须服务于主线剧情，开篇绝不堆设定。

**构建三要素**：
```
① 核心冲突锚点
→ 一句话定死整个世界观的核心矛盾
→ 例：美食末世→外星文明把人类当食材，人类靠改变体质降低食用价值完成反击

② 核心规则体系（≤3条铁则）
→ 战力体系上限
→ 金手指的核心限制
→ 世界运行逻辑
→ 规则越简单，读者越容易理解，越不容易战力崩坏

③ 差异化记忆点
→ 1个让读者记住的独有设定
→ 例：便利店通未来、验钞灯杀鬼、BMS食材分级、稳健系统
→ 避开同质化内卷，拿到平台差异化流量扶持
```

**合规校验**（同步执行）：
- 不能涉及真实宗教、敏感历史、违规政治内容
- 历史文必须符合平台考据要求
- 玄学/灵异文只写惩恶扬善，禁止封建迷信害人

**系列书适配**：
- 核心规则与差异化设定贯穿全系列
- 每卷解锁一个新世界观分支
- 保持系列一致性，同时给读者持续新鲜感

---

### 第二步：角色系统设计

**核心原则**：所有角色必须服务于主线剧情，有强标签、强动机。配角不超过5个，拒绝工具人。

**主角设计铁三角**：
```
① 强身份标签
→ 一句话让读者记住
→ 例：普通高中生伪装的气血大佬、重生1988的便利店老板

② 强核心动机
→ 明确、不可动摇的目标
→ 例：活下去 / 改命救所有人 / 搞钱逆袭
→ 所有剧情围绕这个动机推进

③ 强优缺点
→ 优点对应爽点，缺点对应剧情冲突
→ 例：主角极度稳健→优点=布局精准不翻车，缺点=容易错过机会引发冲突
→ 拒绝完美无缺的圣人主角
```

**反派设计核心**：
- 必须有合理动机与智商，不能无脑降智
- 反派目标必须和主角核心动机直接冲突
- 反派越强，主角反杀越爽
- 反派实力必须严格遵守世界战力规则

**配角设计规范**：
- 每个核心配角必须有独特标签与作用（推动主线/放大主角人设/提供情绪价值）
- 单本核心配角不超过5个
- 配角人设必须前后一致，不能随意变卦

**人设一致性校验**：
- 提前定死主角行事准则、说话风格、能力边界
- 所有剧情都不能突破这个边界，从根源避免人设崩塌

### 第三步：双轨大纲规划

**核心原则**：同步搭建「主线剧情大纲 + 平台节奏大纲」双轨体系。

**主线剧情大纲（4个核心模块）**：
```
① 核心主线
→ 一句话定死主角从开篇到结局的完整成长路径
→ 例：重生1988→靠未来便利店搞钱→成为时代首富→弥补前世遗憾

② 核心转折点
→ 全书3个核心大反转
→ 分别放在：付费节点 / 中期高潮 / 结局前

③ 爽点预埋
→ 每3章一个小爽点
→ 每10章一个中型爽点
→ 每20章一个大爽点

④ 伏笔回收
→ 所有伏笔必须提前标注回收节点
→ 避免挖坑不填、烂尾
```

**平台节奏大纲（分平台精确适配）**：

```
番茄短故事（18章）节奏：
├─ 第1-3章：开篇锁流（完读率≥50%）
├─ 第4-15章：稳定追读（每章钩子+每3章爽点）
└─ 第16-18章：收官爆发（回收伏笔+终极爽点）

番茄长篇（20~100章）节奏：
├─ 前10章：开篇锁流（追读率≥35%）
├─ 第12章：付费节点
└─ 每6章一个中等爽点

起点长篇（50~100章单部）节奏：
├─ 前3章：开篇留存（留存率≥40%）
├─ 第35章：上架爆发
└─ 每20章一个大爽点
```

**系列书适配**：
- 单本大纲有完整起承转合
- 结局留下系列核心悬念
- 每卷主线递进，世界观逐步展开

### 第四步：分阶段标准化写作

**全程格式安全铁则**（从根源避免平台封禁）：
```
- 禁用Markdown表格（用纯文本列表或→符号代替）
- 单段列表不超过5条
- 每段不超过3行
- 单句不超过20~25字（番茄20字/起点25字）
- 禁用平台敏感符号组合
```

**分阶段写作规范**：

```
【开篇锁流期】
短篇→前3章 | 长篇→前10章
严格按黄金开篇公式：
  0-300字：核心冲突
  300-800字：金手指亮相
  800-1200字：首次爽点落地
  结尾：强钩子强制追读

【稳定追读期】
短篇→第4-15章 | 长篇→第11-80章
- 每章结尾留钩子
- 每3章一个小爽点
- 对话占比符合平台要求
- 心理描写≤10%

【收官完结期】
短篇→第16-18章 | 长篇→第81-100章
- 回收所有伏笔
- 终极爽点+完美结局
- 留系列书悬念
```

### 第五步：三维质量自检体系

**替代原有单一内容自检，从三个维度全面校验**：

**第一维度：格式合规自检**
```
□ 无Markdown表格
□ 单段列表≤5条
□ 每段≤3行
□ 无敏感符号组合
□ 无违禁内容（涉政/涉黑/低俗/未成年违规）
```

**第二维度：算法数据适配自检**
```
开篇校验：
□ 首章300字内出核心冲突
□ 首章完成闭环
□ 前三章完读率达标（番茄≥50%/起点≥40%）

节奏校验：
□ 每章结尾有钩子
□ 每3章有爽点
□ 付费节点正确（番茄第6章/起点第35章）

听读适配校验（番茄优先）：
□ 对话占比≥60%（番茄）/≥50%（起点）
□ 无长难句
□ 大段心理描写已拆分

内容红线校验：
□ 无圣母/恋爱脑/战力崩坏/人设崩塌
```

**第三维度：内容质量自检**
```
□ 主角/配角行事风格符合前期设定
□ 战力遵守世界规则，无故越级=0次
□ 剧情无逻辑漏洞
□ 伏笔有对应回收节点
□ 爽点有铺垫、有反馈
```

### 第六步：全周期发布运营

**新书预热期（上线前→首秀/上架前）**
```
番茄：
- 提前创建作品，上传前3章
- 简介必须包含：核心冲突+爽点预期
- 标签精准覆盖热门赛道

起点：
- 提前发布开篇，同步更新至20章
- 申请签约，拿到签约后同步冲新书榜
- 引导读者收藏、投票
```

**推荐爆发期（首秀/上架→完结）**
```
核心动作：
- 严格保持稳定日更（绝对不断更）
- 番茄日更5~10章 / 起点日更2~3章
- 拿满全勤奖

流量优化：
- 每天观察后台数据
- 追读率低的章节立即修改结尾钩子
- 完读率低的开篇立即优化

互动运营：
- 回复读者评论
- 预埋本章说梗（起点）
- 引导读者互动，提升互动率
```

**完结长尾期（完结后）**
```
- 申请平台完结扶持流量
- 优化作品简介、标签
- 完结后立即发布系列书第二本预告
- 沉淀核心读者，第二本首订高于前作
- 3~5本完结书叠加，稳定月入1~2k
```

### 协同创作标准工作流（扩充版）

```
第一步【记忆加载】
expert-memory → 加载/建立项目记忆
├─ 检查是否有现有项目记忆文件
├─ 如果是新项目，建立新的项目记忆档案
└─ 输出：项目基础信息卡（题材/平台/字数目标）

第二步【世界观构建】
worldbuilding/xuanhuan/xihuan → 确定世界框架
├─ 调用对应题材的世界观专家
├─ 构建三层世界框架
└─ 输出：世界观设定文档（≤1000字精简版）

第三步【角色建立】
character → 建立人物档案
├─ 主角设计（铁三角）
├─ 反派设计（3个主要反派）
└─ 输出：角色设定卡（主角/反派/核心配角）

第四步【大纲规划】
```
