## 第四层：系列书协同创作流程（扩充新增）

### 4.1 系列书创作的核心原则

```
原则一【单本独立完整】
→ 每本书有独立的起承转合
→ 读者从任意一本开始都能看懂
→ 但埋系列核心悬念吸引读者追全系列

原则二【核心规则贯穿全系列】
→ 差异化设定/金手指/力量上限全系列统一
→ 不能中途改变核心规则（会引发战力崩坏）

原则三【每卷有独特亮点】
→ 保持新鲜感，不能完全重复
→ 例：第一卷打脸，第二卷商战，第三卷星际

原则四【系列进度管理**
→ 每卷完结后评估：读者追读率/订阅数据
→ 根据数据决定下一卷方向
→ 数据差则及时调整或完结
```

### 4.2 系列书专家调度规则

```
系列书第一卷（新书启动）
→ 按正常单本书流程走
→ 重点：通过 expert-memory 建立系列基础记忆
→ 产出：系列基础设定文档（永久保存）

系列书第二卷及后续
→ expert-memory → 加载系列基础记忆
→ 评估上一卷数据表现
→ 调整大纲后重新通过构思门禁和大纲门禁
→ 复用已有的世界观和角色体系（增量调整）

系列书数据异常处理：
→ 追读率下降：检查节奏是否拖沓/爽点是否不够
→ 订阅下降：检查人设是否崩塌/剧情是否注水
→ 读者流失：检查是否偏离核心卖点
```
