# 其他作者风格模板补全

> SKILL.md保留了男频核心作者（耳根/辰东/天蚕土豆）的完整模板。
> 本文件补充其他常用作者的详细模板，按需加载。

---

## 血红风

**适用场景：** 快节奏爽点、信息密度高、东西融合、每章双爽

**核心特征：**
```
① 信息密度：每段都有料，不写空话
② 明暗双线：表面剧情+暗线，每章推进两条
③ 短句冲击：重要台词单独成段，冲击力强
④ 宝物/机缘快速交代：遇到→判断→获取，三步完成
```

**模仿模板：**

```
升龙丹。

三个字一出，全场哗然。

「竟然是升龙丹！这种东西，怎么可能出现在这里！」
「这东西，至少值三座城池！」

主角没有说话。
他只是看着手中的丹药，看了很久。

然后，他收了起来。

动作很平静。
但他心里已经动了。

这东西，他必须拿到。

不只是为了自己。
```

## 烽火戏诸侯风

**适用场景：** 文青细腻、人物立体、金句、权谋布局

**核心特征：**
```
① 金句要落在具体行为上：不说"他很难过"，说"他把那封信烧了，但火柴还攥在手里"
② 氛围用物件表达：离别不说离愁，说"他把她送的那支笔留在了桌上"
③ 人物立起来靠细节：不是描述性格，是给一个只有这种性格的人才有的行为
④ 长句但节奏好：烽火的长句是"有停顿的长句"，不是流水账
```

**模仿模板：**

```
那封信，他看了三遍。

第一遍，在灯下。
第二遍，在黎明前最冷的时候。
第三遍，他没有看。他把信叠好，放进了贴身的口袋里。

然后他站起来，推开门，走了出去。

外面在下雪。
雪很大。
他走出去的时候，没有回头。

但他知道，她是看着他的背影消失的。

很多年以后，他还会记得那个雪夜。
不是记得雪。
是记得那支她留下的笔。

他一直留着。
```

## 江南风

**适用场景：** 情绪浓度最高、悲剧底色、情感爆发

**核心特征：**
```
① 感官记忆法：用一种感官串起整个情绪
② 未完成的事：最痛的不是失去了，是"还没来得及"
③ 沉默比话语更重：重要角色不说话，比说什么都重
④ 时间压缩：很长的时间跨度，用一句话带过，反而更显命运感
```

**模仿模板：**

```
那是他最后一次见到她。

他没有说再见。
因为他们都知道，不会再有下次了。

后来的很多年里，他都会在某个忽然想起她的瞬间，想起那个下午。

阳光很好。
她站在窗边，头发被风吹起了一点。
她回头，对他说了一句话。

他记得她说了什么。
他只是不知道，她是在什么时候决定要离开的。

是在说那句话的时候？
还是更早？

他不知道。
他只知道，从那以后，他再也没有见过那样的阳光。
```

## 忘语风 / 鹅是老五风（凡人派）

**适用场景：** 修炼逻辑严谨、谨慎低调、扮猪吃虎

**核心特征：**
```
① 韩立的谨慎：每一次冒险都有理由，不是莽撞，是"不得已"
② 宝物来去有逻辑：得到机缘有代价，失去机缘有原因
③ 淡定是底色：遇到再大的事，主角第一反应是"想清楚"
④ 细节填充：修炼的具体步骤、材料的模样、环境的描写
```

**模仿模板：**

```
林渊没有立刻动作。

他先放出神识，将周围方圆百丈扫了一遍。

没有埋伏。

他又看了看天色，判断了一下时辰。

现在走，最安全。

但他还是多看了一眼那处禁制的入口。

机缘，往往就在这一眼里。

但他更清楚的是——机缘的另一面，是风险。

他没有多停留。

转身，向另一个方向离去。
```

## 跳舞风

**适用场景：** 嘴炮、对白精彩、性格鲜明、反驳

**核心特征：**
```
① 对话要有交锋：不是一方说完另一方答，是"你的话刺到了我的痛点"
② 性格从对白里长出来：不用形容词，直接写他怎么说话
③ 反击要有节奏：铺垫一句，反击一句，结束一句
④ 轻松调侃穿插：紧张场景里一句调侃，反而显得主角更从容
```

**模仿模板：**

```
「你知道我最讨厌什么人吗？」

对方冷笑：「愿闻其详。」

「就是像你这种，明明什么都不懂，还装得自己很有见识的人。」

主角叹了口气：「你看你，占了三分之三了。」

全场哄笑。

对方的脸终于变了：「你——」

「我什么我？」主角拱了拱手，「承让。」
```
