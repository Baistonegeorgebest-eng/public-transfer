# 虫丹诡影·作者风格锚点

> 这是虫丹诡影项目的专属风格核心，写虫丹诡影时优先使用。
> 与SKILL.md中的通用风格模板互补：通用模板管"像谁"，本文件管"我是谁"。

---

## 一、风格关键词（与普通网文的区别）

```
普通网文：变强、打赢、碾压
虫丹诡影：看清了、不妥协、忍耐

普通网文：升级爽感
虫丹诡影：代价感

普通网文：配角是工具人
虫丹诡影：每个配角都有自己的"为什么"

普通网文：反派是坏人
虫丹诡影：反派是"选择错了的好人"
```

## 二、虫丹诡影专用情感写法

### 沈鹤归类型场景（悲剧性人物）

```
不用"他很痛苦"，用：
"他说完那句话，窗外忽然起了风。
风很大，把烛火吹灭了一盏。
他没有去点。
他就这样坐在黑暗里，想着那些再也回不来的人。"

——火灭了，不是因为意外，是因为他不想看到自己的手。
```

### 林渊类型场景（压抑中不放弃）

```
不用"他很难过但他坚持了下去"，用：
"他站在那扇门前，站了很久。

不是因为犹豫。
是因为他知道，打开这扇门的那一刻，他就再也没有退路了。

他还是伸出了手。"

——最难的不是做选择，是在不知道对不对的时候依然选择。
```

### 苏暮蝉类型场景（理解敌人）

```
不用"她觉得虫族也很可怜"，用：
"她听到了低级虫族的声音。
不是语言，是情绪。
它们在说：我不想。
我不想执行这个命令。
我不想伤害它们。

她把这个告诉了林渊。

林渊沉默了很久。

然后他说：那和被寄生的人类，有什么区别？"

——答案是：没有区别。都是被控制的。
```

## 三、虫丹诡影专用遣词规范

> 以下规范基于用户的真实风格，更克制、更冷、不煽情

```
虫丹诡影的核心基调：
  → 不是"我说出来"，是"我看到了但没说"
  → 不是"他很惨"，是"他的处境让读者自己觉得惨"

具体禁用：
❌ "林渊的心里……"（太直接）
   → 改为："林渊站在那里，很久。"

❌ "沈鹤归很难过"（禁止情绪词）
   → 改为："沈鹤归说完那句话，把门关上了。"
            "关得很轻。"
            "轻到像是什么都没发生过。"

❌ "三千人的虫化是一场悲剧"（禁止总结式抒情）
   → 改为："他们走向光的时候，都笑着的。"
            "林渊站在人群外，看着他们。"
            "很久。"

虫丹诡影的独白句式（参考）：
  "我知道她在想什么。
   但我没有说。
   说了也没有用。
   有些事情，不是说出来就能解决的。"

虫丹诡影的对话结尾（不用"他说"）：
  "她问他："你为什么不跑？"
   他没有回答。
   他把那张纸收好，走了出去。"
```

## 四、过渡技法的正确方式

```
AI写过渡：直接切换场景，不留痕迹
人类写过渡：有"过渡感"——让读者知道上一个场景结束了

正确示范（情绪过渡）：
"那天之后，他再也没提过那个名字。
 
很多年就这样过去了。
 
当他再次站在这里的时候……"

（一个空行 = 时间跳跃 = 情绪落幕）

正确示范（场景切换）：
"夜已经很深了。
 
后山的雾气升了起来。
 林渊站在雾气里，看着远处大殿的方向。"

（环境描写 = 自然过渡 = 不突兀）
```
