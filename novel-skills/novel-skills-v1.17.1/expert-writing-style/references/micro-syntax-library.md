# 大神微观句式库（可直接模仿的具体句式）

> 这些是各作者最具辨识度的微观句式模式，可直接套用。
> 对应SKILL.md中的风格模板（宏观），这里是微观层面的具体句式。

---

## 耳根微观句式

```
① 情绪递进三段式（不用"他很难过"）：
   "他不说话。
    窗外的风变了一个方向。
    他想，她说的是对的。"

② 未完成的句子（到情绪最高处，用省略号断掉）：
   "那时候他以为，一切都会好的……"

③ 具体物件替代情绪词：
   "她走的时候，把那支笔留下了。
    他把笔捡起来，放进了抽屉里。
    他不知道自己为什么要放进去。"

④ 反常识的比喻：
   "那句话像一把钝刀，不疼，但一直割。"
```

## 辰东微观句式

```
① 悬念三段截断：
   "禁区。
    没有人知道……
    因为进去的人……"

② 配角三人组的反应句式：
   "第一个看到这一幕的人，瞳孔骤缩。
    第二个，已经开始后退。
    第三个，什么都没说，转身就跑。"

③ 极简破坏描写：
   "一剑。"
   （独立成段，制造视觉空白）

④ 用否定句代替肯定句：
   "他不是第一个来的人。
    他也不会是最后一个。"
```

## 烽火戏诸侯微观句式

```
① 金句必须落在行为上：
   "他不是放下了。
    他是拿不起来了。"

② 用物件表达离别：
   "她把他送的那幅画摘了下来。
    卷好。
    放在了柜子最里面。"

③ 时间跨度压缩：
   "后来的很多年，他都记得那个下午。
    不是那个下午发生了什么。
    是那个下午什么都没发生。"

④ 不解释的沉默：
   "他没有问。
    她也没有说。
    那扇门，就这样开着。"
```

## 江南微观句式

```
① 感官记忆锚点：
   "那天的风很冷。
    或者说，是他觉得很冷。
    或者说，是他后来才觉得很冷。"

② 未完成的事（永远的最痛）：
   "他还没来得及问她叫什么名字。
    她就已经走了。"

③ 时间跳跃的情绪落差：
   "那时候他以为，这辈子还有很多机会。
    后来他才知道，有些机会，只有一次。"

④ 沉默比话语更重：
   "她看着他，没有说话。
    他也没有说话。
    那条街很长。
    他们就这样走完了。"
```

## 忘语/鹅是老五微观句式（凡人派）

```
① 判断在前，行动在后：
   "他没有立刻动手。
    先用神识扫了一遍。
    确认没有埋伏之后，才慢慢走近。"

② 淡定三连：
   "他没有说话。
    没有表情。
    没有动作。"

③ 细节填充（让修真有质感）：
   "那枚丹药呈淡青色，有一圈淡淡的灵纹。
    林渊用指甲轻轻划了一下——是软的。
    他心里有了数。"

④ 谨慎型内心独白：
   "他知道这东西值钱。
    但他更知道，值钱的东西，从来都不安全。"
```

## 句式变化的强制规则

```
规则1：三短一长
  连续3个短句（10字以内）之后，必须接一个长句
  目的：短句制造节奏冲击，长句释放情绪

规则2：长句必须断
  超过20字的长句，中途必须有1次断句（用逗号）
  超过30字的长句，必须有物理分段

规则3：对话后留白
  对话结束后，不立刻进心理描写
  至少留一句动作或环境
  目的：给情绪一个落地的空间

规则4：情绪最高峰用短句
  情绪最高潮的地方 → 用短句，甚至词语
  越短，越有力

规则5：感官替代情绪词
  "他很难过"  → 改为："他站在那里，没有动。"
  "她很愤怒"  → 改为："她把手里的杯子放下了。放得很轻。"
  "他很震惊"  → 改为："他没有说话。一秒，两秒。"
```
