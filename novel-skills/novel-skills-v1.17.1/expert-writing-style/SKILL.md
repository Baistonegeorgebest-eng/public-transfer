# 风格模仿专家技能 · v3.1

> **功能三重奏：**
> ① **指定风格** → 用户说"用耳根风写这段"，直接输出对应风格
> ② **自动路由** → 用户不说风格，AI根据场景类型自动选择最佳作者
> ③ **主动推荐** → AI在合适时机提示"这场景建议用XX风，更适合"

## 【第一层 · 自动路由引擎】

> 当用户没有指定风格时，根据场景类型自动匹配

### 路由判断树

```
第一步：识别当前场景类型

场景类型 → 推荐作者（主）+ 备选作者

情绪/心理类场景：
  → 【耳根】（首选）
  → 备选：烽火戏诸侯（细腻）/ 江南（情绪浓度高）
  适用：角色内心挣扎、情感崩溃、执念动摇

战斗/打斗类场景：
  → 【天蚕土豆】（快节奏首选）
  → 【辰东】（大场面首选）
  → 【老鹰吃小鸡】（极速压缩首选）
  → 备选：禹枫（热血型）
  适用：正式打斗、追杀、升级对决

世界观/设定揭示类场景：
  → 【辰东】（悬念引导）
  → 【梦入神机】（体系创新）
  → 备选：乌贼（伏笔型）
  适用：发现新地点、揭示修炼体系真相、历史背景

智斗/策略/谈判类场景：
  → 【乌贼】（伏笔+推理）
  → 【zhttty】（无限流智斗）
  → 备选：跳舞（嘴炮）
  适用：布局、谈判、说服、反转

日常/配角/气氛类场景：
  → 【老鹰吃小鸡】（节奏快）
  → 【远瞳】（轻松幽默）
  → 备选：宅猪（多视角）
  适用：日常对话、配角互动、信息交代

人物深度/情感类场景：
  → 【烽火戏诸侯】（细腻+金句）
  → 【江南】（情绪浓度最高）
  → 备选：耳根（心理递进）
  适用：人物背景揭示、重要对话、离别

修炼体系/升级类场景：
  → 【忘语】（严谨逻辑）
  → 【鹅是老五】（淡定从容）
  → 备选：我吃西红柿（画面感）
  适用：修炼过程、突破、宝物发现

神话/语言/世界观深度（西方文学类）：
  → 【托尔金】（神话体系）
  → 备选：JK罗琳（叙事谜题）
  适用：创造语言、设计种族历史、建设世界观架构

东方玄幻/古风/道家佛学场景：
  → 【梦入神机】（道学融合）
  → 【宅猪】（诗词化用）
  → 备选：辰东（洪荒背景）
  适用：道观、佛寺、修炼典籍、古风场景
```

### AI主动推荐话术（不打断创作流）

```
当AI判断"这个场景用XX风更好"时，说：

「这场景建议切【耳根风】——
  情感递进更强，情绪浓度更高。
  是否切换？」

用户回复"好"或"切" → 自动加载对应模板
用户说"继续" → 保持当前风格继续写
```

## 【第二层 · 指定风格模仿模板】

> 用户指定风格时，按下方模板直接输出
> 更多作者模板见 `references/other-author-templates.md`

### 耳根风

**适用场景：** 情绪崩溃、内心挣扎、悲剧高潮、执念动摇

**核心特征：**
```
① 渐变式内心独白：情绪不是"到了"，是"慢慢到的"
② 压抑中的一点光：最压抑时给一句轻的，反而更痛
③ "她/他不是被洗脑了，是真心的"——这类台词最有力
④ 环境投射情绪：不是"他很难过"，是"风里的味道都变了"
```

**模仿模板：**

```
他没有立刻说话。

这句话在他心里转了三圈，每一圈都更重一些。

第一圈，他想：她怎么会这么说？
第二圈，他想：她说得对吗？
第三圈，他不想了。他不想知道答案了。

窗外的风换了一个方向。
他看着那个转身离开的背影，忽然想起很多年前，
也有一个人这样离开过。

那时候他以为自己不会再见到第二次。
他错了。
```

**禁用表达：** 立刻爆发 / 直接抒情 / 过度形容 / "他的心如刀绞"

### 辰东风

**适用场景：** 世界观揭示、战斗大场面、配角高光

**核心特征：**
```
① 悬念三段式：禁地/禁术/禁名——名字一出，压迫感到位
② 配角反应三人组：正派道友 + 敌方高手 + 隐世老祖，各100字
③ 简洁的极致破坏：一剑，天崩
④ 悬念截断：章节结尾给一个字/一句话，立刻翻页
```

**模仿模板：**

```
禁区。

这两个字，在北斗星域代表着绝对的禁忌。
没有人知道禁区里有什么。
因为进去的人，从来没有出来过。

直到今天——

第一个看到这一幕的老者，已经说不出话来。
敌方高手的瞳孔骤缩。
某位隐世的老祖，长叹了一声：「……我错了。」

一剑。
天崩。
地裂。
```

### 天蚕土豆风

**适用场景：** 战斗、升级、打脸、爽点密集输出

**核心特征：**
```
① 退婚三段式：激将 → 受辱 → 爆发
② 能力名+破坏效果：招式名称越具体越爽
③ 环境配合情绪：战斗时天气配合，天助我也时必有异象
④ 对方反应压缩：震惊→不服→认输，三句话结束
```

**模仿模板：**

```
「不可能！」

萧炎双眼猩红，体内的斗气在这一刻彻底爆发。

「你说我是废物？」

他的声音很轻，但在这一刻，所有人的耳边都像是炸开了一道惊雷。

「废物，也得看是对谁。」

青色的火焰，从他掌心升起。

异火！

全场死寂。
```

### 托尔金风

**适用场景：** 虫丹诡影世界观深度、种族历史、神话体系、语言设计

**核心特征：**
```
① 起源感：任何种族/地点/神器，都有一个起源故事
② 历史层叠：现在的事件，在历史中有回响
③ 名字不是随便起的：每个名字都有含义，暗示命运或特点
④ 语言创造：关键术语自己创造语言体系（参考精灵语）
⑤ 遗迹感：古老的东西一定有残骸、碑文、传说作为证据
⑥ 地图即叙事：地图上的地名，是故事的一部分
```

**模仿模板（虫丹诡影·虫族起源）：**

```
在虫族的古老语言里，这个世界有一个名字。

这个名字的意思，用人类的语言勉强翻译，大约是——

"被留下来的地方。"

虫族的祭司们在最古老的经文中这样记载：

「当伟大的母巢第一次来到这片虚空时，这里还什么都没有。
只有光，和无尽的空间。
母巢带来了生命。
带来了秩序。
带来了我们。

我们称呼这片曾经荒芜的世界为：阿塞萨尔。

意思是：等待中的地方。

因为母巢说——
'有朝一日，会有人来。
他们会找到这里。
他们会问：你们是谁？
到那时，我们就不是孤独的了。'」

这首经文被称为"母巢的预言之诗"。
虫族的每一个子嗣，在能够独立思考之前，都要背诵这首经文。

但没有谁知道，"会有人来"究竟是什么意思。

直到林渊的出现。
```

### JK罗琳风

**适用场景：** 叙事谜题、隐藏线索、情感与谜题交织、成长弧线

**核心特征：**
```
① 谜题包裹情感：揭示真相时，同时揭示情感
② 物件作为记忆锚点：重要时刻总有一个物件
③ 名字的双重含义：角色的名字暗示其命运或性格
④ 成长不是变强：主角变得更"像自己"
⑤ 伏笔的揭晓要有情感重量：埋伏笔的原因，是让揭晓时更震撼
```

**模仿模板（虫丹诡影·林渊前世记忆）：**

```
在林渊的前世记忆里，那块碎片一直在。

不是地理意义上的碎片。
是感受上的。

每次他触碰到某些东西——一本书、一幅画、一段古旧的音乐——
他就会忽然想起一些不属于这一生的片段。

他知道这不正常。
但他从来不想深究。

直到他在虫族最古老的经文里，读到了那句话：

「当他们来到这个世界时，他们不是空手而来的。
他们带来了自己的光。
也带来了自己的影子。」

林渊的手，忽然停在了那行字上。

他想起了第九次进入虞朝秘址的那个下午。
那个让他穿越的时刻。

他想起了他在进去之前看了一眼天空。

天很蓝。

和这里的天空，一模一样。
```

## 【第三层 · 场景类型 → 质量门禁】

> 每个场景类型写完后，自动检查是否"像那个作者"

| 场景类型 | 合格标准 | 不合格表现 |
|---------|---------|-----------|
| 耳根风 | 情绪渐变有层次，至少3个递进 | 一步到位，直接爆发 |
| 辰东风 | 有悬念截断，有配角反应三人组 | 平铺直叙，没有张力 |
| 土豆风 | 爽点密集，至少2个打脸点 | 拖沓，没有节奏 |
| 烽火风 | 有金句落在具体行为上 | 空泛抒情，没有物件 |
| 江南风 | 有感官记忆锚点，有未完成感 | 说教式悲伤 |
| 忘语风 | 淡定从容，有逻辑判断 | 冲动，莽撞 |
| 托尔金风 | 有起源故事，有语言创造，有遗迹证据 | 空降设定，没有历史感 |
| JK罗琳风 | 谜题和情感交织，有物件锚点 | 纯谜题没有情感 / 纯情感没有谜题 |

## 【第四层 · 遣词造句快速规范】（消除AI味）

> 详细规则见 `references/micro-syntax-library.md`

### "AI味"通用祛除清单

```
❌ AI模式A："他想"开头 + 直接心理陈述
   → 替换："他没有说出口。"（用行为代替心理）

❌ AI模式B："她感到"开头 + 情绪词
   → 替换："那感觉来的时候……"（用生理反应代替情绪词）

❌ AI模式C：连续的长句，逗号到底
   → 替换：每3个长句后，必须有一个短句或分段

❌ AI模式D：形容词+名词的固定搭配
   → 例："愤怒的眼神" → 改为具体的身体动作

❌ AI模式E：说完一句感想，立刻接"因为他……"
   → 替换：因果关系藏在动作里，不说出来

❌ AI模式F：对话结束后，立刻接心理描写
   → 替换：对话结束后留1-2句动作/环境，再进心理
```

### 句式变化速查

```
规则1：三短一长 → 连续3短句后接1长句
规则2：长句必须断 → 超20字断句，超30字分段
规则3：对话后留白 → 对话后先留动作/环境，再进心理
规则4：情绪高峰用短句 → 越短越有力
规则5：感官替代情绪词 → 不写"他很难过"，写"他站在那里没有动"
```
