# 跨职业技能组合与平衡设计

> 多职业体系的组合模式、平衡法则与节奏把控。

## 1. 跨职业组合的五种经典模式

### 模式一：战士+法师=魔战士
战斗方式：近战输出+远程魔法支援
技能组合：
→ 近战：剑术（战士）+ 法术加成（法师）
→ 效果：剑上附带魔法伤害，攻守兼备

### 模式二：刺客+法师=暗影法师
战斗方式：隐匿+爆发魔法
→ 潜行（刺客）+ 致命魔法（法师）
→ 效果：从暗处突袭，魔法伤害翻倍

### 模式三：战士+辅助=圣骑士
战斗方式：防御+增益+治疗
→ 护盾（辅助）+ 治疗（辅助）+ 剑术（战士）
→ 效果：攻守一体，单挑和群战都能应对

### 模式四：召唤+法师=召唤师
战斗方式：召唤物为主+法师辅助
→ 召唤（召唤师）+ 强化（法师）+ 控制（法师）
→ 效果：多个召唤物配合法师控制战场

### 模式五：多元素法师=元素领主
战斗方式：多元素组合攻击
→ 火+水=蒸汽爆炸
→ 火+雷=烈焰雷暴
→ 水+冰=绝对零度
→ 效果：元素组合产生超越单一元素的威力

## 2. 组合技能设计模板

### 命名公式
主技能名+副技能名 = 新技能名

### 示例
剑术+火焰 = 炎龙剑
"他将火焰灵力注入剑身，一剑斩出——火龙破空。"

寒冰+剑术 = 冰魄剑
"寒气凝结成冰，他一剑挥出，冰刃如雨。"

雷法+符箓 = 天雷符
"他甩出符箓，口中念念有词——符箓化作雷光，轰然炸开。"

### 组合技能展示模板
① 铺垫（300字）：展示两个基础技能的威力
② 触发（200字）：展示组合技能的触发条件
③ 释放（200字）：详细描写组合技能的效果
④ 结果（200字）：展示组合技能的决定性效果

## 3. 职业平衡设计

### 平衡原则
核心原则：没有最强的职业，只有最强的组合

### 平衡维度

| 维度 | 近战 | 远程 | 辅助 | 召唤 |
|------|------|------|------|------|
| 伤害 | 高 | 中 | 低 | 中（总量高） |
| 生存 | 高 | 低 | 中 | 低 |
| 控制 | 低 | 高 | 中 | 中 |
| 爆发 | 高 | 高 | 低 | 中 |
| 持续 | 高 | 中 | 高 | 中 |

### 克制关系
→ 近战克制召唤（快速接近秒杀召唤物）
→ 远程克制近战（保持距离输出）
→ 辅助克制远程（治疗/护盾抵消伤害）
→ 召唤克制辅助（召唤物多，消耗战优势）

### 设计提示
每个职业要有独特价值：
→ 近战的价值：爆发高，不怕消耗
→ 远程的价值：安全距离，持续输出
→ 辅助的价值：让队友更强
→ 召唤的价值：数量压制，战术多样

## 4. 动态平衡设计

### 为什么很多网文的技能体系会崩溃？
原因：技能之间没有互相制约

### 动态平衡的核心
→ 每个技能都有优势
→ 每个技能都有劣势
→ 没有"最强技能"，只有"最合适技能"

### 三技能循环克制
技能A（攻击型）：优势=瞬间爆发高，劣势=消耗大不能持久，被B克制
技能B（持续型）：优势=持久战，劣势=瞬间爆发低，被C克制
技能C（爆发型）：优势=瞬间爆发极高，劣势=冷却时间长，被A克制

三技能循环克制 = 动态平衡
