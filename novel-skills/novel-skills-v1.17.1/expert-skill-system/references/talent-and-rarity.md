# 天赋与资质体系深度设计

> 天赋决定起点，努力决定终点。天赋体系的设定要与世界观相匹配。

## 1. 天赋类型

### 类型一：血脉天赋（最经典）
→ 与生俱来的天赋
→ 例：天生具有寒冰体质，只能修炼冰系功法
→ 优点：合理，缺点：开局就固定了路线

### 类型二：觉醒天赋（越来越流行）
→ 修炼到一定程度才觉醒
→ 例：前3个境界没有，到第4个境界突然觉醒
→ 优点：可以制造惊喜感

### 类型三：稀缺天赋（高端玩法）
→ 亿万人中才有一个
→ 例：先天混沌体，整个世界只有1个
→ 优点：增加主角的独特感

### 类型四：多天赋组合（复杂但有趣）
→ 主角有多个天赋
→ 天赋之间可以组合
→ 例子：寒冰体质+剑道天赋=冰剑道

## 2. 天赋稀有度体系

→ 凡品（普通人，90%）
→ 黄品（有一定天赋，5%）
→ 玄品（优秀天赋，3%）
→ 地品（顶尖天才，1%）
→ 天品（传说级别，0.1%）
→ 禁忌天赋（历史上只有几个，亿分之一）

### 稀有度不只是"数字"，还有社会意义
→ 稀有度决定社会地位
→ 稀有度决定资源获取难度
→ 稀有度决定人际关系

## 3. 天赋觉醒设计

觉醒时机：
→ 危急时刻觉醒（最常见）
→ 情感冲击觉醒（感人）
→ 修炼到某个境界自动觉醒（宿命感）

觉醒的叙事价值：
→ 觉醒 = 主角潜力的证明
→ 觉醒前有多弱，觉醒后有多强
→ 觉醒的时机就是高潮的时机

## 4. 组合天赋的创新设计

组合天赋的原理：
→ 天赋A + 天赋B = 组合天赋C
→ 组合天赋比单一天赋强
→ 但需要找到正确的组合方式

组合天赋的发现过程：
① 先分别获得天赋A和天赋B
② 某个契机发现可以组合
③ 组合后变成全新的能力
④ 组合后还有继续组合的可能性

## 5. 资质设定表

| 资质类型 | 特征 | 影响 |
|---------|------|------|
| 废柴资质 | 修炼速度极慢 | 但有特殊机缘 |
| 普通资质 | 修炼速度一般 | 需要更多努力 |
| 优秀资质 | 修炼速度较快 | 主角的理想设定 |
| 天才资质 | 修炼速度极快 | 但也容易遇到瓶颈 |
| 绝世资质 | 极少数人拥有 | 有独特的修炼路线 |

### 资质提升方式
→ 服用天材地宝
→ 完成特殊试炼
→ 师父传授
→ 顿悟

### 设计原则
① 资质不等于实力 → 努力/机缘/智慧可以弥补
② 资质有上限但可以突破 → 突破本身就是爽点
③ 隐藏资质 → 主角初期被低估，后期觉醒
④ 资质反差 → 高资质不一定成功，低资质不一定失败
