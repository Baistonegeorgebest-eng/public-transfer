## 1. 技能获取设计

### 1.1 六大技能获取方式

**方式一：师承传授**
- 优点：合理，有传承感
- 缺点：需要铺垫师父角色
- 适合：仙侠/武侠

**方式二：苦修自悟**
- 优点：符合成长感，有成就感
- 缺点：节奏可能拖沓
- 适合：稳健流/传统玄幻

**方式三：击杀获取**
- 优点：爽感强，节奏快
- 缺点：容易战力崩坏
- 适合：系统流/无限流

**方式四：任务奖励**
- 优点：激励明确
- 缺点：需要任务系统支撑
- 适合：游戏异界

**方式五：天赋觉醒**
- 优点：有神秘感
- 缺点：容易变成万能挂
- 适合：重生/穿越

**方式六：道具附带**
- 优点：金手指明确
- 缺点：容易依赖道具
- 适合：所有题材

### 1.2 技能获取禁忌

❌ 技能获取太容易（打一个怪掉10个技能）
→ 解决：每个技能获取都需要代价

❌ 技能获取太难（100万字还没几个技能）
→ 解决：按节奏分配，主角10-20万字内要有3-5个核心技能

❌ 技能之间无关联（学了10个完全独立的技能）
→ 解决：技能要有主线（如全部是剑道/全部是火焰系）

❌ 技能数量无上限
→ 解决：主角不超过20个核心技能

### 1.3 技能获取的叙事设计

技能不是凭空来的，要有获取过程：

| 获取方式 | 叙事价值 |
|---------|---------|
| 任务奖励 | 主角付出努力，获得回报，有成就感 |
| 探索发现 | 主角好奇心，获得惊喜，有探索感 |
| 传承 | 主角获得认可，承担责任，有仪式感 |
| 战斗夺取 | 主角用实力说话，有胜利感 |

情感层次示例：悲伤（师父死亡）→ 接受（获得传承）→ 责任（承担传承的重量）

## 2. 技能树设计

### 2.1 技能树结构设计

**单一技能树示例（剑道）：**

主干：剑术入门 → 小成 → 大成 → 剑意 → 心剑合一 → 万剑归宗

支线：
→ 火焰剑道（剑+火）
→ 寒冰剑道（剑+水）
→ 雷电剑道（剑+雷）
→ 每条支线都是一个独特的战斗风格

**多技能树示例（多职业）：**

主职业（战士）：近战/防御/冲锋
副职业（法师）：远程/元素攻击
副职业（辅助）：治疗/增益
→ 职业之间可以组合
→ 战士+法师=魔战士
→ 战士+辅助=圣骑士

### 2.2 三层架构

```
主干技能（每个角色必须掌握，3-5个）
  → 构成角色的基本战斗方式
  → 每个主干技能有2-3个分支方向

专属技能（角色独有的招牌技，1-3个）
  → 角色最核心的能力，构成"人设标签"
  → 专属技能应该有独特的视觉效果/触发条件
  → 规则：专属技能的使用频率 ≤ 每次大战斗1次（稀缺=珍贵）

组合技能（多个技能叠加产生的新效果）
  → 低级技能 + 低级技能 = 中级组合效果
  → 专属技能 + 主干技能 = 高级组合效果
  → 组合是展示角色"创造性"的核心场景
```

**架构原则：**
- ① 技能总数控制：全书主要技能 ≤ 30个（太多记不住）
- ② 技能命名统一：同一类技能使用相同的命名风格
- ③ 技能可视化：每个技能都要有独特的画面效果
- ④ 技能有弱点：没有完美的技能，每个都有克制/反制方式

### 2.3 技能升级逻辑

**升级公式：**
技能效果 = 基础效果 × (1 + 熟练度系数) × 天赋加成

**层次设计：**
| 层级 | 名称 | 效果 |
|------|------|------|
| 第1层 | 入门 | 普通攻击 |
| 第2层 | 小成 | 攻击+5%伤害 |
| 第3层 | 大成 | 攻击+15%+附带效果 |
| 第4层 | 精通 | 范围攻击+20%伤害 |
| 第5层 | 大师 | 感知攻击+无视防御 |
| 第6层 | 宗师 | 召唤万剑攻击 |

## 3. 技能战斗体系

### 3.1 战斗技能六分类

| 类型 | 作用 | 示例 | 冷却 |
|------|------|------|------|
| 输出技能 | 造成伤害 | 火球术/破天剑 | 高频 |
| 控制技能 | 定身/沉默/禁锢 | 冰封术/石化 | 中等 |
| 防御技能 | 格挡/护盾 | 金刚罩/护体剑气 | 低频关键 |
| 位移技能 | 瞬移/突进 | 缩地成寸/瞬步 | 高频 |
| 治疗技能 | 恢复生命 | 回春术/灵泉 | 中等 |
| 增益技能 | 提升属性 | 狂暴术/疾风步 | 低频 |

### 3.2 技能战斗节奏公式

① 控制技能开局（定住对手，争取主动）
② 位移技能跟进（贴近对手）
③ 输出技能连招（打出伤害）
④ 防御/治疗应对（处理反击）
⑤ 最终爆发（收尾或翻盘）

### 3.3 平衡性校验矩阵

```
              威力   消耗   冷却   使用条件   综合评分
技能A（火球）   3      2      1      容易       中
技能B（陨石）   5      5      4      困难       高（但稀有）
技能C（治疗）   1      1      1      容易       低（但必须有）
技能D（禁术）   5+     5+     -      极难       极高（但代价巨大）
```

**校验规则：**
① 威力-代价对等原则：威力越强 = 代价越大
② 使用频率合理性：基础技能威力不能太强，杀手锏威力必须强
③ 反制可行性：每个强力技能必须有至少1种反制方式
④ 替代性检查：功能相似的技能合并或删掉一个

**禁忌：**
- ❌ "万能技能"——一个技能能解决所有问题
- ❌ "零代价大招"——威力巨大但无消耗无冷却
- ❌ "遗忘技能"——学了之后再也没用过
- ❌ "版本答案"——某个版本之后完全碾压其他技能

## 4. 技能代价设计

### 4.1 七种代价类型

| 类型 | 说明 | 效果 |
|------|------|------|
| 消耗型 | 消耗灵力/法力 | 限制连发，逼主角省着用 |
| 代价型 | 伤人伤己/消耗寿命 | 逼主角不轻易用 |
| 限制型 | 需要特定条件 | 只能用一次/特定场合 |
| 反噬型 | 用完有副作用 | 用完会虚弱/失控 |
| 冷却型 | 需要冷却时间 | 逼迫多技能组合 |
| 充能型 | 需要蓄力/收集 | 特殊手段补充能量 |
| 组合代价型 | 越强越多重代价 | 普通攻击无代价→终极技能多重代价 |

### 4.2 核心原则

**铁律：越强的技能，代价越大。没有代价的技能 = 万能的技能 = 战力崩坏。**

### 4.3 代价使用的叙事技巧

**铺垫**：前文提到代价的存在
**使用**：描写代价对主角的影响
**恢复**：合理的恢复机制（休息/天材地宝/时间）
**脆弱时刻**：恢复期间是脆弱时刻，可制造紧张感

### 4.4 代价的心理层次

升级不只是数字增加，代价也要有层次：

```
升级心理四层次：
第一层：能力提升（我变强了）
第二层：身份变化（我成为了什么样的人）
第三层：代价增加（我付出了什么）
第四层：责任加重（我需要承担什么）
```

升级叙事示例：
> "他突破了。力量在体内咆哮，比以前强了一倍。但他知道，金丹境的强者，寿命只剩十年。而她，还在等他。他突然不想突破了。但箭已离弦。"

## 5. 技能升级节奏

### 5.1 技能获取节奏模型

| 阶段 | 字数 | 技能数量 | 节奏要求 |
|------|------|---------|---------|
| 新手期 | 1-10万字 | 3-5个基础技能 | 技能简单，效果明确 |
| 成长期 | 10-30万字 | 每10万字+2-3个 | 开始出现技能组合 |
| 中期 | 30-80万字 | 不超过20个 | 开始出现高级/终极技能 |
| 后期 | 80万字+ | 不再增加 | 重点展示技能升级/觉醒 |

**节奏禁忌：**
- ❌ 前期技能太多（读者记不住）
- ❌ 后期还在增加基础技能（战力崩坏）
- ❌ 技能没有进化（一直用同样的技能）

### 5.2 升级节奏公式

**三阶九级制：**

初级（1-3级）：掌握基础
- 升级条件：练习/战斗中领悟
- 升级频率：每3-5章升级一次
- 升级效果：威力提升、消耗降低

中级（4-6级）：融会贯通
- 升级条件：需要特殊契机（悟道/奇遇/生死战斗）
- 升级频率：每10-15章升级一次
- 升级效果：质变（技能形态变化/增加新效果）

高级（7-9级）：登峰造极
- 升级条件：需要极稀有的条件（传承/觉醒/牺牲）
- 升级频率：每25-40章升级一次
- 升级效果：颠覆级变化（技能本质改变/影响世界规则）

**验证公式：**
```
升级爽感 = 预期差 × 展示机会 × 使用价值
→ 预期差：读者没想到能这么快升级 / 升级幅度超预期
→ 展示机会：升级后有即时的战斗/场景来展示新能力
→ 使用价值：新能力能解决之前解决不了的问题
→ 三者缺一，升级就不爽
```

### 5.3 技能升级的叙事节奏

| 节奏类型 | 描述 | 效果 |
|---------|------|------|
| 实力对比升级 | 先描写强者的技能，再描写主角逐步达到 | 升级有明确参照物 |
| 危机倒逼升级 | 遇到强敌，现有技能不够，危机中触发 | 升级有紧迫感 |
| 顿悟型升级 | 长时间积累+特定情境下顿悟 | 技能质变 |
| 资源辅助升级 | 获得珍贵材料/传承辅助升级 | 升级有物质基础 |

## 6. 避坑清单

### 境界体系
❌ 境界名太多（超过9个大境界）→ 读者记不住
❌ 境界之间没有明确战力差距 → 战力崩坏
❌ 主角升级太快（3章一个境界）→ 每个境界至少用10章以上铺垫
❌ 用现代词汇命名境界 → 玄幻/仙侠用传统命名更符合调性

### 技能体系
❌ 主角技能超过20个核心技能 → 读者记不住
❌ 技能之间毫无关联 → 技能要有主线（同一流派/同一属性）
❌ 最强技能无代价 → 战力崩坏根源
❌ 万能技能 → 所有战斗变成"一招鲜"

### 展示与节奏
❌ 前期技能太多 → 读者记不住
❌ 后期还在加基础技能 → 战力崩坏
❌ 技能无进化 → 一直用同样的技能，读者腻烦

### 质量检查清单
- [ ] 技能体系有可记忆的名字和效果吗？
- [ ] 技能效果可以量化（有强弱之分）吗？
- [ ] 每个技能有明确的能力边界吗？
- [ ] 技能获取有合理代价吗？
- [ ] 技能之间有主线关联吗？
- [ ] 最强技能有最大代价吗？
- [ ] 战斗有技能组合的智斗感吗？
- [ ] 没有"万能技能"吗？
- [ ] 主角核心技能不超过20个吗？
- [ ] 境界设定不超过9个大境界吗？
- [ ] 跨境界战斗有充分铺垫吗？
- [ ] 技能展示有时机规划吗？
- [ ] 技能获取节奏符合节奏模型吗？
