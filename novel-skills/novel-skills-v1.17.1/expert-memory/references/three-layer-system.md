### 12.3 .learnings/ 跨章节记忆系统

> 来源：clawhub novel-generator skill，2026-04-08引入

每个项目应维护 `.learnings/` 目录作为轻量级记忆系统：

```
项目目录/
├── .learnings/
│   ├── CHARACTERS.md      ← 角色状态（出场/死亡/立场变化）
│   ├── LOCATIONS.md       ← 地点信息（地理/功能/关联事件）
│   ├── PLOT_POINTS.md     ← 关键情节转折（已发生/即将发生）
│   ├── STORY_BIBLE.md     ← 世界观核心设定和规则
│   └── ERRORS.md          ← 失败案例（12.2定义）
├── .bookstatus.md          ← 进度追踪
├── .footprint.md           ← 防重复
└── ch*.txt                 ← 章节正文
```

**与现有机制的关系**：
- `.learnings/CHARACTERS.md` ↔ expert-memory 设定总表（轻量版）
- `.learnings/ERRORS.md` ↔ 本节12.2（同文件）
- `.learnings/PLOT_POINTS.md` ↔ expert-memory 伏笔追踪表（简化版）
- `.learnings/STORY_BIBLE.md` ↔ 设定总表的世界观部分

**核心差异**：`.learnings/` 是每章生成前必读的轻量级记忆，不是session级的宏观记忆。

### 12.4 经验丢失防护

**历史教训**：

| 项目 | 丢失的经验 | 损失 |
|------|-----------|------|
| 气功砍穿神魔 | 封面生成弯路、238重复段落发现过程、禁止列表积累 | 下一项目从零摸索 |
| 美食末世 | 福利注入方法论、番茄平台参数、子代理并行经验 | 下一项目从零摸索 |

**量化损失**：两个项目470+章经验、数十次试错、quality-gate两次升级——全部丢失。

**防护机制**：
```
① 每个项目结束时 → 提炼通用经验到 novel-memory.md
② 每个禁止列表条目 → 评估是否具有通用性，通用则追加到全局列表
③ ERRORS.md → 跨项目继承（新项目启动时读取前一项目的ERRORS.md）
④ IMA知识库 → 项目复盘文档永久保存
```
