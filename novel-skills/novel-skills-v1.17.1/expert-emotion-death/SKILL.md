## 使用指南

### 分工边界

| | expert-emotion | expert-emotion-death |
|--|---------------|-------------------|
| 时间跨度 | 情感线全程 | 聚焦单次顶点时刻 |
| 核心 | 情绪流/甜宠/日常 | 死亡/牺牲的瞬间与余韵 |
| 读者感受 | 心动/治愈 | 流泪/心碎/沉默 |
| 写作量 | 数十章 | 通常3~10章 |

```
expert-emotion是"河流"，expert-emotion-death是"瀑布"。
没有河流，瀑布无从存在。没有瀑布，河流缺少高光。
```

### 联动流程

```
Step 1：先用expert-emotion设计完整情感线
Step 2：识别悲情顶点，切换expert-emotion-death
Step 3：调用死亡四阶段框架
Step 4：死亡后，用expert-emotion处理余韵
```

### 快速路由

```
→ 英雄为他人牺牲 → 类型一·英雄牺牲
→ 因为爱而选择牺牲 → 类型二·为爱而死
→ 有未竟之事，死不瞑目 → 类型三·遗憾而死
→ 死前有误解，死亡揭露真相 → 类型四·误解而死
→ 比死更重的悲情（不发刀） → 不发刀写法
```

### ⚠️ 禁止单独使用

> expert-emotion-death不能脱离expert-emotion单独撑起情感线。发刀子的前提是：读者已经在乎这个角色。

## 一、悲情场景的本质：不是"写死亡"，是"写失去"

### 为什么"发刀子"能让人哭？

核心矛盾：
```
写好死亡场景 = 让读者在情感高点瞬间流泪（不需要相信世界）
写好长篇故事 = 让读者相信整个世界的运作逻辑（需要大量铺垫）
两个能力互相独立 = 很多作者能写出"哭死人"的片段，却撑不起百万字长篇
```

### 悲情 vs 普通虐心

| | 普通虐心 | 发刀子 |
|--|---------|--------|
| 核心 | 情感被压制 | 情感关系被永久打破 |
| 结果 | 还能恢复 | 无法恢复 |
| 读者心理 | "心疼" | "失去" |
| 情绪持续 | 几章内消散 | 贯穿全书 |

**发刀子是一个系统：从铺垫到落刀到回收，缺一不可。**

## 二、死亡场景四阶段框架（核心框架）

### 阶段一：建立情感投入（死前铺垫）

**三种投入方式：**

#### 方式一：日常细节法

在死亡前写3~5个"无用"的日常互动。

```
❌ "卡尔是队里的老兵，作战经验丰富。"（只知道"设定"）

✅ "每次任务结束后，卡尔都会坐在营地边缘磨他的刀。
一把旧刀，刃口都磨平了，他也不换。队长问过他为什么不换。
卡尔说：'这把跟了我很多年。'队长当时没当回事。"
（读者通过细节"认识"了这个人，读者在乎这把刀了）
```

#### 方式二：目标渴望法

让角色有一个强烈的渴望/目标。死亡 = 这个渴望永远无法实现。

```
✅ "他这辈子就想再看一眼家乡的那棵树。他离开的时候，还是春天。
树还没发芽。'等仗打完了，'他说，'我要回去看一眼那棵树发芽的样子。'
他再也没回去过。"
```

#### 方式三：关系镜像法

让其他主要角色对这个死亡角色说一句真心话。

```
✅ "队长从来不喝醉。那天晚上他喝醉了，说的第一句话是：'我最怕的人就是他了。'
他怕他，因为卡尔从不抱怨，从不倒下，从不让任何人看到他软弱的样子。
所以当他倒下的时候——队长发现，他最怕的事情，已经发生了。"
```

### 阶段二：打破信号（死亡来临前的预兆）

**关键：让读者"有预感但不愿相信"。**

#### 信号一：语言暗示（最有效）

角色说一些像告别的话，第一遍读以为是普通对话，事后才明白是告别。

```
❌ "战友，明天我们一起回去！"（读者第一遍就知道他要死了）

✅ "战友说：'那封信，帮我寄回去。'他笑了笑：'好。'"
（读者事后回想：他当时就把这当作遗言了）
```

#### 信号二：时间压缩

突然加快节奏 → 读者无意识地感受到"有什么要发生了" → 死亡来临 → 节奏突然恢复 → 读者觉得死亡之后的世界很空旷。

#### 信号三：环境突变

天气、光线、声音突然变化。读者无意识地感到不安。

```
"战斗结束的时候，天突然阴了。队长后来回忆说，他当时就觉得不对劲。
但他不知道是什么。很多天后他才明白：是光变了。从那之后，他再也没见过那种光。"
```

### 阶段三：落刀时刻（死亡瞬间）

**核心原则：动作 > 语言，动作 > 形容词，细节 > 概述。四个字：少即是多。**

#### 五感优先级

```
第一优先：听觉（最不容易被理性过滤）
第二优先：触觉
第三优先：视觉
第四优先：嗅觉
第五优先：味觉
```

#### 动作链写法

```
❌ 结论式："卡尔痛苦地死去，战友们非常悲伤。"

✅ 动作链："他倒下的时候，手里还握着那枚徽章。
指节从边缘慢慢滑落。徽章碰到地上的声音很轻。
在那一刻，他什么都听不见了——风声、战友的喊声、刀剑碰撞声，全都消失了。
只有一种奇怪的感觉：冷。"

✅✅ 五感+留白："他倒下的时候，远处的鸟叫了一声。很普通的一种鸟叫。
他突然想起来，很久以前，有人跟他说过——'这种鸟，叫的声音像是在叫回家。'
然后他就不再想什么了。战友冲过来的时候，徽章在地上，很凉。鸟叫停了。"
```

**为什么更感人？** 读者在读"徽章在地上，很凉"时，脑子里会补全所有画面。这个"补全"是读者自己完成的，效果比作者直接写"他死了，大家都悲伤"强得多。

### 阶段四：余韵回收（发刀后的处理）

**发完刀后，不要立刻切场景。留一段余韵。**

#### 余韵三种方式

**方式一：物件触发记忆（最常用）**
```
"战争结束后的第三个月，队长回到了营地。路过那片空地的时候，他低头看了一眼地上。
地上什么都没有了。徽章早就被收走了。但他还是低头看了一眼。"
```

**方式二：日常改变（次常用）**
```
"每次任务结束后，卡尔都会坐在营地边缘磨他的刀。他走了之后，那个位置空了很久。
有一天，队长路过，坐了下去。刀没有磨。他只是坐在那里，什么都没做。"
```

**方式三：物件贯穿主线（最强写法）**

物件在故事高潮再次出现，和死亡时的意义形成升华呼应。

```
第5章：卡尔把玩旧徽章，"这是我妈给我的"
第80章：徽章落地，卡尔闭上眼睛
第190章：决战前夜，队长把徽章放在主角手里："这是他的。现在是你的。"
→ 好奇→心碎→继承
```

## 三、物件象征：让死亡"活"在故事里

### 选择标准

```
① 读者见过它 ≥ 2次（眼熟）
② 有非功能性意义（不是为了任务而存在）
③ 能被读者描述（徽章、信、戒指——可以）
④ 和死亡角色身份直接关联
⑤ 能在新角色手中再次出现（传承性）
```

### 物件象征设计五步法

```
Step 1：第3~8章内，让死亡角色和物件产生第一次关联（非功能性）
Step 2：死亡前，物件和死亡角色产生最后一次关联（死亡前3章内）
Step 3：死亡时刻，物件是最后一个动作的载体（滑落/塞进别人手里）
Step 4：死亡后，物件在"相似情境"中再次出现
Step 5（可选）：故事高潮或结尾，物件意义升华
```

## 四、克制对白：少即是多

### 四层克制

**第一层：不说出口** —— 他想说什么，但嘴唇动了动，什么声音也没有。把徽章塞进队长手里。

**第二层：最简单的话（≤5字）** —— "……活着回去。" 三个字。比任何遗言都重。

**第三层：说"反话"** —— "回去以后，别跟我妈说我在这儿受伤的事。"（第一遍读以为是气话，事后才明白是告别）

**第四层：什么都不说（最高克制）** —— 倒下的时候，他张嘴了。什么都没说出来。只是看着队长。看了很久。然后闭上了眼睛。

### 禁止出现的对白

❌ 自我总结 / ❌ 命令型 / ❌ 解释型 / ❌ 煞情型（连续三句感叹句）

## 五、死亡场景类型与写法

### 类型一：英雄牺牲（正面死亡）

为他人献出生命。读者情感：崇敬+悲痛。

```
写法要点：
① 死亡前写"他还有牵挂"（越有牵挂越显牺牲）
② 死亡动作要"慢"（用时间感拉长）
③ 死后要有人继承他的意志（物件/话语/遗愿）

"他本来可以跑。但他留了下来。'你们先走。'
他说完这句话的时候，手里已经握着那枚旧徽章了。
他其实还有很多事没做完。但他没提那些。
他只说：'那棵树，你帮我看一眼。'
队长后来真的去看了。那棵树很大。站在树下，他什么都说不出来。"
```

### 类型二：为爱而死（情感死亡）

因为爱而选择牺牲。读者情感：心碎+温暖。

```
写法要点：
① 死前最后一句话要对这个人说
② 不是"我爱你"，而是具体的一件小事
③ 物件是两人关系的锚点

"'那封信，我没寄出去。'她的声音很轻。
那封信一直在她怀里，和那枚旧徽章放在一起。
她本来是想亲口给他的。但她没有这个机会了。
他把这句话告诉了主角。主角沉默了很久。
然后他说：'我知道。那封信，在她房里。我见过。'
那封信最终被寄出去了。晚了三年。"
```

### 类型三：遗憾而死（BE/悲情）

有未竟之事，死不瞑目。读者情感：憋屈+心疼+释然。

```
写法要点：
① 未竟线索必须在死亡前至少埋10章
② 死亡不要立刻揭开，让读者等待
③ 揭开时一句话/一个动作/一个物件就够

"他的眼睛一直睁着。队长伸手想帮他合上，但合不上。
'他在等什么？'没人知道。
直到战争结束三年后，主角发现了那封信。
他看完之后，在那棵树前站了很久。
然后他回去了。合上了他的眼睛。动作很轻，就像合上一本书。"
```

### 类型四：误解而死（最虐）

死前两人有误解，死亡揭露真相。读者情感：极度心碎+后悔。

```
写法要点：
① 误解必须是"真实存在的"——读者也以为是这样
② 死亡不要立刻揭开误解，要延迟
③ 揭开的力量来自物件或沉默，不是来自解释

"他倒下了。她跑过去，握住他的手。他的手很凉。
她想说：你为什么这么傻。但他说：'那张照片，我其实……'
话没说完。她后来翻遍了他所有的遗物。
那张照片上，是她。不是别人，是她。
是她从来没见过的、年轻时候的她。那是他藏了一辈子的东西。"
```

## 六、落刀时机：什么时候"发刀子"最有效

### 最强时机（高情绪落差）

| 时机 | 效果 | 适用 |
|------|------|------|
| 读者刚产生好感 → 立刻杀死 | 最出乎意料，冲击力最强 | 配角突然死亡 |
| 即将达成目标 → 死在终点前 | "就差一步"的遗憾 | 悲情英雄之死 |
| 刚化解危机 → 死在平静时刻 | 反差最大（情绪过山车尖刺） | 贯穿全文的角色 |
| 读者刚"习惯"存在 → 突然杀死 | "日常被打破"的不安感 | 长线角色 |

### 最弱时机（尽量避免）

| 时机 | 原因 |
|------|------|
| 反派死亡 | 读者：活该，不会悲伤 |
| 读者还没认识就死了 | 读者：这是谁？ |
| 死了之后才告诉读者是好人 | 太晚了，情感投入不足 |
| 男频主角死亡 | 大多数读者不接受（需大量铺垫） |
