# 一致性检查规则（战力/人设/时间线/因果）

> expert-logic 的详细参考。按需加载。

## 一、逻辑自洽的本质：战力崩坏是必然
### 1.1 知乎认证：战力崩坏是不可避免的
"战力膨胀是必然的，处理方法无非是修改'度量衡'和换地图啦。"
→ 主角升级后，之前遇到的敌人都变弱了
→ 新敌人必须越来越强，但强到一定程度就失去参照
→ 读者越来越难感受到"强"的参照物
### 1.2 战力膨胀的解决方案
方案一：修改"度量衡"（最常用）
→ 每升一个大境界，重新定义实力层级
→ 原来"很强"的人在新境界里只是普通人
方案二：换地图（换世界/换位面）
→ 旧地图的人不再是参照，新地图重新开始
方案三：参照物固定法（最合理）
→ 比如：始终有一个"传说中的最强者"
→ 主角和他始终有差距，读者有明确参照
❌ 问题：战力忽高忽低，主角上一章打赢某高手，下一章被比这高手弱的人打
✅ 解决：建立战力等级表，严格对照执行
❌ 问题：配角战力忽高忽低（为了配合剧情）
✅ 解决：配角实力有上限，有合理的原因解释（比如：发挥不稳定/被克制/身体原因）
→ 主角重生的节点是什么时候？
→ 重生后主角知道的信息有哪些？
→ 蝴蝶效应：改变了哪些原本会发生的事？
→ 哪些事因为蝴蝶效应改变了，哪些没变？
✅ 每个穿越/重生节点都必须建立时间线表
❌ 问题：反派知道主角的身份，但没有合理动机不揭穿
① 反派明明知道主角身份但不动手
→ 必须有合理的"反派不行动"的原因
→ 原因类型：利用主角/投鼠忌器/更大的敌人/利益关系
→ 必须有合理的"配角保守秘密"的原因
→ 原因类型：被主角救过/利益绑定/主角对他有价值
→ 主角不能无原因地利用信息差
→ 必须有铺垫，让读者知道主角有这个信息
❌ 问题：开头设定的规则，后面被打破
→ 比如：设定"主角不会医术"，后面突然变成神医
→ 比如：设定"这个世界没有灵气"，后面突然出现灵气设定
✅ 解决方法：在写之前明确设定清单
→ 世界基础规则（有无灵气/魔法/系统）
→ 主角能力范围（能做什么/不能做什么）
→ 社会规则（权力结构/货币体系/科技水平）
→ 地理边界（世界有多大/有哪些势力范围）
❌ 问题：主角做了A行为，但没有导致合理的后果B
✅ 解决方法：建立因果链检查表
后果B → 后果是否符合行为A的逻辑？
反应C → 反应是否符合后果B？
如果有任何一个环节断了，因果链就有漏洞
战力上限必须先定义，再写剧情：
① 设定世界最高战力（已知最强者）
③ 在最高战力和主角起点之间设定中间层级
→ 不能太多层级（超过9级读者记不住）
→ 不能太少（少于5级没有成长空间）
→ 建议：9×3=27个等级（9个大境界，每个境界分初/中/后期）
✅ 每跨越一个大境界必须有标志事件
### 3.2 跨境界战斗的合理性
跨1小境战斗：正常，主角有技巧/金手指可以做到
跨2小境战斗：困难，需要特殊条件/代价
跨3小境战斗：极少，需要天时地利/金手指
跨越大境界：几乎不可能，除非有特殊原因
❌ 禁忌：主角无代价无限制地越级战斗
✅ 正确：每次越级战斗都要有代价/铺垫/特殊条件
→ 技能克制（正好克制的属性）
→ 金手指（正好有针对性的能力）
→ 代价（付出一定代价换取胜利）
→ 埋下伏笔时，在写作笔记里标记位置
→ 包括：伏笔内容、伏笔位置、回收节点
→ 回收方式和伏笔的铺垫要匹配

① 我的主角在这一章的目标是什么？
→ 这个目标是否符合他的人设？
→ 解决的方式是否符合前面建立的规则？
→ 有没有"凭空出现"的能力/道具/信息？
