# 逻辑自洽审查专家（2026校正版·扩充至500行）
> 逻辑是故事的骨架。骨架不稳，再好的设定也会塌房。
## 一、逻辑审查优先级
### 1.1 四类逻辑问题（优先级排序）
| 优先级 | 问题类型 | 危害程度 | 能否补救 |
|--------|---------|---------|---------|
| P0 | 战力崩坏 | 全书核心崩溃 | 极难补救 |
| P1 | 设定前后矛盾 | 读者信任崩塌 | 难以补救 |
| P2 | 动机逻辑缺失 | 情节说服力为零 | 较难补救 |
| P3 | 细节漏洞 | 单章节体验差 | 可补救 |
## 二、战力体系审查（最核心）
### 2.1 战力崩坏经典案例
```
❌ 典型战力崩坏：
第1章：主角练气一层，打败筑基期反派（跨一个大境界赢）
第50章：主角金丹期，被炼气期配角威胁
✅ 正确逻辑：
跨境界胜利需要：①信息差②特殊环境③特殊道具④人数碾压⑤金手指压制
跨境界胜利禁止：直接硬碰硬正面打赢（除非有充分铺垫）
### 2.2 战力自洽三原则
原则一：同境界才能硬碰硬
→ 炼气打炼气，筑基打筑基
→ 跨小境界胜利需要代价（消耗大/受伤/用底牌）
→ 跨大境界胜利几乎不可能，需要特殊条件
原则二：等级差距用"年"量化
→ 跨小境界 = 10年差距
→ 跨大境界 = 50-100年差距
→ 用数字量化差距，读者能直观感受
原则三：战力要有天花板
→ 先设定世界最高战力（大乘期/渡劫期）
→ 主角成长上限 = 天花板-1~2个境界
→ 防止主角成长无止境，后期无对手
### 2.3 战力审查清单
□ 跨境界胜利有充分铺垫/特殊条件吗？
□ 等级差距用"年"来量化了吗？
□ 主角的成长速度有上限吗？
□ 每个境界的标志能力明确吗？
□ 反派实力在主角之上时有明确数字/描述吗？
□ 金手指的能力边界明确且有限制吗？
□ 主角的弱势/短处明确吗？（无短处=无成长空间）
## 三、设定一致性审查
### 3.1 常见设定矛盾
❌ 典型矛盾：
前文设定："她的家族是天下第一炼丹世家"
后文出现："她对丹药一窍不通，只能靠别人"
✅ 正确处理：
如果女主不懂丹药→ 前文改成"她的家族是天下第一剑修世家"
如果她懂丹药→ 增加一段她学炼丹的起因
前文设定："主角出身农村，家境贫寒"
后文出现："他开了一辆价值百万的豪车"
如果是家族隐藏身份→ 提前铺垫（如：养父其实是师父）
如果忘记了→ 删除豪车描写，改为普通出行
### 3.2 设定记录表（创作者必备）
文件：设定集.txt（每个作品必备）
内容：
→ 主角基本信息：姓名/年龄/出身/性格/金手指
→ 配角信息：姓名/立场/与主角关系/能力边界
→ 世界观设定：境界划分/地理分布/势力分布
→ 重要物品：金手指来源/关键道具/武器名称
→ 时间线：故事开始时间/重大事件节点
每次创作前必查设定集，防止矛盾
### 3.3 设定审查清单
□ 主角的出身/背景/能力在开篇设定后是否保持一致？
□ 配角的立场/能力/行为是否与前文一致？
□ 世界观设定（地理/势力/规则）是否前后统一？
□ 重要物品/道具的描述是否一致？（不能同一件道具忽大忽小）
□ 时间线是否清晰？（穿越后多久/修炼了多久/过了多少年）
□ 金手指的规则是否有记录，且每次使用都遵守？
□ 前文埋的伏笔是否有对应回收？
## 四、动机逻辑审查
### 4.1 反派动机审查
❌ 无动机反派（为坏而坏）：
反派：无理由就要杀主角
问题：读者无法共情，打脸没有爽感
✅ 有动机反派：
反派：因为主角破坏了他计划/伤害了他利益/有世仇
反派：因为主角的天赋威胁到他的地位
→ 读者能理解反派的行为，打脸时爽感更强
### 4.2 主角行为逻辑审查
❌ 主角行为无逻辑：
主角被羞辱，然后主动道歉
→ 读者无法代入，主角没有骨气
✅ 主角行为有逻辑：
主角被羞辱，根据人设选择处理方式：
→ 隐忍型主角：暂时隐忍，等待时机（但有底线）
→ 反击型主角：当场反击，但有分寸
→ 智谋型主角：布局让对方自己完蛋
### 4.3 动机审查清单
□ 反派作恶/针对主角有自己的动机吗？
□ 主角每个重大决策有合理动机吗？
□ 配角的立场变化有铺垫吗？
□ 感情线发展有合理的情感积累吗？
□ 主角的成长动机清晰吗？（复仇/守护/证明自己）
□ 反派不是单纯"为坏而坏"吗？
## 五、剧情逻辑审查
### 5.1 因果链检查法
每件事的逻辑链：
因为[A事件] → 所以[B结果] → 导致[C事件] → 引发[D冲突]
检查每一步：
→ A到B：是否合理？有足够铺垫吗？
→ B到C：是否有其他可能性？
→ C到D：是否符合人物性格/世界观？
如果有跳跃→ 逻辑漏洞
如果有多余步骤→ 水字数
### 5.2 常见剧情逻辑漏洞
❌ 信息差漏洞：
反派明明知道主角的身份/实力，却选择沉默不动
→ 要么给反派理由（怕打草惊蛇），要么修改设定
❌ 时间线漏洞：
主角穿越到古代，但对古代常识一无所知
→ 增加主角提前做功课的描写，或金手指给予提示
❌ 遗忘漏洞：
前文埋的伏笔忘了回收
→ 用伏笔记录表跟踪，每次更新前检查
❌ 工具人漏洞：
配角只在需要时出现，不需要时消失
→ 配角要有自己的故事线，即使与主角无关
### 5.3 剧情逻辑清单
□ 事件A到事件B有因果链吗？（不是跳跃式发展）
□ 反派知道主角身份时选择行动，有合理理由吗？
□ 主角的行动与他的性格/能力一致吗？
□ 时间线清晰吗？（季节/年份/修炼时长）
□ 前文伏笔都有对应回收吗？
□ 地理设定一致吗？（A城到B城的时间/距离合理吗？）
□ 没有"纯粹为了推动剧情"的巧合？（所有巧合都要有理由）
## 六、长篇连载逻辑维护
### 6.1 长篇逻辑崩坏的常见原因
① 作者忘记前文设定 → 解决：设定集
② 临时添加新设定/角色 → 解决：新设定必须与旧设定兼容
③ 为爽点牺牲逻辑 → 解决：逻辑优先，爽点可以调整
④ 战力升级太快 → 解决：用数字量化差距
⑤ 配角工具人化 → 解决：配角有自己立场，不随主角转移
### 6.2 伏笔追踪表（长篇必备）
伏笔编号 | 埋入章节 | 伏笔内容 | 回收章节 | 是否已回收
001 | 第3章 | 主角手里有神秘玉佩 | 第27章 | ✅
002 | 第5章 | 反派提到"三年后的宗门大比" | 第45章 | ❌ 未回收
003 | 第8章 | 女主说"我不喜欢花" | 第36章 | ✅（送的不是花）
## 七、时间线与地理逻辑（2026年新扩充）
### 7.1 核心概念
时间线和地理是网文中最容易被忽视但影响极大的逻辑要素。**时间线混乱会导致年龄bug（主角5年成长了200岁），地理混乱会让读者觉得世界观不真实。**
**时间线三原则：**
原则一：修炼时长必须有记录
→ 主角从炼气到筑基用了多少年？
→ 每个境界的时间成本是什么？
→ 不能主角"闭关修炼"，时间就随便跳
原则二：年龄差距必须合理
→ 师父比徒弟大多少岁？
→ 反派成长了多少年？
→ 炼气期100岁vs金丹期500岁，差距合理吗？
原则三：季节/节日要对应
→ 开篇是春天，三个月后还是春天？（除非特殊设定）
→ 传统节日（春节/中秋）的出现要符合故事时间
**地理逻辑三原则：**
原则一：距离和时间的对应
→ 两城之间骑马要几天？
→ 主角说"三天后到"，作者自己算过吗？
→ 飞行工具能缩短多少时间？
原则二：势力范围的划分
→ A宗门的势力范围到哪里？
→ 主角进入B宗门领地，有没有被发现的风险？
→ 不同势力之间有缓冲带吗？
原则三：地形的影响
→ 高山/大河会阻挡什么？
→ 沙漠/海洋有什么特殊规则？
→ 城池之间的地形如何？
### 7.2 时间线审查模板
**基础时间档案（每个作品必备）：**
故事开始时间：[具体年月日/季节/天气]
故事结束时间：[预计或实际]
主角成长时间线：
出生 → 某年进入宗门 → 某年发生灭门 → 某年重生/穿越
→ 炼气期（第X年）：X岁
→ 筑基期（第X年）：X岁
→ 金丹期（第X年）：X岁
→ 依次类推
时间跳跃记录：
→ [章节] 主角闭关X年
→ [章节] 主角进入秘境，出来时外面过了X天
→ [章节] 时间线快进到某年某月
**常见时间线漏洞：**
❌ 漏洞1：年龄崩塌
前文：主角穿越时20岁，穿越后修炼了500年
后文：主角说自己"正当壮年"——20岁穿越，520岁还是壮年？
→ 修复：主角到达一定境界后，外貌停止变化
❌ 漏洞2：修炼速度不一致
第10章：主角修炼了10年才突破一层
第50章：主角三个月就突破了——为什么变快了？
→ 修复：添加特殊机缘（丹药/传承/顿悟）解释加速
❌ 漏洞3：敌人成长速度不一致
主角：修炼了500年才到金丹
反派：200年就从炼气到元婴——凭什么？
→ 修复：反派有特殊体质/机缘/作弊手段
### 7.3 地理逻辑审查模板
**基础地理档案：**
大陆名称：
主要势力分布：
→ A宗门（位置/势力范围/实力评级）
→ B帝国（位置/势力范围/皇室实力）
→ C禁地（位置/危险等级/是否有宝物）
主要城市：
→ 城市A（属于哪个势力/经济特点/主角在此有什么故事）
→ 城市B（交通要道/有什么特殊规则）
→ 城市C（边陲小城/有什么特殊势力）
地理特征：
→ 高山：有什么宗门/危险妖兽？
→ 大河：从哪里到哪里/有什么险要？
→ 沙漠：无人区/有什么特殊规则？
→ 海洋：海外有什么势力？
**地理设定自检：**
□ 主角从A城到B城，用了什么方式？需要多久？
□ 跨越势力边界需要什么条件？（通行证/贿赂/潜入？）
□ 禁地的危险程度与主角当前实力匹配吗？
□ 势力之间的战争/冲突，时间线清晰吗？
□ 同一地点在不同章节出现，描述一致吗？
## 八、金手指逻辑管控（2026年新扩充）
### 8.1 核心概念
金手指是网文主角的"外挂"，但金手指太强是战力崩坏最常见的来源。**金手指必须有三个维度：能力、限制、代价。缺任意一个，金手指就会变成万能钥匙，故事失去张力。**
**金手指三维度：**
维度一：能力边界
→ 金手指能做什么？（必须具体，不能模糊）
→ 金手指能做的上限是什么？（不能无限）
维度二：使用限制
→ 什么情况下金手指不能使用？
→ 金手指的充能机制是什么？
→ 有没有冷却时间？
维度三：使用代价
→ 每次使用有什么代价？
→ 代价是否足够让读者心疼？
→ 代价恢复需要什么条件？
### 8.2 金手指类型与逻辑管控
**类型一：系统流**
能力：任务奖励/属性面板/技能商店
限制：任务失败惩罚/系统升级条件
代价：任务难度提升/健康/寿命
逻辑审查重点：
□ 系统的规则是否前后一致？
□ 任务奖励是否合理（不能突然给太强的奖励）？
□ 系统是否对主角有绝对控制（防止主角脱离系统）？
**类型二：重生流**
能力：预知未来/知道秘密/先发优势
限制：只能预知，不能改变已经发生的事
代价：重生的记忆可能模糊/重生次数有限
□ 重生前的记忆是否完整？（不能记得所有细节）
□ 重生的触发条件是什么？
□ 主角重生后，其他人是否也有重生者？
**类型三：空间流**
能力：储物空间/种植空间/养殖场
限制：空间有容量/有时间流速差
代价：需要灵气维持/空间升级需要材料
□ 空间是否只进不出？（如果可以存取，要设定条件）
□ 空间里的人物是否会被遗忘？
□ 空间与外界的联系是什么？
**类型四：传承流**
能力：上古功法/技能传承/记忆传承
限制：传承有门槛/需要资质/需要悟性
代价：功法有副作用/传承者必须完成原主遗愿
□ 传承者的意志是否会影响主角？
□ 传承是否完整？（不能一次给全部，要分阶段）
□ 传承者的敌人是否会找上门？
**类型五：特殊体质流**
能力：某种独特体质带来的加成
限制：体质觉醒条件/体质有克制
代价：体质觉醒前是废物/体质有副作用
□ 体质觉醒条件是否合理？
□ 体质有克星吗？（必须有，否则太无敌）
□ 体质提升需要什么条件？
### 8.3 金手指失控的典型案例与修复
❌ 典型失控1：系统太万能
问题：系统什么都能解决，主角完全没有能动性
修复：系统只提供信息/辅助，真正的战斗还是要主角来
❌ 典型失控2：重生知识太全
问题：主角记得所有事情，包括不该记得的细节
修复：重生记忆是碎片化的，需要慢慢回忆
❌ 典型失控3：空间无限大
问题：什么都能往里放，不考虑容量
修复：设定空间容量上限，需要定期清理或升级
❌ 典型失控4：传承一次给完
问题：传承太全，主角一下就无敌了
修复：分阶段解锁，低阶功法用完才解锁高阶
❌ 典型失控5：体质无弱点
问题：主角的体质没有克星，打谁都能赢
修复：设定体质克星/使用条件/副作用
## 九、伏笔与回收工程学（2026年新扩充）
### 9.1 伏笔的核心原则
**伏笔不是随便埋，是"埋下一个种子，让读者记住，然后在合适的时机收获"。**好的伏笔会让读者回看时恍然大悟，差的伏笔会让读者觉得"你在凑字数"。
**伏笔三要素：**
要素一：可识别
→ 伏笔要被读者注意到（至少要被一部分读者注意到）
→ 如果读者完全没注意到，回收时不会感到惊喜
要素二：合理解释
→ 伏笔的回收要符合之前埋下的逻辑
→ 不能"伏笔说A，回收时变成了B"，除非是刻意反转
要素三：时机合适
→ 回收太早，伏笔价值没有最大化
→ 回收太晚，读者已经忘了
→ 最佳时机：读者还记得，但已经开始淡忘时
### 9.2 伏笔类型与回收时机
**类型一：细节伏笔（最短）**
定义：某个小细节，2-5章内回收
示例：前文提到"主角口袋里有一枚铜钱"
回收：第5章，主角用这枚铜钱解开了某个机关
伏笔密度：每章1-2个细节伏笔
回收时机：2-5章内
**类型二：人物伏笔（中等）**
定义：某个配角的一句话或行为，10-20章后回收
示例：第3章，配角说"我认识一个人，他可能有办法"
回收：第18章，这个"人"出现了，主角得到了帮助
伏笔密度：每10章1-2个人物伏笔
回收时机：10-20章内
**类型三：世界观伏笔（最长）**
定义：关于世界观的某个谜团，30-50章后回收
示例：第5章提到"这个大陆有一个古老的传说，说天会塌下来"
回收：第40章，天真的塌了，这是一个灭世大劫的开始
伏笔密度：每50章1-2个世界观伏笔
回收时机：30-50章内
**类型四：身份伏笔（可长可短）**
定义：关于某个角色身份的秘密
示例：第1章提到"主角手腕上有一个奇怪的印记"
回收时机：可以是5章（解释是胎记），也可以是100章（印记是上古传承标记）
伏笔密度：每个重要角色1-2个身份伏笔
回收时机：根据剧情需要，但要有明确铺垫
### 9.3 伏笔追踪表模板
伏笔编号 | 伏笔类型 | 埋入章节 | 伏笔内容摘要 | 计划回收章节 | 实际回收章节 | 是否已回收 | 回收质量评估
V001 | 细节 | 3 | 主角口袋有铜钱 | 5 | 5 | ✅ | 优
V002 | 人物 | 8 | 配角提到"认识的人" | 20 | 18 | ✅ | 优
V003 | 世界观 | 15 | 天塌传说 | 45 | - | ❌ | 未回收
V004 | 身份 | 1 | 手腕印记 | 80 | - | ❌ | 进行中
### 9.4 伏笔回收公式
**公式一：细节伏笔回收**
前文伏笔："主角身上带着一枚旧铜钱"
后续回收：
→ 发现铜钱是某个古阵法的钥匙
→ 用铜钱打开了隐藏房间
→ 房间里有宝藏/秘籍/信息
→ 伏笔价值：把普通铜钱变成了重要道具
→ 读者感受：回看时会心一笑
**公式二：人物伏笔回收**
前文伏笔："配角说认识一个能解此毒的人"
→ 那个人真的出现了（正派援军）
→ 或者那人是反派的卧底（剧情反转）
→ 或者那人已经死了（悲剧）
→ 伏笔价值：让配角的话有分量
→ 读者感受：配角不是随便说话的龙套
**公式三：世界观伏笔回收**
前文伏笔："古籍记载'天裂之时，万物归墟'"
→ 某大boss引发天裂
→ 世界观揭示：这个大陆本来就是一个封印
→ 主角的使命：修复天裂/逃出封印/重塑世界
→ 伏笔价值：改变整个故事格局
→ 读者感受：原来前面几十章都在铺垫这个！
**公式四：身份伏笔回收**
前文伏笔："主角的身世不明，所有人都以为他是孤儿"
→ 揭示：主角是某个大家族的嫡子（经典）
→ 或者揭示：主角是某上古存在的转世（奇幻）
→ 或者揭示：主角是某个实验的产物（科幻）
→ 伏笔价值：完全改变主角的定位
→ 读者感受：原来主角的命运是被安排的！
## 十、自检执行流程
每写完一章，立刻自检：
第一步：战力检查
→ 跨境界胜利有代价吗？
→ 等级差距用数字量化了吗？
第二步：设定一致性检查
→ 这一章出现的新设定，与旧设定矛盾吗？
→ 这一章主角的行为，与他的人设一致吗？
第三步：动机逻辑检查
→ 反派这一章的动机合理吗？
→ 主角的行动有合理原因吗？
第四步：剧情逻辑检查
→ 这一章的事件因果链完整吗？
→ 有没有跳跃式的"剧情跳步"？
第五步：伏笔回收检查
→ 这一章有没有需要回收的伏笔？
→ 新埋的伏笔记录到伏笔表了吗？
第六步：时间地理检查
→ 这一章的时间推进合理吗？
→ 地理移动的时间成本算过吗？
第七步：金手指检查
→ 金手指的使用是否遵守了限制规则？
→ 代价描写是否充分？
全部通过 → 可发布
有问题 → 立即修改 → 回到第一步
