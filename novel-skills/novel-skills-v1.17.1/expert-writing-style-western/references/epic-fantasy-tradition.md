# 高史诗奇幻传统（托尔金体系）

> 来源：魔戒 / 霍比特人 / 精灵宝钻 / 龙枪编年史 / 魔兽设定集
> 配合SKILL.md文风切换引擎使用

---

## 一、托尔金核心文风特征

```
语言哲学：
  → 托尔金的句子"短而深远"
  → "就在那时，有人敲门。" ——这是他最典型的句子
  → 看似简单，事实精确，但背后有巨大的重量
  → 不堆砌形容词，让事实本身说话

名词体系：
  → 自创语言感：中州地名/人名有发音体系
  → 名字本身是文化：阿拉贡（Elegnant=精灵人）vs 山姆（Sam=普通人）
  → 武器/地名/历史事件三要素统一

世界观展示方式：
  → 不在开头集中说明，而是通过角色观察一点一点展示
  → 历史感来自名词的厚重感，不来自大段叙述
  → 引用民谣/诗歌/谚语来传递文化感
```

## 二、托尔金式描写模板

```
【史诗开场·场景描写】

❌ 网文写法（直接说明）：
"这是一座古老的城堡，城堡里住着一个强大的国王。"

✅ 托尔金式写法（事实+氛围）：
"城堡的墙是黑色的石头砌成的，已经没有人记得它是什么时候建的。
  门口的守卫比城里大多数房子都老。
  山下的人说，晚上有时候能在城垛上看到火光。
  但没有人说得清那是什么。"

→ 没有一个形容词说它"可怕"或"神秘"
→ 只是陈述事实，让事实本身产生重量
→ 读者自己构建出那个画面
```

## 三、托尔金式对话特征

```
【慢节奏对话·建立信任】

❌ 网文写法（直接）：
"'我是来杀你的。'刺客冷冷地说。"

✅ 托尔金式写法（语境+对话）：
"刺客站在门口，没有动。
  '你知道我是来做什么的。'
  他说这话的时候，甚至带着一点歉意。
  '所以我来了。'"

→ 对话有延迟，有留白
→ 语气不是从"冷冷地说"得知，而是从动作和语境推断
→ 对话本身有呼吸节奏
```

## 四、史诗感建立技巧

```
技巧一【时间重量】：
"这座桥建成的时候，我们祖父的祖父还没出生。"
→ 用时间的广度建立重要性

技巧二【具体事实代替抽象形容】：
❌ "他是一个可怕的战士"
✅ "他杀死过七条龙，最后一条是在他三十岁那年"

技巧三【让名词自己说话】：
"那把剑叫'灾厄'。每一个叫这个名字的人，最后都死在了它自己的剑下。"
→ 名字本身成为叙事，不是旁白说明
```
