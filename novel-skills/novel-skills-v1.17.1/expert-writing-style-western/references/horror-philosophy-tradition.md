## 一、克苏鲁传统：宇宙恐怖（心理恐惧）

### 核心文风特征

```
代表作品：克苏鲁神话（洛夫克拉夫特）/ 黑暗质量效应 / 异形系列

核心哲学：
  → 恐惧不是来自"我知道我面对什么"
  → 恐惧来自"我意识到我永远无法理解"
  → 宇宙是冷漠的，不是恶意的

恐惧的三个层次：
  第一层（初级）：你看到怪物 → 恐惧是视觉的
  第二层（中级）：你意识到某些东西在操控你 → 恐惧是认知的
  第三层（高级）：你意识到你自己的认知是不可靠的 → 恐惧是形而上学的

写作原则：
  → 不要描述不可名状之物
  → 描述引起不可名状感的体验
  → 用不精确的语言表达超越语言的事物
```

### 克苏鲁式恐惧描写模板

```
✅ 克苏鲁式写法（感知失真）：
"他看到了它。
  不是"看"——是那个过程有了一个名字。
  他的词汇表里没有对应的词。
  他有眼睛，所以他"应该"能看到。
  但他的大脑在尖叫。
  不是"害怕"。是某种更原始的东西。
  他的脚开始往后退——不是因为他想退。
  是因为他的腿已经不听他的了。"

→ 不描述怪物的样子（读者想象>作者描述）
→ 描述恐惧的体验，而不是恐惧的对象
```

### 认知恐怖建立技巧

```
【信息揭示·层层叠加】

"教授研究了三天的石板。
  第一天，他发现了符号的规律。
  第二天，他能读出一些词。
  第三天，他读完了。
  然后他开始哭。
  他的助手说：教授，这上面写了什么？
  他说：我现在知道为什么它是密封的了。
  不是为了保护我们。
  是为了保护那些不知道的人。

  那天夜里，教授自杀了。
  遗书只有一句话：
  '不要读它。'"
```

## 二、阿西莫夫传统：哲学推理（思想实验）

### 核心文风特征

```
代表作品：银河帝国 / 基地系列 / 机器人系列

核心哲学：
  → 思想是行动的主人
  → 每个情节都是一个哲学命题的戏剧化展示
  → 对话不是信息传递，是思想碰撞

语言哲学：
  → 最简洁的语言，承载最复杂的想法
  → "我是一个机器人。"（然后这句话改变了人类历史）
  → 没有一个词是浪费的

叙事声音：
  → 冷静，克制，几乎是数学的
  → 情感的爆发通过叙述的突然停顿来表达
  → 时间跨度可以很大，但每个场景都是精确的切片
```

### 哲学对话模板

```
✅ 阿西莫夫式写法（思想即戏剧）：
"谢顿沉默了很久。
  '你的证据，'他终于说，'是完美的。'
  年轻的数学家脸上露出笑容。
  '但你得出了错误的结论。'
  '这不矛盾吗？'
  '不。'谢顿站起来，'完美的证据，错误的结论。
  这才是历史真正的形状。'"
```

## 三、推理小说传统（阿加莎·克里斯蒂/柯南·道尔）

### 阿加莎·克里斯蒂（优雅悬疑）

```
核心特征：
  → 表面平静，暗流涌动
  → 波洛的对白=表面闲聊，实为信息采集
  → 真相揭露时，一切早有预兆
  → 最后十页=所有线索一次性回收

✅ 波洛式问话：
"昨晚你睡得好吗？"
  她说：很好。
  他说：哦。
  她说：您为什么这么问？
  他说：没什么。只是问问。
  ——对话结束，但实际上什么都没有说
```

### 柯南·道尔（简洁行动）

```
核心特征：
  → 直接，干净，没有废话
  → 华生的观察=给读者的信息
  → 悬念来自具体的空间位置

✅ 华生式观察：
"那是一把普通的椅子。"
  但福尔摩斯看了它很久。
  "这张椅子，'他说，'在最近四十八小时内，被四个人坐过。'
  "你怎么——"
  "椅背上有四种不同的鞋印。其中一种是女人的高跟鞋——高跟，细跟。'
  "所以？'
  "所以。这是一个女仆的鞋印，但这个房间里的女仆是个平底鞋。"
```
