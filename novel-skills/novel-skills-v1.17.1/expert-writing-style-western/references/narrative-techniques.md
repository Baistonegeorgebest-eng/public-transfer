## 一、西方文学结构技法

### 1.1 三幕式结构（好莱坞标准）

```
第一幕（25%）：建置
  → 介绍角色/世界/冲突
  → 关键事件：激励事件（打破日常）

第二幕（50%）：对抗
  → 角色追求目标，遭遇障碍
  → 中点：假胜利或假失败
  → 关键事件：灵魂黑夜（最低谷）

第三幕（25%）：解决
  → 最终对决/最终选择
  → 关键事件：高潮+结局

网文适配：
  每卷 = 一个三幕
  全书 = 多个三幕嵌套（大三幕套小三幕）
```

### 1.2 英雄之旅（坎贝尔12步）

```
① 平凡世界 → ② 冒险召唤 → ③ 拒绝召唤
→ ④ 遇见导师 → ⑤ 跨越门槛 → ⑥ 考验/盟友/敌人
→ ⑦ 接近最深洞穴 → ⑧ 磨难 → ⑨ 奖赏
→ ⑩ 返回之路 → ⑪ 复活 → ⑫ 带着仙药归来

网文适配：
  步骤①②③ = 开篇（1-3章）
  步骤④⑤ = 奇遇+入门（4-10章）
  步骤⑥⑦⑧ = 成长+战斗（全书主线）
  步骤⑨⑩⑪⑫ = 大结局（最后10章）
```

### 1.3 POV技法详解

```
GRRM的POV（Point of View）技法：
  每章锁定一个角色的视角
  读者只知道该角色知道的信息
  切换视角时提供新信息/新角度

优势：
  ① 制造信息差（读者知道的比角色多/少）
  ② 多线叙事不混乱
  ③ 角色死亡时冲击力极大

网文应用：
  长篇可用POV（每卷不同视角）
  短篇建议单一视角（避免混乱）
  POV角色 ≤ 5个（多了读者记不住）
```

## 二、叙事视角切换术

```
第一人称（I）：
  → 优势：代入感极强，适合内心戏多的故事
  → 劣势：视野受限，只能写"我"看到的
  → 适合：悬疑/恐怖/情感向

第三人称有限（He/She + 单一角色内心）：
  → 优势：比第一人称灵活，同时保留代入感
  → 劣势：仍受限于单一角色视角
  → 适合：大多数网文/通俗小说

第三人称全知（上帝视角）：
  → 优势：可以写任何角色的内心和任何场景
  → 劣势：容易降低代入感
  → 适合：史诗/群像/历史题材

POV多视角切换（GRRM式）：
  → 优势：多线叙事，信息差制造张力
  → 劣势：读者可能偏爱某些视角
  → 适合：百万字长篇/复杂世界
```

**视角切换规则：**
1. 场景内不切换视角（一个场景锁定一个视角）
2. 视角切换时用章节分隔或明确标记
3. POV角色数量控制在5个以内
4. 每个POV角色提供独特的信息/角度

## 三、对话节奏差异化

```
类型一：紧张型对话（短句+打断）
  → 场景：争吵/审讯/战斗前

类型二：舒缓型对话（长句+留白）
  → 场景：日常聊天/回忆/思考

类型三：潜台词型对话（说的≠想的）
  → 场景：社交场合/感情戏/政治博弈

类型四：独白型对话（一个人说，另一个人沉默）
  → 场景：忏悔/告白/训话
```

## 四、场景电影化描写

```
① 镜头感（选择"拍摄角度"）
  → 远景：交代环境
  → 中景：展示人物互动
  → 近景：聚焦细节
  → 特写：强调关键信息

② 剪辑感（控制叙事节奏）
  → 快切：紧张场景用短句短段
  → 长镜头：舒缓场景用长句长段
  → 跳切：省略过渡，直接跳到关键画面

③ 声画感（调动多感官）
  → 不只写"看到的"，还要写"听到的/闻到的/感觉到的"
```

## 五、演进时间线：西方文学叙事技法变迁

### 古典时期（19世纪前）
- 荷马史诗→但丁《神曲》→莎士比亚戏剧
- 特征：宏大叙事、英雄主义、全知视角

### 现代主义（20世纪初-中期）
- 卡夫卡、乔伊斯、海明威、福克纳
- 特征：意识流、碎片化叙事、不可靠叙述者

### 后现代主义（20世纪中-晚期）
- 博尔赫斯、卡尔维诺、品钦
- 特征：元叙事、戏仿、多层嵌套、打破第四面墙

### 当代（21世纪）
- 《三体》的宏大叙事+科学内核、《权力的游戏》POV群像
- 特征：类型融合、全球化叙事、跨媒介叙事

## 六、实战案例：西方风格在中文网文中的应用

### 案例一：《诡秘之主》的POV群像

**技法运用：** 借鉴《冰与火之歌》POV结构
**具体做法：** 每个大章节以不同角色视角展开，但核心线索始终围绕克莱恩
**可复用公式：** 主角POV占比60% + 配角POV 30% + 反派POV 10%

### 案例二：《灵境行者》的海明威式简洁

**技法运用：** 冰山理论——只写水面之上的1/8
**可复用公式：** 描述=动作+结果+留白（≤3句/场景）

### 案例三：《宿命之环》的不可靠叙述者

**技法运用：** 借鉴《搏击俱乐部》《禁闭岛》的不可靠叙述
**可复用公式：** 建立读者信任→植入误导→揭示真相→重新定义之前所有事件
