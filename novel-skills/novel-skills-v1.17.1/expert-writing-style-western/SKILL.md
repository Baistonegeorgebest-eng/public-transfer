## 一、两种文风的底层逻辑

### 1.1 网文风格 vs 西方文学风格

```
网文风格（中式）：
  语言密度：信息密度高，字字有推进
  叙事节奏：快·密·强，爽点驱动
  读者位置：代入主角，视角单一
  情绪模式：紧张→爽，循环驱动
  语言特征：口语化，直接，少描述，多对话

西方文学风格：
  语言密度：允许留白，允许节奏慢
  叙事节奏：允许平静章节，允许氛围感
  读者位置：观察+感受，不只是代入
  情绪模式：压抑→释放，或无释放
  语言特征：书面化，精确，有节奏感，多层次描写
```

### 1.2 什么时候必须用西方文风

```
✅ 写西幻/北欧/中世纪题材 → 必须用
✅ 写有外国文化背景的角色 → 必须用
✅ 写深沉/压抑/恐怖氛围 → 必须用
✅ 与外国角色对话场景 → 必须用（语气）
✅ 写宗教/信仰/哲学主题 → 必须用
✅ 写战争/政治/外交 → 建议用

❌ 写中式背景/穿越/现代都市 → 不需要
❌ 打怪升级的爽点密集区 → 网文风格优先
❌ 节奏飞快的战斗场景 → 网文风格优先
```

### 1.3 两种风格的比例分配（西幻题材）

```
西幻题材·文风比例参考：

整体（按字数）：
  西方文学质感：40~60%（场景描写/氛围/对话质感）
  网文爽点密度：40~50%（保持节奏）
  留白/情绪铺垫：10~20%（建立氛围）

具体分配：
  日常/外交/政治场景 → 西方文风70% + 网文30%
  战斗/升级/打脸场景 → 网文风格70% + 西方文风30%
  情感/心理/氛围场景 → 西方文风80% + 网文20%
  悬疑/推理/信息揭示 → 西方文风60% + 网文40%
```

## 二、西幻题材的文风整合框架

### 2.1 文风切换引擎

```
根据场景类型，自动选择文风组合：

【外交/谈判/政治博弈】
→ GRRM POV 40% + 战锤文件体 30% + 阿西莫夫对话 30%
→ 核心：每个字都有政治含义
→ 详见：references/dark-gothic-tradition.md

【战斗/动作场景】
→ 网文节奏 50% + 冰风谷动作描写 30% + 托尔金简洁句 20%
→ 核心：动作精确，信息不丢失
→ 详见：references/epic-fantasy-tradition.md

【氛围/恐怖/神秘场景】
→ 克苏鲁恐惧 40% + 哥特环境 30% + 战锤黑色幽默 30%
→ 核心：让读者自己产生情绪
→ 详见：references/horror-philosophy-tradition.md

【哲学/推理/谜题场景】
→ 阿西莫夫 40% + 阿加莎对话 40% + GRRM POV 20%
→ 核心：思想是行动的原因
→ 详见：references/horror-philosophy-tradition.md

【日常/情感/角色深度】
→ 托尔金细节 30% + GRRM POV 40% + 网文情感 30%
→ 核心：具体的细节传递情感重量
→ 详见：references/epic-fantasy-tradition.md
```

### 2.2 西幻题材网文的禁忌清单

```
❌ 不要用中文网文的"霸气""威压"等词汇写外国贵族
  → 换成：无声的沉默 / 眼神的变化 / 物件的象征

❌ 不要用"恐怖如地狱"等陈词滥调
  → 换成：具体的感知细节（让他描述自己的感受）

❌ 不要让主角用中文式的内心独白解释西方宗教/哲学
  → 换成：角色行动折射思想，不直接说明

❌ 不要在一个章节里同时出现中文俗语和西方神话体系
  → 例："说曹操曹操到" + "索伦的阴影"=混搭感太强

❌ 不要用网文的速度写POV多视角
  → 每个POV章节至少需要100字的"角色声音建立"
```

### 2.3 西幻开篇黄金模板（第一章必须用）

```
第一章开篇·西幻版：

【场景建立在前，冲突在后】

第一段（3~5句）：
  → 建立物理空间（托尔金式：事实+重量）
  → 不要说明，描述

第二段（3~5句）：
  → 引入角色，角色观察这个空间
  → 用角色的反应折射空间的意义

第三段（3~5句）：
  → 出现第一丝不对劲（GRRM式：每个细节都有问题）
  → 不要直接说明，留给读者疑惑

第四段：
  → 钩子出现在第一章的第300~500字
  → 钩子=读者必须翻下一页的理由
```

## 三、大神风格对照：中文网文 vs 西方文学

| 维度 | 中文网文大神 | 西方文学传统 |
|------|-----------|-----------|
| 句式 | 短句多，节奏快 | 允许长句缠绕 |
| 形容 | 直接，密集 | 精确，允许留白 |
| 情感 | 直接表达 | 通过行动折射 |
| 世界观 | 直接说明 | 通过体验建立 |
| 战斗 | 招式密集 | 动作精确，节奏如舞 |
| 对话 | 功能性强 | 有呼吸感，有弦外音 |
| 恐惧 | 视觉冲击 | 认知失真 |
| 政治 | 主角碾压 | 每个人有自己的逻辑 |
| 时间感 | 快速推进 | 允许章节慢下来 |

### 共用原则（无论哪种风格）

```
✅ 事实>形容（具体的细节永远比形容词有力）
✅ 动作>旁白（让角色做某事，不只是说某事）
✅ 节奏>字数（慢章节有慢章节的功能，不是浪费时间）
✅ 声音>信息（每个角色有自己的语言方式，这是区分角色的关键）
✅ 克制>堆砌（越是重要的时刻，越要克制）
```

## 四、西方风格应用自检

- [ ] 使用了哪些西方叙事技法？（POV/意识流/冰山理论/...）
- [ ] 技法是否与题材匹配？（悬疑适合不可靠叙述，甜文不适合）
- [ ] 是否过度翻译腔？（"他感到一阵说不清道不明的..."应避免）
- [ ] 中文读者是否能自然理解？（不需要注释也能读懂）
- [ ] 是否有1-2个"西方感"名场面？（读者会截图传播的那种）

## 五、与 expert-literary-prose 的协作

本skill侧重西方文学原著的技法拆解（英文原文的修辞、结构、叙事策略），`expert-literary-prose` 侧重中文译本的调性模仿（翻译腔、庄重感、异质感）。两者互补：前者是「学西方怎么写」，后者是「在中文里怎么还原那种感觉」。西幻创作时建议同时调用。
