## 快速参考

### 核心原则速查

| 原则 | 说明 |
|------|------|
| 原著还原优先 | 同人核心是"看到我喜欢的角色"，不是看原创角色 |
| OOC零容忍 | 一级OOC（致命）= 必须删除重写 |
| 用户自创 > skill规范 > 默认原著 | 用户自创体系是"项目宪法" |
| CP必须标注 | 标题/简介明确CP向，不标注=得罪所有读者 |

### 避坑速查

| 坑 | 解决 |
|----|------|
| OOC | 建立角色三要素表，每段对白过OOC检查 |
| 战力崩坏 | 严格遵守原著战力体系，越级战斗必须有充分理由 |
| 剧情抄袭原著 | 同人是二创不是复述，必须有新东西 |
| 金手指太强 | 金手指必须有代价和限制，不能碾压一切 |
| CP争议 | 标题/简介明确标注CP向 |
| 设定自相矛盾 | 写之前整理原著设定清单，写作过程中随时对照 |
| 开局信息量过大 | 同人读者已熟悉原著，不需要重新介绍世界观 |
| 忽视原著粉丝情感 | 尊重原著角色，不要恶意贬低/丑化任何角色 |

## OOC防控体系

OOC（Out Of Character）是同人创作的死刑判决。读者来看同人，核心需求就是"看到我喜欢的角色"。一旦OOC，读者会立刻弃书并在评论区差评。

### OOC防控四步法

**第一步：角色核心三要素表**
每个重要角色必须建立：
- 核心性格（不可改变的底色）：如"嘴硬心软""绝对理性""守护本能"
- 行为模式（遇到问题的反应方式）：如"先动手再说话""先分析再行动"
- 语言风格（说话方式和口头禅）：如"嘛""草""在下""本大爷"

**第二步：场景代入测试**
写完一个角色的对白/行为后，问自己："如果原作作者看到这段，他会觉得这个角色说出来/做出来是合理的吗？"如果答案是"不确定"，就修改到确定为止。

**第三步：原著对标法**
遇到不确定的角色反应时，翻原著找到类似场景："原著中这个角色遇到类似情况时是怎么反应的？"以此为基准来写当前场景。

**第四步：读者视角检查**
想象自己是最挑剔的原著粉丝："这段有没有让我觉得'这不是他/她会说的话/做的事'的地方？"有就改，没有就过。

## 金手指设计快速参考

同人金手指核心：利用信息差和新能力改变原著走向。

| 类型 | 优势 | 限制 | 写法 |
|------|------|------|------|
| 剧情预知型 | 上帝视角快感 | 蝴蝶效应递减 | 前期预知碾压，中后期靠实力 |
| 系统辅助型 | 升级线清晰 | 不能太万能 | 不能碾压原著最强 |
| 血脉觉醒型 | 与原著自然融合 | 不能凭空发明 | 在原著基础上延伸 |
| 穿越继承型 | 身份感强 | 能力不能太离谱 | 需要学习适应 |
| 道具强化型 | 跨界感强 | 能力有上限 | 不能是唯一依赖 |
| 改命重生型 | 角色认同感最强 | 不能突然变全能 | 保留前世记忆，能力需重新积累 |

→ 详见 [references/power-system.md](references/power-system.md)（战力体系规范+金手指六种类型详解）

## 同人安全赛道（2024-2026）

```
① 改命治愈 → 改变原著悲剧结局（最高人气）
② 甜向日常 → 原著角色的日常生活（轻松治愈）
③ 规则怪谈 → 原著世界观+怪谈元素（新赛道）
④ 跨界喜剧 → 两个作品联动（JoJo梗/玩梗）
⑤ 回忆补完 → 填补原著空白/前传/后传
```

## 鬼灭专项速查

- 呼吸法体系：风/水/炎/雷/岩/日/月等（遵循原著）
- 用户自创体系（如"光之呼吸"）优先级高于默认规范
- 无惨的压迫感是贯穿全文的核心冲突
- 柱级 > 甲级 > ... > 癸级（战力等级必须遵守）
