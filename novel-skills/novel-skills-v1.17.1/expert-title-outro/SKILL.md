## 一、书名设计：3秒决定读者去留

### 1.1 书名三要素

```
① 类型一眼可辨：读者3秒内知道这是什么类型的书
② 核心卖点明确：读者知道这本书能满足什么期待
③ 有记忆点：让读者记住你的书名
```

### 1.2 爆款书名公式

**公式一：题材+金手指**
```
格式：[题材]+[金手指/核心优势]
示例：
✅《玄幻：开局获得满级天赋》
✅《都市：我的系统会说话》
✅《穿越：我在古代当首富》

❌ 错误示范：
❌《命运之路》→ 太文艺，读者不知道是什么类型
❌《重生之我是xxx》→ 泛滥了，没有特色
```

**公式二：身份反差型**
```
格式：[身份A]/[身份B]+[爽感核心]
示例：
✅《废物赘婿：今日起，我不做人了》
✅《外卖员：我是世界首富的儿子》
✅《假太监：皇帝是我老婆》
```

**公式三：情绪冲击型**
```
格式：[极端情绪/极端情境]+[具体人物]
示例：
✅《妻子背叛后，我亮出万亿家产》
✅《女儿被欺负那天，我灭了一个家族》
✅《系统说我不配当男主》
```

**公式四：悬念型**
```
格式：[悬疑点]+[人物/情境]
示例：
✅《三年后，他回来复仇了》
✅《她消失的999天里，发生了什么》
✅《那个秘密，她至死都没说出口》
```

### 1.3 书名避坑

```
❌ 书名超过15个字 → 手机屏幕显示不全
❌ 书名用生僻字/繁体字 → 读者搜索不到
❌ 书名和内容不符 → 读者点进来发现被骗
❌ 书名太文艺 → 起点/番茄核心用户不喜欢文艺风
```

## 二、章节标题设计

### 2.1 章节标题的作用

```
① 提醒读者上一章的内容（降低弃书率）
② 暗示本章的核心爽点（吸引点进来）
③ 建立期待感（让读者知道本章有什么）
```

### 2.2 爆款章节标题公式

**公式一：数字+悬念**
```
✅《第45章：他回来了，带着万亿财富》
✅《第89章：三年之约，今日到期》
→ 数字给读者进度感，悬念吸引点击
```

**公式二：对话冲突型**
```
✅《她说："离婚。"他说："好。"》
✅《"你配不上我女儿。"他笑了笑，拿出一样东西。》
→ 对话直接展示冲突，读者立刻知道本章有爆点
```

**公式三：动作+结果型**
```
✅《他抬手，一巴掌扇在丈母娘脸上》
✅《他打开那个盒子，所有人都傻了》
→ 动作具体有画面感，结果是悬念吸引点击
```

**公式四：身份揭晓型**
```
✅《他的身份，终于揭晓》
✅《原来，他才是幕后大佬》
→ 适合身份反转类情节
```

### 2.3 章节标题避坑

```
❌ 标题和内容不符 → 读者觉得被骗
❌ 标题太文艺 → 网文读者喜欢直白
❌ 标题剧透太多 → 读者看标题就知道结局
❌ 标题太长 → 手机屏幕显示不全
```

## 三、章节结尾钩子设计（最核心技能）

### 3.1 钩子的本质

```
钩子 = 让读者"忍不住点下一章"的设计
好的钩子三要素：
① 具体事件（不是模糊的情绪）
② 悬念感（读者想知道结果）
③ 时间压力（下一秒就要发生/不能等太久）
```

### 3.2 钩子十种经典类型

**① 死亡威胁型（最强钩子）**
```
"那把剑，直刺他的心口。他避无可避。就在这时——"
→ 读者心跳加速，必须点下一章
```

**② 身份揭示型**
```
"他抬起头，对上了那张脸。那一刻，他整个人都僵住了。那是……他的父亲。"
→ 读者想知道：父亲为什么在这里？
```

**③ 真相逼近型**
```
"那封信上的字迹，他越看越熟悉。他猛然想起——三年前的那一夜。"
→ 读者想知道：真相是什么？
```

**④ 命运抉择型**
```
"三天后，他要做出选择。是把剑交给敌人，换取家人的安全？还是……"
→ 读者想知道：主角会怎么选？
```

**⑤ 敌人降临型**
```
"天边，出现了一道金色的光。那是……渡劫期的强者。他们，来找他了。"
→ 读者想知道：主角能赢吗？
```

**⑥ 机会出现型**
```
"那个秘境，传闻里面有一件上古神兵。但进入的人，十不存一。"
→ 读者想知道：主角会进去吗？
```

**⑦ 关系转折型**
```
"她推开门，看到了不该看到的一幕。他怀里，抱着另一个女人。"
→ 读者想知道：她会原谅他吗？
```

**⑧ 任务/挑战型**
```
"系统发布了新任务：杀死渡劫期强者一名。时限：三天。奖励：未知。"
→ 读者想知道：主角能做到吗？
```

**⑨ 时间倒计时型**
```
"三年一度的宗门大比，还有七天。他必须在此之前突破。"
→ 读者想知道：他能突破吗？
```

**⑩ 意外发现型**
```
"他翻开那本古籍，看到了一行字。'那个人的真实身份，藏在这座山的深处。'"
→ 读者想知道：那是谁？
```

### 3.3 钩子避坑

```
❌ 钩子太模糊 → "她心里很矛盾" → 改为具体事件
❌ 钩子没有时间压力 → "后来发生了一件事" → 改为有时间限制
❌ 钩子剧透太多 → 读者知道结局了就不追了
❌ 钩子用情绪而非事件 → "他很紧张" → 改为具体动作
```

## 四、悬念设计进阶技法

### 4.1 悬念的核心原理

```
悬念 = 信息差
→ 读者知道的 > 角色知道的 = 期待感
→ 读者不知道 = 好奇感
→ 角色不知道 = 紧张感

三个层次：
浅层悬念（1章内揭晓）→ 每章必备
中层悬念（3-5章揭晓）→ 维持追读
深层悬念（贯穿全书）→ 核心驱动力
```

### 4.2 悬念设置四技巧

**技巧一：问题植入** — 每章结尾植入一个问题，读者带问题进入下一章

**技巧二：多重悬念叠加** — 浅层+中层+深层同时存在，解决一个立刻有新的补上

**技巧三：悬念升级** — 同一主题每次出现都升级：小问题→生死攸关

**技巧四：悬念对冲** — 两个悬念同时存在互相竞争，交替出现保持新鲜感

### 4.3 悬念设计模板

**模板一：身份悬疑型（贯穿全书）**
```
深层悬念：主角的真实身份是什么？
升级节点：第5章暗示 → 第15章发现特殊血脉 → 第50章线索被销毁 → 第80章揭晓
```

**模板二：仇人悬疑型（复仇主线）**
```
深层悬念：谁是灭门的真正主谋？
升级节点：以为是A → A被杀线索断 → B出现嫌疑大 → B是棋子 → 幕后C出现
```

**模板三：感情线悬疑型（女频）**
```
深层悬念：男主对女主是真情还是假意？
升级节点：特别好（是真爱？）→ 伤害她（是假的？）→ 真相揭露（是保护）→ 双向表白
```

## 五、标题结尾联动设计

### 5.1 核心概念

书名、章节标题、章节结尾是三位一体的"注意力管理系统"。

**联动三原则：**
```
原则一：书名承诺的，章节要兑现
  → 书名说"开局获得满级天赋" → 前10章必须展示能力

原则二：章节标题预告的，正文要展开
  → 标题是"她消失了" → 正文要解释为什么消失

原则三：章节结尾的悬念，标题要暗示
  → 结尾是"他打开了那个盒子" → 下章标题可以是"盒子里是什么"
```

### 5.2 联动设计模板

**模板一：爽点预告型**
```
书名：《开局获得满级天赋》
第5章标题：《满级天赋的第一次展示》
结尾钩子："所有人都在等着看他的笑话。他抬起头，微微一笑。下一瞬——"
下一章标题：《他只用了一招，所有人都沉默了》
```

**模板二：身份反差型**
```
书名：《妻子背叛后，我亮出万亿家产》
结尾钩子："她跪在他面前，哭得梨花带雨。他看着她，沉默了三秒。然后，他说了一句话。"
下一章标题：《他说："晚了。"》
```

**模板三：多线并进型**
```
结尾钩子："天劫散去，他踏入了渡劫期。与此同时，他的手机响了。另一条世界线，出事了。"
下一章标题：《都市世界：他的公司被人查封了》
→ 悬念A即将解决 → 引出悬念B → 多线轮动
```

## 六、不同题材的标题结尾设计

### 6.1 男频都市题材

**书名偏好：** 身份反差（废物赘婿/假太监）、金钱（万亿资产）、逆袭（从今天开始）
**结尾偏好：** 打脸型（最强）→ 逆袭型 → 感情型 → 敌人型

### 6.2 男频玄幻/修仙题材

**书名偏好：** 系统（开局获得满级）、宗门（我成了宗门老祖）、修炼（修炼9999年）
**结尾偏好：** 突破型（最强）→ 战斗型 → 宝物型 → 敌人型

### 6.3 女频都市/古言题材

**书名偏好：** 甜宠（嫁给/闪婚）、虐文（重生后/假死后）、身份（夫人/假千金）
**结尾偏好：** 感情转折（最强）→ 误会型 → 复仇型 → 身份揭露型

### 6.4 题材专属钩子模板

**都市打脸钩子（男频）**
```
"他掏出手机，发了一条短信。三分钟后，一辆劳斯莱斯停在了门口。'董事长，您来了。'"
下一章标题：《所有人都在问他是谁》
```

**修仙突破钩子（男频）**
```
"他翻开那本古籍，看到了一行字。'此功法，需以心血祭炼，方可大成。'他沉默了一夜。"
下一章标题：《他咬破手指，按在了那行字上》
```

**古言感情钩子（女频）**
```
"他转身离开，却在门口停住了。他回头看了她一眼。那眼神里，有愤怒，也有……"
下一章标题：《她看到了他眼底的泪光》
```

## 七、质量检查清单（完整版）

```
书名检查：
□ 一眼可辨题材  □ 有核心卖点  □ 有记忆点  □ ≤15字  □ 无生僻字  □ 与内容相符

章节标题检查：
□ 有悬念  □ 与内容相符  □ ≤20字  □ 有数字（进度感）

章节结尾钩子检查：
□ 每章有具体事件钩子  □ 有明确时间压力  □ 无情绪空泛  □ 无过多剧透
□ 浅层+中层+深层悬念叠加

悬念设计检查：
□ 有贯穿全书的深层悬念  □ 每5章有中层悬念  □ 每章有浅层悬念
□ 悬念有升级  □ 回收有惊喜感

标题结尾联动检查：
□ 书名承诺10章内兑现  □ 章节标题正文有展开  □ 结尾悬念标题有暗示
```
