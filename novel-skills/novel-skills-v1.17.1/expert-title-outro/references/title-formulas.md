# 标题公式详解

## 番茄短故事标题公式

### 公式一：身份+处境+爽点
```
格式：[身份标签]+[核心处境]+[爽点结果]
示例：《社畜重生：这次我成了霸道总裁》
要点：身份要让读者有代入感，处境要引发共鸣，爽点要明确
```

### 公式二：悬念+情绪
```
格式：[悬念事件]+[情绪钩子]
示例：《消失五年的老公突然回家，身后跟着一个女孩》
要点：悬念要具体，情绪要强烈，让读者第一眼就有好奇心
```

### 公式三：反差+趣味
```
格式：[反差对比]+[趣味元素]
示例：《高考落榜的我，被大学破格录取了》
要点：反差要大，趣味要新，让读者觉得有意思
```

### 情感设计三要素
```
① 第一眼就有情绪 → 读者被标题的情绪感染
② 让读者知道读了会爽 → 标题暗示阅读体验
③ 让读者知道这是什么类型 → 类型标识清晰
```

## 书名拟定流程

### 六步法
```
第一步：确定核心关键词 → 包含题材关键词（方便搜索/推荐）
第二步：确定差异化角度 → 和同类作品区分开来
第三步：确定表达形式 → 口语化/文艺化/冲击力
第四步：检查类型信息 → 读者3秒内知道类型
第五步：检查情感信息 → 标题传递情绪
第六步：检查无障碍 → 无生僻字、无难以理解的表达
```

### 书名包含的信息层
```
类型信息（必须）：玄幻/都市/仙侠/言情…
卖点信息（必须）：金手指/重生/系统/逆袭…
情绪信息（推荐）：爽/燃/甜/虐…
记忆点（推荐）：反差/悬念/趣味…
```

## 标题设计四要素

```
① 关键词 → 包含题材关键词（方便搜索/推荐）
② 悬念/好奇心 → 让读者想点进去看
③ 情绪共鸣 → 标题本身传递情绪
④ 差异化 → 和同类作品区分开来
```

## 起标题五种经典公式

```
① 人物+处境 → 《重生1988：我的便利店通未来》
② 反差/反转 → 《全公司都觉得我是花瓶》
③ 金手指+用途 → 《我的败家系统能买命》
④ 情感关键词 → 《资助她十年她却毁我名声》
⑤ 悬念/问句 → 《她到底是谁？》
```

## 章节名拟定技巧

```
→ 章节名可以透露情节但不能剧透结局
→ 章节名要与内容相符不能做标题党
→ 系列章节名要有统一的格式
→ 章节名≤20字，手机屏幕友好
```

## 标题创作速成公式

```
身份+冲突+反转：
  例：窝囊废父亲的身份 + 女儿被绑架的冲突 + 父亲原来是顶级特工的反转

情绪+悬念+好奇：
  例：她等了他十年的情绪 + 他突然出现却认不出她的悬念 + 为什么认不出的好奇
```
