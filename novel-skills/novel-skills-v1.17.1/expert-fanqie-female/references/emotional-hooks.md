# 女频感情线深度技法

## 追妻火葬场的神经科学

为什么"追妻火葬场"能让人哭？

大脑机制：
- 读者代入女主视角，经历了所有委屈
- 委屈积累 = 催产素被压抑
- 当男主开始追妻时，催产素爆发 = 极度的情绪释放
- 这就是为什么"追妻"能让读者又哭又爽

**追妻成功三要素：**
1. 追妻过程要长（至少30章）
2. 女主不能太快原谅（要虐男主）
3. 但女主必须有反应（不然读者会弃）

**追妻火葬场禁忌：**
- ❌ 女主太快原谅（失去爽感）
- ❌ 男主追妻太容易（失去张力）
- ❌ 追妻过程太短（读者情绪还没释放就结束了）

## 追妻火葬场核心结构

女主离开（冲突爆发，全书最压抑部分）→ 男主追悔（情感压抑，全书最虐心部分）→ 女主新生（独立成长，全书最有爽感部分）→ 最终重逢或彻底分开（情感高潮）

**关键要素：**
- 女主要有独立的事业和追求，不能只是等待被救赎的角色
- 男主必须有真实的悔过，不是虚伪的表演

## 情感钩子五层体系

```
第一层：外貌吸引 → "他第一次注意到她的眼睛"
第二层：性格欣赏 → "原来她不是看起来那样柔弱"
第三层：情感依赖 → "没有她在身边，他第一次觉得不安"
第四层：灵魂共鸣 → "只有她能理解他说不出口的话"
第五层：命运绑定 → "他们注定要在一起，但命运不许"
```

## 每章情感推进公式

```
情感值变化 = 本章情感事件 × 角色反应深度

有效情感事件（+1~3）：
  → 肢体接触（不经意的触碰、牵手、拥抱）
  → 专属对待（他对别人冷淡，只对她温柔）
  → 醋意场景（看到对方和异性亲近）
  → 秘密分享（说出从未告诉别人的秘密）

无效情感事件（+0或负值）：
  → 平铺直叙的日常（一起吃饭、散步）
  → 没有情感反馈的事件
  → 过度虐心（连续5章以上都在虐）
```

## 番茄女频高追读情感节奏

- 甜3章 → 虐1章 → 甜2章 → 大虐1章 → 暴甜反转
- 每10章必须有一个"高甜名场面"
- 虐的目的是为了让甜更甜，不是为了虐而虐

## CP感制造模板

CP感不是"两个好看的人在一起"，而是"两个人之间的化学反应"。

**CP感三要素：**

① **称呼系统** → 独特的称呼 = 关系的标签
- 他叫她：小东西/笨蛋/名字最后一个字
- 她叫他：全名/先生/某个专属昵称
- 称呼变化 = 关系进展的信号

② **互动模式** → 固定的相处方式 = CP的"人设"
- 斗嘴型：表面吵架实际互相关心
- 默契型：一个眼神就懂对方
- 守护型：一方默默保护另一方
- 互补型：一个冲动一个冷静

③ **名场面制造** → 每个CP都需要几个"封神名场面"
- 雨中等她 / 为她挡刀 / 喝醉告白
- 名场面要反复回忆，形成读者的"情感锚点"

**CP浓度检测：**
- 每5章必须有至少1个双人互动名场面
- 每10章必须有至少1次关系进展（称呼/态度/距离变化）
- 避免连续3章男女主不见面（读者会弃文）
- 副CP的甜度不应超过主CP（避免喧宾夺主）

## 真假千金深层结构

核心情感：身份认同危机
- 不是"谁是真正的千金"，而是"谁才是真正的自己"
- 最终的情感落点是"自我认同"

女主视角的情感层次：
1. 被冒名顶替的愤怒（表层）
2. 对自己价值的怀疑（深层）
3. 找到真正的自己（核心）

结构：建立对立（20%）→ 矛盾激化（30%）→ 真相揭露（50%）→ 各自找到身份认同（100%）

## 甜宠感情递进

甜宠不是一甜到底，而是"递进式甜"：
- 甜1：初识（互相看不惯）
- 甜2：暧昧（欲拒还迎）
- 甜3：确认（正式在一起）
- 甜4：困难（外部压力/误解）
- 甜5：解除误会（更深的甜）
- 甜6：HE/确定结局

每个甜度递进要有具体的事件/场景作为触发点。

## 虐文情绪节奏

虐30%（建立关系）→ 甜20%（确认关系）→ 虐40%（冲突爆发）→ 甜10%（短暂和解）→ 虐30%（高潮）→ HE/BE

虐文成功的关键：
- 虐要有理由（不能为了虐而虐）
- 虐之后要有情感修复（不然读者会弃）
- 最好的虐是"明明可以避免但因为误会"
