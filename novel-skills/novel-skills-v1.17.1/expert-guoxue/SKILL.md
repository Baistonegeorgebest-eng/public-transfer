## 一、2026年平台对国学元素的态度

| 态度 | 平台 | 说明 |
|------|------|------|
| 鼓励+流量扶持 | 番茄/起点 | 国学元素+玄幻/修仙有专项推荐 |
| 禁止 | 全平台 | 封建迷信害人（只能写惩恶扬善） |
| 允许但要转化 | 全平台 | 玄学/命理元素必须"正向转化" |

**正向转化原则**：
- ❌ 写"算命先生说你会死"→ 导向恐怖/迷信
- ✅ 写"算命先生说你命里有贵人"→ 引导主角遇见贵人（正向）

## 二、修仙体系设计（九大境界体系）

### 2.1 标准境界模型（直接可用）

| 境界层级 | 名称 | 特点 | 对应战力 |
|---------|------|------|---------|
| 第1层 | 炼气期 | 入门，感知灵气 | 可感知普通人 |
| 第2层 | 筑基期 | 稳固根基 | 可对普通人展示 |
| 第3层 | 金丹期 | 凝丹成功 | 一人敌一城 |
| 第4层 | 元婴期 | 神识初成 | 可对抗小型宗门 |
| 第5层 | 化神期 | 神识大成 | 可对抗中型宗门 |
| 第6层 | 炼虚期 | 炼化虚无 | 可对抗大型宗门 |
| 第7层 | 大乘期 | 即将飞升 | 修真界顶端存在 |
| 第8层 | 渡劫期 | 渡天劫 | 每渡一次天劫 |
| 第9层 | 飞升（大乘圆满） | 进入仙界 | 故事终点或新开始 |

### 2.2 每境界三层次设计

```
每个境界 = 初/中/后期
例：炼气初期 → 炼气中期 → 炼气后期
→ 每个层次差距用"年"来衡量（10年/50年/100年）
→ 防止战力崩坏：跨小境界 = 10年积累差距
→ 跨大境界 = 百年积累差距
```

### 2.3 修仙体系避坑

- ❌ 境界名太多（超过9个大境界）→ 读者记不住
- ❌ 境界之间没有明确的战力差距 → 战力崩坏
- ❌ 主角升级太快（3章一个境界）→ 建议每个境界至少10章铺垫
- ❌ 用现代词汇命名境界（"青铜/白银/黄金"）→ 玄幻/仙侠用传统命名

### 2.4 经脉觉醒与境界对应

```
炼气期 → 感应任督二脉（基础灵力通道）
筑基期 → 打通十二正经（稳固根基）
金丹期 → 贯通奇经八脉（丹田凝聚）
元婴期 → 神识经脉觉醒（意识外放）
化神期 → 全身经脉通达（神识大成）
渡劫期 → 经脉逆转化仙（天劫洗髓）
```

## 三、金木水火土五行设计

### 3.1 五行相生相克（直接可用的设定表）

```
相生：木生火 → 火生土 → 土生金 → 金生水 → 水生木
相克：木克土 → 土克水 → 水克火 → 火克金 → 金克木

战斗应用：
→ 金属性功法克木属性（用金剑破木盾）
→ 火属性功法克金属性（用火烧金）
→ 水属性功法克火属性（用水灭火）
```

### 3.2 五行体质设计

| 体质 | 优势 | 劣势 | 适配功法 |
|------|------|------|---------|
| 金体质 | 攻伐最强 | 防御弱 | 剑道/刀法 |
| 木体质 | 恢复最强 | 攻伐弱 | 医术/丹药 |
| 水体质 | 变化最强 | 无明显长处 | 身法/幻术 |
| 火体质 | 爆发最强 | 持续性弱 | 雷法/炎术 |
| 土体质 | 防御最强 | 速度慢 | 护体/阵法 |

### 3.3 五行应用场景

```
炼丹：需要火候（心火）+ 材料（木属）+ 水液（水属）
炼器：需要金火（金）+ 炉火（火）
布阵：需要五行方位对应材料
风水：阴宅/阳宅选址与五行调和
```

### 3.4 五行在武器中的体现

```
金兵器：锋利主攻（剑、刀、戟）
木兵器：柔韧主生（棍、鞭、藤）
水兵器：绵密主守（绸、扇、伞）
火兵器：爆发主烈（锤、斧、锏）
土兵器：厚重主稳（盾、鼎、碑）
```

## 四、中医经络与修炼体系融合

### 4.1 十二正经体系

```
手三阴：肺经、心经、心包经
手三阳：大肠经、小肠经、三焦经
足三阳：胃经、膀胱经、胆经
足三阴：脾经、肝经、肾经

修炼应用：
→ 打通任督二脉 = 突破关键节点
→ 每条经脉 = 一个技能/功法槽位
→ 经脉通达程度 = 修炼资质高低
```

### 4.2 穴位设定

```
丹田：储存灵气，核心位置
气海：辅助储存，突破时扩充
百会：神识汇聚，头部穴位
涌泉：接地气，修炼根基

战斗应用：
→ 点穴封经脉 = 定身/限制对方能力
→ 破穴伤元气 = 重创对手
→ 护穴保命 = 关键时刻救主角
```

### 4.3 经络与修炼的关系

```
通脉 = 突破
阻塞 = 瓶颈
打通 = 升级
任脉主阴，督脉主阳，冲脉为血海，带脉约束诸脉

节气与修炼：
春分木气旺 → 适合修炼木属性功法
夏至火气旺 → 适合修炼火属性功法
秋分金气旺 → 适合修炼金属性功法
冬至水气旺 → 适合修炼水属性功法
```

## 五、八卦易学融入修炼体系

### 5.1 八卦基础对应表

| 卦象 | 方位 | 自然物 | 性情 | 对应修炼属性 |
|------|------|--------|------|------------|
| 乾 ☰ | 西北 | 天 | 刚健 | 金属性/剑道/至刚 |
| 坤 ☷ | 西南 | 地 | 柔顺 | 土属性/阵法/至柔 |
| 震 ☳ | 东 | 雷 | 震动 | 雷法/速度 |
| 巽 ☴ | 东南 | 风 | 入道 | 风法/身法/隐匿 |
| 坎 ☵ | 北 | 水 | 陷落 | 水属性/冰法/智谋 |
| 离 ☲ | 南 | 火 | 光明 | 火属性/炎术/丹道 |
| 艮 ☶ | 东北 | 山 | 停止 | 土属性/防御/封印 |
| 兑 ☱ | 西 | 泽 | 喜悦 | 幻术/音律/诱惑 |

### 5.2 八卦融入修炼的三种技法

**技法一：卦象决定修炼资质**
```
乾卦体质：天生剑胚，适合剑修
坤卦体质：厚德载物，适合阵法、炼器
坎卦体质：智谋深沉，适合符箓、幻术
离卦体质：天生火灵，适合丹道、炎术
```

**技法二：六十四卦演算法**
```
两卦相叠 = 新的修炼状态
例：乾上坤下 = 天地否卦 → 困顿之相，修炼停滞
→ 可以设计"修炼遇到坎卦境界"需要破解卦象才能突破
```

**技法三：占卜道具融入剧情**
```
道具：蓍草（古法）、铜钱（三枚占卦）
效果：可预知吉凶，为主角提供线索
限制：每三日只能占一卦，否则折损寿元
→ 占卜结果模糊→ 给读者悬念，又不剥夺主角能动性
```

### 5.3 八卦应用模板

**模板一：天赋测试型（玄幻开篇常用）**
```
场景：宗门天赋测试 → 测试碑显示乾卦 → 众人误判 → 主角实际兼修多卦
→ 公式：测卦象（铺垫）→ 众人误判（冲突）→ 真相揭露（爽点）
```

**模板二：修炼瓶颈型（中期突破）**
```
场景：修炼遇瓶颈 → 占卜"遇坎则脱" → 主动进入险地 → 获得传承突破
→ 公式：占卜指引（悬念）→ 主动涉险（行动）→ 脱困突破（爽点）
```

**模板三：敌我预测型（智斗环节）**
```
场景：大战前夜 → 占卜"今晚子时东南有变" → 提前埋伏反杀
→ 公式：卦象线索（信息差）→ 提前布局（智谋）→ 反杀成功（爽点）
```

**模板四：宝物卦象型（寻宝情节）**
```
线索：蓍草占卜"西南有泽，兑象临门" → 发现湖泊古修士遗址 → 获得泽属性宝物
→ 公式：卦象线索（引导）→ 解读+行动（探索）→ 宝物到手（收获）
```

## 七、古风场景描写指南

### 7.1 古风场景元素词库

```
建筑：飞檐翘角、白墙黛瓦、回廊幽深、亭台楼阁
服饰：广袖流仙裙、束腰博带、簪缨世家
器物：青铜鼎、白玉杯、檀木扇、骨瓷盏
自然：烟雨江南、大漠孤烟、雪山之巅、云海翻涌
颜色：月白、鸦青、胭脂红、松石绿、藕荷
声音：夜雨打芭蕉、雪落寒窗、风过竹林、泉水叮咚
气味：沉水香、瑞脑香、墨香、书卷气
```

### 7.2 场景描写三层次

```
宏观场景（社会背景）：
  → 时代特征：盛世/乱世/末法时代
  → 社会结构：贵族/平民/修士

中观场景（宗门家族）：
  → 宗门氛围：严谨/松散/邪恶
  → 标志性场景：山门/大殿/禁地

微观场景（个人）：
  → 居室布置反映身份和性格
  → 随身物品 = 法器/丹药/功法
```

### 7.3 古风场景避坑

- ❌ 现代词汇混入："很帅"、"太牛了"、"666"
- ✅ 用古风词替代（风姿绰约、气度不凡）
- ❌ 大段景物描写超过200字
- ✅ 景物描写不超过3句，只选最有代表性的意象
- ❌ 用西方奇幻设定套东方题材
- ✅ 东方用东方名词，不用"魔法"用"术法/神通"

## 八、命名规则

### 8.1 人物命名

```
东方玄幻/仙侠：单名+姓氏，或复姓+单名
→ 典型：萧炎、林动、叶凡、苏铭、独孤败天
→ 避免：英文名、音译名混入

反派命名：要有角色气质
→ 邪魅反派：夜无常、魔刹、邪羽
→ 阴险反派：白子画（外表正派实则反派）
→ 憨厚反派：赵铁柱、张大彪

女主命名：要有记忆点和美感
→ 避免：男性化太强的名字
→ 推荐：白月光、林诗音、柳如烟
```

### 8.2 神兵命名四要素

```
五行属性：属金=白/西/锐，属木=青/东/生
方位来源：东皇太一/西王母/南极仙翁
材质：玄铁/青钢/紫电
形态：轩辕剑/盘古斧/女娲石

组合公式：[五行]+[方位]+[材质]+[形态]
→ 示例：西方玄铁·锐金剑 = 属金+西方+玄铁+剑形
```

### 8.3 宗门/帮派命名

```
命名公式：[方位/元素]+[意象]+[门派类型]
→ 青云门（青云+门）
→ 玄冥谷（玄冥+谷）
→ 天机阁（天机+阁）
→ 缥缈宗（缥缈+宗）
```

## 九、历史典故融入技法

### 9.1 三步法

**第一步：确定剧情核心**
```
复仇 → 勾践卧薪尝胆/伍子胥过昭关
智谋 → 空城计/田忌赛马
忠诚 → 苏武牧羊/岳飞精忠报国
牺牲 → 女娲补天/大禹治水
```

**第二步：选择典故形态**
```
直接引用：让角色直接说出典故（简洁有力）
间接暗合：不点名但情节完全对应（更高级）
反向颠覆：用典故的反面（推陈出新）
```

**第三步：融入方式**
```
对话植入：角色口述典故
旁白点题：叙事者直接提及
情节对应：情节走向与典故一致
名字暗合：角色名字取自典故
```

### 9.2 典故应用模板

**卧薪尝胆型（复仇线）**：家族灭门→隐忍蛰伏→积蓄力量→手刃仇人

**空城计型（智斗线）**：实力不足→敌人兵临城下→奇谋惑敌→援军赶到/另有后手

**师门恩怨型（修仙常用）**：师兄弟反目→争夺掌门/秘籍→背叛陷害→归来复仇

**背水一战型（绝境翻盘）**：被逼绝境→烧掉退路→绝境激发潜能→反杀成功

## 十、阴阳学说与天文历法

### 10.1 阴阳在修炼中的运用

```
阳主发散，阴主收敛
修炼时阳气上升阴气下降形成周天
阴阳平衡是修炼的根本
阴阳失调会导致修炼出问题（心魔/走火入魔）
```

### 10.2 古代天文与修炼

```
二十八星宿 → 对应人体二十八个穴道
修炼时感应星宿可以加速突破
节气与修炼节奏：
→ 春分木气旺 → 木属性功法事半功倍
→ 夏至火气旺 → 火属性功法事半功倍
→ 秋分金气旺 → 金属性功法事半功倍
→ 冬至水气旺 → 水属性功法事半功倍
```

### 10.3 古代历法与称谓

```
干支纪年：增加历史感
二十四节气：可设计为特殊日期（机遇日/劫难日）

古代称谓体系：
→ 平民：郎君/娘子/相公/官人
→ 贵族：公子/小姐/老爷/夫人
→ 官员：大人/老爷/宰相/尚书
→ 皇室：陛下/殿下/太子/公主
```

## 十三、质量检查清单

- [ ] 境界设定不超过9个大境界，每境3层次
- [ ] 五行相生相克有明确逻辑
- [ ] 战力差距用"年"衡量，无战力崩坏
- [ ] 国学元素正向转化（惩恶扬善）
- [ ] 无现代词汇混入古风场景
- [ ] 命名符合东方调性，无西方奇幻名词
- [ ] 场景描写不超过3句/次
- [ ] 神话谱系有基本自洽性
- [ ] 八卦/典故融入为剧情服务（不是掉书袋）
- [ ] 典故使用不超过3个/章（不过度堆砌）
- [ ] 每种设定有明确的能力边界和代价
- [ ] 诗词风格与情境匹配
