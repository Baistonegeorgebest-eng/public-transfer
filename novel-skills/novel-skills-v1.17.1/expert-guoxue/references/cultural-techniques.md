## 1. 历史考据法

国学/历史题材的核心竞争力是"文化质感"。历史考据不是"查百科"，而是"理解历史逻辑"。

### 三层考据深度模型

```
第一层：表层考据（必须做到）
  → 服饰、饮食、建筑、礼仪的基本准确
  → 朝代背景的大事件和著名人物
  → 称呼和官职的基本规范
  → 工具：百度百科 + 历史类纪录片

第二层：制度考据（提升质感）
  → 科举制度/官制/兵制/税制
  → 婚丧嫁娶的礼仪流程
  → 城市布局和日常生活细节
  → 工具：《中国历代政治得失》/学术论文

第三层：思想考据（高级质感）
  → 儒释道三家的核心思想差异
  → 特定时代的主流价值观
  → 古人的思维方式和表达习惯
  → 工具：经典原著 + 学术专著
```

### 考据避坑指南

- 不要穿越式表达：古人不会说"加油""OK""我觉得emmm"
- 不要现代价值观硬套：古代的忠孝观/婚姻观/阶级观与现代不同
- 不要过度考据影响叙事：考据是工具不是目的
- 模糊处理不确定的细节："大约/似乎/据传"比编造好

## 2. 文化植入公式

好的文化植入应该是"读者不觉得在学知识，但读完之后确实学到了"。

### 文化植入四层级

```
第一级：道具植入（最简单）
  → 角色使用的物品有文化内涵
  → 例：用"青花瓷"盛药 → 暗示角色身份
  → 例：佩戴"玉佩" → 暗示家族传承
  → 例：使用"狼毫笔" → 暗示书法功底

第二级：场景植入（中等）
  → 场景描写融入文化元素
  → 例：写茶馆 → 融入茶道文化
  → 例：写科举 → 融入八股文/考场规则
  → 例：写节日 → 荣入民俗活动

第三级：情节植入（高级）
  → 文化元素驱动剧情发展
  → 例：通过"对联"考验才学 → 推动科举线
  → 例：通过"五行相克"破阵 → 推动冒险线
  → 例：通过"诗词"传情 → 推动感情线

第四级：思想植入（最高级）
  → 故事主题反映传统哲学
  → 例：因果轮回 → 佛家思想
  → 例：无为而治 → 道家思想
  → 例：知行合一 → 王阳明心学
```

### 文化植入度自测

- 读者能否通过小说学到至少3个传统文化知识点？
- 文化元素是否与情节自然融合（而非强行插入）？
- 古代元素的使用是否有考据依据？
- 是否避免了"现代人穿古装"的违和感？

## 3. 古今融合技法

古今融合题材的核心挑战是"让现代读者代入古代设定"。解决方案是"用现代情感共鸣连接古代文化框架"。

### 三模式

```
模式A：现代人穿古代（穿越流）
  → 优势：读者代入感强
  → 挑战：避免"现代优越感"
  → 技法：主角的现代知识只在特定领域有效
  → 核心：主角在适应古代的过程中成长

模式B：古代人穿现代（反穿越）
  → 优势：天然反差萌，喜剧效果好
  → 挑战：不能让古代人太"土"
  → 技法：古代人的"格格不适"制造笑点和感动
  → 核心：古代精神在现代社会中的价值

模式C：古代背景+现代内核（架空古代）
  → 优势：自由度最高，不必严格考据
  → 挑战：容易"不伦不类"
  → 技法：取古代的"形"（服饰/礼仪/称谓），用现代的"神"（价值观/情感）
  → 核心：让读者感觉"虽然是古代但很亲切"
```

### 避坑清单

- ❌ 穿越者用现代管理知识轻松管理古代国家
- ❌ 古代人开口就蹦英文/网络用语
- ❌ 用现代民主思想直接否定古代制度
- ✅ 穿越者的现代知识有适用范围和局限性
- ✅ 古代人的思维方式有其内在逻辑
- ✅ 古今碰撞产生的是"化学反应"而非"单方面碾压"

### 自检清单

- [ ] 历史背景是否经过至少"表层考据"？
- [ ] 角色对话是否符合古代表达习惯？
- [ ] 文化元素是否自然融入情节（非强行插入）？
- [ ] 是否至少植入了3个有深度的传统文化知识点？
- [ ] 古今融合模式是否清晰（穿越/反穿越/架空）？
- [ ] 故事主题是否反映了某种传统哲学思想？
