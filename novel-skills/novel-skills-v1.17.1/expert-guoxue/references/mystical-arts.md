## 1. 符箓设计

### 1.1 五行符箓系

```
金符：破甲符（破防）、金剑符（攻击）
木符：疗伤符（恢复）、缠根符（困敌）
水符：寒冰符（减速/冰冻）、水盾符（防御）
火符：烈焰符（攻击）、灼伤符（持续伤害）
土符：厚土符（防御）、地裂符（范围攻击）

组合符箓（高级）：
→ 水火济济符（阴阳平衡，威力倍增）
→ 五行归元符（五行合一，究极一击）
```

### 1.2 八卦符箓系

```
乾符：刚猛无匹，克制阴邪
坤符：厚重如山，擅长防守
震符：雷霆之威，速度最快
巽符：来去如风，善于隐匿
坎符：以柔克刚，深不可测
离符：光明正大，克制鬼魅
艮符：不动如山，封印第一
兑符：悦纳百川，迷惑心智

八卦合用：
→ 乾坤二符合用 = 天地锁（最强困敌）
→ 坎离二符合用 = 水火济（最高攻击）
```

### 1.3 血符/禁符（高风险高收益）

```
设定：燃烧寿元/精血/灵魂换取符箓威力
效果：威力是普通符箓的10倍以上
代价：使用后虚弱/折寿/被反噬
场景：主角濒死时的最后反击、绝境翻盘

典型用法：
"他咬破舌尖，一口精血喷在符纸上。"
"符纸燃烧，化作一道金光——"
"这一击，足以毁天灭地。"
"代价是，他的寿元，缩短了十年。"
```

## 2. 法阵设计

### 2.1 基础困敌阵（五行材料）

```
名称：五行锁灵阵
材料：金剑五把/木桩五根/水盆五个/火把五支/土块五块
方位：按五行方位摆放
阵眼：一块下品灵石（激活核心）
效果：困住阵内敌人，无法逃脱
破解：破坏阵眼/找到阵门/以力破力
```

### 2.2 八卦迷踪阵

```
名称：八门金锁阵
来源：奇门遁甲
八个门：休/生/伤/杜/景/死/惊/开
生门：安全，可逃出
死门：致命，绝不可入
景门：幻象，容易迷路

剧情用法：
→ 主角被困于"景门"，看到幻象（考验心智）
→ 主角识破幻象，找到"生门"逃脱
→ 或者主角引敌人入"死门"，不战而胜
```

### 2.3 攻防一体阵（宗门战）

```
名称：护山大阵
类型：宗门防御阵法
等级：决定能抵挡什么级别的攻击
维护：需要专人定期注入灵力
弱点：阵眼位置，一旦被发现就危险

典型用法：
宗门被攻 → 大阵启动 → 敌人久攻不下
转折：敌人找到阵眼 → 大阵被破
反转：主角早有预料，在阵眼处设伏
```

## 3. 丹药设计

### 3.1 九品丹药体系

```
下品丹药（白色光晕）：普通人可用，效果微弱
中品丹药（绿色光晕）：炼气期适用，效果稳定
上品丹药（蓝色光晕）：筑基期适用，效果显著
极品丹药（紫色光晕）：金丹期适用，可遇不可求
神品丹药（金色光晕）：只有传说中存在

每个品阶有"丹毒"：
→ 服用同一丹药超过3颗，丹毒积累，副作用出现
→ 需要"解丹毒"的丹药或方法
```

### 3.2 丹药功能分类

```
突破类：破境丹（帮助突破境界，成功率提升50%）
治疗类：回春丹（恢复伤势）、续命丹（吊命不死）
辅助类：聚灵丹（加速修炼）、悟道丹（提升悟性）
攻击类：爆灵丹（短时间提升战力，但有后遗症）
解毒类：清心丹（解除心魔/幻术）、百解丹（通用解毒）

组合丹药（高级）：
→ 阴阳和合丹（男女双修必备）
→ 九转还魂丹（复活一次，但有巨大代价）
→ 天道悟心丹（让主角瞬间领悟功法）
```

### 3.3 炼药师等级

```
丹徒：能炼制下品丹药
丹师：能炼制中品丹药
大丹师：能炼制上品丹药
丹宗：能炼制极品丹药
丹圣：能炼制神品丹药（整个大陆不超过3个）
丹神：传说中存在，从未有人见过

主角如果是炼丹师：
→ 开篇：给配角/反派炼丹，换取资源（建立地位）
→ 中期：自创丹方（体现主角天才）
→ 后期：炼制神品丹药（终极爽点）
```

### 3.4 丹方来源

```
传承：师父临终传授
古迹：上古遗迹中获得
创造：主角自创（天才炼丹师专属）
抢夺：杀人夺宝，顺带获得丹方
```
