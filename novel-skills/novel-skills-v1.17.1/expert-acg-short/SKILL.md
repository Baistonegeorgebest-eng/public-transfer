# 二次元同人短故事专家（番茄短故事专项）

> 利用原著粉丝的情感基础，用短篇幅完成一个完整的情感闭环。每章独立成行，结尾必须有温暖/反转型设计。

## 快速参考

### 基础参数

| 指标 | 推荐值 |
|------|--------|
| 总字数 | 1.2万~2万字（理想值1.5万字） |
| 章节数 | 12~18章 |
| 每章字数 | 800~1200字 |
| 对话占比 | ≥50% |
| 每段字数 | ≤4行（适配手机阅读） |
| 更新节奏 | 一次性完结或日更2~3章 |

### 爆款公式速查

| IP | 公式 | 核心 |
|----|------|------|
| 鬼灭 | 200字穿越+金手指+改变一个角色命运+温暖结局 | 让读者"被治愈" |
| 咒术 | 200字穿越+介入主线+角色说出原著没说出口的话 | "如果当时有人理解你" |
| 跨界喜剧 | 穿越媒介+现代常识破解难题+跨界道具打boss | 世界观碰撞 |
| 规则怪谈 | 建立世界规则→角色遵守→解谜→反转 | 智力爽感 |
| 改命治愈 | 穿越到悲剧节点+信息差介入+改变配角命运+温暖结局 | "这个角色值得被拯救" |

## 五大安全赛道速查

```
① 改命治愈 → 改变原著悲剧结局（最高人气）
② 甜向日常 → 原著角色的日常生活（轻松治愈）
③ 规则怪谈 → 原著世界观+怪谈元素（新赛道）
④ 跨界喜剧 → 两个作品联动（JoJo梗/玩梗）
⑤ 回忆补完 → 填补原著空白/前传/后传
```

→ 详见 [references/five-tracks.md](references/five-tracks.md)（五大赛道详解+标准结构+写作要点）

## 开篇速查

### 禁忌开篇
- 重新介绍世界观（读者已经知道了）
- 大段原创背景铺垫（读者来看的是原著角色）
- 主角前世描述（直接进入原著世界）
- 超过300字没有出现原著角色或原著元素

### 推荐开篇

| 方式 | 适用赛道 | 示例 |
|------|---------|------|
| 原著名场面再现 | 改命治愈 | 「炼狱杏寿郎的刀断了。——这一次，有人挡在了他前面。」 |
| 角色日常切入 | 甜向日常 | 「灶门祢豆子醒来时，发现哥哥不在身边。门外传来练习水之呼吸的声音。」 |
| 悬念开场 | 规则怪谈 | 「虎杖悠仁发现走廊尽头多了一扇门。门上贴着纸条："从现在开始，不要回头。"」 |
| 反差开场 | 跨界喜剧 | 「五条悟看着眼前这个光头。对方蹲在地上捡超市打折的白菜。」 |
| 倒叙开场 | 回忆补完 | 「宇智波鼬看着佐助的背影。他的眼睛模糊了——因为他想起了十二岁那年的那个夜晚。」 |

→ 详见 [references/opening-rhythm.md](references/opening-rhythm.md)（开篇公式+15章节奏模板+五种钩子设计）

## 结尾速查

| 类型 | 核心 | 适用 |
|------|------|------|
| 温暖治愈型 | "他/她还活着"就够了 | 改命治愈（推荐） |
| 反转型 | 出乎意料又在情理之中 | 规则怪谈/悬疑 |
| 留白型 | 给读者想象空间 | 回忆补完 |

结尾禁忌：强行大团圆 / 没交代关键角色命运 / 悲剧收尾 / 开放式过多

→ 详见 [references/endings.md](references/endings.md)（三种结尾详解+遗憾型/开放式写法+短篇vs长篇对比）

## 平台适配

### 番茄小说·短故事板块

标题公式：
- 「原著名+角色名+情绪词」（例："鬼灭之刃：让炼狱杏寿郎活下来的那个人"）
- 「如果XX没有发生」（例："如果五条悟没有被封印"）
- 「原著角色的日常」（例："草帽团的船上今天也闹翻了"）

文本格式：
- 每段≤3行
- 对话占比≥50%
- 每章800~1200字
- 章节总数12~18章
- 必须一次性完结或日更2~3章

### 避坑

- 不能抄袭其他同人作品的情节
- 不能出现涉政/涉黄/涉暴内容
- 不能恶意丑化原著角色
- 标题不能欺骗读者（与内容严重不符会影响完读率）

## OOC防控速查（同人短故事适用）

同人短故事中角色少，每个角色必须精准。

```
① 精读原著 → 记录角色的说话方式/行为模式/价值观
② 建立行为矩阵 → 每种情境下角色会怎么做
③ 确定绝对底线 → 角色绝对不会做的事
④ 对话指纹 → 每个角色3-5个语言特征
⑤ 写后自查 → 读一遍检查是否有"这不是他会说的话"
```

## ACG短故事终极检查

- [ ] OOC五步核查通过
- [ ] 每章有情感闭环（温暖/反转）
- [ ] 跨界有化学反应非简单叠加
- [ ] 章节结尾有钩子
- [ ] 300字内出现原著元素
- [ ] 标题含原著名+情绪关键词
- [ ] 对话占比≥50%
