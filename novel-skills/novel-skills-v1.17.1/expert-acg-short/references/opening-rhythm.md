# 短故事开篇公式与节奏模板

## 开篇禁忌

- 重新介绍世界观（读者已经知道了）
- 大段原创背景铺垫（读者来看的是原著角色）
- 主角（穿越者）的前世描述（读者不关心，直接进入原著世界）
- 超过300字没有出现原著角色或原著元素

## 推荐开篇五种方式

### 方式一：原著名场面再现（最高效）
直接重现原著中最让读者意难平的场景，然后在关键时刻做出改变。

示例：
> 「炼狱杏寿郎的刀断了。上弦之三的拳头已经挥到了他面前。——这一次，有人挡在了他前面。」

### 方式二：角色日常切入（甜向首选）
从原著角色的日常生活场景开始，建立温馨基调。

示例：
> 「灶门祢豆子醒来的时候，发现哥哥不在身边。门外传来练习水之呼吸的声音——比昨天更熟练了。」

### 方式三：悬念开场（规则怪谈首选）
直接抛出一个异常事件，制造紧张感。

示例：
> 「虎杖悠仁发现了一件怪事。学校走廊的尽头，多了一扇门。门上贴着一张纸条："从现在开始，不要回头。"」

### 方式四：反差开场（跨界喜剧首选）
用两个世界的反差制造喜剧效果。

示例：
> 「五条悟看着眼前这个光头。对方正蹲在地上捡超市打折的白菜。"你就是传说中一拳解决一切的男人？""嗯。白菜打折，帮我拿两颗。"」

### 方式五：倒叙开场（回忆补完首选）
从角色成年后的某个瞬间开始，倒叙过去。

示例：
> 「宇智波鼬看着佐助的背影消失在走廊尽头。他的眼睛开始模糊了——不是因为万花筒写轮眼的副作用。是因为他想起了十二岁那年的那个夜晚。」

## 标准字数分配

| 指标 | 推荐值 |
|------|--------|
| 总字数 | 1.2万~2万字（理想值1.5万字） |
| 章节数 | 12~18章 |
| 每章字数 | 800~1200字 |
| 对话占比 | ≥50% |
| 每段字数 | ≤4行（适配手机阅读） |

## 章节节奏表（15章模板）

| 章节 | 内容 | 结尾钩子 |
|------|------|---------|
| 第1章 | 原著触发：重现名场面/建立日常 | 改变即将发生 |
| 第2章 | 分歧点：主角做出不同选择 | 蝴蝶效应预告 |
| 第3章 | 小成功：第一次改命/甜向互动 | 更大的挑战在等着 |
| 第4章 | 平静过渡：角色适应新状态 | 异常信号出现 |
| 第5章 | 危机初现：改变命运带来的新问题 | 危机升级 |
| 第6章 | 角色闪光：原著角色的高光时刻 | 更大的考验 |
| 第7章 | 最大考验：面对原著核心悲剧 | 成败在此一举 |
| 第8章 | 关键抉择：角色做出重要决定 | 结果揭晓 |
| 第9章 | 高潮爆发：最大情感爆发点 | 余波 |
| 第10章 | 余波处理：改变带来的后续影响 | 新的开始 |
| 第11章 | 新日常：展示改变后的世界 | 最后一个悬念 |
| 第12章 | 最终悬念：解决最后问题，所有线收束 | 大结局前的宁静 |
| 第13章 | 大结局：完整情感闭环 | 温暖/反转/留白 |

## 章节钩子设计（同人专属）

### 钩子一：原著反转钩
> 「所有人都以为他会像原著一样死去。但他看着手中的日轮刀——刀刃的颜色，变了。」

### 钩子二：CP暧昧钩
> 「她帮他包扎好了伤口。"谢谢。""不用谢。"她转过身去，脸上的红晕他看不到。——但他感觉到了她手指残留的温度。」

### 钩子三：悬念揭示钩
> 「虎杖悠仁打开了那扇门。门后面站着的，是他以为已经死去的人。」

### 钩子四：危机升级钩
> 「灶门炭治郎闻到了鬼的气息。但不对——这个味道，不属于任何一只他认识的鬼。」

### 钩子五：情感爆发钩
> 「宇智波佐助转过身，看着鸣人。"你为什么一直追着我？""因为我们是朋友啊，笨蛋。"佐助的嘴角——很久没有动过的嘴角——微微上扬了。」
