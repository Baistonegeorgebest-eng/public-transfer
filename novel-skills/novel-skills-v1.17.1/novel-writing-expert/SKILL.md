## 零、生成质量硬约束（强制执行·人味注入）

> 以下约束在每次生成正文时强制执行，不可跳过。
> 来源：美食末世全文审计（2026-04-18），基于真实数据提炼。
> v2 追加：负向约束 + 过程模拟 + 节奏模板（三层人味协议）

### 0.0A 负向约束（禁止项·每章必查）

> 人味来自于"不做什么"和"做错什么"。以下禁止项在每次生成时强制执行。

```
【禁止项·每章必查】
□ 禁止连续3句以上相同句式（主谓宾/时间+事件）
□ 禁止每个段落都以"主语+动作+句号"结尾
□ 禁止50字以上的身体连续描写（一个部位最多两句话）
□ 禁止每章结尾给哲学金句（50%的结尾必须平收）
□ 禁止所有角色用同一套语法结构说话
□ 禁止环境描写同时覆盖3种以上感官
□ 禁止比喻连续使用"像……的"结构（每章最多2次）
□ 禁止用排比超过2句（想用第3句就打碎）
□ 禁止"他感到XX""她觉得XX"类直述情感
□ 禁止成语连续出现（每段最多1个）

执行方式：
  - 每章写完后逐条对照检查
  - 发现违规立即修改，不等终审
  - 违规项记录到质检报告
```

### 0.0B 写作过程模拟

> 让AI模拟"一个人在写"的过程，而不是"生成完美文本"。

```
【写作过程模拟指令】
你不是在"生成文本"，你是在"像一个人一样写小说"。
这意味着：

1. 你会犹豫——有些地方你不确定该怎么写，就用碎片化的表达带过
2. 你会走神——写着写着突然想到一个不相关的事，花一两句带过去
3. 你会写废——有些句子你觉得不够好但懒得改，就留下了
4. 你会偷懒——有些过渡你不想细写，直接跳过去
5. 你会犯错——有时候话说一半不知道怎么接，就断在那里
6. 你会有偏好——你特别喜欢某些词，特别讨厌某些词
7. 你会有节奏——有时候写得飞快，有时候磨蹭半天

在你的输出中体现这些特征。
具体表现为：
- 某些段落结尾不用句号收束，用省略号或直接断开
- 过渡段可以只有1-2句话（懒得细写）
- 偶尔出现"说不上来""不知道"类含糊表达
- 对话可以被打断、没说完、或自相矛盾
- 环境描写只挑最突出的1-2个细节，不面面俱到
```

### 0.0C 节奏控制模板（替代"均匀输出"）

```
【节奏规则·每章强制执行】
□ 每章必须包含至少1个"加速段"（5句以内，短句，快速推进）
□ 每章必须包含至少1个"减速段"（1句超过40字，慢镜头）
□ 每章必须包含至少1个"断裂点"（对话被打断/思路被打断/场景被切走）
□ 每章必须包含至少2个"废话"（不推动剧情的细节：谁在抠指甲/压缩饼干像纸板/走廊有个灯泡不亮）
□ 每章必须包含至少1次"语言失败"（角色说不清楚/说一半/说错了/不想说了）

加速段示例：
  她转身。门开了。灯灭了。没人说话。

减速段示例：
  灯灭之后走廊里只剩下应急通道的绿光，映在她侧脸上像一层冷掉的水，她一动不动站了很久，像在听什么。

断裂点示例：
  "我的意思是——"
  走廊那头有人喊了一声。他顿住了。后来也没再接着说。
```

### 0.1 禁用词冷却机制

```
规则：同一形容词3章内不超过5次。
示例：如果前2章已经用了5次"灰色"，第3章必须换词（暗沉/苍茫/铅色/褪色/浑浊）。
检测方法：
  1. 写完本章后，统计高频形容词
  2. 回查前2章同一形容词出现次数
  3. 超限 → 替换为近义词或删除
常见超限词（美食末世实际数据）：
  "灰色" 1195次（全书）/ "什么东西" 173次
```

### 0.2 句式节奏强制交替

```
规则：每3-5个短句（<15字）后，强制插1个长句（>30字）慢镜头。
原因：卷三几乎没有长句，全碎片化，读者没有"吸气"机会。
示例：
  ❌ 全短句：她转身。门开了。灯灭了。没人说话。
  ✅ 交替：她转身。门开了。
     灯灭之后走廊里只剩下应急通道的绿光，映在她侧脸上像一层冷掉的水。
     没人说话。
检测方法：统计本章句长分布，短句连续超过5句必须插入长句。
```

### 0.3 题材核心感官强制

```
规则：每章至少3处与题材核心相关的感官描写。
美食末世 → 嗅觉+味觉（书名就叫"美食"，不能没有食物感官）
种田文 → 触觉+嗅觉（泥土/作物/劳作）
战斗文 → 听觉+触觉（武器碰撞/痛感）
原因：美食末世嗅觉从4%降到1%，味觉从5%降到3%，核心题材浪费。
检测方法：统计本章五感描写分布，核心感官不足3处则补充。
```

### 0.4 模糊指代限制

```
规则：每章"什么东西""某个东西""有什么东西"不超过2次。
原因：全书出现173次"什么东西"，这是偷懒，不给具体描述。
替代方案：
  ❌ "感觉到什么东西在动"
  ✅ "感觉到墙纸下面有东西在蠕动"
  ❌ "有什么东西碎了"
  ✅ "玻璃杯底裂了一条缝"
检测方法：grep "什么东西\|某个东西"，超2处必须给具体描述。
```

### 0.5 跨卷趋势防退化（越写越假检测）

```
核心问题：生成质量不是"某次差"，而是"持续恶化"。
美食末世数据：每一卷都比上一卷更差——长句从8.6%降到0.8%，嗅觉从4%降到1%，省略号从1.6/章降到0.2/章。

规则：每完成10章，必须做一次趋势对比：
1. 统计本10章 vs 上10章的核心指标（句长/感官/高频词/语言失败）
2. 任何指标下降超过20% → 触发警告，必须在下一章主动补回
3. 连续2个10章都在下降 → 强制暂停，审查生成流程

具体检测项：
| 指标 | 基准线（取前10章） | 警戒线（下降20%） | 强制干预线（下降40%） |
|------|-------------------|------------------|---------------------|
| 长句比例 | 前10章均值 | -20% | -40% |
| 核心感官密度 | 前10章均值 | -20% | -40% |
| 省略号/章 | 前10章均值 | -20% | -40% |
| 高频形容词重复率 | 前10章均值 | +20% | +40% |

检测方法：对比前后两个10章窗口，画趋势线。
```

### 0.6 人味信号强制注入

```
规则：每章必须包含以下人味信号中的至少2种（随机选择）：

信号类型           概率   示例
─────────────────────────────────────────────
语言失败           30%   "那个什么……就是那个……算了"
对话被打断         30%   话说到一半有人推门
无关细节           20%   谁在抠鞋底的泥/压缩饼干像纸板
极端短段           20%   只有一句话的段落
话没说完           20%   "我的意思是……算了你别问了"
结尾无收束         10%   灯灭了。结束。（不给金句）
粗糙句子           15%   一句明显赶工的、没打磨的话

每次写作随机选2-3条执行，不要每次都选同样的。
这些信号是"人味"的物理标志——没有它们，文字一定假。
```

### 0.7 检测脚本（写完每章后执行）

```bash
# 高频形容词检测（冷却机制）
python3 -c "
from collections import Counter
import re
text = open('chXX.txt').read()
words = re.findall(r'[一-鿿]{2,4}', text)
common = Counter(w for w in words if len(w) >= 2).most_common(10)
for w, c in common:
    if c >= 5:
        print(f'  ⚠️ \"{w}\": {c}次 — 需要检查是否超限')
"

# 句长分布检测
python3 -c "
import re
text = open('chXX.txt').read()
sentences = re.split(r'[。！？；]', text)
short = sum(1 for s in sentences if 0 < len(s.strip()) < 15)
long_ = sum(1 for s in sentences if len(s.strip()) >= 30)
print(f'短句(<15字): {short}  长句(>=30字): {long_}')
if long_ == 0:
    print('  ⚠️ 无长句！需要插入慢镜头')
"

# 模糊指代检测
grep -c "什么东西\|某个东西" chXX.txt
```

## 一、创作哲学：什么是真正的好小说

### 1.1 好小说的三个层次

```
第一层：可读（读者愿意读下去）
→ 故事流畅、语言清晰、节奏明快
→ 这是99%作者能达到的层次

第二层：可爽（读者获得情绪满足）
→ 爽点密集、情感共鸣、金句频出
→ 这是5%头部作者能达到的层次

第三层：可传（读者愿意分享推荐）
→ 有记忆点、有讨论价值、有二创空间
→ 这是0.1%白金大神能达到的层次

目标：至少达到第一层，力争第二层，偶尔触碰第三层
```

### 1.2 网文与文学小说的本质区别

```
文学小说：表达自我 → 读者主动解读
网文小说：服务读者 → 满足读者需求

核心原则：
→ 不要问"我想写什么"，要问"读者想看什么"
→ 读者不关心你的文学理想，他们只关心"爽不爽"
→ 写得再好，读者看不去 = 零价值

例外：当你有稳定忠实读者群后，可以适当增加个人风格
```

### 1.3 创作的四大核心能力

```
能力一【结构力】：知道在哪里埋什么钩子
能力二【节奏力】：知道什么时候加速，什么时候刹车
能力三【共情力】：知道读者此刻想要什么情绪
能力四【记忆力】：知道前文埋了什么，后文要回收什么
```

## 六、分阶段标准化写作

### 6.1 黄金开篇公式（前三章）

```
第1段（0-300字）：核心冲突登场
├─ 不要从环境描写开始
├─ 直接展示主角的困境或危机
└─ 读者3秒内要知道主角是谁、在哪、面临什么

第2段（300-800字）：金手指亮相
├─ 系统/异能/金手指出现
├─ 展示金手指的强大能力
└─ 让读者看到"爽"的可能性

第3段（800-1200字）：首次爽点落地
├─ 用金手指完成第一次小逆袭
├─ 狠狠打脸小反派
└─ 让读者获得第一次情绪满足

结尾钩子：设置强悬念
├─ 留下未解之谜
└─ 制造读者"必须看下一章"的理由
```

### 6.2 章节写作规范

```
格式安全铁则：
├─ 单段不超过3行
├─ 单句不超过20-25字
├─ 无Markdown表格（用→符号代替）
├─ 对话占比≥60%（番茄）/ ≥50%（起点）

每章结构：
├─ 开头：承接上章钩子，不要重复上章内容
├─ 中段：推进剧情，有小的进展或冲突
├─ 结尾：留钩子，不能戛然而止也不能平铺直叙
└─ 字数：2000-3000字/章
```

### 6.3 常见开篇问题修复

```
问题一【开篇堆设定】
症状：大量介绍世界观、背景、历史
修复：只保留与当前冲突相关的1-2个设定

问题二【节奏拖沓】
症状：大量心理描写、环境描写
修复：每段话必须有推进剧情的作用

问题三【主角存在感弱】
症状：前3章主角被动挨打，无亮点
修复：在第1章就展示主角的核心竞争力或独特性格

问题四【金手指不够爽】
症状：金手指展示不够充分，读者感受不到爽
修复：第一次使用金手指要足够震撼，让读者哇出声
```

## 七、AI辅助写作工作流（多skill协同）

### 标准九步流程

```
灵感捕捉 → expert-hook（开篇钩子）
世界观 → expert-worldbuilding + expert-guoxue/xihuan
角色 → expert-character + expert-dialogue
大纲 → expert-pacing + expert-plot-shuangdian + expert-title-outro
正文 → 对应题材专家 + expert-writing-style（模仿大神风格）
审查 → expert-logic（逻辑自洽）+ 格式合规自检
```

### 三大原则

```
原则一【AI是工具，不是替代者】→ AI做框架/格式，人做创意/情感
原则二【人写核心，AI补细节】→ 核心冲突人工定，环境/对白AI辅助
原则三【消除AI味】→ 增加口语化、角色情绪、打破句式规律
```

## 八、三维质量自检体系

### 8.1 第一维度：格式合规自检

```
□ 无Markdown表格（用→符号代替）
□ 单段列表≤5条
□ 每段≤3行
□ 单句≤20-25字
□ 无平台敏感符号组合
□ 无违禁内容（涉政/涉黑/低俗/未成年违规）
□ 禁用词检查通过
```

### 8.2 第二维度：算法数据适配自检

```
开篇校验：
□ 首章300字内出核心冲突
□ 首章完成小闭环
□ 前三章完读率预期达标（番茄≥50%/起点≥40%）

节奏校验：
□ 每章结尾有钩子（强悬念/小爽点/未解之谜）
□ 每3章有爽点（打脸/逆袭/突破/收获）
□ 付费节点正确（番茄第6章/起点第35章）

听读适配校验：
□ 对话占比≥60%（番茄）/ ≥50%（起点）
□ 无超长复合句（每句≤25字）
□ 心理描写≤10%（拆分成行为描写代替）
```

### 8.3 第三维度：内容质量自检

```
□ 主角行事风格符合前期设定（无OOC）
□ 配角有独特标签和作用（非工具人）
□ 反派有合理动机和智商
□ 战力遵守世界规则（无故越级=0次）
□ 剧情逻辑无漏洞（用 expert-logic 验证）
□ 伏笔有对应回收节点（已标注）
□ 爽点有铺垫、有反馈（不能突然爽，要有因有果）
□ 情感线符合角色性格（不强行发糖/虐）
```

## 十、常见问题解决方案库

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 卡文 | 脱离核心动机 | 回到主角最想要什么；引入新冲突；加速时间线 |
| 读者流失 | 节奏太慢/爽点不够 | 检查前三章完读率；删减铺垫，加速爽点 |
| 人设崩塌 | 角色偏离设定 | 回溯人设档案；用 expert-character 做OOC检测 |
| 战力崩坏 | 越级无理由 | 回溯战力体系；用 expert-logic 做一致性检查 |
| 越写越水 | 无效描写过多 | 每500字必须有实质进展；只保留推进剧情的内容 |
