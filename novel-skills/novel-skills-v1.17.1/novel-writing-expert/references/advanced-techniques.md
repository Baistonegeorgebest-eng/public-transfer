## 多题材融合公式

当代网文趋势是"跨题材融合"成为爆款常见路径。题材融合不是简单堆砌，而是找到两个题材之间的化学反应点。

### 三种融合模式

```
模式一：主次融合（一个为主，一个为辅）
→ 主题材提供核心驱动力和世界观
→ 辅题材提供差异化卖点
→ 例：修仙（主）+ 经营（辅）= 开宗立派流
→ 比例：主题材70%，辅题材30%

模式二：双核心融合（两个题材平分秋色）
→ 两种题材各有独立的故事线，在关键时刻交汇
→ 例：都市 + 玄幻 = 都市异能
→ 比例：各50%，交替推进

模式三：颠覆式融合（用A题材解构B题材）
→ 用一个题材的逻辑去解读另一个题材
→ 例：用经济学分析修仙世界的资源分配
→ 核心卖点："新颖的角度"
```

### 融合避坑指南

- ❌ 什么都加一点（"修仙+都市+言情+科幻+末日"=四不像）
- ❌ 辅题材喧宾夺主（言情文突然变成硬科幻）
- ❌ 两个题材的世界观矛盾（修仙世界出现手机）
- ✅ 融合后有1+1>2的效果
- ✅ 每个题材元素都有存在的理由

## 风格统一性检查

长篇写作最隐蔽的问题是"风格漂移"——写着写着，文风从冷峻变成搞笑又变成煽情。

### 三维度检查

```
维度一：语言风格
→ 叙述语言的正式程度（文言/白话/口语）
→ 对话的语言风格（古风/现代/方言）
→ 比喻和修辞的使用频率和风格
→ 检查方法：随机抽取第10章、第50章、第100章对比

维度二：叙事节奏
→ 场景描写的详细程度（细笔/粗笔）
→ 对话与叙述的比例
→ 章节长度的一致性
→ 检查方法：统计每章字数和对话占比

维度三：情感基调
→ 整体基调（轻松/沉重/紧张/温馨）
→ 幽默使用的频率和方式
→ 暴力/情感描写的尺度
→ 检查方法：每10章做一个情感标签
```

### 维护技巧

```
技巧一：建立风格指南
→ 开写前写一份1页的"风格指南"
→ 包含：语言风格/叙述视角/情感基调/禁止使用的表达

技巧二：定稿锚点
→ 把第1章的定稿作为"风格锚点"
→ 每写完10章，与锚点对比

技巧三：朗读检查
→ 把章节朗读出来（或用TTS播放）
→ 耳朵比眼睛更容易发现风格不一致
```

## 长篇架构自检

百万字长篇需要定期进行"架构自检"——检查故事是否偏离初始规划。

### 六步自检法

```
步骤一：主线检查 → 故事主线是否清晰？最近20章是否偏离？
步骤二：节奏检查 → 最近20章节奏如何？是否有"塌陷段"（连续3章无冲突）？
步骤三：角色检查 → 主角成长是否清晰？配角是否"活的"？是否有"工具人"？
步骤四：伏笔检查 → 已埋伏笔是否有回收计划？是否有"忘记的伏笔"？
步骤五：数据检查 → 追读率趋势？哪章完读率最高/最低？读者评论问题？
步骤六：心态检查 → 作者自己对故事是否满意？是否需要调整大纲？
```

### 自检频率

| 频率 | 范围 | 时间 |
|------|------|------|
| 每10章 | 快速自检（步骤一+二） | 15分钟 |
| 每30章 | 中度自检（步骤一~四） | 1小时 |
| 每50章 | 全面自检（六步全执行） | 半天 |
| 数据异常时 | 立即自检 | — |
