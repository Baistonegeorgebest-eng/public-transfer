## 一、故事的本质

```
故事 = 角色 + 冲突 + 变化

角色：读者关心的人
冲突：角色想要但难以得到的东西
变化：角色因为追求目标而发生的内在改变

三者缺一不可：
  有角色无冲突 = 人物传记（无聊）
  有冲突无角色 = 事件报道（冷漠）
  有变化无冲突 = 总结报告（空洞）
```

## 二、读者心理的三层需求

```
表层需求（娱乐）：
  → 爽/甜/燃/搞笑/刺激
  → "我想看主角打脸反派"

中层需求（情感）：
  → 共鸣/感动/被理解/被认可
  → "我想看主角经历和我一样的困境然后走出来"

深层需求（意义）：
  → 思考/启发/世界观扩展
  → "我想通过这个故事理解人性/世界/自己"

好的故事同时满足三层：
  表层爽感抓住读者 → 中层情感留住读者 → 深层意义让读者回味
```

## 三、写作的永恒法则

```
法则一：展示而非告知（Show, Don't Tell）
  ❌ "他很生气"
  ✅ "他的拳头攥紧了，指节发白"

法则二：每个场景必须有冲突
  ❌ "他们吃了晚饭，聊了聊天"
  ✅ "晚饭时，他终于鼓起勇气说出了那句话"

法则三：结尾必须比开头更有力量
  开头：让读者想知道"然后呢"
  结尾：让读者觉得"值得"

法则四：删掉一切不推动剧情的内容
  如果删掉一段话，故事不变 → 删掉它

法则五：人物必须有缺点
  完美的角色 = 无趣的角色
  缺点 = 冲突的来源 = 角色成长的空间
```

## 好小说的三个层次

```
第一层：可读（读者愿意读下去）→ 99%作者能达到
第二层：可爽（读者获得情绪满足）→ 5%头部作者
第三层：可传（读者愿意分享推荐）→ 0.1%白金大神
```

## 网文与文学小说的本质区别

```
文学小说：表达自我 → 读者主动解读
网文小说：服务读者 → 满足读者需求
核心：不要问"我想写什么"，要问"读者想看什么"
```

## 创作的四大核心能力

```
【结构力】知道在哪里埋什么钩子
【节奏力】知道什么时候加速，什么时候刹车
【共情力】知道读者此刻想要什么情绪
【记忆力】知道前文埋了什么，后文要回收什么
```
