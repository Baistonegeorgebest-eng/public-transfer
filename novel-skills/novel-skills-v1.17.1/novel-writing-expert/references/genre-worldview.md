## 赛道选择四维度评估

| 维度 | 关键问题 |
|------|---------|
| 平台适配度 | 番茄=快节奏高爽点；起点=长篇深度世界观；晋江=感情线文笔 |
| 竞争激烈度 | 红海赛道（战神/赘婿）需极致差异化；蓝海赛道更容易出头 |
| 变现能力 | 番茄=广告分成+全勤；起点=订阅+打赏；晋江=订阅制 |
| 个人擅长度 | 你最擅长什么？看过最多同类？能持续输出吗？ |

## 世界观构建三原则

```
原则一【剧情优先于设定】
→ 先想剧情需要什么，再设计什么设定
→ 不要为设定而设定

原则二【开篇只展示20%】
→ 第一章只展示读者当前需要的设定
→ 剩余80%随着剧情推进逐步揭示

原则三【设定即冲突】
→ 每个设定都要能引发冲突
→ 没有冲突的设定是无效设定
```

## 三层世界框架速建法

```
底层：地理+物理规则
├─ 世界有多大？（一国/一界/多元宇宙）
├─ 主要的能量体系是什么？（灵气/斗气/魔力）
├─ 力量上限是多少？（主角能达到什么境界）

中层：社会+政治规则
├─ 势力分布（3-5个主要势力）
├─ 社会等级结构
├─ 资源分配规则

顶层：信仰+哲学规则
├─ 这个世界的核心价值观是什么？
├─ 什么是绝对禁忌？
└─ 世界的终极秘密是什么？
```

## 差异化世界观四步法

```
第一步：找一个原型参考
→ 《凡人修仙传》的等级体系 / 《诡秘之主》的职业系统

第二步：找到一个独特切入点
→ 与原型的差异化在哪？
→ 例："稳健流"修仙（别人冒险我苟住）

第三步：设计1-3条独特规则
→ 例：灵气随季节流动 → 宗门随灵气迁徙

第四步：规则衍生社会结构
→ 独特规则 → 独特社会现象 → 这就是你的故事背景
```
