## 主线剧情大纲

### 四步法

```
第一步：写出核心主线（一句话）
→ 主角是谁？→ 经历了什么？→ 最终得到什么？
→ 例：废物赘婿被退婚后激活系统，一路打脸逆袭成为首富

第二步：规划核心转折点（3个）
→ 第一个转折：开篇困境（第1-3章）
→ 第二个转折：中期高潮（第10-15章）
→ 第三个转折：最终结局（第18-20章）

第三步：设置爽点密度
→ 每3章一个小爽点
→ 每10章一个中等爽点
→ 每20章一个大爽点

第四步：埋设伏笔并标注回收节点
→ 伏笔：主角佩戴的神秘玉佩（第3章埋）
→ 回收：玉佩是上古传承（第15章揭）
```

## 平台节奏大纲

### 番茄短故事节奏（18章）

```
第1-3章：开篇锁流（冲突+金手指+首次爽点）
第4-15章：稳定追读（每章钩子+每3章爽点）
第16-18章：收官爆发（回收伏笔+终极爽点）
```

### 起点长篇节奏（50-100章）

```
第1-10章：开篇锁流（3章留存率≥40%）
第11-35章：上架前积累（追读率维护）
第35章：上架爆发（付费节点）
第36-100章：稳定订阅（每20章大爽点）
```

## 2026年AI工具链与前沿趋势

2026年AI辅助写作渗透率超40%，但核心创意/人物塑造/情节设计仍需人工把控。

### 主要工具

| 工具 | 强项 | 适用场景 |
|------|------|---------|
| 笔灵AI | 网文风格 | 起稿/润色 |
| DeepSeek | 逻辑推理 | 检查战力体系 |
| Kimi | 长文本分析 | 拆爆款 |

### 防崩核心机制
- 每5万字生成摘要防止AI遗忘
- 战力追踪表每10万字检查一次
- 伏笔表每50万字全面审查
- 版本管理每5万字备份一次

### 多专家协同创作标准流程

```
需求输入 → 记忆加载(expert-memory) → 世界观构建(worldbuilding)
→ 角色建立(character) → 大纲规划(pacing+plot-shuangdian)
→ 正文输出(题材专家) → 质量审查(logic) → 标题优化(title-outro)
→ 最终输出(格式合规终检)
```

### AI辅助三大原则
1. **AI是工具**：做灵感激发、框架设计、格式检查
2. **人写核心**：核心创意、情感表达、风格把控人工定
3. **消除AI味**：增加口语化、角色情绪、打破句式规律
