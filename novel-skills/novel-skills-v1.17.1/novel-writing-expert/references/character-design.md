## 主角设计铁三角

### 铁三角一：身份标签（一眼记住）
- 一句话描述主角
- 例："身患绝症的便利店老板" / "被退婚的废物赘婿"

### 铁三角二：核心动机（推动剧情）
- 主角一定要追求什么？
- 动机越强烈，剧情越紧凑
- 例：活下去 / 复仇 / 逆天改命 / 守护家人

### 铁三角三：性格优缺点（制造冲突）
- 优点 = 爽点来源
- 缺点 = 冲突来源
- 例：极度稳健 → 优点=布局完美，缺点=错过机会

## 反派设计四要素

### 要素一：合理动机
- 反派不是无脑坏，他有自己的逻辑
- 好动机：利益冲突/立场对立/误解
- 坏动机：无脑欺负主角

### 要素二：智商在线
- 反派至少和主角一样聪明
- 主角赢要赢得艰难，反派输要输得有价值

### 要素三：强大实力
- 反派越强，主角反杀越爽
- 每个大反派对应一个主角成长阶段

### 要素四：独特个性
- 给反派一个让人记住的特点
- 例：永远优雅的反派 / 说话带毒舌的反派

## 配角设计规范

### 核心配角（≤5人）

| 类型 | 作用 |
|------|------|
| 导师型 | 给主角提供信息和成长 |
| 伙伴型 | 陪伴主角，分担压力 |
| 对手型 | 与主角良性竞争 |
| 情感型 | 提供情感共鸣 |
| 工具型 | 推动特定剧情 |

### 设计原则
- 每个配角必须有独特作用（不能是工具人）
- 每个配角必须有独特标签（一句话能说清楚）
- 配角人设必须前后一致（不能随时变卦）
