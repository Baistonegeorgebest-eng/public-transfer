## 二、神机的题材漂移

神机是少数在2013-2015年期间从传统修仙/武侠转向科幻的头部作者。这不是一个普通的选择——因为大多数和他同级的作者（辰东、西红柿、猫腻）没有做过同类型的"题材跳跃"。

```
神机: 修仙(06) → 国术(08) → 气运(09) → 永生(10) → 修真(12) → 科幻(13)
西红柿: 现代→古代→未来→现代（不换本质）
辰东: 修行→修行→修行→修行（全在修行宇宙内）
土豆: 斗气→元力→元力→元力（全在模板内）
```

神机的"题材跳跃"就是他作为作者的签名：不断在**不同的"世界规则"中测试同一个问题——"什么力量是最强的？"**
