## 二、核心发现

### 2.1 血红完整进化线（7本确认）

```
偷天(398万) → 邪龙道(381万) → 逆龙道(171万) → 光明纪元(717万) → 开天录(450万) → [升龙道] → [三界血歌]

感叹：2.80 → 3.96 → 4.81 → 5.63 → 1.73 → 0.02 → 1.83
省略：0.34 → 0.80 → 1.43 → 0.55 → 4.66 → 4.42 → 0.38
均句：41 → 41 → 37 → 40 → 33 → 40 → 38
```

**关键发现：**
1. **逆龙道是血红的"问号之王"** — 问号6.0/千字，全场血红作品最高。结合升龙道6.91/千字的数据，血红的"权力对话"技法需要大量问句来驱动。
2. **逆龙道的段均107字** — 血红段落最长的作品。比光明纪元(78)、邪龙道(74)、偷天(85)都长。说明逆龙道是血红最"慢节奏"的叙事——一段像一篇小散文。
3. **光明纪元是血红感叹密度的峰值** — 5.63/千字，但省略仅0.55。这是血红最"外放"的阶段：情绪靠感叹释放，不用省略留白。
4. **开天录是血红的"转身点"** — 感叹从5.63骤降到1.73，省略从0.55飙到4.66。血红在这里从"感叹外放"转向"省略内收"。
5. **升龙道是最终形态** — 感叹0.02+省略4.42，完全内收。

**修正后的进化路径：**
```
血红不是线性进化，是有回弹的：

早期(偷天)：感叹中等(2.80)，省略极低(0.34)，逗号中等(51.8)
  → 还在找自己的标点节奏

中期(邪龙道→逆龙道→光明纪元)：感叹持续走高(3.96→4.81→5.63)
  → 热叙述阶段，情绪外放

转折点(开天录)：感叹骤降(1.73)，省略飙高(4.66)
  → 发现"留白比爆发更有力"

成熟期(升龙道→三界血歌)：感叹归零(0.02)或极低(1.83)
  → 完全转向省略号留白+逗号串长句

→ 核心转变：从"用感叹号释放情绪"到"用省略号让读者自己感受情绪"
```

```
原甜点区间定义：感叹1-5，省略1-5，均句35-55字
修正后：
  - 感叹1-5区间包含了两种完全不同类型的作品：
    a. 克制型（感叹1-3）：更俗·大荒蛮神(1.28)、开天录(1.73)、大奉打更人(1.70)、偷天(2.80)
    b. 中等型（感叹3-5）：暗影神座(5.11)、太阳王之证(4.98)、逆龙道(4.81)、暴风法神(4.69)
  - 感叹3-4/千字可能是网文成熟期的自然平衡点依然成立
  - 但更精确的甜点区间应根据题材细分
```
