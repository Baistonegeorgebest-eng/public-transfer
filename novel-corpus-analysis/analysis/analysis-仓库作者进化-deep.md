## ⚠️ 重要修正

本分析原将带着仓库到大明、明天下、明末边军一小兵归为同一作者。经三轮交叉核验：
- **带着仓库到大明 + 明天下** → **迪巴拉爵士**（2本）
- **明末边军一小兵** → **老白牛**（独立作者）

"感叹断崖式收敛80%"的叙事应修正为：**两位不同作者的风格差异**，非同一作者的进化。迪巴拉爵士的2本确实有感叹下降（8.33→2.25），但仅2本不足以构建完整进化线。下方保留原始数据供参考。

## 二、核心发现

### 1. 感叹：断崖式收敛

```
带着仓库(8.33) → 明天下(2.25，-73%) → 明末边军(1.70，-80%)
```

**感叹从8.33降到1.70，总降幅80%。** 第一本到第二本之间是断崖——73%的降幅仅用一部作品就完成。

- 带着仓库(8.33)：热血穿越文，情绪外放
- 明天下(2.25)：**突然切换到冷笔**——这可能是作者意识到自己的感叹过度
- 明末边军(1.70)：稳定在冷笔区间

### 2. 逗号：明末边军是异常值

明末边军的逗号79.0/千，比前两本(59)高出34%。这是该作者唯一一部"逗号流"作品。

结合题材分析：明末边军是最"写实"的历史文——军事题材需要大量战术描写和对话，这些场景天然需要更多逗号来组织信息。

### 3. 段均：持续增长

```
带着仓库(33.0) → 明天下(40.5) → 明末边军(56.1)
```

段均从33增长到56，增幅70%。**段落越来越长**——作者在成熟期更倾向于长段落叙事。

### 4. 短句率：急剧下降

```
带着仓库(12.1%) → 明天下(6.4%) → 明末边军(3.4%)
```

短句率从12.1%降到3.4%——**明末边军几乎不用短句**（3.4%意味着全书100句话里只有3句是10字以内的）。这在全库中属于极端长句流。

### 5. 长句率：飞跃式增长

```
带着仓库(36.3%) → 明天下(55.4%) → 明末边军(65.3%)
```

长30%从36%增长到65%——**明末边军有65%的句子超过30字**。这是全库前10%的水平。

## 三、严肃度推断

- 带着仓库：3-4（穿越爽文，情绪外放）
- 明天下：6（突然收敛，风格转变）
- 明末边军：7-8（冷笔写实，严肃历史叙事）

**这位作者的严肃度跨越是全库最大的之一**——从3跳到7，仅用了两部作品。

这是全库中"成熟"速度最快的案例之一——仅用两部作品就从热血穿越文(感叹8.33)跳到了严肃历史小说(感叹1.70+逗号79+长句65%)。
