### 1. 三部都是冷笔长句流

三部作品感叹全部低于1.71，属于"极致克制"区间。烽火的标点指纹和猫腻高度相似：
- 猫腻感叹范围：0.84-1.52
- 烽火感叹范围：0.23-1.71

两人都是"几乎不用感叹号"的文笔派。

### 2. 句号递增

```
陈二狗(12.8) → 雪中(14.9) → 剑来(20.7)
```

句号从12.8升到20.7（+62%），和滚开的句号递增方向一致但幅度小得多。

### 3. 均句递减

```

```

均句从68.1降到38.7（-43%）。烽火的句子越来越短。

**这和猫腻的U型曲线不同：** 猫腻的均句是先升后降（间客50.1是高峰），而烽火是单调递减。

### 4. 陈二狗是烽火的标点指纹极值

陈二狗的感叹0.23（全场前5低）+均句68.1（全场前10长）+句号12.8（全场后10%）——这是烽火最极端的标点指纹。

陈二狗是烽火的都市文，篇幅也最短（112万字）。短篇幅+都市题材可能让他更"放得开"写长句。
