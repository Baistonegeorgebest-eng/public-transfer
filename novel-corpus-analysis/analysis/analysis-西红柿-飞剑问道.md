## 二、开局：归来的剑客

**Ch1「归来」**（无单章长度数据）：

> "江州，天下十九州之一，临近东海，境内多湖泊。江州境内，广凌郡城。……'六年了。'一位布衣青年腰间挂着一柄剑，牵着马行走在街道上，'终于回来了……'"

飞剑问道的开局是最"干净"的西红柿开局：
```
主角的设定：
  不是被忽视 → 已经成熟（六年后归来）
  不是被升级 → 已经有剑
  不是被灭族 → 有家乡可归
```

这是"归来的剑客"母题——一种中国武侠中最经典的开局。秦云已经离开家乡六年——他回来不是为了"升级"，而是**因为有未完的事**。
