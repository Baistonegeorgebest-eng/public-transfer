### 6.76感叹号 — 乌贼为什么突然"喊"了？

这个数值是乌贼平均的2-3倍。解释在于题材：**现代武道社**。在"大学武道社"这个语境下：
- 训练 → 要有喝彩
- 比赛 → 要有尖叫
- 青年恋爱的对话 → 激动

这不代表"写得差了"——这是**场景匹配的语义需要**。

## 二、开局：秋老虎下的武道社

**Ch1「少年壮志不言愁」**：

> "秋老虎威风凛凛，依旧巡视着人间，下午三点的阳光炽白而酷烈，晒在厚重黑沉的巨大场馆外表……'松城大学武道社！'"

武道宗师的开局和乌贼所有其他作品都不同：**没有异世、没有剃度、没有附身**——只有一个大学生走向武道社时"近乡情怯"的心情。

```
乌贼的开局光谱:
  奥术: 穿越→科学→异世
  一世: 醒来→和尚→身份剥夺
  诡秘: 枪伤→附身→存在恐慌
  武道: 秋老虎→武道社→普通大学生 ← 最"现实"的乌贼
```

这是乌贼在长年写"异世"之后的一次**"地面化"尝试**。楼成不是一个"理解者"（路西恩/克莱恩）——他是**一个"行动者"**。

## 三、在乌贼进化中的位置

```
一世之尊(2015)  →  武道宗师(2017)  →  诡秘之主(2018)
身份剥夺            日常回归           恐惧普遍
30.4%对话           31.2%对话          33.3%对话
└─ 哲学(我是谁) ─→  └─ 人际(我们在一起) ─→  └─ 恐惧(我不能理解)
```

武道宗师是架在"身份"和"恐惧"之间的**"人际"**——它把乌贼的关注从"我自己的存在"扩展到了"我与他人的关系"。这在诡秘中进化为"我不能告诉别人我的秘密"。
