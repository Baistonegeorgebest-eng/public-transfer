## 二、开局：14岁的平静

**Ch1「我改主意了」**（无单章长度数据）：

> "'那少年是个什么样的人？''很沉稳，坐了半个时辰，姿势都没变过……像是谨慎，更像是心思深刻，戒备心很强，甚至隐有敌意。''多大了？''十四岁。'"

择天记的开局是所有猫腻作品中最"内收"的——通过**两个旁观者的对话**来介绍主角。陈长生甚至没有亲自出场——他只是被**谈论**的。

```
猫腻开局策略:
  庆余年: 双声道（现代+古代）—直接
  间客:   "我很悲愤！" —直接
  将夜:   "小酒馆" —从侧面
  择天记: "那少年是什么样的人？" —从旁观者 ← 最"远"的镜头
  大道朝天: "四大从来都遍满" —从诗词
```

这种"三次折射"（读者→旁观者→主角的缺席→后来出现的主角）创造了猫腻独特的**延宕效应**——让"少年"这个形象在读者心中长出了足够的期待。

---

## 三、在猫腻进化中的位置

择天记是猫腻从"复仇"到"逆天"的过渡。陈长生的命运比所有猫腻之前的角色都更重——**"他只能活二十岁"**。这不是范闲的"我双穿"、不是许乐的"我父亲是司令"——这是**"我出生就注定要早死"**。

```
猫腻主角的"重量":
  范闲: 双声道 → 轻（有些余度）
  许乐: 从底层来 → 中
  宁缺: 复仇者 → 重
  陈长生: 寿命倒计时 → 最重
```
