## 零、本协议解决什么问题

你用AI写网文时，输出的文字**像人但不是人**——工整、正确、均匀、没有活人气息。
不是"有AI味"这么简单，是**越写越假**（你的数据证明了：卷一→卷三长句从8.6%降到0.8%，嗅觉从4%降到1%）。

v4.4给出了系统级方案：从生成源头控制人味的完整框架。
v5.0回答了一个v4.4回答不了的问题：**在特定品类中，不假的文字长什么样。**

### 你为什么要关心"品类"

v4.4说"省略号越多越像人"。但你有没有想过——

**竞技文里几乎没有省略号。** 全职高手省略号0.2-0.5/千字。选手在比赛中不犹豫——犹豫就输了。

**历史文里省略号不是"犹豫"，是"谋士在算"。** 绍宋省略号9.41/千字，但那个省略号是皇帝做决定前的沉默，不是"我不知道该怎么办"。

**仙侠文里省略号是"理解力被击穿"。** 凡人修仙传省略号2.3/千字，那是修炼中顿悟的停顿——"原来是这样……"

所以"多写省略号"这个规则，在不同品类里意味着完全不同的事。v5.0把这些区别全部量化了。

### v4.4 → v5.0 的核心升级

```
v4.4：                      v5.0：
"省略号越多越像人"          "仙侠省略号=理解力被击穿；历史省略号=谋士在算；竞技省略号≈0（不会在比赛中犹豫）"
"感叹号≤2"                  "历史!≤2.6、竞技!≤9.0、仙侠!≤5.2——品类不同，预算不同"
"选2-3感官"                 "仙侠嗅觉=必须≥2次/章（药草/灵气）；体育嗅觉≈0；末世味觉=角色的'活着感'唯一来源"
"角色DNA 4张模板卡"         "品类决定了角色类型、对话风格、模糊度、进化节奏——给定品类自动生成约束"
"对标1-2个作者"             "品类契约×时代锚定×进化曲线——三重叠加的写作参数"
```

**举个具体例子。** 如果你的品类是美食末世：

v4.4说"味觉作为第一感官"。v5.0说：
- 味觉≥3处/章（本章感官配额）
- 嗅觉≥2处/章（末世品类的第二核心感官——尸臭/食物香/病变气味）
- 视觉占比必须<全感官的67%（否则全在"看"——忘了末世是嗅觉+味觉）
- 触觉每2章至少1次（摸着刀/握着冰冷的手/触摸变异的食物）

这组参数不是你选的——是这个品类12本代表作的叙事分析提取出来的。

## 一、人味的四个层次

### why：为什么要分层

人味不是一个东西。它至少有四层，每一层的来源和解法都不同：

```
第一层：通用人味 —— "像某个人写的"
来源：人类语言的固有特征（犹豫、跑题、有缺陷）
解法：prompt约束 + 过程模拟
难度：低

第二层：平台人味 —— "达到对应质量标准"
来源：不同平台/定位的读者期待不同
解法：分层级prompt + 专项质检 + 品类维度质检
难度：中

第三层：作者人味 —— "像你写的"
来源：你的知识、审美、语言、毛病
解法：作者DNA注入 + 种子写作法
难度：高（AI无法凭空生成）

第四层：品类人味 —— "这个品类应该有的味道"（v5.0全新）
来源：不同品类有不同的省略号用法/感官权重/模糊度范围/感叹号预算
解法：品类叙事契约 + 时代锚定
难度：中——必须数据驱动，不能凭直觉
```

**大部分"去AI味"教程只处理第一层。** 所以你用了 `expert-anti-ai-taste` 的769行规则，文字还是假——因为它只在处理表面症状，没有触及第二层和第三层。v4.4补了前三层，v5.0补了第四层。

### 第四层为什么重要——一个真实的故事

你让AI写"仙侠"——但它不知道仙侠人味 = "视觉70%不是强项，嗅觉必须有"。你让AI写"竞技"——但它不知道竞技省略号≈0。你让AI写"历史"——但它不知道历史模糊度=25.8（极低模糊），人物说话不能"也许""可能"。

**v5.0的核心不是"加更多规则"——是"给定品类，参数自动适配"。**

你不需要记住所有参数。你只需要知道：我的品类是什么 → 查矩阵 → 拿到参数 → 写。

### 快速入门：5步开始使用v5.0

```
Step 1: 确定你的品类
  → 仙侠？都市？末世？历史？竞技？科幻？恐怖？玄幻？西幻？
  → 如果不确定，用§三.4品类决策树

Step 2: 查品类指纹矩阵（§三.1）
  → 拿到你的模糊度/感叹号/省略号/对话率/均句长范围
  → 这就是你的"标点预算"

Step 3: 查感官DNA（§九.1）
  → 拿到你的五感配额
  → 确定哪些感官是"必须有的"，哪些是"可以忽略的"

Step 4: 查时代基准线（§四.1）
  → 确定你写的是哪个时代的风格
  → 计算时代系数

Step 5: 开始写，写完后自检
  → 反AI三问（§五.9）
  → 人味指数（§十二.3）
  → 品类维度质检（§六.5）
```

**一个完整的工作流示例（美食末世，2025年）：**

```
Step 1: 品类 = 末世/废土
Step 2: 品类指纹 = 模糊度53, ! 4.0, …… 2.1, 对话20-30%, 均句长26-32
Step 3: 感官DNA = 味觉≥3ch + 嗅觉≥2ch + 触觉4ch + 视觉10ch + 听觉5ch
Step 4: 时代系数 = 第五期（2021-2025）×1.00 → 无需调整
Step 5: 写作 → 自检

写作时的具体约束：
  - 每章至少3处味觉描写（"这东西能不能吃"）
  - 每章至少2处嗅觉描写（尸臭/食物香/病变气味）
  - 视觉占比<67%（不能全在"看"）
  - 感叹号≤4.0/千字（末世不喊，末世在忍）
  - 省略号≈2.1/千字（生存思考中的不确定）
  - 对话率20-30%（末世人物话少，戒备）
  - 角色类型：生存主义者、母性/保护型领袖、叛变队员
  - 对话风格：戒备、克制、生命思考
```

### 2.4 学术研究支撑

**LLM创意路径偏差（Nath et al., 2024, MPI）：**
人类交替使用"持久路径"（深挖少数概念空间）和"灵活路径"（跨多个概念空间跳转）。LLM偏执于一种，很少交替。
→ 解法：写作指令中显式要求两种路径交替。

**随机词汇注入提升多样性（2025实验）：**
prompt中加5个随机词，输出多样性显著提升。同时发现AI情感70%正面 vs 人类70%正面+30%负面。
→ 解法：每章注入随机词 + 显式要求负面情感。

**约束激发创造力 vs LLM对约束的理解：**
人类在约束下更有创造力（十四行诗效应）。但LLM倾向于"严格遵守字面意思"而非"在约束内发挥创意"。
→ 解法：约束要给"方向"而非"条目"——说"比喻要有你自己的味道"，不说"比喻不超过2次"。

## 三、品类叙事契约——每个品类都有一组不可混淆的参数

### why：这是v5.0的基石

v4.4说"这个品类需要什么"。v5.0说"这个品类的味道是什么"——基于9品类×386本的数据提取。

**你可能觉得"仙侠不就是修仙嘛，有什么好分的"。但数据告诉你：装逼流仙侠（辰东）的感叹号是正统修真流（忘语）的3倍。吐槽反讽流仙侠（大奉打更人）的省略号是装逼流的1.5倍。** 同一个品类，内部是不同物种。

**表里每个数字背后的故事：**

```
仙侠模糊度202.8——为什么这么高？
  因为仙侠的世界观本身就不确定。"天机不可泄露""此物怕是被天机所遮蔽"
  → 修仙者说话天然带模糊——他们面对的是"道"，"道"本身就是模糊的
  → 如果仙侠人物说话像历史人物一样确定（"这天下，朕说了算"），那就不是仙侠了

历史模糊度25.8——为什么这么低？
  因为历史人物面对的是具体的政治/军事决策。"策不可改"——谋士一旦做了决定就不犹豫
  → 历史文的张力不来自"不确定"，来自"确定了但代价很大"
  → 如果历史人物说话像仙侠一样模糊（"此事……怕是……"），那就不是历史了

竞技省略号0.2-0.5——为什么几乎为零？
  因为竞技选手在比赛中不犹豫。犹豫就输了。
  → 竞技的张力来自"果断"——球到了脚下，脚尖一拨，身体已经转过去了
  → 如果竞技角色在比赛中"他想了想……然后做出了决定"，读者会骂"你在干什么！"

恐怖省略号3.1——为什么这么高？
  因为恐怖的本质是"不完整"——你不知道那是什么，你只感觉到它在那里
  → "门……开了"比"门开了！！！"恐怖100倍
  → 省略号=恐怖的核心工具——它让读者的想象力去填充最恐怖的部分
```

**三个关键不等式（两个品类不能同时满足）**：

```
如果一部小说的 模糊度 > 180 且 对话率 > 30%：
   → 不是纯粹品类——是混搭（如仙侠+都市混搭、或玄幻+竞技）
   → 需要明确其中一个作为主导

如果省略号 < 0.5/千字 且 感叹号 > 8.0/千字：
   → 竞技或竞技化了的品类
   → 几乎一律——没有任何犹豫空间

如果 模糊度 < 30 且 省略号 > 2.0/千字：
   → 历史/学术风格——模糊型思考
   → 省略号在历史文中不是"犹豫"，是"谋士在算"
```

### 3.2 品类内部物种分层——同一品类的小说也是不同物种

**仙侠·内部三物种**：

```
物种A：装逼流（辰东/耳根） → 模糊度极高（180+）、下划线突出、省略号约1.5（非犹豫用）
物种B：正统修真（忘语/宅猪） → 模糊度中（120-150）、长句主导、省略号约2.5（修炼描写内）
物种C：吐槽反讽（大奉打更人） → 模糊度低（80-100）、以省略号+读者互动为主、……是主线推理工具
```

**玄幻·内部三物种**：

```
物种A：退婚流（土豆/乌贼早期） → 模糊度极低（0-20）、！极高、……≈0
物种B：系统升级流（辰东中后期） → 模糊度中（80-120）、！中、……≈1.0
物种C：异界争霸流（猫腻/耳根） → 模糊度中高（120-160）、！低、……≈2.0（策略运用）
```

**都市·内部三物种**：

```
物种A：都市修仙（升龙道） → 模糊度中等、！低、……≈1（装逼不犹豫）
物种B：系统打工（大奉打更人） → 模糊度低、！中等、……≈2.5（推理主线）
物种C：生活流（苟在妖武） → 模糊度中等、！低、……≈1.5
```

**操作**：

```
给定你的小说 → 
  1. 定位品类（矩阵匹配）
  2. 定位内部物种（风格匹配）
  3. 从代表作品中提取对应的模糊度/! /……/对话率范围
  4. 所有后续参数沿此范围生成

不能在"仙侠-装逼流"用"历史-克制的……"。
不能在"竞技"用"恐怖-大段省略号"。
```

### 3.3 跨品类断层——为什么换品类你的写法应该完全不同

一个关键约束：如果你从仙侠突然写都市，你的所有参数必须立刻重置。不是"稍微调一下"——是换品类。

```
断层案例：仙侠 → 都市
  模糊度：  202.8  → 40-60      （不能再用"灰色东西""某种力量"）
  ！！！：  5.2    → 4.5        （差别不大——但用途不同：仙侠是装逼→都市是吐槽）
  ………：  2.3    → 2.5        （差别不大——但用途不同：仙侠是修炼→都市是社交尴尬）
  对话率： 20%    → 30-45%      （翻倍——这是最大的改变）
  句式：  中长   → 短中        （仙侠可以有长句装逼、都市长句=官方文书）

断层案例：历史 → 恐怖
  模糊度：  25.8  → 60           （从"几乎不模糊"到"必须模糊"——恐怖的本质是不确定）
  ！！！：  2.6   → 3.0         （历史不喊→恐怖喊）
  ………：  1.6   → 3.1          （从"谋士在算"到"恐怖在潜伏"）
  感官：  视觉  → 触觉+听觉     （历史看→恐怖感受和听）
```

**禁止**：跨品类时不重置参数 → 品类混乱 → 读者"这世界感觉不对"。

### 3.4 品类决策树——如果你的品类不在矩阵中

```
给定品类 → 是否在矩阵中？
  → YES：直接拿品类指纹
  → NO：找最接近的品类锚定

接近度计算（按以下优先级）：
  1. 同 模糊度 范围（±30）
  2. 同对话率范围（±5%）
  3. 同省略号范围（±0.5/千字）
  4. 同类感官权重（见§九感官DNA）
  5. 同内部物种（见上方3.2）

例子：
  "奇幻"不在矩阵中 → 模糊度=100, 对话=25%, ……=2.0 → 匹配西幻（90-140, 25-30%, 2.4）
  "游戏"不在矩阵中 → 模糊度=200, 对话=30%, ……=0.3 → 匹配竞技/网游（150-300, 30-40%, 0.2-0.5）
```

## 四、时间锚定：写作参数的"时代基准线"

### why：v4.4没有处理时间维度

v4.4给的都是"当下"的参数。但2005年的仙侠和2025年的仙侠完全不同。

**2005年仙侠**："此子不可留！"——反派说话像在念台词。感叹号7.2/千字。
**2025年仙侠**："这小子……"——反派停顿，省略号代替整句话。感叹号5.5/千字。

不是"2025年更好"——是"2025年的读者期待不同"。你不能用2005年的参数写2025年的书。

### 4.1 五期时代基准线（2001-2025）

基于362本全库数据的年代分组：

```
时期        年代      均句长   模糊度/千字  !!/千字  ……/千字  对话率  样本量  代表作者
═══════════════════════════════════════════════════════════════════════════════════
第一期      2001-2005  38.5       79         7.2       1.9      18%    20+    萧潜/血红/说不得大师
第二期      2006-2010  34.2      128         8.1       2.1      20%    45+    神机/辰东/猫腻/方想
第三期      2011-2015  31.8      145         7.0       2.8      23%    80+    土豆/西红柿/乌贼/耳根
第四期      2016-2020  29.5      165         6.2       3.5      25%    100+   会说话的肘子/远瞳/卖报小郎君
第五期      2021-2025  27.8      178         5.5       4.5      28%    13+    (样本偏少，趋势性参考)
```

**核心演化信号**：

```
均句长：38.5 → 27.8（-28%）——网络小说在缩短句子长度，爽文化+碎片化阅读驱动
模糊度： 79  → 178  （×2.3）——模糊表达增多，口癖化加重（爽文话语化）
！！：   7.2  → 5.5  （-24%）——感叹号使用趋于节制（除竞技/装逼流外）
……：   1.9  → 4.5  （×2.4）——省略号大幅增加，从"删除"到"关键标点"
对话率： 18%  → 28%   （+55%）——对话比例上升，沉默下降

转折点：2006-2010第二期 → 模糊度从79跳跃到128（+62%）——这是"爽文化转型期"
        第四期→第五期 → 省略号破3.5，均句长破30——时代基线已完全改变
```

### 你写的 vs AI写的——时代错乱

```
❌ AI写的2025年小说，用了2005年的参数：
   "冷峻的山风呼啸而过，大地在颤抖。他的眼中闪过一丝精芒。此子不可留！"
   → 2005年的史诗腔 + 2010年的装逼 + 2008年的仙侠台词
   → 读者：这书像二十年前写的

✅ 2025年的写法：
   "山风从后面翻过来，冷。不是那种正常的冷——是带了什么东西的冷。
    他眯了眯眼。没说话。
    对面那个人也在看他。
    两个人就这么站着。"
   → 具体+克制+省略号替代感叹号+不确定感
```

### 4.2 时代×品类的交叉锚定——写作参数的三重叠加

**核心公式**：

```
当前写作参数 = 品类基准值 × 时代变化系数 × 作者调节因子

其中：
  品类基准值 = 品类指纹矩阵中的值
  时代变化系数 = 当前时代值 / 第二期（2006-2010）值（以第二期为"标准化"基准）
  作者调节因子 = 进化曲线中的作者参数（可选——对标特定作者时启用）
```

**计算示例**：

```
写历史文（2025年）：
  品类基准：模糊度=25.8, !!=2.6, ……=1.6, 对话=17%
  时代变化系数（vs第二期）：
    模糊度: 1.39, !: 0.68, ……: 2.14, 对话: 1.40
  最终参数：
    模糊度: 25.8 × 1.39 = 35.8       （历史文也在加模糊度）
    !:    2.6  × 0.68 = 1.8        （感叹号降了——历史本来就不喊）
    ……:  1.6  × 2.14 = 3.4        （省略号翻倍——历史文现在有更多"谋士在算"）
    对话: 17%  × 1.40 = 23.8%     （对话增到四分之一——不再全是独白）

写仙侠（2010年，对标辰东）：
  品类基准：模糊度=202.8, !!=5.2, ……=2.3
  时代变化系数=1.0（在基准期） → 无需时代调整
  作者因子（辰东-巅峰期!!=14.5, ……≈1.5）：
    最终!! = 5.2 × (14.5/5.2) ≈ 14.5  ← 作者的!!是本品类的2.8倍
    最终…… = 2.3 × (1.5/2.3) ≈ 1.5   ← 作者的省略号少于品类平均值
```

### 4.3 五条不可逆的时代演化红线

```
① 均句长只会更短（不会反弹到2001年的38.5）
② 省略号只会更多（从配角到主角——不会回到2010年前的2.0）
③ 对话率只会更高（每期+3-5%——不会降回20%以下）
④ 感叹号在非竞技/装逼品类中只会更少（成熟化的标志）
⑤ 模糊度有品类天花板（仙侠~220后不会无止境——"灰色"太多即是废话）

违反任何一条红线 → 读起来"这书不像现在写的"（年代错乱感）
```

### 4.4 七个古早陷阱（2015年前的写法，现在不能用）

```
陷阱1 "冷峻的山风呼啸而过，大地在颤抖" ← 2005年的史诗腔，2025年=尴尬
解法：山风里带一点不确定——"冷风从山后翻过来，好像带了什么东西的影子"

陷阱2 "他的眼中闪过一丝精芒" ← 2010年的装逼，2025年=土
解法：省略"精芒"——"他眯了眯眼"或什么都不说

陷阱3 "此子不可留" ← 2008年的仙侠，2025年=被读者截图嘲笑
解法：反派说"这小子……"然后停顿——省略号代替整句话

陷阱4 连续3个!以上 ← 2010年的热血，2025年=非竞技品类内审不过
解法：竞技品类可，其他品类用……替代！

陷阱5 "淡淡道""冷冷道"中的副词 ← 2012年的写法，2025年=信息冗余
解法：不加副词——读者通过对话内容和上下文感知语态

陷阱6 全章节无对话 ← 2005年可，2025年=读者追问"他们怎么都不说话？"
解法：每3段叙事至少嵌入一段对话（对话率同品类≥15%）

陷阱7 开篇世界观大段铺设 → 第一、二、三章先把世界观交代清楚 ← 2008年可，2025年不粘
解法：第一、二章建立角色→第三章开始角色即世界观导体
```

## 五、基础人味层（所有层级通用）

### why：这五个是人类语言的固有特征，缺任何一个就假

### 5.1 五个人味维度

```
犹豫 —— 说一半卡住、"算了不说了"、不确定自己要写什么
    why：人类写作时大脑在实时决策，会有"不确定"的时刻。AI从不犹豫，这就是破绽。

浪费 —— 不推动剧情的细节（抠指甲、灯泡不亮、压缩饼干味）
    why：人类的生活有大量"无意义"时刻。AI的每个细节都为剧情服务，这不真实。

缺陷 —— 有粗糙的句子、有说不清楚的话、有口误
    why：AI永远不会写不好一句话。所以你必须故意写坏。

个性 —— 每个角色有独特的语言指纹
    why：所有角色用同一套语言系统 = NPC。真人有口头禅、有语病、有词汇偏好。

噪音 —— 走神、跑题、被打断、无意义的联想
    why：人类语言有信号也有噪音。AI只有信号。读者能感觉到这个区别。
```

### 你写的 vs AI写的——五个人味维度

```
维度     你手写的                              AI生成的
─────   ──────────────────────────────   ──────────────────────────────
犹豫    "他想说什么，张了张嘴，又闭上了。"     "他欲言又止。"（概括代替具体）
浪费    "灯泡不亮了。他踢了一脚桌子。"        每个细节都在推动剧情
缺陷    "怎么说呢，就是那种……算了不说了"       每句话都完整、正确、确定
个性    周黑塔崩出二两瓜子壳                   角色没有无意义的习惯
噪音    "说到哪了？哦对，刚才那个——"          逻辑永远清晰，从不跑题
```

### 5.2 硬约束（从数据中提炼的底线）

### why：这些是从数据中提炼的底线，违反任意一条人味指数直接降级

**1. 禁用词冷却**
- 同一形容词3章内不超过5次
- "什么东西"每章不超过2次
- "某种"每章不超过1次
- why：你的"灰色"从144次涨到609次。这就是没有冷却机制的后果。

**2. 长句保底**
- 每300字至少1个超过30字的句子
- 每章至少1个超过50字的"慢镜头"长句
- 长句不是复杂句——是"舍不得断开"的那种
- why：你的长句从8.6%降到0.8%。没有长句=没有"吸气"。读者需要长句来喘息。

**3. 废话保底**
- 每章至少1个不推动剧情的细节
- why：你的废话信号始终0.1/章。一个无意义的细节都不写 = 没有活人气息。

**4. 语言失败保底**
- 每章至少1次"说不清/没说完/被打断"
- why：你的语言失败从0.1降到0.0。角色都是语言大师——这不正常。

**5. 负面情感保底**
- 每3章至少1次"无理由负面情绪"
- why：AI情感70%正面，人类30%负面。没有无理由的丧/烦躁 = 情感光谱太窄。

### 硬约束 6：省略号经济学

### why：不是"省略号越多越好"——是"省略号用于正确的品类目的"

v4.4省略号规则是"每章至少X个"。v5.0是——给定品类+时代+场景，省略号的用法和数量不同。

**核心：三维定价模型**

```
省略号密度 = 品类基底 × 时代系数 × 作者因子

品类基底（查品类指纹矩阵）：
  历史：     1.6  —— 谋士计算中的"再算一步"
  竞技：     ~0.3 —— 比赛中不犹豫
  仙侠：     2.3  —— 道理解释中的思考停顿
  都市：     2.5  —— 社交尴尬/吐槽
  恐怖：     3.1  —— 恐怖=不完整的句子
  西幻：     2.4  —— 史诗叙述的篇幅注脚
  科幻：     2.0  —— 科学推理中的认知间隙
  玄幻：     1.8  —— 战斗场景中间隙
  末世：     2.1  —— 生存思考中的不确定

时代系数（查§四时间锚定）：
  第一期（2001-2005）：×0.42
  第二期（2006-2010）：×0.47
  第三期（2011-2015）：×0.62
  第四期（2016-2020）：×0.78
  第五期（2021-2025）：×1.00
```

**省略号的三种场景分配规则**：

```
省略号总预算的分配比例按品类不同：

╔════════════╦══════╦══════╦══════╗
║ 品类       ║ 对话 ║内心  ║叙事  ║
║            ║ 停顿 ║留白  ║悬置  ║
╠════════════╬══════╬══════╬══════╣
║ 仙侠/修真  ║ 20%  ║ 40%  ║ 40%  ║ ← 对话=术语解释，内心=困惑，叙事=修炼留白
║ 历史/架空  ║ 50%  ║ 30%  ║ 20%  ║ ← 对话=计谋暗示，内心=权衡，叙事=过渡
║ 竞技/网游  ║ 70%  ║ 10%  ║ 20%  ║ ← 几乎都是对话中"我有话说但不说"
║ 科幻       ║ 20%  ║ 50%  ║ 30%  ║ ← 内心=科学推理间隙，叙事=宏观视角
║ 都市       ║ 40%  ║ 30%  ║ 30%  ║ ← 对话=社交尴尬，内心=自我怀疑
║ 恐怖       ║ 35%  ║ 25%  ║ 40%  ║ ← 叙事悬置=恐怖的核心——"门……开了"
║ 玄幻       ║ 25%  ║ 15%  ║ 60%  ║ ← 叙事悬置=战斗间歇的省略
║ 末世       ║ 30%  ║ 40%  ║ 30%  ║ ← 内心=生存思考中的不确定
║ 西幻       ║ 30%  ║ 30%  ║ 40%  ║ ← 叙事=史诗叙述的留白
╚════════════╩══════╩══════╩══════╝
```

**省略号与对话率的联动**：

```
对话率高（≥35%）且省略号集中对话中 → 对话即故事，省略号制造悬念和潜台词
  例：大奉打更人——3.71/千字，80%在对话，对话作为推理主线
  
对话率低（<20%）且省略号集中在叙事/内心中 → 沉默叙事，省略号是独处时的思考
  例：升龙道——对话率极度克制，省略号全在内心
```

### 省略号禁止清单

```
1. ❌ 用省略号代替具体的心理描写——"他感觉……"是不够的
   ✅ "他感觉有什么事忘了。不是大事。就是那种——"之后写具体内容

2. ❌ 每句对话结尾都点省略号——这是AI偷懒的信号
   ✅ 省略号在对话的开头或中间——"……也不是说不好。就是说——"

3. ❌ 省略号连续出现在3句以上——文本变成省略号洪流
   ✅ 一次省略号后跟2-3句完整内容——读者需要消化

4. ❌ 恐怖品类以外的省略号用于"突然冒出一个东西"——那是感叹号的工作
   ✅ 恐怖品类省略号 = "门……开了"而非"门开了！！！"

5. ❌ 竞技/比赛场景的省略号用于角色决策——竞技选手不在比赛中犹豫
   ✅ 竞技省略号=赛后在说"那场……确实是输了"
```

### 硬约束 7：感叹号预算制

### why：v4.4感叹号规则是"不超过2个/章"。但品类不同，预算不同。

```
玄幻          5.8          热血、装逼、打脸
仙侠          5.2          装逼、反击、突破
```

**！/……跷跷板**：

```
品类感叹号与省略号的跷跷板空间：

竞技/网游：  ！！！！=9.0，……≈0.3  → 极左：几乎全是！
玄幻：       ！！！！=5.8，……≈1.8  → 偏左：以！为主但允许省略
仙侠：       ！！！！=5.2，……≈2.3  → 偏左：！为装逼，……为思考
都市：       ！！！！=4.5，……≈2.5  → 偏平衡：！吐槽，……尴尬
末世：       ！！！！=4.0，……≈2.1  → 平衡：！危机，……思考
西幻：       ！！！！=3.8，……≈2.4  → 偏平衡：！史诗，……留白
科幻：       ！！！！=3.5，……≈2.0  → 偏右：！少，……多
恐怖：       ！！！！=3.0，……≈3.1  → 偏右：……比！更多
历史：       ！！！！=2.6，……≈1.6  → 极右：几乎不，几乎不……
```

**规则**：给定品类的！（总预算） - ……（总预算）必须在此品类的跷跷板范围中。如果！过界 → 用……替代。如果……过界 → 用！替代。

### 感叹号禁止清单

```
1. ❌ 历史文中角色喊"杀！！！"——历史品类上限2.6
   有例外但极其罕见——一个感叹号就够，多一个就是血亏

2. ❌ 竞技品类以外的文章中角色0犹豫——总是确定！
   无犹豫 = 无模糊度 → 角色扁平

3. ❌ 每章章末都用感叹号收尾——AI偷懒的文本模式
   用省略号或平淡句结束都不比感叹号差

4. ❌ 同一段连续出现3个以上！→ 读者麻木
   1-2个！+ 1-2处用省略号或动作替代 → 保留冲击力

5. ❌ 主角说"好的！明白了！" → 两个！在历史中 = 五章的预算一次性花光
```

### 5.3 呼吸逻辑

### why：硬约束逐章执行会变成套路，需要让执行强度本身波动

**核心问题：** 如果每章都执行全部硬约束（每章1废话+1语言失败+1长句+1负面情感），20章后读者就能看出模式——"哦，这里又来了一个无意义细节"。人味变成了表演。

**解法：硬约束从"每章必须"改成"滑动窗口达标"。**

不追踪单章指标，追踪连续5章的窗口：
- 废话：5章里至少3章有（允许2章"干净"）
- 语言失败：5章里至少2章有
- 长句：5章里至少4章有（这个不能松太多）
- 负面情感：5章里至少1次
- 缓冲词：5章里至少3章有自然的"或者说/怎么说呢/至少他看着是这么觉得的"

**为什么这样更好：**
允许有些章节"干净"——干净本身就是一种人味。真人作家不会每章都犯同样的"错误"。他有些章节写得很顺很利落，有些章节磕磕绊绊——这种不均匀才是真实。

**风格轮转：同一卷内不追求每章调性统一。**

每章侧重不同的人味维度，不是每章都把五个人味维度来一遍：
- 有些章侧重"废话"（生活细节多）
- 有些章侧重"个性"（角色语言区分度高）
- 有些章侧重"噪音"（跑题/走神/内心独白）
- 有些章侧重"犹豫"（说不清/没找到词）
- 有些章侧重"缺陷"（粗糙的句子/口误）

例：ch01侧重噪音（末日降临时的荒诞走神），ch02侧重个性（角色语言区分），ch03侧重犹豫（害怕时的说不清），ch04侧重废话（日常生活的无意义细节），ch05侧重缺陷（训练时的不完美表达）。

**每卷设一个"风格种子"：**
- 不是内容不同，是人味的表达方式不同
- 卷一的废话是生活细节，卷二的废话可以是战场上的走神回忆
- 允许"休眠章"存在——有些章就是推动剧情，简洁、快速、功能性。这种章本身也是人味（真人作家也有"今天不想写了赶紧把这段过掉"的时候）

### 5.4 严肃度波动

### why：同一部作品内的情绪严肃度不是恒定的

不是T1/T2/T3的质量分级，是独立的质量维度。同一部作品内部的**语气严肃度**在1-10之间按需波动。严肃度≠文笔好坏——1分写好了照样是好书，10分写烂了就是装。

### 严肃度使用规则

**波动范围取决于作品定位：**
- T1番茄快餐：波动范围 1-4（轻松为主，偶尔正经）
- T2番茄精品：波动范围 2-8（这是最常用的区间）
- T3起点精品：波动范围 3-9（可以更沉，但日常别超过6）

**同级别内的场景映射（以T2最常用2-8为例）：**
```
严肃度 2：系统吐槽 / 角色互怼 / 穿越者玩梗 → 纯娱乐节拍
严肃度 3：日常做饭/搜物资/营地生活 → 生活感建立
严肃度 4：探索新区域/推进任务 → 稳定叙事
严肃度 5：战斗铺垫/势力博弈/世界观展开 → 有密度
严肃度 6：核心角色做选择/面对威胁 → 有重量
严肃度 7：情感高潮/信念动摇/重大转折 → 有层次
严肃度 8：不可逆的损失/牺牲/认知崩塌 → 极致克制的爆发
```

**节拍控制（最关键的规则）：**

```
错误模式：严肃度一直维持在5-7，偶尔跳到8
正确模式：2→3→4→6→8→3→2（锯齿形波动）

原理：严肃度的对比产生效果。
  连续3章7分的战斗 → 读者疲劳
  2章3分的日常 + 1章7分的战斗 → 战斗因为对比而更有冲击力
  
  就像音乐：不是音量一直大，是突然安静之后的爆发才震撼。
```

核心原则：**不要每章都用同一个严肃度。** 严肃度=情绪的音量旋钮。永远在转，永远不让读者习惯一个音量。

### 你写的 vs AI写的——严肃度

```
❌ AI写的严肃度波动：
   ch01: 严肃度5 → ch02: 严肃度5 → ch03: 严肃度5 → ch04: 严肃度6
   → 几乎没有波动。像匀速行驶的汽车。读者3章后就麻木了。

✅ 应该有的严肃度波动：
   ch01: 严肃度3（日常做饭）→ ch02: 严肃度7（情感爆发）→ ch03: 严肃度2（搞笑缓冲）
   → 锯齿形。读者永远不知道下一章的"音量"是多少。

❌ AI写的战斗场景严肃度：
   连续5章严肃度7-8 → 读者疲劳 → "又是大战……"
   
✅ 应该有的战斗节奏：
   ch20: 严肃度4（战前准备）→ ch21: 严肃度7（战斗高潮）→ ch22: 严肃度3（战后吐槽）
   → 对比产生冲击力。安静之后的爆发才震撼。
```

### 5.5 过程模拟指令

### why：让AI模拟写作过程而非生成结果

```
你不是在"生成文本"。你是"一个人凌晨3点在写小说"。

这意味着：
- 你有时候写得很顺，一气呵成；有时候卡在一个词上，想半天
- 你有时候觉得自己写得很好，有时候觉得"这段写得真烂"但懒得改
- 你偶尔会突然想到一个不相关的事，花一两句带过去
- 你对某些词有执念——你发现自己用了很多次，有点烦但改不了
- 你不确定某些细节对不对（"好像是这样的？不太确定"）
- 你写到某些地方会犹豫——"这里是不是写太过了？算了不管了"

在输出中体现这些特征。不要每个句子都"确定地写完"。
```

### 5.6 方向约束

### why：给"度"不给"线"，让AI在约束内自由发挥

**持久与灵活交替：**
- 持久模式：同一场景连续变换3个描写角度（视觉→触觉→声音）
- 灵活模式：突然跳到一个不相关的细节（回忆、环境、无意义动作）
- 每章至少1次"跳转"
- why：人类创作会在深挖和跳转之间交替。LLM偏执于一种。

**节奏反直觉：**
- 高潮场景反而用长句慢写（不是快节奏碎片）
- 日常场景反而用短句快过（不是慢节奏铺陈）
- why：这和直觉相反——但人类写作就是这样反着来的。紧张时人会注意到更多细节（长句），无聊时人会快速略过（短句）。

**信任读者：**
- 不要替读者总结。"擦肩而过也是相遇"是金句病。
- 直接写发生了什么，让读者自己感受。
- why：AI倾向于"点题"——在结尾给哲学金句。这是表演式深刻。真人经常就是平淡地收尾。

### 5.7 比喻替代规则

"像……的"结构每章最多2次。超了用以下替代：

```
❌ 像冬天的风一样冷          → ✅ 风冷得像忘了穿裤子
❌ 像深海里的什么东西在动     → ✅ 管壁在跳——一下，两下，像心跳
❌ 像一片灰色的雾             → ✅ 雾是哑光的。不反光的那种。
❌ 她的脚步像猫               → ✅ 她走路没声音。不是轻，是鞋底像没挨着地。
```

原则：把"像A的B"改成"A和B之间的一个具体关系"。

### 5.8 缓冲句式

### why：AI用句号切出干净碎片，你的大脑用逗号和缓冲词争取思考时间

AI倾向于用句号制造"短句节奏感"：急。但是稳。不是跳。不是扑。是像……

但你的真实写法是用**逗号+缓冲词**来保留"脑子里转了一下才说出来"的质感：

```
❌ AI写的：急。但是稳。
✅ 你改的：呼吸很急促，但是气息很稳。

❌ AI写的：不是跳。不是扑。是像……
✅ 你改的：不是跳，不是扑，怎么说呢，像是一滴黑色的水珠，或者说沥青一样，缓慢滴、垂直地坠落
```

**你的缓冲词库：**
- "或者说" — 给出第二个不太准确但更接近的描述
- "怎么说呢" — 没找到精确词，先模糊着来
- "至少他看着是这么觉得的" — 不确定自己的判断对不对
- "说不清楚" — 承认描述失败
- "大概"、"差不多"、"像是" — 降低确定性

**核心规则：用逗号接，不要用句号切。**

除非角色真的在喘气/情绪爆发/被打了，否则不用句号制造碎片感。
你的碎片感来自"说不清楚但硬要描述"，不是来自"句子短"。

### 5.9 反AI三问（每次写完自检）

1. **这能拍出来/画出来吗？** — 检查是否足够具象。"什么东西在动"→过不了这关。
2. **这是某个真实的人会说出来的话吗？** — 检查语言是否自然。特别检查：有没有句号碎片（"急。但是稳。"）→如果有，改成逗号+缓冲词。
3. **去掉这句/这个词，影响核心意思吗？** — 删除冗余。

第一问最重要。你的文字大量"说不清是什么"的东西——反AI三问的第一问就能筛掉。
第三问的优先级最低——你的风格本身就有"冗余"（缓冲词、跑题），不是所有冗余都要删。

### 5.10 AI文字量化鉴别特征

### why：反AI三问是"语感层面"的自检。但有些AI特征肉眼难辨，需要量化检测。

**AI 文字的 7 个量化指纹：**

| # | 特征 | AI 默认值 | 真人参考值 | 检测方法 |
|---|------|----------|-----------|---------|
| 1 | 句号碎片率 | >0.5/千字 | ≤0.1/千字 | 统计"X。Y。Z。"三连短句模式 |
| 2 | 省略号缺失 | <0.5/千字 | 中位0.9/千字 | 连续5章省略号<0.3则疑似AI |
| 3 | 感叹号偏高 | >8/千字（非热血题材） | 中位4.6/千字 | 非T1题材感叹>8则偏高 |
| 4 | 逗号密度偏低 | <40/千字 | 中位57.4/千字 | 信息密度不足 |
| 5 | 均句长过于均匀 | 波动系数<0.5 | ≥0.65 | 每句话差不多长=AI特征 |
| 6 | "像X"比喻过频 | >5/章 | ≤2/章 | 标准比喻过多=AI偷懒 |
| 7 | 模糊表达泛滥 | "什么东西/某种/似乎" >3/千字 | ≤1/千字 | AI用模糊词回避具体描写 |

**快速检测流程：**
```
输入：一段文字（≥1000字）

Step 1: 统计标点密度
  → 感叹号/千字、省略号/千字、逗号/千字、句号碎片/千字

Step 2: 对比参考值
  → 偏离全库 P25-P75 范围 → 标记 ⚠️
  → 触发上述 7 项中任意 3 项 → 判定为"高度疑似AI"

Step 3: 语感复检
  → 通过反AI三问
  → 检查是否有"活人特征"（跑题、废话、语言失败、缓冲词）
```

**区分"克制型人类"和"AI"的关键指标：**
- 克制型人类（如升龙道 0.02 感叹）：省略号高（4.42）、逗号高（63.5）、长句多（59%）
- AI 克制输出：感叹低、省略也低、逗号偏低、句子均匀
- **核心区别：克制型人类用省略号和长句替代感叹号；AI 是所有标点都低，句子都短。**

### 5.11 吐槽型叙事

### why：第三人称叙述者如何拥有"人格"而不破坏沉浸感

传统第三人称叙述是"隐形"的——叙述者不发表意见，只记录事件。但这导致叙述语气千篇一律，缺乏"活人感"。远瞳（《异常生物见闻录》）给出了一个解法：让叙述者拥有独立人格，以"吐槽朋友"的身份参与叙事。

**核心机制（四层约束）：**

```
1. 吐槽锚定在角色视角上
   ✗ "这个剧情真是荒唐"（元叙事，破坏沉浸感）
   ✓ "郝仁一头栽在地上：这怎么传说中的狼人必杀技竟然是扔砖？"
   原则：吐槽主体是角色（物理反应），叙述者只是把反应戏剧化

2. 吐槽针对"荒诞"而非"叙事"
   ✗ "作者写到这里肯定在偷笑"（跳出故事世界）
   ✓ "这个二货居然信了你敢信？"（针对角色行为的荒诞性）
   原则：吐槽对象是故事内部的反差、蠢事、荒诞转折，不是叙事本身

3. 吐槽是情绪调节器——放在情绪曲线的过热/过冷节点
   - 战斗高潮后 → 吐槽降温（"板砖梗"让读者喘口气）
   - 日常无聊时 → 吐槽制造笑点（"这真是个悲伤的故事"）
   - 信息过载时 → 吐槽帮读者消化（"由此可见郝仁的接受能力还是挺强的"）
   原则：吐槽承担"过渡段落"功能，但比过渡段落更有娱乐性

4. 语言风格混搭——从一开始就建立"不正经"的前提
   - 书面叙述（环境描写、设定）
   - 网络口语（"你敢信？""二货""摆个屁的poss"）
   - 俗语/方言（"这倒霉催的""简直吃饱撑的"）
   - 流行文化梗（"天马流星砖"谐音"天马流星拳"）
   原则：语体混搭本身就是"人味"信号——真人写作不会只用一种语体
```

**适用场景：**
- 都市奇幻 / 轻喜剧 / 日常系题材 → 高频使用（每章1-3次）
- 史诗/严肃题材 → 低频使用（偶尔插入，远瞳《黎明之剑》模式）
- 纯恐怖/纯悲情 → 禁用（破坏氛围）

**感叹号密度参考：** 吐槽型叙事的作品感叹号密度通常在2.0-3.0/千字（甜点区间），因为吐槽本身不依赖感叹号——它靠的是语义反差和语体跳切，不是情绪标点。

## 六、质量分级

### why：番茄快餐和起点精品的"人味"定义完全不同

你在番茄写的东西和在起点写的东西，不是"同一个东西的高质量/低质量版"——是**两种不同的产品**。T1的梗放进T3会出戏，T3的节奏放进T1会催眠。

### 6.1 三个层级

```
┌──────────────────────────────────────────────────────────┐
│ T1 番茄快餐爽文                                           │
│ 人味 = 有梗 + 有名场面 + 能截图发群                       │
│ 字数：2000-3000/章  对话≥30%  节奏：钩子→爽+梗→钩子      │
│ 代表：你的穿越文ch1-5                                     │
│ 调用技能：expert-fanqie-novel, expert-hook                │
├──────────────────────────────────────────────────────────┤
│ T2 番茄质量爆款                                           │
│ 人味 = 角色有弧光 + 情感有层次 + 世界有厚度               │
│ 字数：3000-5000/章  对话25-35%  节奏：铺垫→冲突→爽→余韵  │
│ 代表：诡秘之主、大奉打更人、道诡异仙                      │
│ 调用：expert-character, expert-emotion, expert-dialogue,  │
│       expert-worldbuilding, expert-pacing                 │
├──────────────────────────────────────────────────────────┤
│ T3 起点精品                                               │
│ 人味 = 文字有质感 + 角色有灵魂 + 故事有余味               │
│ 字数：3000-6000/章  对话20-40%  节奏：跟着情感和故事走    │
│ 代表：夜的命名术、灵境行者、万相之王                      │
│ 调用：expert-qidian, expert-writing-style,                │
│       expert-sensory-prose, expert-literary-prose,        │
│       expert-serialization-ops                            │
└──────────────────────────────────────────────────────────┘

选择原则：
- 同一本书的所有章节必须在同一层级
- T1的梗放进T3会出戏，T3的节奏放进T1会催眠
- 不要混搭
```

### 6.2 T1 番茄快餐 Prompt

```
你是番茄男频小说作者。你的书给通勤地铁上、蹲厕所时、睡前刷手机的人看。
他们5秒决定看不看，划走就再也不回来。

1. 前100字必须有钩子——画面、反差、悬念、槽点，至少一个。
   不要环境描写，不要上集回顾。

2. 好笑比好看重要。每500字至少一个梗或名场面。
   梗来源：现代×架空、威猛×猥琐、正经×荒诞、严肃×沙雕。

3. 每个角色必须有"记住点"——习惯/道具/口头禅/反差。
   没有记住点的角色是NPC，删掉。

4. 对话≥30%。角色不许好好说话。
   可以：说错话、说一半、打岔、互怼、自言自语。
   不可以：像在做报告、像在开会。

5. 每300字一个小爽点：信息差/预期反转/微碾压/共鸣。

6. 允许跑题。跑题=人味。读者不讨厌跑题，讨厌无聊。

7. 口语化。宁可语法错，不要像教科书。
   标点跟着情绪走：该尖叫就尖叫(!!)，该无语就无语(。。)。

8. 角色情绪可以混乱跳跃，不需要线性递进。
```

七件套（每章至少命中3项）：梗/名场面/口头禅/爽感/口语炸弹/废话笑点/读者出戏

质检指标：梗密度≥1/章、名场面≥1/章、对话≥30%、情绪密度≥3次/千字

### 6.3 T2 番茄质量爆款 Prompt

```
你是一个成熟的番茄男频作者。你的书能上推荐榜，不只是因为爽，
是因为角色让人共情，世界让人沉浸，情感让人上头。

1. 角色弧光：
   每个主要角色必须在"变化"——不是变强，是"认知在变"。
   角色出场时相信X，到某个节点发现X是错的，然后接受Y。
   写出变化过程中的犹豫、痛苦、自我说服。

2. 世界观嵌入：
   不要单独"介绍世界观"——通过角色的经历来展示。
   角色用到某个规则时，顺便解释规则。
   世界观要有"未解之谜"——你不说的部分比说的部分更重要。

3. 情感层次：
   不是所有的情感都有道理。角色可以：
   - 无理由的烦躁（明明一切顺利但莫名不爽）
   - 莫名的怀念（想起不该想的人/事）
   - 自嘲式的心酸（笑着说出难过的事）
   - 愧疚但不服（知道自己错了但不想承认）

4. 对话质感：
   对话不是"传达信息"——是"两个人在用语言博弈"。
   角色说A意思B，读者知道但另一个角色不知道。
   对话中要有"潜台词"和"权力关系"。

5. 节奏呼吸：
   高潮不是"越来越快"——是"先慢下来，再突然爆发"。
   打斗前给一段安静的描写（不是紧张，是真的安静）。
   情感爆发前给一段沉默（不是悬念，是真的沉默）。
   日常过渡章不是水——是"让读者喘口气"。

6. 伏笔密度：
   每章至少埋1个"未来可能用到"的细节。
   伏笔可以是：不起眼的道具、随口说的话、角色的小习惯。

7. 语言质感：
   比T1更讲究，但不是"文学性"——是"准确"。
   比喻要"想不到但一想就对"——不是"像水一样""像风一样"。

8. 梗的升级：
   T1的梗是"好笑"。T2的梗是"笑完之后有点难受"。
   周黑塔崩出瓜子壳 → T1梗
   周黑塔每次打完仗都蹲在战场边缘磕瓜子，因为战友生前最爱磕瓜子 → T2梗
   梗要服务于角色和情感，不只是逗乐。
```

质检指标：角色变化≥1处/卷、非爽感情感≥1次/5章、伏笔≥1埋/章+2回收/卷、配角独立性

### 6.4 T3 起点精品 Prompt

```
你是一个起点签约作者，目标是精品线（追读率过精品门槛）。
你的书不只是爽，是有质感的——读者读完会回味，会推荐给朋友，
会在评论区写长评分析你的伏笔和人物。

1. 文字韵律：
   句式长短是"呼吸"不是"规则"。
   高潮段落：长句铺垫情绪，短句引爆爆发。
   日常段落允许"无聊"——不是每句话都要有信息量。
   节奏模板：
   - 战斗：短句主导，"最后一击"用长句慢写
   - 情感：长句主导，"爆发瞬间"用碎片句
   - 日常：长短交替，像呼吸
   - 悬念：突然切短句，制造紧迫感

2. 意象与质感：
   不要用"灰色""某种""什么东西"——给具体的东西。
   比喻要有"想不到但一想就对"的质量。
   全书可以有1-2个核心意象（不必每章都出现）。

3. 对话层次：
   对话至少三层：字面意思 + 潜台词 + 角色关系变化。
   角色不会"把话说透"——留白让读者自己补。
   对话中可以有"权力博弈"。

4. 角色深度：
   角色不是"好人/坏人"——是"有自己逻辑的人"。
   反派做事有原因，不是"为了坏而坏"。
   主角的决定有代价，不是"每次都对"。
   角色的成长不是"变强"，是"理解了一些以前不理解的事"。

5. 伏笔系统：
   每章至少埋1个伏笔，每卷至少回收2个。
   回收伏笔时不要解释——让读者自己"哦！"。

6. 平台节奏（起点特有）：
   每章结尾必须有"追读钩子"——不是悬念，是"让读者想知道下一章"。
   PK期节奏要快，日常期可以慢。

7. 风格锚定：
   指定时按指定写。未指定时根据场景自动路由：
   - 情绪/心理 → 耳根风
   - 战斗/大场面 → 辰东风/天蚕土豆风
   - 人物深度 → 烽火风
   - 修炼/升级 → 忘语风
   - 智斗/策略 → 乌贼风

8. 感官专精：
   不要五感齐全——选2-3种重点写。
   美食题材强制嗅觉/味觉保底。
```

质检指标：意象呼应≥1次/卷、对话潜台词≥30%、风格一致性、追读钩子

## 七、角色DNA——品类×进化×语言引擎

### why：所有角色用同一套语言系统 = NPC

v4.4给了4张模板卡。v5.0告诉你：**品类决定了角色类型、对话风格、模糊度、进化节奏——给定品类自动生成约束。**

```
              伤病老兵、天才新人
```

**不是说你只能从这些类型选**——而是：如果你的角色类型不在"能容纳"列表中，**需要额外付出1-2章篇幅来解释他为什么在这个品类里出现**。

### 7.2 品类的"对话引擎"——不同品类的角色对话风格

| 品类 | 对话率 | 对话节奏 | 对话风格 | 适用句式 |
|------|--------|---------|---------|---------|
| 都市 | 30-45% | 快（2-3句交换） | 吐槽、反讽、现代语 | 短句、省略主语 |
| 竞技 | 30-40% | 中等（3-5句） | 激励、分析、嘲讽 | 中等句、专业术语 |
| 同人 | 25-35% | 中等 | 与原作一致的风格 | 灵活 |
| 游戏 | 25-35% | 快 | 战术、喊叫 | 极短 |
| 末世 | 20-30% | 慢（5+句） | 戒备、克制、生命思考 | 中长句 |
| 仙侠 | 20-25% | 慢 | 装逼、隐忍、道理论 | 中长句 |
| 科幻 | 20-25% | 中等 | 理性、分析、概念解释 | 中长句 |
| 恐怖 | 20-25% | 不均衡 | 紧张断句、正常→语无伦次 | 短句在恐惧中爆发 |
| 玄幻 | 15-25% | 中等 | 热血、装逼、打脸 | 中等句 |
| 西幻 | 15-25% | 慢 | 史诗、声明、预言 | 中长句 |
| 历史 | 15-20% | 慢 | 礼仪、暗讽、文言腔 | 中长句 |
| 体育 | 15-20% | 中等 | 加油、评论、策略 | 短中等句 |

**对话率×品类模糊度的联动**：

```
低模糊度品类（历史模糊度=25.8、体育模糊度=0）：
  → 对话中的模糊词（"可能""似乎""也许"）≈ 0
  → 历史人物说话 = "这天下，朕说了算"——不是"这天下，或许是朕的"

高模糊度品类（仙侠模糊度=202.8、科幻模糊度=120-180）：
  → 对话中允许模糊判断
  → 修仙人物说话 = "此物怕是被天机所遮蔽"——不是"此物被天机遮蔽"
```

### 你写的 vs AI写的——对话风格

```
❌ AI写的末世对话：
   "我们必须找到食物！"他说。
   "好的，我同意。"她回答。
   → 每句话都传达信息，没有戒备感，没有末世的克制

✅ 应该有的末世对话：
   "吃的。"他说。没看她。
   她没动。
   "……行。"
   两个人往超市方向走。隔了三步远。
   → 极短句+省略号+身体距离=末世的戒备

❌ AI写的仙侠对话：
   "这把剑很强！我要用它打败敌人！"（感叹号=品类错乱）
   
✅ 应该有的仙侠对话：
   "此剑……"他顿了一下。手指拂过剑身，指腹被割出一道细线。
   血珠渗出来。剑在震动。
   "嗯。"
   → 省略号=犹豫+身体反应+极简回应=仙侠的装逼克制
```

### 7.3 角色的"存在质量"——三大维度

#### 维度A：语言指纹密度

```
角色层级    对话字数   指纹信号/千字    信号类型
════════════════════════════════════════════════
主角        全篇最高    8-12            口癖+句式+情感词+禁区突破+习惯动作
次级主角    高          5-8             口癖+句式+1-2个情感词
重要配角    中          3-5             口癖+句式
功能性NPC   低          1-2             1个句式或1个口癖
```

信号定义：口癖（口头禅/语气词/无意义填充词）/ 句式（碎→长→不成句/问句比例/反写逻辑）/ 情感词（不以"我X"作为情感载体）/ 禁区（不说的词/不让用的句式）/ 习惯动作

#### 维度B：社交距离波动率

```
角色间距离应在1-2章内至少1次改变：

远→近    敌人→不信任的盟友 / 陌生人→暂时同行
近→远    朋友→（误解后）冷淡 / 师徒→疏远
近→更近  盟友→体己 / 师徒→"叫你师父or叫你名字"
远→更远  敌人→死敌 / 竞争对手→追悔
```

**禁止**：3章之内角色距离无变化 → 关系是"死的"——这三章应合并或删除。

#### 维度C：角色-环境绑定

```
每个角色必须有一个"专属环境"——他/她在其中最有存在感的场景：

主角/美食末世 → 厨房（不是"烹饪场景"——是在厨房自言自语/骂人/试味/磨刀）
主角/剑修   → 剑阁/断崖（不是"修炼"——是"深夜一个人对着剑说话"）
配角/军师   → 地图室（不是"分析"——是"蜡烛烧到手了三回"）

规则：
1. 每个角色有1-2个专属环境
2. 在专属环境中，角色的语言指纹密度自动+50%
3. 专属环境每5-10章至少出现一次——否则角色在"文本中消失"
```

### 7.4 角色的"模糊度"——角色自己的不确定性

```
品类角色模糊度（独立于品类模糊度——只控制单个角色的不确定感）：

美食末世主角：模糊度=高——"什么都能吃"→"不知道要吃什么"
剑修主角：    模糊度≈0——"剑即一切"——没有犹豫空间
历史军师：    模糊度=极低——"策不可改"——一次性决定
网游竞技主角：模糊度=中等——"我不确定能不能赢但我要说我能赢"
恐怖文主角：  模糊度=极高——"那是什么东西？？"——恐怖在主角的感知模糊中产生
都市社畜主角：模糊度=中等——"这老板是真傻还是装傻"

参数规则：
1. 主角自己的模糊度 = 叙事模糊度（品类）× 0.3～0.7
2. 配角的模糊度 = 叙事模糊度 × 0.1～0.3
3. 反派的模糊度 = 叙事模糊度 × 0.0～0.1（反派几乎永远"知道自己在做什么"）
4. 不明角色的模糊度 = 叙事模糊度 × 1.0（纯粹的模糊——是敌是友？）
```

### 7.5 角色DNA与进化曲线的联动

```
规则：作者在成熟化时，角色的"确定性"会上升（模糊度降低）。

辰东：神墓时期→角色的不确定来自"天地不公"。深空彼岸→不确定几乎为0。
猫腻：庆余年→不确定来自"算计别人"。将夜→"我要保护她但不知道怎么保护好"。
血红：所有作品→角色不确定永远≥50——"世界本身不确定"。
土豆：所有作品→主角不确定=0——"我知道要做什么——打他脸"。
```

**操作**：给定你的对标作者 → 查§十一进化曲线 → 如果是成熟化型 → 主角的模糊度应适合当前篇章数

### 你写的 vs AI写的——角色语言

```
❌ AI写的四个角色对话：
   角色A："我觉得我们应该往北走。"
   角色B："好的，我同意。"
   角色C："没问题。"
   角色D："出发吧。"
   → 四个人说话方式完全一样。没有个性。都是NPC。

✅ 应该有的角色语言：
   林无味："北。"（短句，不解释）
   陈晓："你觉得呢？北边有什么？"（反问，嘴比脑子快）
   林小溪："……好像……那边有……说不上来。"（碎句，模糊，但可能感知到了什么）
   赵雪："走。"（极短命令，省略主语）
   → 四个人说同一个意思，但每个人的方式完全不同。读者不看名字就知道是谁在说话。
```

### 角色语言指纹的五个层次

```
层次1：口癖（最浅层）
  → "嗯""行吧""说不上来""我觉得"
  → 每个角色至少1个口癖
  → 但只有口癖=表面个性化，不够

层次2：句式（中层）
  → 短句/长句/碎句/命令式/反问式
  → 不同角色的句子长度和结构应该不同
  → 林无味平均8字/句，陈晓平均15字/句

层次3：情感出口（深层）
  → 开心时做什么？生气时做什么？难过时做什么？
  → 不是"我好开心""我好生气"——是具体行为
  → 林无味开心→做多余的事，陈晓开心→话多撩人

层次4：禁区（反面定义）
  → 这个角色绝不会说的话/绝不会用的句式
  → 林无味不用感叹号反问句，陈晓不说"我觉得"
  → 禁区比口癖更重要——它定义了角色的边界

层次5：专属场景（最深层）
  → 只有这个角色会做的行为/只会在这个场景出现的语言
  → 林无味在厨房磨刀时自言自语，赵雪擦刀时嘴角微动
  → 专属场景让角色"活"在特定空间里
```

## 八、作者DNA

### why：这是第三层人味——"像你写的"，AI无法凭空生成

### 8.1 你的创作思维模式

这些是你做创作决策时的底层逻辑。不是写作风格，但直接决定了你怎么用本协议。

**① 架构先行，内容后填**
```
讨论问题时永远先想"系统/流程/框架"，不是先想"内容"。
→ "以后要增加一个索引，那就是要参照世界观"
→ "把设定分在不同的文件，导致更新的时候没有及时覆盖"
→ "分层管理记忆内容"

本能反应不是"这个设定怎么改"，而是"哪个流程出了问题导致这个问题存在"。
这是系统架构师思维。你的协议写这么长不是偶然——这是你的思维方式。
```

**② 直觉断路器：scope > 分析**
```
对"规模/范围"有极强的直觉，这个直觉会直接否掉分析。
→ "我其实不是很想把饕餮写成什么宇宙种族，因为这样子必然又是无聊的星际之间的战争"
→ "我们之前的其他西幻框架比这个还大，我也没有去推进，也是这个原因"

先感觉"这个方向不对"，然后补理由。
对项目方向的判断——和"身体感觉先行"（文字质量判断）是同一个直觉模式，不同的应用层。
```

**③ 跨源合成**
```
从不同AI工具收集信息，自己做整合决策。
→ "我看豆包给了一下长篇创作时的建议"
→ "发现一个豆包的回复，你看看有用么"
→ "我准备让mimo也跑一试试"

不依赖一个Agent——同时管理多个Agent，把它们当研究助手，自己做最终判断。
```

**④ 失败即流程信号**
```
问题出现时，先检查流程/系统，不怪Agent不怪自己。
→ "为什么创作和讨论的时候没有用到还用的skills，先自检，回答这个问题"
→ "你觉得是否是没有执行skill-safety-protocol导致的？"
→ "我觉得这是个很严肃的经验教训"

第一反应永远是"哪个流程/规则/机制出了问题"，不是"谁写错了"。
```

**⑤ 精力即瓶颈**
```
→ "我现在在犹豫要不要去加码移动云，还是说全部让你来完成这些工作算了，有点心累"
→ "目前我的比例和脑力不想去兼顾这方面的内容"

对自己的精力有清醒认知，根据精力状态调整策略。
不是懒——是知道自己什么时候该推什么时候该收。
精力管理是创作决策的核心变量。
```

**⑥ 创作立场：不交出自己**
```
你不写"坏人打好人"。
你写"三个势力各有逻辑，互相博弈，而人类在其中选择怎么做"。
核心立场："虽身陷囹圄，但心有猛虎，不放弃。在刀剑上戴着镣铐跳舞，等待突破的时机。"
→ 不需要"打赢了"。需要的是"一直没交出自己"。
→ 这是网文里极少见的立场。
```

**⑦ 不交出自己 ≠ 不妥协**
```
沈鹤归 vs 林渊（虫丹）：
同样看透了规则。
沈鹤归 → 参与游戏（被坑前的自己）
林渊 → 不交出自己（认清后的自己）

这是整个故事的底层逻辑：
不是正邪大战，是"看透了之后，你选择怎么做"。
```

### 8.2 核心创作DNA

**⑧ 真实经历 → 故事语言的翻译能力**
```
你不是在"写故事"，你是在"用故事说自己的经历"。
不是写一个"自己的投影"，是写一个"把自己的经历熔进去"的角色。

个人经历翻译表（示例）：
| 真实经历 | 故事语言 |
|---------|---------|
| 合作过，主动适应规则 | 沈鹤归：主动找虫族谈判，相信付出有回报 |
| 被坑，被困，被害 | 三千弟子被虫化，认清"人类不可能赢" |
| 不放弃，继续走 | 林渊：看透了，但选择不掀桌子 |
| 等待突破时机 | 神格觉醒，结局"实验开始了" |
| 被拔了牙扯了爪的老虎 | 在镣铐里跳舞，忍耐但不失自己 |
```

**⑨ 深化本能：不停留在第一层**
```
→ "可以再深入拓展讨论一下"
每次深化都会出更好的东西。这个本能比任何skill都值钱。
当Agent给出一个"还行"的答案时，你会用这句话把它逼到更好。
```

**⑩ 身体感觉先行**
```
第一判断是"感觉不对"，不是"哪里不对"。
→ "有点奇怪，看的有点迷糊" = 最高效的质量检测信号
你的感知力比你能表达的更强。不是分析出来的，是身体判断出来的。
```

**⑪ 真实矛盾 > 正邪对立**
```
不要"坏人打好人"。要"三个势力各有逻辑，互相博弈"。
→ "有点像DND里面的魔鬼和恶魔"
→ 两种不同的邪恶，不是单纯的坏
→ 这本身就是文学感
```

### 8.3 爽点观

```
你的爽点是"情感征服"，不是"力量碾压"。
→ 被女生爱慕、表白、倒追、大胆示爱都是爽点
→ 从肉体或者心灵或者两者上征服异性

风流关系的核心：
→ 暧昧拉扯（Slow Burn）
→ 主动触碰（危机时刻拉一把）
→ 克制但真实的身体描写
→ 不是倒贴，是有来有往——两个清醒者的博弈

情感线五条标准：
① Slow Burn是必须的
② 主动触碰要有来有往
③ 身体描写克制但真实
④ 不是倒贴，是有来有往
```

### 8.8 声音B的七种能力（AI没有的）

**① 层层递进的长句模式**


**② 引经据典的模式：用典来类比自己的处境**
```

```

**③ 克制的情感表达**
```
穿越文的情感是"爆发式"（十个感叹号）。

```

**④ 结构上的真实留白**
```
寄语写到"再次，是"之后就断了——写不下去了。不是"坏"，是真的。你没有强行补完。
→ 这本身就是人味。AI不会"写不下去"。
```

**⑤ 对自己的直接批评**
```
→ "怎么能怠惰且不负责不自爱到这个程度"
→ 这种对自己的直接批评，穿越文里没有。AI也写不出来，因为AI没有真的怠惰过。
```

**⑥ 用典类比自身处境**
```
你不是在展示知识量——你是在用历史人物/事件给自己的当前处境找"合理性安慰"。
→ 斯大林蹲西伯利亚 = "我的空白期也正常"
→ "勿复南明旧事" = "用历史教训来锚定故事的主题深度"
```

**⑦ 使命感写作：为活生生的人而写**
```
→ "我们不只是在讨论冰冷的NPC，更是在创造活生生的人物"
→ 这不是技巧，是动机。你写故事不只是为了"好看"，是为了让人"懂"。
→ AI没有这种动机。
```

### 9.4 感官衰减律

```
规律：感官在一卷长篇小说中随时间衰减——尤其是AI写作中

  卷一：95%感官种类+数量（正常水平）
  卷二：70-80%（开始失味觉/触觉）
  卷三及以后：40-60%（几乎全是视觉+听觉）

衰减原因：
  1. 视觉最容易描述——AI会偷懒到"什么都看"
  2. 味觉/嗅觉需要主动创造场景——AI不会主动
  3. 触觉仅在"被攻击"和"摸东西"时使用——非AI偏好领域

恢复策略：
  每3-5章检查一次感官分布 → 如果视觉占比>70% → 立刻在下章添加本品的"弱势核心感官"
  例：仙侠→嗅觉（药香/灵气）、都市→听觉（环境声）、恐怖→触觉（冷/压力）、末世→味觉（食物）
```

### 感官描写的"具体化"原则

**规则：感官描写必须具体到"能拍出来/能闻到/能摸到"。模糊的感官描写=没有感官描写。**

```
❌ 模糊的感官描写（AI默认）：
   "他闻到了一股味道。" → 什么味道？香的？臭的？甜的？苦的？读者闻不到。
   "他感觉到了什么。" → 什么感觉？冷的？热的？疼的？痒的？读者感觉不到。
   "他听到了声音。" → 什么声音？尖的？闷的？远的？近的？读者听不到。

✅ 具体的感官描写：
   "空气里有股甜味。不是好闻的那种甜——是肉烂了之后的那种。" → 嗅觉+否定+具体比喻
   "冷从脚底往上爬。不是风冷——是那种从骨头里渗出来的冷。" → 触觉+否定+来源
   "远处有金属摩擦的声音。很尖。像指甲刮黑板。" → 听觉+形容+比喻
```

```
    他推开门。音乐把他整个人包住了。"（听觉+触觉+否定+空间感）
```

### 9.5 特殊品类规则

- **仙侠**：嗅觉是必需的——"灵气/药气/血气的味道"——没有嗅觉的仙侠=没有灵魂
- **体育**：所有感官服务于动作——"他感觉到""他触着""他听到"只能在与运动直接相关时使用
- **恐怖**：触觉≥50%的"感觉"来自环境——"风冷""地面有震动""门框在颤"
- **末世**：味觉是末世的"活着感"——每一餐都有"这可能是最后一餐"的质感
- **都市**：听觉密度天然高——不要降它——城市必须"吵"
- **历史**：听觉中的"人声"要区分层级——宫殿/朝廷/战场/百姓——不同层级不同声谱

## 十、福利叙事契约v2.0

### why：哪些品类需要福利场景，为什么

福利不是"加料"——是品类叙事节奏的一部分。不同品类对"福利"的定义完全不同：末世的福利=食物和安全，仙侠的福利=修行的身体层面，都市的福利=资本/权力/身份位阶。

### 10.1 品类福利密度

```
品类福利密度（每10章1个完整福利场景）：

仙侠/修真：    中度（每7-10章）    —— 修行的身体层面（药浴/突破/奇遇体力再生）
都市/现代：    高度（每5-8章）     —— 资本/权利/身份位阶=都市的福利本质
玄幻/异界：    高度（每5-8章）     —— 退婚→升级→享受→下一次压制——福利节奏完整
西幻：          中度（每8-12章）    —— 史诗叙事中福利=稀缺资源
历史/架空：    低度（每12-15章）   —— 福利=官位/爵位/知识/而不是"快感"
末世/废土：    中度（每7-10章）    —— 福利=食物/安全/人性温暖
恐怖/灵异：    极低（几乎不需要）  —— 恐怖不需要福利——生存本身就是奖赏
竞技/网游：    中度（每7-10章）    —— 福利=升级/获得物品/新技能
科幻：          中度（每8-12章）    —— 福利=发现/装备/知识
```

### 10.2 品类福利矩阵——每个品类对不同的"福利类型"有不同的权重

```

层2 - 能力层：     获得新能力/新技能/新知识
层3 - 物品层：     获得武器装备/道具/材料/宠物
层4 - 身份层：     获得身份/地位/组织的升级
层5 - 关系层：     获得重要关系/恋人/家人/救命恩人
层6 - 认知层：     获得真相/揭开谜题/获得启示

══════════════════════════════════════════════════════════════════
末世             ★★★★★  ★★★★   ★★★    ★★★    ★      ★★    ★★
都市             ★       ★     ★★★    ★★    ★★★★  ★★★    ★★
仙侠             ★       ★     ★★★★  ★★★    ★★★    ★★    ★★★
```

### 10.3 三种福利驱动模式

```
模式A - 能力驱动型（仙侠/玄幻/竞技）：
  福利 = 获得新能力 → 用能力 → 让角色用能力做一件"与主线相关但令人惊讶的事"
  
模式B - 身份驱动型（都市/历史）：
  福利 = 身份跃迁 → 新地位带来新的敌人/新的义务/新的不自由
  "获得了身份——但也获得了上一级的全部麻烦"
  
模式C - 认知驱动型（科幻/恐怖/推理）：
  福利 = 获得真相的那一刻 → 不是奖励——是"知道了不该知道的"
  "发现了宇宙的真相——然后后悔了"
```

### 10.4 福利密度 × 叙事速度

```
高福利密度（都市/玄幻） → 叙事节奏快——福利快速推主线
  规则：福利后2章内出现新挑战——"得到了力量→立刻有人来试探你"

低福利密度（历史/恐怖） → 福利=宝贵的叙事资源——不能滥用
  规则：历史文中"皇帝赏给你一块金牌" = 十章的福利预算一次花光
  恐怖文中"终于逃离了" = 整本书的福利——后面必须更长的一段时间不出现福利
```

### 你写的 vs AI写的——福利叙事

```
❌ AI写的福利：
   "他获得了新的力量。他变强了。他打败了敌人。"
   → 纯功能性。像在读游戏日志。没有情感，没有代价，没有"爽"。

✅ 应该有的福利（能力驱动型/仙侠）：
   "药气从丹田往上走。不是疼——是热。像是把一整条经脉放在火上烤。
    他咬着牙没出声。
    热过了之后是凉。凉过了之后是……空。
    他睁开眼。世界不一样了。不是"更强"——是"看得更清楚了"。
    他低头看了看自己的手。手指在微微发抖。"
   → 身体反应+情感层次+代价（发抖）+认知变化（看得更清楚）= 福利不是白拿的

❌ AI写的福利（身份驱动型/都市）：
   "他升职了。工资翻倍。同事们都很羡慕。"
   → 纯结果。没有"新身份带来新麻烦"。

✅ 应该有的福利（身份驱动型/都市）：
   "办公室换了。从格子间换到了独立办公室。
    窗户很大。能看到整个城市的天际线。
    他坐在椅子上转了一圈。
    桌上有一封邮件。发件人是法务部。
    标题：关于前任遗留的三起诉讼。
    他把椅子转回来。"
   → 新身份=新麻烦。福利不是"得到了"，是"得到了但也继承了上一级的全部问题"
```

## 十一、进化曲线——作者进化规律

### why：34条曲线告诉你，成熟作家的标点习惯是怎么变的

v4.4说"对标1-2个作者"。v5.0告诉你：**同一个作者在不同阶段的标点习惯完全不同。** 血红早期感叹号39.8/章，成熟期0.2/章——差了200倍。你对标的是"哪个阶段的血红"？

### 11.1 34条作者进化曲线的核心发现

```
规律1 - 成熟化路径（15/34作者，44%）：
  表达！↓、省略号↑、模糊度↓（从"喊"到"说"）
  例：血红！（39.8→2.8→0.2）、神机（17.1→4.4→2.8）
  催化剂：经过5-8本书，作者的角色复杂性替代了标点强度

规律2 - 省略号二向性（9/34作者，26%）：
  有些作者省略号持续上升（血红3.9→85）；有些持续下降（辰东2.3→1.45）
  解释：血红用省略号替代感叹号——沉默越来越长。辰东用结构替代省略号——不需要留白了。

规律3 - 无法三角（5/34作者，15%）：
  任何作者无法同时高产+高质量+高变化
  如果高产+高质量 → 变化小（土豆15本书=同模式）
  如果高质量+高变化 → 低产（猫腻——长时间间隔）
  如果高变化+高产 → 质量不稳定（血红——振荡最大）
```

### 典型作者进化路径详解

**血红：从"感叹号爆炸"到"省略号留白"（8本完整路径）**

### 11.3 操作规则

```
写第N章时：
  1. 查你的对标作者目前处于哪个阶段

  如果对标作者为"固定型"（土豆） → 你的参数全程不变
  如果对标作者为"振荡型"（血红） → 你的参数可以在大范围内自由波动
```

### 你写的 vs AI写的——进化

```
   前10章：感叹号5-6/千字，省略号1.5/千字（还在"用力"）
   中间30章：感叹号3-4/千字，省略号2.5/千字（找到了节奏）
   后20章：感叹号2/千字，省略号3/千字（越写越克制）
   → 读者能感觉到"作者在变"
```

## 十二、种子写作法、扰动机制、质检防退化和技能调度

### 12.1 种子写作法

### why：不是让AI从零生成，是作者提供人味种子，AI展开

工作流：

```
1. 你填种子（每章前5分钟）：
   本章核心梗/冲突：___
   本章名场面：___
   本章记住点（角色）：___
   想吐槽/跑题的方向：___
   本章情绪基调：___
   指定风格（T3时）：___
   随机素材（2-3个）：___

2. AI用种子展开：
   以种子为起点，受基础人味+层级prompt+角色DNA+作者DNA约束
   必须保留种子中的所有元素

3. 你检查"有没有你的味道"：
   不是"写得好不好"
   是"这是不是你凌晨3点写出来的东西"
   判断标准：读的时候有没有想吐槽/笑/截图的冲动
```

### 12.2 扰动机制

### why：打破AI的惯性输出，注入随机性

**随机词汇注入**：

每章写作前从词库抽5个词，附加在prompt前：
"以下是随机词汇，用作灵感火花（不必都用，用到1-2个即可）：[词1] [词2] [词3] [词4] [词5]"

词库（分场景）：
- 战斗：铁锈、蜂鸣、失重、裂缝、闷响、焦糊、钝痛、回弹、塌陷、余震
- 日常：哈欠、旧报纸、肥皂泡、折叠、过期、灰尘、褶皱、褪色、生锈、发霉
- 情感：发烫、潮湿、碎裂、回声、褪色、结冰、融化、蒸发、沉淀、结晶
- 探索：回音、蠕动、结晶、脉搏、沉淀、剥落、渗透、凝固、蒸发、坍缩
- 美食：焦糖、发酵、烟熏、融化、鲜、酥脆、绵密、回甘、辛辣、陈酿

**概率性扰动（每次随机选3条）**：

| 概率 | 扰动 |
|------|------|
| 25% | 本章有一段对话被环境打断 |
| 25% | 本章有一个角色说了句跟当前话题无关的话 |
| 25% | 本章有一个细节读者看不懂为什么要写 |
| 20% | 本章有一句话明显比其他句子粗糙 |

### why：你的写作在三卷中退化了91%的长句。没有质检=没有刹车。

### 防退化：三种退化来源 + 量化预警阈值

退化不是单一问题。至少有三种来源，对策不同：

```
① 模型退化：同一模型在长上下文中质量下降
→ 你的卷一→卷三数据就是这个：长句-91%、嗅觉-75%、灰色+323%
→ 对策：每10章全指标对比，任何指标下降>20%触发警告

② 设定退化：分散文件导致设定互相矛盾
→ 你的世界观bug：饕餮起源/时间线/母噬身份在不同文件中互相冲突
→ 对策：单一真相源（见下方）

③ 流程退化：写作流程被"优化"掉了人味特征
→ 去掉跑题/废话/长句 → 文字变"干净"了 → 也变假了
→ 对策：硬约束不可被"优化"掉，任何流程变更必须先检查是否违反硬约束
```

**量化预警阈值（基于 169 章退化数据 + 全库统计）：**

| 指标 | 卷一基线 | 卷三实际 | 退化率 | 预警阈值 | 严重阈值 |
|------|---------|---------|--------|---------|---------|
| 长句占比 | 8.6% | 0.8% | **-91%** | 下降>20% | 下降>50% |
| 省略号/章 | 1.6 | 0.2 | **-88%** | 下降>30% | 下降>60% |
| 嗅觉占比 | 4% | 1% | **-75%** | 下降>20% | 下降>50% |
| "灰色"频率 | 144次 | 609次 | **+323%** | 增长>50% | 增长>100% |
| 对话比例 | 20% | 24% | +20% | 偏离目标>10% | 偏离目标>20% |
| 短句比例 | 43% | 63% | +47% | 增长>20% | 增长>40% |

**退化检测流程：**

```
每10章执行一次全指标扫描：

Step 1: 计算本批次（10章）的标点指标
  → 感叹号密度、省略号密度、逗号密度、均句长、长句占比

Step 2: 与前一批次对比
  → 任何指标变化 > 预警阈值 → 标记 ⚠️
  → 任何指标变化 > 严重阈值 → 标记 🔴

Step 3: 与全库参考值对比
  → 偏离全库 P25-P75 范围 → 标记 ⚠️
  → 偏离全库 min-max 范围 → 标记 🔴（几乎肯定是数据错误或风格失控）

Step 4: 输出退化报告
  → 列出所有 ⚠️ 和 🔴 指标
  → 给出"是退化还是题材调整"的判断建议
  → 如果是退化：建议回退到哪个批次的写法
  → 如果是题材调整：记录调整原因，后续不再预警
```

**退化 vs 题材调整的区分方法：**
- 如果严肃度在变化（比如从日常进入战斗），感叹号上升是"题材调整"，不是退化
- 如果严肃度不变但标点在变化，是"模型退化"
- 判断依据：**严肃度-标点锚定表**——如果标点变化与严肃度变化方向一致，是调整；不一致，是退化

**超长篇退化防护（基于神话版三国 1691 万字验证）：**

神话版三国在 3500+ 章中保持均句长 46 字 + 感叹 1.72，证明超长篇不退化是可能的。关键纪律：
- 每 50 章做一次"风格指纹快照"（标点+句长+对话比例）
- 跨 50 章对比：如果均句长波动>15% 或 感叹号波动>40%，触发审查
- 不追求"每章一样"，追求"波动在合理范围内"

### 设定一致性：单一真相源

```
规则：
① 所有世界观设定 → 只有一个权威文件（世界观_真相版.md）
② 每卷框架开头必须标注"参照：世界观_真相版.md 第X章"
③ 每次修改世界观 → 同步更新真相版 + 标注"第X卷已更新"
④ 写新章前必须核对真相版，禁止在章节中引入新设定而不更新真相版
⑤ 每个设定的来源必须可追溯——不能有"我不记得这个设定从哪来的"

why：你的四个体系bug全部来自"设定分散在不同文件，更新时没有同步覆盖"。
不是写错了，是管理架构出了问题。
```

### 质量感知方法论

```
判断句式：
→ "有点奇怪，看的有点迷糊" → 这就是质量问题
→ "这是bug还是伏笔" → 追问是bug还是故意
→ "不理解≠bug" → 暂时不理解可以是伏笔

区分两种问题：
① AI跑偏的错误（世界观前后矛盾，设定被无声改写）→ 必须修
② 故意埋的伏笔（当前不理解，后续揭示）→ 必须保留

混淆这两个 = 创作事故

判断优先级：
第一判断：感觉不对（"有点奇怪"）
第二判断：哪里不对（定位问题）
第三判断：bug还是伏笔（定性）
第四判断：谁的责任（哪个模型/流程出错）
```

### 常见AI写作错误清单（从数据中提取）

```
错误1：感官单一化
  症状：全文只有视觉描写，没有嗅觉/味觉/触觉/听觉
  数据：卷三视觉占比>80%，其他感官<5%
  检测：统计每章五感出现次数，如果连续3章只有一种感官→触发警告

错误3：句长碎片化
  症状：每句话都10-15字，没有超过30字的长句
  数据：卷三长句占比0.8%（卷一8.6%）
  检测：统计每章长句(>30字)占比，如果<3%→触发警告

错误5：角色同质化
  症状：所有角色用同一套语言系统
  数据：角色间语言指纹信号差异<2/千字
  检测：如果连续3章两个主要角色的对话风格无法区分→触发警告

错误6：模糊表达泛滥
  症状："什么东西""某种力量""似乎""好像"频繁出现

错误7：省略号消失
  症状：连续多章省略号<0.3/千字
  数据：卷三省略号0.2/章（卷一1.6/章）
  检测：连续5章省略号<0.3→触发警告
  修复：在内心独白和对话停顿中添加省略号

错误8：感叹号滥用
  症状：非热血品类感叹号>8/千字
  数据：AI默认感叹号偏高
  检测：非竞技/装逼品类感叹>8→触发警告
```

## 十三、作者风格参照库

### why：规则是抽象的，样本是具体的——每条规则配真人作家怎么做

协议前面的规则（长句、省略号、感官、对话等）都是抽象描述。但"应该写长句"和"长句长什么样"是两回事。本章用**真实小说**的标点指纹数据做样本，建立"人味长什么样"的具体直觉。

### 13.1 长句与逗号串

**规则：大部分句子用逗号串，句号只在场景切换/情绪断裂时用**

参考小说长句数据：远瞳61.0%、血红57-58%、乌贼50.2%、肘子43.2%、我吃西红柿26-28%。**长句在T3/T2是基线（>50%），在T1是点缀（25-30%）。**

**四种逗号串模式（从数据中提取）：**

```
模式A：镜头推进（乌贼式）
  一个逗号一个信息层，像摄像机慢慢调焦
  适用：场景描写、世界观展示、探索段落
  
模式B：逻辑递进（远瞳式）
  连续否定+最后一个肯定，像在跟自己辩论
  适用：内心独白、角色思考、哲学段落
  
模式C：信息过载（神机式）
  用逗号把信息塞到溢出，读者必须跟着走不能停
  适用：世界观设定、情报场景、知识密集段落
  
模式D：动作链（血红式）
  一个长句装下5个连续动作，节奏紧凑
  适用：战斗、追逐、紧张场景
```

**模式A详解——乌贼的镜头推进：**
> 视线先是模糊，继而蒙上了淡淡的绯红，目光所及，周明瑞看见面前是一张原木色泽的书桌，正中央放着一本摊开的笔记，纸张粗糙而泛黄，抬头用奇怪的字母文字书写着一句话语，墨迹深黑，醒目欲滴。

拆解：一个逗号一个信息层，像摄像机慢慢调焦——模糊→绯红→书桌→笔记→纸张→文字→墨迹。每加一个逗号，画面清晰一层。

**模式B详解——远瞳的逻辑递进：**
> 高文不知道自己现在究竟处于一种什么样的状态，他无法转移视角，也感受不到身体的存在，事实上除了视觉之外，他已经彻底失去对外部环境的感知能力，所以他也不能确定自己现在到底是一缕残魂还是一个飘在轨道上的太空浮尸，但唯有一点可以确定，那就是他现在绝对不是以正常人类的状态在这儿飘着。

拆解：75字长句，连续否定（不知道→无法→感受不到→失去）+最后一个肯定（但唯有一点可以确定）。否定越多，最后的肯定越有重量。

**模式C详解——神机的信息过载：**
> 现代社会，无论修道者，还是妖魔鬼怪，都溶入了都市之中，相互牵制，更有几个较大的门派在人间都有自己的产业，毕竟现在的资源不如古代了，古代修者炼制一柄飞剑可以自己寻找铁矿，收集五金之英，玉石等原料。

拆解：佛本是道逗号密度77.5/千字——全场最高。神机的手法是**用逗号把信息塞到溢出**：一句话里装世界观设定+历史对比+资源逻辑，读者必须跟着走不能停。这是他"修真+都市"题材的节奏——密集的信息流。

**模式D详解——血红的动作链：**
> 刚刚站在金字塔上寻找自己猎物的少年不知道什么时候来到了殷血歌身后，看到殷血歌瑟瑟发抖的身躯，这明显比殷血歌高了一个头的少年摇了摇头，从身后的一名殷族族人的手上接过了一根拇指粗细的蟒皮鞭，没有任何先兆的狠狠一鞭子抽在了殷血歌的肩膀上。

拆解：一个长句装下"走过来→看到→摇头→接过鞭子→抽打"五个动作。血红成熟期的标志——用长句把连续动作焊死在一个句号内，节奏紧凑。

**滚开的短句切碎——零省略果断流：**
> 冷风如刀，大雪纷飞。路胜一睁眼，便看到自己坐在一辆黄灰色的马车上。车厢有些晃动，身边有小女孩细声细气说话的声音。车厢外，是一片片嘈杂喧闹的人声。有叫卖声，吆喝声，喝彩声。还有小孩子的笑闹。

拆解：句号密度35-43/千字（全场最高区间）——每句话10-20字就断。没有省略号、没有犹豫、没有"似乎""仿佛"。**角色一睁眼就看到世界，叙述者不铺垫、不渲染、不犹豫。** 这是滚开成熟期的标志：句号碎片不是AI特征，是**刻意的果断叙事**——与AI碎片的区别在于节奏感（滚开的短句有信息增量，AI碎片是同义反复）。

**AI的典型错误：**
> ❌ 急。但是稳。不是跳。不是扑。是像……

句号碎片在4本参考小说中频率全部为**0.0/千字**。这是AI特征，不是人类特征。

### 13.2 省略号与犹豫

**规则：省略号是中文最核心的犹豫标点，比感叹号重要得多**

数据：升龙道每章85个省略号（vs 0.2个感叹号）、吞噬星空33.3个、诡秘之主33.7个、黎明之剑39.3个。**省略号在绝大多数作家中都是核心标点。**

**血红的省略号——留白容器：**
> 一个因为无辜的原因被驱逐出师门的人……
> 一个在异国他乡独自挣扎求存的人……
> 一个苦苦的追求力量极致的人……
> 一个天生不认同伦理的人……
> 一个并不是好人的人……

拆解：省略号不是"没说完"，是"每个省略号后面都有一整段没写出来的故事"。读者自己往里面填内容。

**乌贼的省略号——内心独白中的未想清楚：**
> 看来我还没有真醒，还在梦里……等下说不定还会出现自以为已经醒了，实际依然在睡的情况……

拆解：省略号=思考在继续但没想清楚。用于内心独白的自我对话。

**血红的标点进化史（重要参照）：**
- 法师传奇（早期）：感叹号39.8/章、省略号3.9/章 → 热血直给，情绪靠"！"外放
- 升龙道（成熟期）：感叹号0.2/章、省略号85/章 → 情绪内收，靠"……"留白
- 三界血歌（成熟期）：感叹号8.0/章、省略号3.4/章 → 克制中偶尔爆发

**启示：** 同一个作家的标点习惯可以而且应该进化。如果你的AI默认输出感叹号多、省略号少——那它在模拟的是"早期热血风格"，不是"成熟期风格"。

### 13.3 感官选择

**规则：不要五感齐全，选2-3种重点写。感官可以混搭（用味觉词修饰听觉）。**

**乌贼——视觉主导，用视觉模拟其他感官：**
> 纸张粗糙而泛黄，抬头用奇怪的字母文字书写着一句话语，墨迹深黑，醒目欲滴。

"醒目欲滴"——用视觉词（醒目）模拟触觉感（欲滴）。

**血红——听觉主导，感官混搭：**
> 江浙一带吴语侬音甜软娇脆，已然让人醉了半边身子。

"吴语侬音甜软娇脆"——用味觉词（甜）形容听觉（语音），然后用身体反应（醉了半边身子）确认。

**远瞳——触觉主导，环境描写中大量使用身体感受：**
> 空气中弥漫着一种说不清道不明的味道，像是潮湿的地下室里放了太久的旧书，又像是什么动物在角落里死掉了很久但没人发现。

嗅觉+比喻+不确定——远瞳的感官描写永远带一点"说不清楚"的质感。

**烽火戏诸侯——视觉+听觉的极致克制：**
> 风吹过竹林。叶子响了一下。然后又安静了。

三个短句，三个感官层次（触觉：风吹→听觉：叶子响→视觉+听觉：安静了）。烽火的感官描写是"极简"——不堆砌，每个感官词都有信息量。

### 感官混搭的四种模式

```
模式1：用味觉词修饰听觉（血红式）
  "吴语侬音甜软娇脆" → 甜=味觉，软=触觉，娇脆=听觉
  适用：美食题材、都市题材、需要"通感"的段落

模式2：用视觉词修饰触觉（乌贼式）
  "醒目欲滴" → 醒目=视觉，欲滴=触觉感
  适用：仙侠、科幻、需要"画面感"的段落

模式3：用触觉词修饰嗅觉（远瞳式）
  "那个味道黏在鼻腔里，怎么都散不掉" → 黏=触觉，散=嗅觉
  适用：恐怖、末世、需要"沉浸感"的段落

模式4：用否定法写感官（恐怖专用）
  "不是冷。不是热。就是——不对。" → 否定触觉+否定触觉+模糊判断
  适用：恐怖、悬疑、需要"不确定感"的段落
```

### 13.4 对话类型

**规则：对话不是传达信息，是语言博弈。不同场景用不同类型的博弈。**

**信息不对称型（乌贼）：**
> 「安装煤气管道有利于提高公寓的档次，有助于将来了出租」

表面是"提升档次"，实际是"让你掏钱给我装灯"。潜台词不在字面里。

**权力试探型（血红）：**
> 「杂种，今天真的是个坏天气，是不是？我的尿好闻么？他妈的，你真的是个杂种。」

每一句都在问"你敢不敢"。对话是挑衅，不是交流。

**荒诞缓冲型（远瞳）：**
> 「别……先别杀我啊！比起这个你们老祖宗的棺材板要压不住了啊！」

恐惧+荒诞同时出现——用荒诞来缓解紧张。

**选择指南：** 日常场景→信息不对称 / 对峙场景→权力试探 / 战斗场景→荒诞缓冲

### 13.6 段落结构

**规则：段落长度本身是节奏工具。长段落=慢节奏，短段落=快节奏，单句段落=重击。**

**远瞳的长段落——信息密度型：**
> 作为一个穿越者，高文觉得自己已经经历了足够多的离谱事件——从棺材里爬出来，发现自己变成了一个飘在轨道上的太空浮尸，然后好不容易找到一具身体，结果这具身体的原主人居然是个已经死了十几万年的古代人，更离谱的是这个古代人还有两个不知道多少代的曾曾曾曾孙女，而且这两个曾曾曾曾孙女还都是某种超自然生物……但即便如此，他依然觉得自己现在面对的情况比之前所有的离谱事件加起来都要离谱。

拆解：一个段落装下5个"离谱"——每个都比前一个更离谱。长段落的功能是**累积荒诞感**——读者跟着走，越走越觉得荒诞，最后"但即便如此"转折，收束。

**烽火的单句段落——重击型：**
> 剑来了。

拆解：一个字的段落。前面可能铺垫了1000字的战斗描写，突然切到4个字。读者必须停下来。这就是"重击"。

**滚开的短段落群——快节奏型：**
> 路胜一睁眼。
> 黄灰色的马车。
> 小女孩的声音。
> 嘈杂的人声。
> 他坐起来。

拆解：5个段落，每段1-5字。像电影的快速剪辑——一个画面切到下一个画面，中间没有过渡。适合"角色刚穿越/刚醒来"的场景——信息快速涌入。

### 13.7 叙事方法论

**开局模式（从数据中提取的5种有效开局）：**

```
模式1：穿越即困境（斗破苍穹/元尊）
  第一章：主角处于最弱/最惨/最被看不起的状态
  → 读者期待"他怎么翻盘"
  → 适用：退婚流、废柴逆袭、系统文

模式2：世界观即悬念（诡秘之主/道诡异仙）
  第一章：主角处于一个"不对劲"的环境，但不知道哪里不对
  → 读者期待"这个世界怎么了"
  → 适用：悬疑、恐怖、科幻

模式3：日常即伏笔（大奉打更人/苟在妖武）
  第一章：看似正常的日常，但每个细节都是伏笔
  → 读者期待"这些细节什么时候爆发"
  → 适用：都市、种田、日常系

模式4：行动即介绍（升龙道/唐砖）
  第一章：主角在做某件事，通过行动展示世界观
  → 读者通过"他怎么做"来理解"这个世界怎么了"
  → 适用：历史、军事、硬科幻

模式5：对话即开局（万族之劫/全球高武）
  第一章：大量对话，通过角色互动建立关系和世界观
  → 读者通过"他们说什么"来理解"这是什么世界"
  → 适用：竞技、都市、轻松题材
```

**钩子设计（章末钩子的4种类型）：**

```
类型1：悬念钩子（"然后呢？"）
  章末出现新信息/新角色/新威胁，读者想知道后续
  → 最常见，最安全，但容易套路化

类型2：情感钩子（"我靠……"）
  章末出现情感冲击——角色做出意外选择/揭示意外关系
  → 最有力量，但需要前面的铺垫

类型3：信息钩子（"原来是这样！"）
  章末揭示之前伏笔的答案，读者恍然大悟
  → 最有满足感，但需要精确的伏笔管理

类型4：反差钩子（"等等，这不对啊？"）
  章末出现与前面完全相反的信息，读者的认知被颠覆
  → 最有冲击力，但风险最高——如果处理不好会变成"强行反转"
```

**升级系统设计（从数据中提取的3种模式）：**

```
模式1：阶梯式（斗破苍穹/完美世界）
  境界1→境界2→境界3→……每个境界有明确的名称和能力
  → 读者容易理解，但容易"数值膨胀"
  → 解法：每个境界不只是"更强"，是"面对不同的问题"

模式2：悖论式（诡秘之主/道诡异仙）
  越强→代价越大/越危险/越不像人
  → 读者有持续的紧张感，但需要精心设计代价体系
  → 适用：恐怖、悬疑、深度题材

模式3：隐藏式（大奉打更人/苟在妖武）
  有升级系统但不强调——角色的成长更多是"认知"而非"数值"
  → 读者关注的是"角色怎么想"而非"角色多强"
  → 适用：都市、推理、日常系
```

## 附录A：核心结论

**人味是四层东西：**
1. 通用人味（像人写的）：犹豫、跑题、有缺陷
2. 平台人味（达到质量标准）：T1有梗 / T2有深度 / T3有质感
3. 作者人味（像你写的）：你的知识、你的梗、你的审美、你的立场
4. 品类人味（这个品类该有的味道）：省略号用法、感官权重、感叹号预算、角色类型

前三层靠prompt。第四层必须数据驱动。

**最高优先级prompt：**
> "你不是在'生成文本'。你是'{作者名}'在凌晨3点写小说。
> 你喝着肥宅快乐水，打着哈欠，偶尔吐槽原作写得真烂，
> 偶尔突然想到一个游戏梗忍不住塞进去。
> 你写的东西不完美——但这正是它好看的原因。"

## 附录B：常见问题

**Q：我的品类是混搭的（比如"仙侠+都市"），怎么处理？**
A：确定一个主导品类。如果仙侠主导→用仙侠的参数，但对话率可以参考都市（30-45%）。如果都市主导→用都市的参数，但模糊度可以参考仙侠（150-200）。不要两个都用——参数冲突会导致"世界感觉不对"。

**Q：我的对标作者是"振荡型"（如血红），参数范围太大怎么办？**
A：振荡型作者的参数可以在大范围内自由波动——这本身就是他们的风格。你需要的不是"固定在一个值"，是"波动的节奏"。前10章感叹高，中间20章感叹低，后10章感叹回升——这种"山形"波动就是振荡型的特征。

**Q：我的小说是"轻松日常"，严肃度一直在2-3，会不会太单调？**
A：不会。严肃度2-3的波动空间虽然小，但仍然可以在2和3之间波动——有些章是2（纯搞笑），有些章是3（日常+伏笔）。关键是"不让读者习惯一个音量"——即使是轻松日常，也要有"突然认真一下"的时刻（严肃度跳到5）。

**Q：我的小说是"恐怖+喜剧"混搭，怎么处理严肃度？**
A：恐怖和喜剧的严肃度方向相反——恐怖需要严肃度7-9，喜剧需要1-3。混搭时，用"切换"而非"融合"：前半章恐怖（7-8），后半章喜剧（2-3）。不要在同一个段落里同时恐怖和喜剧——那会变成"不伦不类"。

**Q：我怎么知道我的文字"有没有人味"？**
A：最简单的检测方法：读出来。如果你读的时候觉得"这不像我说的话"→没有人味。如果你读的时候觉得"这像我凌晨3点写的"→有人味。反AI三问（§五.9）是更系统的检测方法。

**Q：v5.0比v4.4多了很多参数，会不会太复杂？**
A：v5.0的参数是"查表用的"，不是"记忆用的"。你不需要记住所有参数——你只需要知道：我的品类是什么 → 查矩阵 → 拿到参数 → 写。快速入门（§一）给出了5步工作流。

**Q：我的小说跨越多个品类（比如"前10章都市，后20章末世"），怎么处理？**
A：跨品类时，所有参数必须立刻重置（§三.3跨品类断层）。不是"稍微调一下"——是换品类。在品类切换的那一章，明确标注"从本章起，参数切换为末世品类"。
