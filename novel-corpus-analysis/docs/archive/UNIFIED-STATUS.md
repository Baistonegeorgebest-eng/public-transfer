## 🔧 操作备忘

### SSH推送
```bash
GIT_SSH_COMMAND="ssh -i ~/.ssh/.github_miclaw -o StrictHostKeyChecking=no -o ConnectTimeout=30 -o ServerAliveInterval=10" git push origin HEAD:main
```

### SSH密钥路径
`~/.ssh/.github_miclaw`

### 工作目录
- master（小说原文）：`/root/.openclaw/workspace/public-transfer-master-git/novel-txts/`
- main（分析文件）：`/root/.openclaw/workspace/public-transfer-main-git/novel-corpus-analysis/`

### 分析流程
1. 从 master 的 `novel-txts/` 读原文（注意GBK编码需iconv转换）
2. 跑标点统计
3. 读章节内容，理解叙事结构
4. 写深度分析到 main 的 `novel-corpus-analysis/`
5. commit + push

### 质量标准
- **>15KB**：顶级（标点+趋势+场景+跨作者+洞察）
- **10-15KB**：高质量
- **5-10KB**：良好
- **<5KB**：需升级
