## 二、执行计划

### Phase 1：自动计算（2h）

**目标**：从现有deep文件数据中自动提取TCI、译者指纹、品类对比

**步骤**：
1. 解析28本译本的deep文件，提取标点数据
2. 计算TCI = (译本句号/千字 ÷ 中文原作句号均值) × (中文原作逗号/千字 ÷ 译本逗号/千字)
   - 中文原作基准值：句号23.0/千字，逗号60.0/千字（502本均值）
3. 译者指纹评分规则：
   - ⭐⭐⭐⭐⭐：TCI 0.7-1.0（完美本土化）
   - ⭐⭐⭐⭐：TCI 1.0-1.2（优秀本土化）
   - ⭐⭐⭐：TCI 1.2-1.4（中性翻译腔）
   - ⭐⭐：TCI 1.4-1.6（轻度翻译腔）
   - ⭐：TCI >1.6（强翻译腔）
4. 合集一致性：对比同作者/同系列的标点差异
5. 品类对比：匹配中文品类均值，计算偏离度

**输出**：`translation-analysis-auto.md`（28本TCI+译者指纹+品类对比表）

### Phase 2：感官分析（1.5h）

**目标**：提取28本译本的五感描写数据

**步骤**：
1. 复用sensory-extraction脚本的关键词列表
2. 对28本译本的分析文件进行五感关键词扫描
3. 计算五感占比（视觉/听觉/触觉/嗅觉/味觉）
4. 与中文原作品类均值对比

**输出**：`translation-sensory-analysis.md`（28本五感数据+品类对比）

### Phase 3：翻译残痕分析（2h）

**目标**：识别原文句法结构在中文译本中的残留

**步骤**：
1. 句长分布分析：是否呈双峰分布（极短+超长，中间缺档）
2. 破折号密度：高破折号=本土化适配标志
3. 引号使用：中文引号vs英文引号混用
4. 长句结构：是否有英文从句嵌套痕迹（"的的的"连用）

**输出**：`translation-residue-analysis.md`（28本翻译残痕评估）

### Phase 4：整合输出（0.5h）

**目标**：将Phase 1-3结果整合为完整分析文件

**输出**：
- 更新每本译本的analysis文件（追加TCI/译者指纹/感官/翻译残痕）
- 生成`翻译文学分析报告-v2.0.md`（汇总表+品类规律+译者指纹库）
