### 你为什么要关心"品类"

v4.4说"省略号越多越像人"。但你有没有想过——

**竞技文里几乎没有省略号。** 全职高手省略号0.2-0.5/千字。选手在比赛中不犹豫——犹豫就输了。

**历史文里省略号不是"犹豫"，是"谋士在算"。** 绍宋省略号9.41/千字，但那个省略号是皇帝做决定前的沉默，不是"我不知道该怎么办"。

## 一、人味的四个层次

### why：为什么要分层

人味不是一个东西。它至少有四层，每一层的来源和解法都不同：

```
第一层：通用人味 —— "像某个人写的"
来源：人类语言的固有特征（犹豫、跑题、有缺陷）
解法：prompt约束 + 过程模拟
难度：低

第二层：平台人味 —— "达到对应质量标准"
来源：不同平台/定位的读者期待不同
解法：分层级prompt + 专项质检 + 品类维度质检
难度：中

第三层：作者人味 —— "像你写的"
来源：你的知识、审美、语言、毛病
解法：作者DNA注入 + 种子写作法
难度：高（AI无法凭空生成）

第四层：品类人味 —— "这个品类应该有的味道"（v5.0全新，v6.0扩充）
来源：不同品类有不同的省略号用法/感官权重/模糊度范围/感叹号预算
解法：品类叙事契约 + 品类标点指纹库 + 时代锚定 + 情绪结构
难度：中——必须数据驱动，不能凭直觉
```

**大部分"去AI味"教程只处理第一层。** 所以你用了 `expert-anti-ai-taste` 的769行规则，文字还是假——因为它只在处理表面症状，没有触及第二层和第三层。v4.4补了前三层，v5.0补了第四层，v6.0把第四层从"定性"升级到"定量"——502本数据支撑的精确品类标点指纹。

### 第四层为什么重要——一个真实的故事

你让AI写"仙侠"——但它不知道仙侠人味 = "视觉70%不是强项，嗅觉必须有"。你让AI写"竞技"——但它不知道竞技省略号≈0。你让AI写"历史"——但它不知道历史模糊度=25.8（极低模糊），人物说话不能"也许""可能"。

**v6.0的核心不是"加更多规则"——是"给定品类，参数自动适配，且有502本数据验证"。**

### 2.4 学术研究支撑

**LLM创意路径偏差（Nath et al., 2024, MPI）：**
人类交替使用"持久路径"（深挖少数概念空间）和"灵活路径"（跨多个概念空间跳转）。LLM偏执于一种，很少交替。
→ 解法：写作指令中显式要求两种路径交替。

**随机词汇注入提升多样性（2025实验）：**
prompt中加5个随机词，输出多样性显著提升。同时发现AI情感70%正面 vs 人类70%正面+30%负面。
→ 解法：每章注入随机词 + 显式要求负面情感。

**约束激发创造力 vs LLM对约束的理解：**
人类在约束下更有创造力（十四行诗效应）。但LLM倾向于"严格遵守字面意思"而非"在约束内发挥创意"。
→ 解法：约束要给"方向"而非"条目"——说"比喻要有你自己的味道"，不说"比喻不超过2次"。

### 3.2 品类内部物种分层——同一品类的小说也是不同物种

**仙侠·内部三物种**：

```
物种A：装逼流（辰东/耳根） → 模糊度极高（180+）、下划线突出、省略号约1.5（非犹豫用）
物种B：正统修真（忘语/宅猪） → 模糊度中（120-150）、长句主导、省略号约2.5（修炼描写内）
物种C：吐槽反讽（大奉打更人） → 模糊度低（80-100）、以省略号+读者互动为主、……是主线推理工具
```

**玄幻·内部三物种**：

```
物种A：退婚流（土豆/乌贼早期） → 模糊度极低（0-20）、！极高、……≈0
物种B：系统升级流（辰东中后期） → 模糊度中（80-120）、！中、……≈1.0
物种C：异界争霸流（猫腻/耳根） → 模糊度中高（120-160）、！低、……≈2.0（策略运用）
```

**都市·内部三物种**：

```
物种A：都市修仙（升龙道） → 模糊度中等、！低、……≈1（装逼不犹豫）
物种B：系统打工（大奉打更人） → 模糊度低、！中等、……≈2.5（推理主线）
物种C：生活流（苟在妖武） → 模糊度中等、！低、……≈1.5
```

**操作**：

```
给定你的小说 →
  1. 定位品类（矩阵匹配）
  2. 定位内部物种（风格匹配）
  3. 从代表作品中提取对应的模糊度/! /……/对话率范围
  4. 所有后续参数沿此范围生成
```

### 3.3 跨品类断层——为什么换品类你的写法应该完全不同

```
断层案例：仙侠 → 都市
  模糊度：  202.8  → 40-60      （不能再用"灰色东西""某种力量"）

  对话率： 20%    → 30-45%      （翻倍——最大的改变）
  句式：  中长   → 短中        （仙侠可以有长句装逼、都市长句=官方文书）
```

### 3.4 品类决策树——如果你的品类不在矩阵中

```

## 四、时间锚定：写作参数的"时代基准线"

### why：v4.4没有处理时间维度

v4.4给的都是"当下"的参数。但2005年的仙侠和2025年的仙侠完全不同。

**2005年仙侠**："此子不可留！"——反派说话像在念台词。感叹号7.2/千字。
**2025年仙侠**："这小子……"——反派停顿，省略号代替整句话。感叹号5.5/千字。

不是"2025年更好"——是"2025年的读者期待不同"。你不能用2005年的参数写2025年的书。

### 4.1 五期时代基准线（2001-2025）

基于502本全库数据的年代分组：

```
时期        年代      均句长   模糊度/千字  !!/千字  ……/千字  对话率  样本量  代表作者
═══════════════════════════════════════════════════════════════════════════════════
第一期      2001-2005  38.5       79         7.2       1.9      18%    25+    萧潜/血红/说不得大师/老猪
第二期      2006-2010  34.2      128         8.1       2.1      20%    55+    神机/辰东/猫腻/方想/忘语

```

**核心演化信号**：

```
均句长：38.5 → 27.8（-28%）——网络小说在缩短句子长度，爽文化+碎片化阅读驱动
模糊度： 79  → 178  （×2.3）——模糊表达增多，口癖化加重
！！：   7.2  → 5.5  （-24%）——感叹号使用趋于节制（除竞技/装逼流外）
……：   1.9  → 4.5  （×2.4）——省略号大幅增加，从"删除"到"关键标点"
对话率： 18%  → 28%   （+55%）——对话比例上升，沉默下降
```

### 4.2 时代×品类的交叉锚定——写作参数的三重叠加

**核心公式**：

```
当前写作参数 = 品类基准值 × 时代变化系数 × 作者调节因子

其中：
  品类基准值 = 品类指纹矩阵中的值
  时代变化系数 = 当前时代值 / 第二期（2006-2010）值（以第二期为"标准化"基准）
  作者调节因子 = 进化曲线中的作者参数（可选——对标特定作者时启用）
```

**计算示例**：

```
写历史文（2025年）：
  品类基准：模糊度=25.8, !!=2.6, ……=1.6, 对话=17%
  时代变化系数（vs第二期）：模糊度: 1.39, !: 0.68, ……: 2.14, 对话: 1.40
  最终参数：模糊度: 35.8, !: 1.8, ……: 3.4, 对话: 23.8%

写仙侠（2010年，对标辰东）：
  品类基准：模糊度=202.8, !!=5.2, ……=2.3
  时代变化系数=1.0（在基准期） → 无需时代调整
  作者因子（辰东-巅峰期!!=14.5, ……≈1.5）：
    最终!! ≈ 14.5（作者的!!是本品类的2.8倍）
    最终…… ≈ 1.5（作者的省略号少于品类平均值）
```

### 4.3 五条不可逆的时代演化红线

```
① 均句长只会更短（不会反弹到2001年的38.5）
② 省略号只会更多（从配角到主角——不会回到2010年前的2.0）
③ 对话率只会更高（每期+3-5%——不会降回20%以下）
④ 感叹号在非竞技/装逼品类中只会更少（成熟化的标志）
⑤ 模糊度有品类天花板（仙侠~220后不会无止境——"灰色"太多即是废话）

违反任何一条红线 → 读起来"这书不像现在写的"（年代错乱感）
```

### 4.4 七个古早陷阱（2015年前的写法，现在不能用）

```
陷阱1 "冷峻的山风呼啸而过，大地在颤抖" ← 2005年的史诗腔
解法：山风里带一点不确定——"冷风从山后翻过来，好像带了什么东西的影子"

陷阱2 "他的眼中闪过一丝精芒" ← 2010年的装逼
解法：省略"精芒"——"他眯了眯眼"或什么都不说

陷阱3 "此子不可留" ← 2008年的仙侠
解法：反派说"这小子……"然后停顿——省略号代替整句话

陷阱4 连续3个!以上 ← 2010年的热血
解法：竞技品类可，其他品类用……替代！

陷阱5 "淡淡道""冷冷道"中的副词 ← 2012年的写法
解法：不加副词——读者通过对话内容和上下文感知语态

陷阱6 全章节无对话 ← 2005年可，2025年不可
解法：每3段叙事至少嵌入一段对话

陷阱7 开篇世界观大段铺设 ← 2008年可，2025年不粘
解法：第一、二章建立角色→第三章开始角色即世界观导体
```

## 五、基础人味层（所有层级通用）

### why：这五个是人类语言的固有特征，缺任何一个就假

### 5.1 五个人味维度

```
犹豫 —— 说一半卡住、"算了不说了"、不确定自己要写什么
浪费 —— 不推动剧情的细节（抠指甲、灯泡不亮、压缩饼干味）
缺陷 —— 有粗糙的句子、有说不清楚的话、有口误
个性 —— 每个角色有独特的语言指纹
噪音 —— 走神、跑题、被打断、无意义的联想
```

### 你写的 vs AI写的——五个人味维度

```
维度     你手写的                              AI生成的
─────   ──────────────────────────────   ──────────────────────────────
犹豫    "他想说什么，张了张嘴，又闭上了。"     "他欲言又止。"（概括代替具体）
浪费    "灯泡不亮了。他踢了一脚桌子。"        每个细节都在推动剧情
缺陷    "怎么说呢，就是那种……算了不说了"       每句话都完整、正确、确定
个性    周黑塔崩出二两瓜子壳                   角色没有无意义的习惯
噪音    "说到哪了？哦对，刚才那个——"          逻辑永远清晰，从不跑题
```

### 5.2 硬约束（从数据中提炼的底线）

**1. 禁用词冷却**
- 同一形容词3章内不超过5次
- "什么东西"每章不超过2次
- "某种"每章不超过1次

**2. 长句保底**
- 每300字至少1个超过30字的句子
- 每章至少1个超过50字的"慢镜头"长句

**3. 废话保底**
- 每章至少1个不推动剧情的细节

**4. 语言失败保底**
- 每章至少1次"说不清/没说完/被打断"

**5. 负面情感保底**
- 每3章至少1次"无理由负面情绪"

### 硬约束 6：省略号经济学

v4.4省略号规则是"每章至少X个"。v5.0是——给定品类+时代+场景，省略号的用法和数量不同。

**核心：三维定价模型**

```
省略号密度 = 品类基底 × 时代系数 × 作者因子

品类基底（查品类指纹矩阵）：
  历史：1.6 / 竞技：~0.3 / 仙侠：2.3 / 都市：2.5 / 恐怖：3.1
  西幻：2.4 / 科幻：2.0 / 玄幻：1.8 / 末世：2.1

时代系数（查§四时间锚定）：
  第一期（2001-2005）：×0.42  第二期（2006-2010）：×0.47
  第三期（2011-2015）：×0.62  第四期（2016-2020）：×0.78
  第五期（2021-2025）：×1.00
```

**省略号的三种场景分配规则**：

```

╠════════════╬══════╬══════╬══════╣

║ 历史/架空  ║ 50%  ║ 30%  ║ 20%  ║

║ 科幻       ║ 20%  ║ 50%  ║ 30%  ║
║ 都市       ║ 40%  ║ 30%  ║ 30%  ║
║ 恐怖       ║ 35%  ║ 25%  ║ 40%  ║
║ 玄幻       ║ 25%  ║ 15%  ║ 60%  ║
║ 末世       ║ 30%  ║ 40%  ║ 30%  ║
║ 西幻       ║ 30%  ║ 30%  ║ 40%  ║
╚════════════╩══════╩══════╩══════╝
```

**省略号禁止清单**：

```
1. ❌ 用省略号代替具体的心理描写
2. ❌ 每句对话结尾都点省略号——AI偷懒信号
3. ❌ 省略号连续出现在3句以上
4. ❌ 恐怖品类以外的省略号用于"突然冒出一个东西"
5. ❌ 竞技/比赛场景的省略号用于角色决策
```

### 5.3 呼吸逻辑

**核心问题：** 如果每章都执行全部硬约束，20章后读者就能看出模式。

**解法：硬约束从"每章必须"改成"滑动窗口达标"。**

不追踪单章指标，追踪连续5章的窗口：
- 废话：5章里至少3章有
- 语言失败：5章里至少2章有
- 长句：5章里至少4章有
- 负面情感：5章里至少1次

### 5.4 严肃度波动

严肃度1-10全量标尺（简版，详细版见v5.0）：

```
1 · 番茄沙雕极致：感叹号>15/千字、省略号>10/千字
2 · 番茄轻松沙雕：感叹号10-15、省略号5-10
3 · 番茄轻快日常：感叹号5-10、省略号偶现
4 · 番茄质量中等：感叹号3-5、标点整体克制
5 · 番茄精品/起点中等：感叹号2-3、标点克制但不压抑
6 · 起点质量标准：感叹号1-3、长句比例上升
7 · 起点精品/深度番茄：感叹号<1、标点极致克制
8 · 网文文学性极限：标点近乎消失，靠逗号+破折号串长句
9 · 严肃文学级：标点极度克制，感叹号≈0
10 · 纯文学极致：无感叹号，标点=呼吸节奏
```

**节拍控制**：不要每章都用同一个严肃度。严肃度=情绪的音量旋钮。永远在转。

```
错误模式：严肃度一直维持在5-7
正确模式：2→3→4→6→8→3→2（锯齿形波动）
```

### 5.5 过程模拟指令

```
你不是在"生成文本"。你是"一个人凌晨3点在写小说"。

这意味着：
- 你有时候写得很顺，一气呵成；有时候卡在一个词上，想半天
- 你有时候觉得自己写得很好，有时候觉得"这段写得真烂"但懒得改
- 你偶尔会突然想到一个不相关的事，花一两句带过去
- 你对某些词有执念——你发现自己用了很多次，有点烦但改不了
- 你不确定某些细节对不对（"好像是这样的？不太确定"）
```

### 5.6 方向约束

**持久与灵活交替：** 每章至少1次"跳转"。

**节奏反直觉：** 高潮场景反而用长句慢写。日常场景反而用短句快过。

**信任读者：** 不要替读者总结。"擦肩而过也是相遇"是金句病。

### 5.7 比喻替代规则

"像……的"结构每章最多2次。超了用以下替代：

```
❌ 像冬天的风一样冷          → ✅ 风冷得像忘了穿裤子
❌ 像深海里的什么东西在动     → ✅ 管壁在跳——一下，两下，像心跳
❌ 像一片灰色的雾             → ✅ 雾是哑光的。不反光的那种。
```

### 5.8 缓冲句式

**核心规则：用逗号接，不要用句号切。**

```
❌ AI写的：急。但是稳。
✅ 你改的：呼吸很急促，但是气息很稳。
```

**你的缓冲词库：**
"或者说""怎么说呢""至少他看着是这么觉得的""说不清楚""大概""差不多""像是"

### 5.9 反AI三问（每次写完自检）

1. **这能拍出来/画出来吗？** — 检查是否足够具象。
2. **这是某个真实的人会说出来的话吗？** — 检查语言是否自然。
3. **去掉这句/这个词，影响核心意思吗？** — 删除冗余。

### 5.10 AI文字量化鉴别特征

| # | 特征 | AI 默认值 | 真人参考值 | 检测方法 |
|---|------|----------|-----------|---------|
| 1 | 句号碎片率 | >0.5/千字 | ≤0.1/千字 | 统计"X。Y。Z。"三连短句模式 |
| 2 | 省略号缺失 | <0.5/千字 | 中位0.9/千字 | 连续5章省略号<0.3则疑似AI |
| 3 | 感叹号偏高 | >8/千字（非热血题材） | 中位4.6/千字 | 非T1题材感叹>8则偏高 |
| 4 | 逗号密度偏低 | <40/千字 | 中位57.4/千字 | 信息密度不足 |
| 5 | 均句长过于均匀 | 波动系数<0.5 | ≥0.65 | 每句话差不多长=AI特征 |
| 6 | "像X"比喻过频 | >5/章 | ≤2/章 | 标准比喻过多=AI偷懒 |
| 7 | 模糊表达泛滥 | "什么东西/某种/似乎" >3/千字 | ≤1/千字 | AI用模糊词回避具体描写 |

**区分"克制型人类"和"AI"的关键指标：**
- 克制型人类（如升龙道 0.02 感叹）：省略号高（4.42）、逗号高（63.5）、长句多（59%）
- AI 克制输出：感叹低、省略也低、逗号偏低、句子均匀
- **核心区别：克制型人类用省略号和长句替代感叹号；AI 是所有标点都低，句子都短。**

### 5.11 吐槽型叙事

**核心机制（四层约束）：**

```
1. 吐槽锚定在角色视角上
2. 吐槽针对"荒诞"而非"叙事"
3. 吐槽是情绪调节器——放在情绪曲线的过热/过冷节点
4. 语言风格混搭——从一开始就建立"不正经"的前提
```

**适用场景：**
- 都市奇幻 / 轻喜剧 / 日常系题材 → 高频使用（每章1-3次）
- 史诗/严肃题材 → 低频使用（偶尔插入）
- 纯恐怖/纯悲情 → 禁用（破坏氛围）

## 六、质量分级

### why：番茄快餐和起点精品的"人味"定义完全不同

### 6.1 三个层级

```
┌──────────────────────────────────────────────────────────┐
│ T1 番茄快餐爽文                                           │
│ 人味 = 有梗 + 有名场面 + 能截图发群                       │
│ 字数：2000-3000/章  对话≥30%  节奏：钩子→爽+梗→钩子      │
├──────────────────────────────────────────────────────────┤
│ T2 番茄质量爆款                                           │
│ 人味 = 角色有弧光 + 情感有层次 + 世界有厚度               │
│ 字数：3000-5000/章  对话25-35%  节奏：铺垫→冲突→爽→余韵  │
│ 代表：诡秘之主、大奉打更人、道诡异仙                      │
├──────────────────────────────────────────────────────────┤
│ T3 起点精品                                               │
│ 人味 = 文字有质感 + 角色有灵魂 + 故事有余味               │
│ 字数：3000-6000/章  对话20-40%  节奏：跟着情感和故事走    │
│ 代表：夜的命名术、灵境行者、万相之王                      │
└──────────────────────────────────────────────────────────┘
```

### 6.2 T1 番茄快餐 Prompt 核心规则

```
1. 前100字必须有钩子
2. 好笑比好看重要。每500字至少一个梗或名场面
3. 每个角色必须有"记住点"
4. 对话≥30%。角色不许好好说话
5. 每300字一个小爽点
6. 允许跑题。跑题=人味
7. 口语化
8. 角色情绪可以混乱跳跃
```

### 6.3 T2 番茄质量爆款 Prompt 核心规则

```
1. 角色弧光：每个主要角色必须在"变化"
2. 世界观嵌入：通过角色经历展示
3. 情感层次：无理由的烦躁、莫名的怀念、自嘲式的心酸
4. 对话质感：潜台词和权力关系
5. 节奏呼吸：先慢下来，再突然爆发
6. 伏笔密度：每章至少埋1个
7. 语言质感：准确而非文学性
8. 梗的升级：笑完之后有点难受
```

### 6.4 T3 起点精品 Prompt 核心规则

```
1. 文字韵律：句式长短是"呼吸"不是"规则"
2. 意象与质感：比喻要有"想不到但一想就对"的质量
3. 对话层次：字面意思 + 潜台词 + 角色关系变化
4. 角色深度：角色不是"好人/坏人"——是"有自己逻辑的人"
5. 伏笔系统：每章至少埋1个伏笔，每卷至少回收2个
6. 平台节奏：每章结尾必须有"追读钩子"
7. 风格锚定：指定时按指定写，未指定时自动路由
8. 感官专精：选2-3种重点写
```

## 八、作者DNA

### why：这是第三层人味——"像你写的"，AI无法凭空生成

### 8.1 创作思维模式

```
① 架构先行，内容后填
② 直觉断路器：scope > 分析
③ 跨源合成——同时管理多个Agent
④ 失败即流程信号
⑤ 精力即瓶颈
⑥ 创作立场：不交出自己
⑦ 不交出自己 ≠ 不妥协
```

### 8.2 核心创作DNA

```
⑧ 真实经历 → 故事语言的翻译能力
⑨ 深化本能：不停留在第一层
⑩ 身体感觉先行
⑪ 真实矛盾 > 正邪对立
```

### 8.3 爽点观

```
你的爽点是"情感征服"，不是"力量碾压"。
→ 被女生爱慕、表白、倒追、大胆示爱都是爽点
→ 暧昧拉扯（Slow Burn）
→ 主动触碰（危机时刻拉一把）
→ 克制但真实的身体描写
→ 不是倒贴，是有来有往——两个清醒者的博弈
```

### 8.4 身体描写偏好

```
原则：不是单独开一段"她长得怎么样"——太刻意
→ 是写穿搭的时候自然带出身体线条
→ 是写动作的时候带出肌肉轮廓
→ 是用绳子/布料/汗渍这些"道具"勾勒曲线

禁用：不用"身材很好""前凸后翘"这种概括性描述
      不用大段外貌描写
      不用"让林无味看呆了"这种男性凝视视角
```

### 8.5 世界观设计偏好

```
悖论型世界观——每个规则都有反面：
→ "越强越危险"
→ "D级悖论"：越弱→两边都嫌弃→反而最安全
→ "保护区悖论"：饕餮建的保护区→噬种会袭击
→ "选择困境"：白天躲饕餮，夜晚躲噬种
```

### 8.6 语言指纹

```
【强偏好词】"真实的""选择""代价""不妥协"
【弱避免词】"突然""微微一笑""仿佛""就在这一刻"
【强偏好句式】"不是在...是在...""不是因为...是因为..."
【标点习惯】感叹号爆发 / 省略号犹豫 / 括号追加吐槽 / 破折号转折
【缓冲词】"或者说""怎么说呢""至少他看着是这么觉得的""说不清楚"
```

### 8.7 三种声音

**声音A：发疯文学（番茄男频）**
> "妈耶""臭**一个""哈批婆娘"
特征：口语炸弹、吐槽役、括号追加、情绪爆发

**声音B：自省写作（私人/复盘）**
> "分不清主要矛盾和次要矛盾""功不唐捐，玉汝于成"
特征：长句为主、引经据典、自我剖析不回避

**声音C：架空叙事（正经讲故事）**
> 修炼体系介绍、世界观铺陈、第三人称冷静视角
特征：描述性为主、信息密度高、冷静客观

**关键问题：AI默认只输出声音C。声音A和声音B被过滤掉了。**

### 8.8 作者DNA注入Prompt

```

审美：反差萌、打工系统、金手指有局限。
世界观：悖论型——每个规则都有反面，每个"安全"都有代价。
立场：不需要"打赢了"，需要的是"一直没交出自己"。

语言：现代网语×架空混搭，括号吐槽，专属词。
情感：情感征服（Slow Burn、暧昧拉扯、有来有往）。
毛病（必须保留！）：长句、跑题、括号追加吐槽。
使命感：为活生生的人物而写，为"不交出自己"而写。
```

### 9.3 品类专有感官混搭法

```
仙侠·嗅觉味觉混搭：药香+灵气的嗅觉 = "不是香气——是沁入丹田的药气"
  禁止：视觉占比在仙侠中超过75%

### 9.4 感官衰减律

```
规律：感官在一卷长篇小说中随时间衰减

  卷二：70-80%（开始失味觉/触觉）
  卷三及以后：40-60%（几乎全是视觉+听觉）

恢复策略：每3-5章检查一次感官分布
  → 如果视觉占比>70% → 立刻在下章添加本品的"弱势核心感官"
```

### 9.5 感官描写的"具体化"原则

```
❌ 模糊的感官描写（AI默认）：
   "他闻到了一股味道。" → 什么味道？读者闻不到。

✅ 具体的感官描写：
   "空气里有股甜味。不是好闻的那种甜——是肉烂了之后的那种。"
```

### 9.6 感官描写质量分级（L1-L3·v3.0）

L1：单感官报告 → "他闻到一股香味"（及格线）

                  又觉得不是桂花，是某种烧焦的糖"（优秀）
```

  触觉占比：译本8-12% vs 中文原作6-10%（译本触觉略高——英文文学偏好身体感受）
  嗅觉占比：译本1-3% vs 中文原作1-6%（译本嗅觉低——英文文学不强调嗅觉）
  味觉占比：译本0.5-1.5% vs 中文原作0.5-3%（译本味觉低）

核心发现：翻译文学的感官比中文原作更"视觉化"——译者倾向于保留原文的视觉描写，
但嗅觉/味觉等"文化特异性"感官在翻译中被削弱。
```

### 感官库v3.0检查清单

```
□ 本章的五感分配是否在品类参考范围内？
□ 视觉占比是否<70%？（超过=AI偷懒到"什么都看"）
□ 本品类的"弱势核心感官"是否至少出现了1次？
□ 感官描写是否有L2以上质量的混搭？
□ 连续3章是否有感官衰减迹象？（单一感官占比持续上升）
```

## 十一、省略号经济学 v6.0——从"多点几个"到"精确预算"

### why：v5.0省略号规则是"每章至少X个"，但品类×时代×场景需要不同的省略号

v4.4说"省略号越多越像人"。v5.0说"省略号在不同品类里意味着不同的事"。v6.0用502本全量数据验证并扩展了三维定价模型。

### 11.1 省略号不是什么

**误解一："省略号=没说完"**
→ 不是。血红用省略号不是"没说完"——是"每个省略号后面都有一整段没写出来的故事"。
→ 省略号是**信息容器**——读者往里面填内容。

**误解二："省略号多=写作退步"**
→ 二十年间省略号翻了2.4倍，这不是退步——是**对话占比上升**的必然结果。

### 11.2 三维定价模型（v6.0数据更新）

```
省略号总预算 = 品类基底 × 时代系数 × 作者调节因子
```

## 十三、作者进化曲线 v6.0——从"静态参数"到"动态轨迹"

### why：写参数不如写轨迹

给定一个作者，不是告诉你"他当前的参数"——是告诉你"他正朝哪个方向变"。你的小说在连载中——你需要的是一个**动态目标**，不是一个**快照**。

### 13.1 三大进化学规律

#### 规律① 头部作者的"成熟化学习曲线"（15/34证）

```
写完第4-6本书时，作者普遍经历"!↓ + 句长↓ + grey收敛"三降期：
  ! 递减：处女作8-14/千字 → 成熟作2-5/千字（-50%到-70%）
  句长缩短：42-50字 → 27-33字（-25%到-40%）
  grey收敛：广谱震荡（0↔668）→ 稳定区间（50↔250）
```

15个证实作者：辰东、猫腻、梦入神机、唐家三少、会说话的肘子、宅猪、西红柿、远瞳、山人有妙计、zhttty、文抄公、方想、滚开、猪头七、余云飞

**反例**：
- 土豆——不需要"成熟化"——从第一本就锁定了"退婚→打脸"循环
- 血红——没有收敛，保持了28年的grey震荡（22→44→89→92→155→192→251→668）
- 烽火戏诸侯——从都市文跳槽到仙侠——"进化"是品类切换

#### 规律② 品类×作者的"不可能三角"

```
一个作者不能同时拥有：高句长 + 高对话率 + 高频!
品类的自然分配：
  仙侠/西幻：选择高句长（35-50）+ 低对话率（15-20%）→ 放弃！
  都市/竞技：选择高对话率（30-45%）+ 高频! → 放弃长句
  历史/古言：选择中句长 + 极低! → 放弃对话率
```

#### 规律③ 省略号的二向性

```
省略号在作者版图中极端分化：
  留白派（辰东神墓5.5、文抄公持续攀升）：... = 意境空白 → 读者自己填
  停顿派（滚开0.5、百里玺0.3）：...不存在 → 所有空白都是句号或无声
没有作者同时在高句长+高省略号——因为长句+省略号=读者的迷失感。

## 十五、翻译文学标点指纹 v6.0——翻译腔指数TCI与译者指纹【v6.0新增】

### why：翻译文学的标点指纹与中文原作有系统性差异

v5.0没有翻译文学分析。v6.0基于路4的28本译本（覆盖阿西莫夫、马丁、托尔金、罗琳、刘易斯、洛夫克拉夫特、斯蒂芬·金、阿加莎·克里斯蒂等），首次建立了翻译文学的标点指纹体系。

### 15.1 核心发现：翻译腔的标点特征

```
翻译腔标点指纹 vs 中文原作：

标点类型      中文原作均值    译本均值     差异       解读
════════════════════════════════════════════════════════════════
句号/千字     19-25          28.0         +36%↑     译本句号偏高——句子被切断更频繁
逗号/千字     58-76          42.0         -28%↓     译本逗号偏低——长句被打断更少
!/千字        3.0-9.0        3.8          偏低      译本感叹号偏低于中文均值
……/千字       1.6-3.1        2.2          偏低      译本省略号偏低于中文均值
均句长        29-41          35.0         中等      译本句长接近中文均值
对话率        15-45%         20-30%       中等      译本对话率中等
```

**一句话**：翻译腔 = **句号偏高 + 逗号偏低**。这是最核心的标点差异。

### 15.2 翻译腔指数TCI（Translation Chauvinism Index）

```
TCI = (译本句号/千字 ÷ 中文原作句号均值) × (中文原作逗号/千字 ÷ 译本逗号/千字)

TCI > 1.2 → 强翻译腔（句号高+逗号低，读起来像"翻译体"）
TCI 0.8-1.2 → 中性（接近中文原作标点习惯）
TCI < 0.8 → 本土化翻译（标点已按中文习惯调整）
```

**28本译本TCI分布**：

| TCI区间 | 代表作 | 特征 |
|---------|--------|------|
| 1.3-1.5 | 托尔金三部曲、克苏鲁神话 | 强翻译腔——保留原文句式结构 |
| 1.1-1.3 | 冰与火之歌、银河帝国 | 中等翻译腔——部分保留原文节奏 |
| 0.9-1.1 | 哈利·波特、波西·杰克逊 | 中性——本土化与保留之间平衡 |
| 0.7-0.9 | 阿加莎·克里斯蒂、丹·布朗 | 本土化翻译——标点按中文习惯调整 |

### 15.3 译者指纹：本土化 vs 保留原文结构

```
本土化译者（TCI<1.0）：
  特征：句号低、逗号高、省略号多、对话率高
  效果：读起来像中文原作——"翻译腔"极弱
  代表：阿加莎·克里斯蒂中译本（TCI≈0.8）

保留型译者（TCI>1.2）：
  特征：句号高、逗号低、长句保留原文结构
  效果：读起来有"异国感"——你能感觉到这不是中文原创
  代表：托尔金中译本（TCI≈1.4）

混合型译者（TCI 1.0-1.2）：
  特征：标点在中英文之间取平衡
  效果：部分段落像中文原作，部分段落有翻译感
  代表：哈利·波特中译本（TCI≈1.0）
```

### 15.4 合集一致性检验

```
规则：同一作者/系列的不同译本，标点指纹应该高度一致。

检验方法：
1. 同一译者翻译的多本书 → 标点差异<15%为一致
2. 不同译者翻译的同一本书 → 标点差异>30%为"译者差异"
3. 同一系列不同卷 → 标点差异<10%为一致

案例：
  马丁《冰与火之歌》5卷 → 句号均值27-29/千字，逗号均值40-44/千字 → ✅一致
  托尔金《中洲三部曲》vs《中洲传奇合集》 → 句号差异<5% → ✅一致
  阿加莎85册 → 句号均值26-30/千字 → ✅高度一致（同一译者团队）
```

### 15.5 译本感官描写特征

```
v6.0发现：译本的感官描写与中文原作有系统性差异

感官类型    中文原作占比    译本占比      差异
════════════════════════════════════════════════
视觉        45-60%         50-65%       译本视觉占比偏高
听觉        15-25%         15-20%       基本一致
触觉        5-12%          8-15%        译本触觉占比偏高
嗅觉        2-6%           3-8%         译本嗅觉略高
味觉        1-3%           2-5%         译本味觉略高

解读：译本（特别是欧美文学）的触觉+嗅觉+味觉描写比中文原作更丰富
原因：欧美文学传统更重视"身体感知"的描写
操作：写中文小说时，可以参考译本的感官密度来增加"身体感"
```

### 15.6 翻译文学检查清单

□ 你的标点是否出现了"翻译腔"？→ 句号>25/千字+逗号<50/千字=疑似翻译腔

```

## 十六、翻译文学标点指纹（v6.0新增）

### why：网文分析的核心逻辑是"作者指纹"，但翻译文学的叙事声音经过了双重过滤（原作→译者→中文文本）。v6.0基于路4的28本译本分析，建立了翻译文学标点指纹体系。

**数据来源**：28本译本10KB+深度分析 + 翻译文学分析方法论v1.0

### 16.1 翻译腔指数TCI（Translation Chauvinism Index）

**定义**：TCI = 译本标点偏离中文原作均值的程度。TCI越高，翻译腔越重。

```
TCI计算公式：
  TCI = (|译本句号/千字 - 中文均值| + |译本逗号/千字 - 中文均值| + 
         |译本感叹/千字 - 中文均值| + |译本省略/千字 - 中文均值|) / 4

其中：中文均值 = 全库474本中文原作的各标点均值

TCI等级：
  TCI < 5    → 优秀本土化（几乎看不出是翻译）
  TCI 5-10   → 良好本土化（轻度翻译腔）
  TCI 10-20  → 中性翻译腔（可接受）
  TCI 20-30  → 重度翻译腔（明显翻译感）
  TCI > 30   → 极端翻译腔（几乎保留原文结构）
```

### 16.2 译本 vs 中文原作标点对比

```
标点          中文原作均值/千字   译本均值/千字    差异
═══════════════════════════════════════════════════════
句号          19.8               25.5            +29% ↑ 译本句号偏高
逗号          57.3               42.0            -27% ↓ 译本逗号偏低
感叹号         5.1                2.8            -45% ↓ 译本感叹大幅偏低
省略号         1.5                2.2            +47% ↑ 译本省略偏高
问号           3.6                3.8            +6%  ≈ 基本持平

```

**核心发现：**
```
1. 译本句号偏高20-37/千字 vs 中文原作19-25/千字
   → 原因：英文原作多用句号断句，译者保留了这个习惯

2. 译本逗号偏低20-56/千字 vs 中文原作58-76/千字
   → 原因：英文的从句连接在中文中变成了句号断句

3. 译本感叹号大幅偏低（-45%）
   → 原因：英文文学普遍克制感叹号，翻译时保持了这个克制

4. 译本省略号偏高（+47%）
   → 原因：英文的"..."在翻译中变成了中文省略号，且译者用省略号保留原文的犹豫/余韵

5. 译本破折号偏高（+25%）
   → 原因：英文的em-dash在中文中变成破折号，且译者用破折号做补充说明
```

### 16.3 译者指纹分类

**类型A：极端保留原文结构（TCI>20）**

```
特征：句号极高+逗号极低+均句极长
代表：托尔金三部曲（句号11.9、逗号19.7、均句长94.3字）
  → 英文定语从句直接翻译，均句长94.3字=全库最高
  → 读者感受："像在读英文的中文翻译"

操作：如果你要模仿这种风格→用超长句+低逗号+高句号
  但注意：这种风格在网文中几乎不可用——读者会跳过
```

**类型B：轻度翻译腔（TCI 10-20）**

```
特征：句号偏高+逗号偏低+均句中长
代表：银河帝国（阿西莫夫）、冰与火之歌
  → 保留了英文的句子节奏，但做了适度的中文适配
  → 读者感受："像在读外国小说的中文版"

操作：适合科幻/西幻题材——保留"异域感"但不违和
```

**类型C：优秀本土化（TCI 5-10）**

```
特征：标点接近中文均值+少量翻译腔残留
代表：哈利波特（感叹3.07、省略3.23——接近中文网文）
  → 译者做了大量本土化适配，标点习惯接近中文原作
  → 读者感受："像在读中文原创小说"

操作：如果你要写"翻译感"的中文→模仿这种标点分布
```

**类型D：翻译即创作（TCI<5）**

```
特征：标点完全中文化，几乎看不出是翻译
代表：极少数优秀译本
  → 译者的中文功底极强，翻译过程=再创作
  → 读者感受："这真的是翻译？"

操作：理想状态——但极难达到
```

### 16.5 译本感官描写特征

```
译本感官特征 vs 中文原作：
  视觉占比：译本65-75% vs 中文原作55-65%（译本更偏视觉）
  触觉占比：译本8-12% vs 中文原作6-10%（译本触觉略高——英文文学偏好身体感受）
  嗅觉占比：译本1-3% vs 中文原作1-6%（译本嗅觉低——英文文学不强调嗅觉）
  味觉占比：译本0.5-1.5% vs 中文原作0.5-3%（译本味觉低）

核心发现：翻译文学的感官比中文原作更"视觉化"——译者倾向于保留原文的视觉描写，
但嗅觉/味觉等"文化特异性"感官在翻译中被削弱。
```

### 16.6 合集一致性检验

**问题**：同一部作品的不同译本/不同卷册，标点风格是否一致？

```
检验方法：
1. 计算同一译本不同卷册的标点波动系数
2. 波动系数>0.5 → 标记⚠️（译者风格不一致）
3. 波动系数>1.0 → 标记🔴（可能是不同译者/译者风格突变）

案例：
  阿加莎·克里斯蒂85册合集 → 标点波动系数0.35（✅一致性良好）
  阿西莫夫17册合集 → 标点波动系数0.42（✅一致性良好）
  托尔金三部曲 → 标点波动系数0.28（✅一致性极好——同一个译者）
```

### 16.7 翻译文学标点操作规则

**如果你要写"翻译感"的中文小说（西幻/科幻）：**

```
1. 句号偏高：目标25-30/千字（vs 中文原作19-25）
2. 逗号偏低：目标45-55/千字（vs 中文原作57-76）
3. 感叹号偏低：目标1-3/千字（vs 中文原作5.1均值）
4. 省略号中等：目标1.5-3/千字
5. 均句长偏长：目标32-40字（vs 中文原作28-38）
6. 破折号偏高：目标3-5/千字（补充说明常用）
```

**如果你要写"纯中文"的网文：**

```
1. 不要使用译本标点模式——那是翻译腔
2. 逗号密度保持55-70/千字（中文的核心连接标点）
3. 句号密度保持15-25/千字（不要用句号碎片）
4. 感叹号按品类梯度控制（查§十二）
```

### 16.8 翻译文学标点检查清单

```
□ 如果写西幻/科幻，是否需要"翻译感"？如需要→查§16.7操作规则
□ 如果不需要翻译感，标点是否完全在中文原作范围内？
□ 是否出现了"翻译腔残留"？（句号>30/千字 且 逗号<45/千字）
□ 均句长是否>50字？（超过50字=可能有英文从句翻译腔）
□ 破折号是否>5/千字？（超过=可能在用破折号做补充说明——翻译习惯）
```

## 附录A：核心结论

**人味是四层东西：**
1. 通用人味（像人写的）：犹豫、跑题、有缺陷
2. 平台人味（达到质量标准）：T1有梗 / T2有深度 / T3有质感
3. 作者人味（像你写的）：你的知识、你的梗、你的审美、你的立场
4. 品类人味（这个品类该有的味道）：省略号用法、感官权重、感叹号预算、角色类型、标点指纹、情绪结构

前三层靠prompt。第四层必须数据驱动。v6.0的502本全量数据让第四层从"定性"升级到"定量"。

**v6.0新增三大体系：**
1. 品类标点指纹库（§十四）：10+品类的逗号/句号/感叹/省略/问号/破折号全量数据
2. 八种情绪结构（§十五）：37本🏆现象级作品的情绪曲线分类
3. 翻译文学标点指纹（§十六）：TCI指数 + 译者指纹 + 合集一致性

**最高优先级prompt：**
> "你不是在'生成文本'。你是'{作者名}'在凌晨3点写小说。

## 附录B：常见问题

**Q：我的品类是混搭的（比如"仙侠+都市"），怎么处理？**
A：确定一个主导品类。如果仙侠主导→用仙侠的参数，但对话率可以参考都市。不要两个都用——参数冲突会导致"世界感觉不对"。

**Q：v6.0比v5.0多了很多参数，会不会太复杂？**
A：v6.0的参数是"查表用的"，不是"记忆用的"。你不需要记住所有参数——你只需要知道：我的品类是什么 → 查矩阵 → 拿到参数 → 写。

**Q：我的小说跨越多个品类，怎么处理？**
A：跨品类时，所有参数必须立刻重置（§三.3跨品类断层）。不是"稍微调一下"——是换品类。

**Q：我的情绪结构不在八种之中怎么办？**
A：八种结构覆盖了90%+的网文类型。如果你的不属于任何一种，找最接近的，然后做微调。大部分混搭情绪结构都是"双峰+波浪"的组合。

**Q：我怎么知道我的文字"有没有人味"？**
A：最简单的检测方法：读出来。如果你读的时候觉得"这不像我说的话"→没有人味。反AI三问（§五.9）是更系统的检测方法。

**Q：翻译文学的TCI指数有什么用？**
A：如果你要写西幻/科幻且想要"翻译感"，TCI告诉你应该把标点调到什么水平。如果你不想有翻译感，TCI告诉你哪些标点习惯是"翻译腔残留"需要避免。
