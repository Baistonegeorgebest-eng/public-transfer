## 二、核心发现

### 1. 两人都超高感叹，但趋势相反

```
风凌天下：异世邪君(14.30) → 傲世九重天(11.95) → 碧落天刀(8.06) → 梦舞风云(5.39)
老鹰：    全球高武(13.44) → 万族之劫(18.04) → 星门(11.52)
```

- 风凌天下：感叹**递减**（从14.3降到5.4，-62%）——成熟期收敛
- 老鹰：感叹**振荡**（13→18→12）——题材驱动

**风凌天下在收敛，老鹰在振荡。** 这和辰东的"题材振荡型"类似。

### 2. 省略的差异

- 风凌天下：省略4-7（中高水平，持续使用）
- 老鹰：省略5.5-9.5（高水平，且在涨）

老鹰的省略比风凌天下更高。星门的9.49/千省略意味着**每100字就有近1个省略号**——这是全库前5的省略密度。

### 3. 逗号的差异

- 风凌天下：逗号44-62（中等）
- 老鹰：逗号73-86（超高）

老鹰的逗号密度远高于风凌天下。万族之劫的83.1和星门的86.2都在全库前15%。

**老鹰的句子比风凌天下复杂得多。**

### 4. 句号的差异

- 风凌天下：句号9-23（跨度大，从极低到中等）
- 老鹰：句号15-21（稳定中等）

风凌天下的句号跨度大（异世邪君仅8.7），说明他在不同时期使用不同的呼吸节奏。老鹰则很稳定。

### 5. 共同点：感叹+省略双高

两人有一个共同特征：**感叹和省略都高于全库中位数**。这意味着他们的叙事同时追求"情绪爆发"（感叹）和"悬念铺垫"（省略）。

这是热血爽文的标点指纹特征：
- 感叹高 = 情绪外放
- 省略高 = 悬念未完
- 两者结合 = "高潮+悬念交替"的爽文节奏

## 三、差异总结

| 特征 | 风凌天下 | 老鹰 |
|------|---------|------|
| 感叹趋势 | 递减(收敛型) | 振荡(题材驱动) |
| 逗号水平 | 中等(44-62) | 超高(73-86) |
| 省略水平 | 中高(4-7) | 高(5.5-9.5) |
| 句号跨度 | 大(9-23) | 稳(15-21) |
| 句子复杂度 | 中等 | 高 |
| 风格标签 | 热血+适度复杂 | 热血+高复杂度 |

**风凌天下是"简单的热血"，老鹰是"复杂的热血"。**
