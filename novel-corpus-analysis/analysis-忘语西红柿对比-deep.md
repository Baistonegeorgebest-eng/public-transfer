## 二、核心发现

### 1. 忘语：句号恒定型

忘语3部作品的句号在27.2-28.6之间，**变异系数仅2.5%**——这是全库最稳定的句号密度。

忘语找到一个句号节奏后就完全不再调整。他的凡人修仙传（27.5）和仙界篇（27.2）几乎是同一个指纹。

### 2. 西红柿：句号先降后升（U型）

```
星辰变(31.9) → 盘龙(35.6)↑ → 吞噬星空(29.4)↓ → 莽荒纪(32.4)↑ → 雪鹰领主(30.2)↓ → 飞剑问道(36.1)↑ → 沧元图(36.8)↑
```

西红柿的句号有波动，但后期趋势上升（从30.2到36.8）。和猫腻的U型不同，西红柿的句号是**波动+缓慢上升**。

### 3. 两人都是"中高句号型"

- 忘语：句号27-29（全库75%分位附近）
- 西红柿：句号29-37（全库75-90%分位）

两人的句号都比全库中位数22高出20-70%。这意味着他们的句子更短、断句更频繁。

### 4. 感叹的差异

- 忘语：感叹1.4-2.8（低感叹区间）
- 西红柿：感叹2.2-7.9（跨度大，从低到中高）

西红柿的感叹跨度远大于忘语。西红柿从星辰变的2.24到吞噬星空的7.86（+250%），而忘语的感叹变化仅±50%。

### 5. 省略的差异

- 忘语：省略0.4-1.4（极低）
- 西红柿：省略2.0-5.2（中等偏高）

西红柿比忘语更多使用省略号。忘语几乎不用省略号（凡人修仙传仅0.35/千），叙事非常确定。

## 三、共同特征：感叹3-4=成熟期平衡点

两人的感叹都在向3-4区间收敛：
- 忘语：凡人修仙传2.80、玄界之门2.70
- 西红柿：沧元图2.47、星辰变2.24（晚期作品都在低位）

**"感叹3-4/千字是网文成熟期自然平衡点"这个假说在两人身上再次得到验证。**

## 四、学术意义

### 1. "句号流"的定义

忘语和西红柿证明了存在一种"句号流"写作策略：通过较高的句号密度（27-37/千字，比中位数22高20-70%）来控制叙事节奏——句子短、断句频繁、阅读轻快。

这种策略适合：
- 升级流/系统文（需要快速推进）
- 长篇连载（需要保持阅读轻快感）

### 2. 忘语的"恒定型"vs 西红柿的"波动型"

忘语找到句号节奏后就锁定，不再调整。西红柿则在每部作品中微调句号。

这可能反映两种不同的写作策略：
- 忘语：**效率型**——找到最优节奏后量产
- 西红柿：**探索型**——每部作品都尝试微调
