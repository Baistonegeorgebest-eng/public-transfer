## 一、福利内容认定标准 v2

### 1.1 七层体系

| 层级 | 类别 | 说明 | 上架安全 |
|------|------|------|---------|
| L1 | 身体部位描写 | 锁骨/腰肢/腿部/足部/曲线 | ✅ 最安全 |
| L2 | 服饰描写 | 丝袜高跟/裙装/内衣/特殊服饰 | ✅ 安全 |
| L3 | 亲密动作 | 靠近→搂住→亲吻（三级递进） | ✅/⚠️ 视程度 |
| L4 | 暧昧反应 | 脸红/心跳/喘息/声音 | ✅ 安全 |
| L5 | 暧昧氛围 | 独处/意外/卧室/温泉 | ⚠️ 需技巧 |
| L6 | 暗示对话 | "别在这里"/"你想要"/"闭上眼睛" | ⚠️ 需技巧 |
| L7 | 事后暗示 | 整理衣服/裹被子/清晨 | ✅ 安全 |

### 1.2 能上架 vs 不能上架

| 类型 | 能上架（起点/番茄） | 不能上架（VIP/订阅福利） |
|------|-------------------|----------------------|
| 身体描写 | 锁骨/腰线/腿部轮廓/足部 | 具体器官描写/裸露描写 |
| 服饰 | 丝袜高跟/裙装/内衣暗示 | 脱衣过程详细描写/裸体描写 |
| 亲密动作 | 搂住/抚摸/触碰/亲吻(轻度) | 性行为过程描写 |
| 暧昧反应 | 脸红/心跳/喘息/娇羞 | 性反应描写/高潮描写 |
| 氛围 | 独处/意外接近/温泉/卧室 | 性暗示场景/床戏详细描写 |
| 对话 | "别在这里"/"闭上眼睛" | 直接的性暗示/色情对话 |
| 事后 | 整理衣服/清晨/对话暗示 | 详细的事后描写 |

**核心原则：能上架的内容 = 暗示但不直白，用感官代替器官，用留白代替描写。**

### 1.3 VIP/订阅福利的特征

VIP福利内容通常出现在：
- 作者群/粉丝群的订阅福利章节
- 番茄/起点的"番外"章节
- 微博/公众号的"完整版"
- 作者自留的"原稿"

**特征：**
- 比正式上架版多30-50%的亲密描写
- 去掉了打断/克制，补全了留白部分
- 增加了具体的感官细节
- 保留了情感线，不是纯色情

## 四、福利技法体系

### 4.1 三大支柱技法

#### 支柱一：身体描写（L1）

**原则：写轮廓不写器官，写动态不写静态。**

```
❌ 她的胸很大
✅ 她深吸了一口气，胸前的衣料绷紧了一瞬

❌ 她的腿很长
✅ 她交叉双腿，裙摆滑到了膝盖以上

❌ 她的臀部很翘
✅ 她转身的时候，裙摆画了一个弧线
```

**按部位的安全写法：**

| 部位 | 安全写法 | 危险写法 |
|------|---------|---------|
| 锁骨 | 锁骨下方一小片雪白的肌肤 | 直接描写胸部 |
| 腰肢 | 盈盈一握的腰线/水蛇般的腰肢 | 腰臀比/具体数字 |
| 腿部 | 修长的美腿/裹在丝袜中的小腿 | 大腿内侧/腿根 |
| 足部 | 玉足/纤足/脚踝/丝袜包裹的脚 | 直接描写裸足细节 |
| 臀部 | 腰线下/裙摆弧度/背影曲线 | 直接描写臀部 |

#### 支柱二：服饰描写（L2）

**三件套原则：上装+下装+足部，三件同时出现，每件有细节。**

**按世界观适配：**

| 世界观 | 上装 | 下装 | 足部 |
|--------|------|------|------|
| 现代都市 | 衬衫/吊带衫 | 短裙/包臀裙 | 丝袜+高跟 |
| 西幻 | 精灵丝织长裙 | 薄绸织袜 | 绑带长靴 |
| 仙侠 | 仙裙/法袍 | 罗袜/纱裙 | 云履/绣花弓鞋 |
| 末世 | 品牌运动内衣 | 品牌弹力裤 | 品牌帆布鞋 |
| 古风 | 织锦长裙 | 薄绸罗袜 | 锦缎翘头履 |

**动作代替静态：**

```
❌ 她穿着黑色丝袜和高跟鞋
✅ 她低头整了整大腿上的黑色丝袜，指尖从膝盖内侧轻轻抹过，将皱褶抚平
```

#### 支柱三：亲密动作（L3）

**三级递进：**

| 级别 | 动作 | 场景 | 触感词数 |
|------|------|------|---------|
| 轻度 | 靠近/并肩/挽住/搀扶 | 日常互动 | 1-2个 |
| 中度 | 搂住/握住/抚摸/蹭 | 情感升温 | 2-3个 |
| 重度 | 亲吻/压在/缠绵 | 特殊节点 | 3-5个 |

**男性主动原则：**
```
❌ 她的脚很美
✅ 他伸出手，轻轻握住了她穿着丝袜的脚踝
```

## 六、VIP/订阅福利学习要点

### 6.1 VIP福利与上架版的区别

| 维度 | 上架版 | VIP福利版 |
|------|-------|----------|
| 打断/克制 | 有（门响了/有人来） | 去掉或延迟 |
| 留白 | 30%想象空间 | 10-15%想象空间 |
| 感官词密度 | 2-3个叠加 | 4-5个叠加 |
| 亲密程度 | L2-L3为主 | L3-L4为主 |
| 描写长度 | 100-200字 | 300-500字 |
| 事后暗示 | 简短 | 详细 |

### 6.2 VIP福利的学习价值

VIP福利内容的价值不在于"更色情"，而在于：
- **更完整的感官词链**：4-5个叠加的触感描写
- **更自然的亲密递进**：从轻度到重度的流畅过渡
- **更丰富的女性反应**：多层次的暧昧反应描写
- **更真实的氛围营造**：环境细节+五感描写

**学习重点：学技法，不学尺度。**

### 6.3 从VIP内容提炼的技法

| 技法 | 上架版写法 | VIP版写法 | 学习点 |
|------|----------|----------|--------|
| 触感词链 | 滑腻而温热 | 滑腻、细腻、温润、弹性十足 | 词链叠加的节奏 |
| 亲密递进 | 直接握脚 | 靠近→触碰→握住→触感→反应 | 递进的层次感 |
| 女性反应 | 脸红 | 脸红→心跳→喘息→发软→声音变化 | 反应的层次感 |
| 打断时机 | 突然打断 | 累积到临界点再打断 | 打断的张力 |

## 七、写作自检清单

### 基础检查
- [ ] 三件套齐全（上装+下装+足部，每件有细节）
- [ ] 有动作细节（不是静态"她穿着"）
- [ ] 触感词叠加 ≥ 2个
- [ ] 男性有主动触碰/主导动作
- [ ] 女性反应有层次（面部→身体→声音）

### 合规检查
- [ ] 无器官直称
- [ ] 无具体性过程描写
- [ ] 无"湿润/进入"等敏感词
- [ ] 女性挣扎 ≠ 激烈反抗
- [ ] 打断/留白/克制至少一处
