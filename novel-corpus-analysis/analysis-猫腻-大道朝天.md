## 二、开局：苏轼的词

**Ch1「三千里禁」**：

> "四大从来都遍满，此间风水何疑。故应为我发新诗……（苏轼，临江仙，风水洞作，以为题记。）……朝天大陆南方，一片青山绵延数千里……"

猫腻在这里用苏轼的词做章首——不是玄幻小说的惯例，不是紧张的第一个镜头，而是**诗词+地理介绍**。这是一种"文人小说"的自觉——猫腻在从头到尾告诉读者："我写的不是爆发力故事——我写的是**慢火**。"

## 三、在猫腻进化中的位置

大道朝天是猫腻的**"边界测试"**——他在用最慢的速度、最少的感叹、最短的句子来写一个仙侠故事。这是在试探**读者的忍耐上限**。

```
猫腻均句长进化:
  朱雀记: 38.9字 → 庆余年: 46.7 → 间客: 50.5 → 将夜: 44.5 → 择天记: 40.1 → 大道: 30.2
                                         ↑ 极长                         ↑ 极短
```

从50.5字的间客到30.2字的大道朝天——猫腻在生涯后半段从"延长"转向了"压缩"。大道朝天把猫腻的叙述句压缩到了近乎西红柿的水平。
