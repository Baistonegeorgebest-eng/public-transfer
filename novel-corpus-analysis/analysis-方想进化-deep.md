## 二、核心发现

### 1. 方想的"超稳定性"

方想5本的逗号在50-65区间，句号在25-31区间，均句在25-30区间——**核心指标的变异系数全部低于10%**。

这与番茄的稳定性类似，但方想比番茄更稳定：
- 番茄逗号变异系数6.4%
- 方想逗号变异系数10.4%（稍微大一点，因为师士传说偏低）

### 2. 感叹：先升后降

```
师士传说(5.53) → 卡徒(4.97) → 不败战神(6.06) → 修真世界(7.84) ← 峰值 → 五行天(3.69)
```

方想的感叹不是单调收敛，而是**先升后降**：
- 早期到中期：感叹从5.53升到7.84（修真世界是峰值）
- 晚期（五行天）：回落到3.69

修真世界(7.84)是方想最"热血"的作品。这部修仙题材需要更多战斗场面和情绪表达。

### 3. 省略号：保持低位

方想的省略号一直很低（0.47-1.82），远低于全库中位数(2.0)。**他几乎不用省略号留白**——叙事风格是直叙型，不依赖悬念符号。

### 4. 段均：持续缩短

```
师士传说(62.0) → 卡徒(55.3) → 不败战神(42.8) → 修真世界(42.6) → 五行天(40.8)
```

段均从62降到41，降幅34%。这是方想最显著的"呼吸"变化——**段落越来越短，呼吸越来越快**。

师士传说的62字段均是方想的"长段落期"——机甲战斗描写需要长段落来展开。后期作品段落缩短，叙事节奏加快。

### 5. 短句率：稳定在17-19%

方想的短句率（≤10字句子占比）稳定在17-19%，和番茄(19-22%)相似。这说明**方想也是"短句快呼吸"风格**——每5-6句话有一句是短句。

对比：
- 猫腻：8-12%（长句流）
- 番茄：19-22%（短句流）
- 方想：17-19%（**短句流，与番茄同类**）

**方想的核心指纹：低省略+短句+中等逗号+偏高感叹。** 他是"短句直叙型"——不用省略留白，不追求信息密度极致，靠短句和快节奏维持阅读体验。

| 维度 | 方想 | 我吃西红柿 |

方想和番茄是"同类型不同子类"——都是短句快呼吸，但方想更"干脆"（省略极低），番茄更"留白"（省略中等）。

## 五、进化模式总结

方想的进化模式：**感叹先升后降 + 核心指标极稳 + 段均持续缩短 + 省略长期低位**

关键词：**稳态**。方想从第一本就确立了核心节奏（短句+中等逗号+低省略），后续作品只在感叹强度和段落长度上做微调。

他和番茄、忘语属于同一类"稳态型"作者：找到节奏后不再大幅改变。与梦入神机、天蚕土豆的"剧变型"形成鲜明对比。
