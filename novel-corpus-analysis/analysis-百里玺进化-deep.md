## 二、核心发现

### 1. 感叹：从热血到冷笔的三级跳

```
仙府(7.74) → 紫府(3.09, -60%) → 我是仙凡(5.64) → 仙城(4.38) → 百炼(1.47, -81%)
```

百里玺的感叹不是线性递减，而是**阶梯式收敛**：
- 第一阶：仙府之缘(7.74)——早期作品，热血修仙
- 第二阶：紫府→仙城(3-5区间)——中等情绪，稳定写作
- 第三阶：百炼成仙(1.47)——成熟期冷笔，全库修仙文中最低感叹之一

**百炼成仙的感叹1.47是极端值**——对比同为修仙文的忘语(凡人5-6)、耳根(仙逆8-12)，百里玺在961万字的超长篇中保持了极致的冷笔。

### 2. 逗号：持续膨胀，全库罕见

```
仙府(56.5) → 紫府(61.7) → 我是仙凡(60.5) → 仙城(68.9) → 百炼(76.2)
```

逗号从56.5涨到76.2，增幅35%。**百炼成仙的逗号76.2/千是全库前5%水平**——每1000字出现76个逗号，意味着句子内部高度嵌套。

对比：猫腻逗号53-63，忘语逗号55-63，百里玺最终形态(76.2)比他们高出20-40%。

### 3. 省略：全库最低区间

省略始终在0.77-1.52之间——**全库最低水平之一**。百里玺几乎不用省略号，风格极为干脆。

对比：风凌天下省略2-9，肘子省略1-10，百里玺的省略稳定在1左右。

### 4. 均句：持续增长

```
26.0 → 29.1 → 26.2 → 33.7 → 35.1
```

均句从26字涨到35字，增幅35%。结合逗号膨胀，说明百里玺的句子越来越长、内部结构越来越复杂。

### 5. 长句率：飞跃

```
31.8% → 39.4% → 32.7% → 47.7% → 51.0%
```

百炼成仙有51%的句子超过30字——**全库前15%水平**。

## 四、进化模式

百里玺的进化模式是**感叹收敛+逗号膨胀+句长增长**的三重叠加：
