## 二、核心发现

### 1. 感叹"天花板锁死"

猫腻6部作品的感叹密度全部低于1.52/千字，**全库280本中感叹低于1.5的仅有约25本**，猫腻独占6本。

对比：
- 网文中位数：~4.0/千
- 猫腻范围：0.84-1.52
- **猫腻感叹仅为全库中位数的1/3-1/4**

这说明猫腻的写作风格从根本上排斥感叹号——不是"少用"，而是几乎不用。他的情绪表达完全通过句式、词汇和节奏完成，不依赖标点。

### 2. 句号U型曲线

句号密度呈现清晰的U型：

```
朱雀记(22.1) → 庆余年(18.1) → 间客(15.8) ← 最低点 → 将夜(18.6) → 择天记(24.5) → 大道朝天(28.1)
```

**解读：**
- 早期（朱雀记）：句号22.1，段落较长，标点尚在探索期
- 成熟期（间客）：句号降到15.8，句子极长（均句50.1字），这是猫腻文笔最"密集"的阶段
- 晚期（大道朝天）：句号回升到28.1，句子变短（均句28.8字），风格回归简洁

**间客是猫腻的标点指纹极值点**——句号最低、均句最长、段均最长。这部科幻+机甲题材让猫腻的长句能力发挥到极致。

### 3. 省略号渐降

```
朱雀记(3.54) → 庆余年(3.25) → 间客(2.55) → 将夜(2.03) → 择天记(2.35) → 大道朝天(2.74)
```

省略号从3.54降到2.03，再微升到2.74。整体趋势下降但不归零。和血红的"开天录转身"不同，猫腻的省略号变化是渐进的。

### 4. 逗号稳定

逗号密度在53.7-63.1之间波动，**变异系数仅6.8%**，是全库最稳定的逗号密度之一。

这说明猫腻的句子复杂度（从句嵌套程度）从始至终没有大的变化——他的写作节奏是稳定的，变的是句号（呼吸频率）和感叹（情绪强度）。

## 三、与全库对比

| 指标 | 猫腻6本均值 | 全库中位数 | 猫腻位置 |
|------|------------|-----------|----------|
| 感叹 | 1.02 | 4.0 | **后5%** |
| 省略 | 2.74 | 2.0 | 中等偏高 |
| 逗号 | 59.4 | 58 | 中等 |
| 句号 | 21.2 | 22 | 中等 |
| 均句 | 38.5 | 33 | 前25% |
| 段均 | 57.7 | 45 | 前20% |

猫腻的核心特征：**感叹极低 + 均句偏长 + 其余指标中等**。他不是通过标点密度来区分自己，而是通过感叹的极度克制和句子的适度长度。

## 四、间客的特殊性

间客在猫腻作品中是一个异类：

- 段均79.7字（全库前10%）
- 均句50.1字（全库前15%）
- 句号15.8（全库后10%）

间客的标点指纹更接近辰东的长句流，而非猫腻自己的其他作品。这可能与间客的题材有关——机甲+科幻需要大量的技术描写和战斗场景，这些场景天然适合长句连续叙事。

## 五、进化模式总结

猫腻的进化模式：**感叹天花板锁死 + 句号U型曲线 + 省略渐降 + 逗号恒定**

这是一个"成熟型"作者的典型指纹：核心风格（低感叹、稳逗号）从第一本就确立，后续作品只在句号（呼吸频率）上做微调。

与其他作者对比：
- 和天蚕土豆不同（省略归零的剧烈变化）
- 和辰东不同（题材振荡型，感叹起伏大）
- 和血红不同（有明确转身点）

猫腻没有转身点，没有剧烈变化，只有渐进的U型回归。这是"天赋型文笔"作者的指纹特征——风格从一开始就是完整的，后续只是在做减法和微调。
