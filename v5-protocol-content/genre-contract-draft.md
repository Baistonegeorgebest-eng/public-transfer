## §X 品类叙事契约

**为什么要这一章**

v4.4告诉你"用什么标点、写什么感官"——但它假设所有品类用同一套标准。
实际情况：仙侠的grey=202.8，历史文的grey=25.8。差了7.9倍。给历史文套仙侠的节奏 = 写成散文，给仙侠套历史文的节奏 = 写成干柴。

这一章解决的是：每一类小说，**天生命定的叙事参数**是什么。不是"应该写得好"——是"这类小说在结构上就没有那种写法"。

### X.2 每个品类的叙事契约

以下每个小节 = 一套完整的品类叙事DNA：参数基准 + 叙事逻辑 + 代表作案 + 禁脔。

#### X.2.1 历史/架空 —— 策略叙事，不要渲染，要逻辑

**参数基准**：
```
grey       = 25.8（全库最低，比仙侠低7.9倍）
均句长     = 41.2（全库最高之一）
句号/千字  = 28.5（句子少但长——因为逻辑链不能断）
!/千字     = 2.6（全库最低——朝堂不是战场，没人对密折大喊）
省略号/千字 = 1.6（全库最低——政治对话不吞吞吐吐）
```

**叙事逻辑**：
历史文本质上是**信息博弈**。叙事靠对话+决策+谋略推进，不需要内心渲染。当一个角色通过行动和对话表达了意图，再用grey去"描写他的内心"就是冗余——读者已经在对话中读出了他的计算。

长句(41.2字)不是修辞风格，是逻辑需求：策略思维的表现形式是"因为A所以B，而C导致D，因此选择E"。短句会使论述碎片化，看起来像"这个角色不会深思熟虑"。

**范式**：
- 秦吏(grey=7，全库历史最低) → 章节推进全来自"法律条文+行政智慧"
- 绍宋 → 军事历史中的信息密集型叙事
- 宰执天下 → grey在30-50区间，典型的宋代权谋密度

**禁忌（写给这种品类就是自毁）**：
- ❌ grey>60 —— 超过这个值，读者会说"拖沓"，实际上是品类契约被破坏了
- ❌ 均句长<35 —— 短句让策略阅读像"碎片"，失去连贯感
- ❌ !/千字>5 —— 朝堂上出现感叹号等于"皇帝在喊"

**与时代的关系**：
历史文是grey最"保守"的品类。从2006(回到明朝当王爷)到2020(绍宋)，grey始终在25-55区间——没有出现时代性的grey膨胀。在所有品类中，历史文是叙事契约最不可动摇的。

---

#### X.2.2 无限/综穿 —— 规则叙事，长句是宿命

**参数基准**：
```
均句长     = 53.0（全库最高，因为"规则必须解释"）
grey       = 42.5（世界设定通过展示而非沉思传达）
句号/千字  = 21.2
省略号/千字 = 1.8
```

**叙事逻辑**：
无限流每进入一个新世界，必须向读者/角色解释规则、力量体系、威胁等级。这种"规则说明文"天然产生长句。53字均句长不是"文笔冗长"——是**功能需求**。

一个典型句子：
> "主神空间中浮现出金色的文字，上面写着本次轮回世界的三条规则：第一，不得透露主神存在；第二，任务目标是保护关键人物存活至最终事件；第三，违规者将被扣除奖励点数并强制传送回主神空间。"

这种句子在玄幻里是不可接受的冗笔，在无限流里是**必须的**——没有它，接下来50章没有意义。

**为什么grey不高**：
虽然句子很长，但人物不需要"打坐悟道"。心理活动通过"对规则的分析和预判"自然呈现——不需要单独的沉思段落。

**挑战**：
无限/综穿样本仅3本（zhttty系列）。但3本的均句长高度一致（50-55），说明这不是个体风格问题——是品类结构决定的。这个品类的叙事契约是所有品类中**最基本的约束**。

**禁忌**：
- ❌ 跳过规则解释 → 读者不知道"为什么"
- ❌ 短句写规则 → 显得不严肃
- ❌ grey过高 → 冗长不是深度，分析和策略才是

#### X.2.3 游戏/竞技 —— 峰值叙事，感叹号经济学

**参数基准**：
```
!/千字     = 9.0（全库最高，是历史文的3.5倍）
grey       = 47.5（不靠描写取胜）
均句长     = 35.6
省略号/千字 = 2.4
```

**叙事逻辑**：
竞技文是**峰值经济学**的教科书级案例。

足球/电竞的"高潮"频率天然比其他品类高——一场比赛可以有3-5个"进球/绝杀"，每一个都是独立的情感峰值。而仙侠一个大境界突破要铺垫几十章，一两年才有一次。这不是"写得好不好"的问题——是品类结构决定了**高潮点的频次上限**。

关键数据：
- 猪头七系列（足球竞技）: !/千字 = 7-12 —— 全库最高区段
- 林海听涛（足球竞技）: !/千字 = 6-8 —— "克制"版竞技文

同一品类内的6-12 vs 7-12的差异说明：感叹号密度不是纯品类决定——作者的"情绪投资策略"是第二因素。但无论如何，竞技文的!底线(6)已经高于大多数品类的!上限。

**关键时序**：
林海听涛的!/千字从2009(冠军传奇)的5.5 → 2019(绿茵峥嵘)的4.5 —— 十年间微降。趋势说明竞技文在向"克制"方向微调，但品类根基不变。

**禁忌**：
- ❌ !/千字<5 → 竞技文没有感叹号 = 比赛没有进球
- ❌ grey>80 → "他站在球门前，感受着草皮的柔软，回想起童年第一次踢球的下午……" → 读者跳过
- ❌ 均句长>42 → 竞技文长句 = 慢动作回放，破坏比赛节奏

#### X.2.4 科幻/末世 —— 设定叙事，grey是一个变量

**参数基准**：
```
grey       = 96.9
均句长     = 39.2
!/千字     = 4.2
省略号/千字 = 2.9
```

**叙事逻辑**：
科幻品类的grey离散度极大：从纯"设定展示"（grey≈20-40）到思辨型科幻（grey≈500+）。均值96.9掩盖了两种截然不同的叙事逻辑：

**A. 硬设定型**（grey低——小兵传奇、超神机械师）
→ 科幻是"背景板"。叙事手法更接近竞技/历史——靠事件推进，不靠内心渲染。

**B. 思辨型**（grey高——三体、弗诺·文奇、阿西莫夫）
→ 科幻是"主题"。叙事需要大量"对技术的沉思、对人类命运的感悟"来承载主题——但注意：译本作家中阿西莫夫的grey并不高。

**区别于仙侠的关键**：
仙侠的grey=202.8是"修炼"的篇幅需求。"修炼"天然需要内心过程填充。科幻的grey波动则取决于"作者打算把科幻当工具还是当主题"。

与时代趋势：
2016-2020的"效率革命"期，科幻grey整体在下降——与整体行业趋势一致（全库grey从178→122→97）。

**禁忌**：
- ❌ 忽视"设定解释"的节奏——科幻读者的困惑是致命伤
- ❌ grey跳跃到200+但没有对应主题深度 → "故弄玄虚"
- ❌ !/千字<2 → 末世文最怕"末世平淡"

---

#### X.2.5 西方奇幻 —— 平衡叙事，标准化品类

**参数基准**：
```
grey       = 106.5（几乎全库最接近均值）
均句长     = 35.0（接近全库均值）
!/千字     = 4.8（接近全库均值）
省略号/千字 = 2.6（接近全库均值）
```

**叙事逻辑**：
西方奇幻（亵渎、佣兵天下、琥珀之剑、恶魔法则）在所有品类中参数最"标准"。不是平庸——是"奇幻的叙事结构恰好是网文的均值状态"。

可能原因：
- 译本基底：西方奇幻的叙事节奏受魔戒/哈利波特等译本影响
- 受众多样：奇幻读者群跨越"爽文化"和"文学性"两端
- 世界设定天然需要适中的grey（既不能干燥如历史，也不能厚重如仙侠）

**禁忌**：
- ❌ grey<60 → 奇幻"轻薄化"，失去史诗感
- ❌ !/千字>7 → 不是所有的奇幻都需要龙焰般的情感爆发
- ❌ 省略号>4 → 奇幻对话适合"庄重"口吻

---

#### X.2.6 都市/现实 —— 口语叙事，最贴近听众

**参数基准**：
```
!/千字     = 6.5（仅次于竞技文8.9）
grey       = 129.2
省略号/千字 = 2.8
均句长     = 37.9
```

**叙事逻辑**：
都市/现实品类的叙事特点：最接近"日常说话"的节奏。

!/千字=6.5高于仙侠的4.9和玄幻的4.3——因为都市对话中的"情绪峰值"频率更高。都市生活的情节=职场冲突、情感纠葛、人际摩擦，每一个小高潮对应一个感叹号。而仙侠/玄幻的"高潮"往往是大规模战斗/境界突破，频次低但强度大。

grey=129.2高于历史/竞技/无限等"事件驱动"品类——都市需要更多的"日常生活的质地感"。但这种grey不是"文笔好"，是"生活描写不能跳过"的结构需求。

品类分层现象：
- 鉴宝型（黄金瞳）→ grey偏低（70-90），事件驱动
- 情感型（我的26岁女房客）→ grey偏高（180-250），情感驱动
- 都市异能（我在精神病院学斩神）→ grey≈都市均值120-150，但!/千字更高

**禁忌**：
- ❌ grey<80 → 都市文失去"生活的感觉"
- ❌ !/千字<4 → "这个话题不能喊"——但都市就是要能喊的
- ❌ 均句长>45 → 都市长句显得"端着"

---

#### X.2.7 玄幻/异界 —— 均衡叙事，规模=稳定

**参数基准**：
```
grey       = 132.9
样本       = 44本（全品类最多）
均句长     = 36.2
句号/千字  = 22.2
!/千字     = 4.3
```

**叙事逻辑**：
玄幻品类的叙事参数是所有品类中**最稳定的**。

解释：44本的巨大样本容量使品类均值高度可靠。玄幻的叙事结构="升级+战斗+探索"，三个要素各需要中等grey、中等句长、中等情感密度。不是"中庸"——是**品类的三要素恰好拉平了参数**。

品类内部差异（44本中的极端值）：
- 斗破苍穹（土豆）→ grey极低（40-60），纯战斗推进
- 盘龙/星辰变（西红柿）→ grey偏低（60-90），修炼以速度取胜
- 诡秘之主（乌贼）→ grey≈150，思辨型玄幻
- 完美世界（辰东）→ grey≈120-160，史诗型玄幻

与仙侠的关键区别：
玄幻grey=133 vs 仙侠grey=203。不是"仙侠更文艺"——是仙侠的修炼篇幅需要更多grey填充。玄幻的"升级"可以靠战斗+事件推进，仙侠的"修炼"必须靠内心过程填充。

**禁忌**：
- ❌ grey<60 → 玄幻"太空洞"（除非特殊策略如斗破苍穹）
- ❌ !/千字>7 → 不是竞技文，不需要每场比赛进球
- ❌ 省略号<1.5 → 玄幻对话需要停顿

---

#### X.2.8 仙侠/修真 —— 心境叙事，最重的品类

**参数基准**：
```
grey       = 202.8（全库最高）
离散度     = 极大（仙葫5.0 → 奥术神座714，差140倍）
均句长     = 36.2
句号/千字  = 19.4（全库最低 = 最长的叙事段落）
!/千字     = 4.9
省略号/千字 = 2.9
```

**叙事逻辑**：
仙侠的grey=202.8来自一个结构性约束：**修炼需要篇幅**。

写一章"突破元婴期"——如果没有内心描写，就只剩"他运转功法，灵气入体，突破了"7个字。grey不是"文笔膨胀"——是"修炼=内心过程"的篇幅必然产物。

但最大离散度的含义：仙侠是一个品类名掩盖两个物种的事实。

**物种A：法则驱动型**（grey<100）
- 仙葫(5.0)、巫师之旅、凡人修仙传初期(0.35)
- 修炼是"外部规则的破解"，不需要内心升华
- 叙事节奏更接近玄幻——战斗+事件推进

**物种B：心境驱动型**（grey>200）
- 奥术神座(714)、修真四万年(400+)、牧神记(300+)
- 修炼=对世界本质的认知重构
- 叙事需要大量思辨和内心独白
- 道诡异仙的grey极高——中恐+修仙的"心境双重费"叠加

时代趋势：仙侠从2005年的"凡人修仙"(法则驱动)到2020+的"心境修仙"(心境驱动)，品类叙事在不断向grey高区迁移。不是所有仙侠都需要200+grey——但**如果是心境修仙类型，grey偏低是结构缺陷**。

**禁忌**：
- ❌ 法则型仙侠套grey<50但写"悟道"章——"悟"不出来
- ❌ 心境型仙侠grey<100——"这个修真没有境界"
- ❌ 句号/千字>25——仙侠的"故事需要长的呼吸"

---

#### X.2.9 恐怖/灵异 —— 氛围叙事，留白即压迫

**参数基准**：
```
grey       = 141.0
省略号/千字 = 3.1（全库最高）
!/千字     = 3.3
样本       = 6本
```

**叙事逻辑**：
恐怖品类有两个极端需求，造就了全库最高的省略号密度和最特殊的!分布：

**省略号=3.1/千字 → 留白即压迫**：
恐怖小说的核心不是"出现了怪物"，是"你不知道什么时候会出现怪物"。省略号制造了最基础的"未说完"感——一个角色"我想起来了……那个人之前好像……" = 恐怖感产生了。全库最低的历史文省略号=1.6，全库最高的恐怖文省略号=3.1，差了近2倍——这不是偶然，是品类叙事需求的核心信号。

**!/千字=3.3 → 恐怖不需要喊**：
恐怖小说的情感峰值不是"惊叫"——是"不叫"更恐怖。竞技文的9.0是射门，恐怖的3.3是"他看到一个不该出现在镜子里的倒影"。恐怖文没有竞技文那种"进球！"的明确高潮点——恐怖是缓慢积累的。

**grey=141.0 → 渲染即武器**：
恐怖需要环境渲染(grey的一部分)来制造氛围。没有环境描写的恐怖小说="一个怪物突然出现了"——这是动作片，不是恐怖片。历史文不需要灰色是因为策略已经通过对话展示了，恐怖文需要灰色是因为"氛围就是武器"。

**禁区与例外**：
- ❌ 省略号<2.0 → "他完全说完了他要说的" → 不恐怖
- ❌ !/千字>6 → "哎呀！吓死我了！" → 不是恐怖，是搞笑
- ❌ grey<80 → 氛围不够，恐怖失效

**稀有性说明**：
6本恐怖样本是小众——但参数一致。这是个"品类人数少但品类特征最鲜明"的类型。

### X.3 品类选择指南

#### 品类选择法则

1. **一旦选定品类，全书写在该品类的叙事契约内。不可混搭。**
   - 仙侠的grey放进历史 → 历史读者说"拖沓"
   - 竞技的!放进恐怖 → "这鬼片怎么这么燃"

2. **允许品类内部的两个物种共存，但不能在章节之间反复切换。**
   - 仙侠的"法则驱动"和"心境驱动"是物种差异
   - 但单本章节不能一章极低grey(10)、下一章极高grey(300)——读者会困惑

3. **跨品类作者的自然调频。**
   - 肘子从英雄联盟(竞技, grey≈50)到大王饶命(都市异能, grey≈120)→ 自然调频
   - 不会出戏，因为作者会无意识调整

### X.4 品类叙事契约的使用方式

在写作任何一章/任何一段之前，查询所在品类的叙事契约：

1. **校验grey预算**：本章计划的内心/环境渲染量是否超过品类均值±25%？
2. **校验句子结构**：均句长是否在品类甜点区间？（历史文长句是武器，竞技文长句是敌人）
3. **校验情感峰值**：感叹号预算是否匹配品类需求？（竞技文没有足够感叹号=进球没喊出来）
4. **校验停顿密度**：省略号是否符合品类调性？（恐怖文没有足够的省略号=不恐怖）

**不是"不能偏离"——是"偏离要有理由"。**
- 秦吏grey=7偏离品类均值25.8——但有理由：纯逻辑驱动
- 奥术神座grey=714偏离品类均值202.8——但有理由：思辨型心境修仙
- 没有理由的偏离 = 品类契约崩塌

### X.5 品类与断层（跨品类陷阱）

从440篇分析中发现的常见断层：

**断层A：灰色的品类误匹配**
```
错误例：给都市文塞入仙侠的grey(200+)
→ 读者反馈："这段太文艺了""能不能写快点"
→ 不是文笔问题，是品类叙事契约被切换了
```

**断层B：感叹号的时间倒错**
```
错误例：给2025年竞技文套2005年竞技文的!/千字(3.0)
→ 显得"太平淡"——因为现在的竞技文已经适应了6-8的峰值密度
→ 不是写得差，是把现代读者放到二十年前的节拍器上
```

**断层C：句长的品类矛盾**
```
错误例：给无限流写短句规则
→ 无法完整解释世界设定 → 叙事灾难
错误例：给历史文写53字长句
→ "这个朝堂讨论像在念学术论文" → 违和
```
