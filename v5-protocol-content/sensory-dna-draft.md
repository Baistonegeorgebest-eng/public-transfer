## 感官DNA——每个品类天生有不同的感官路线

**v4.4正确说了"不要五感齐全，选2-3种重点写"——但没说选哪2-3种。**

这一章解决的是：**每个品类的主导感官不是作者的自由选择——是品类DNA决定的**。写美食末世应该用嗅觉+味觉主导（不是视觉+听觉）。写历史应该用视觉+听觉加点触觉——味觉在朝堂上没有用武之地。

| 末世/废土 | 23.4 | 10.3 | **9.1** | **2.9** | **3.0** | 视觉+触觉+味觉 | 纯视觉观察 |

**三个关键发现**：

**① 仙侠是唯一嗅觉强品类（6.2/10k）**——"弥漫""散发""血腥"是修道世界的底层感官。如果写仙侠文3章没出现任何气味词——你的读者正在失去"在这个世界里的感觉"。

**② 末世是多感官冠军（五感均衡）**——末世文同时达到触觉9.1+味觉3.0+嗅觉2.9，是所有品类中感官最丰富的。这不是偏好——是废土环境的必然要求（废墟的触感、腐肉的气味、水资源的口感）。

**③ 历史和体育在同一端（感官贫乏）**——历史文用视觉+听觉就够了（朝堂不需要嗅觉）；体育文几乎完全丢弃嗅觉（0.2/10k）。如果写历史文强行加"大殿里有檀香味"——可以，但**每章最多1次**（再多了=违和）。

### S.3 感官混搭法——品类专有的感官组合技

**规则（升级自v4.4）**："不五感齐全"→"用感官混搭——让两种感官在同一个句子中共振。"

#### 仙侠专属：视觉+嗅觉混搭

```
✅ "那朵莲花散发出诡异的紫雾"，站在一里外都能闻到那股甜腻的腐败。
→ 视觉（紫雾）+ 嗅觉（甜腻的腐败）= 单一感官达不到的"仙界邪物感"

✅ 刀锋上泛起一层血光，血腥味浓得像打翻了一坛老酒。
→ 视觉（血光）+ 嗅觉（血腥味）= 双重锚定"这把刀杀过很多人"
```

仙侠中视觉-嗅觉混搭场景：修炼场所、丹房、古战场遗址、灵植药材、妖物出现。

#### 末世专属：触觉+味觉混搭

```
✅ 水入口时有种金属味，像舔过生锈的刀刃——他打了个战栗。
→ 味觉（金属味）+ 触觉（战栗）= 双重锚定"这水不干净"

✅ 风刮过废墟，带着沙子的触感——你能咬到那种干燥的味道。
→ 触觉（沙子触感）+ 味觉（干燥的味道）= 废土环境的全感官临场
```

末世中触觉-味觉混搭是废土环境的核心渲染手法——其它品类做不到这种"身体层面的恶劣感"。

#### 恐怖专属：触觉+听觉混搭

```
✅ 手掌贴上门板，木头是冰的——门后面传来细微的刮擦声，像指甲在划。
→ 触觉（冰）+ 听觉（指甲刮擦）= 双重锚定"门后有东西"

✅ 什么声音都没有。他的背脊贴着墙壁，能感觉到那层石灰底下有什么在动。
→ 听觉（无声音）+ 触觉（墙内有东西在动）= 恐怖在"无声中有物感"
```

恐怖文的核心逻辑：**感觉大于看到**——触觉+听觉混搭让读者"感受到了"恐怖，而不是"看到了怪物"。

#### 历史专属：视觉+触觉混搭

```
✅ 他摩挲着那卷发黄的绢书，纸面有点涩。
→ 视觉（发黄绢书）+ 触觉（面涩）= 锚定古籍的物质感

✅ 刀很重。刀柄的缠绳松了，拇指按下去能触到铁柄本身的冷。
→ 触觉（重、松、冷）= 实物感通过触觉渲染而非视觉描述
```

历史文用视觉-触觉混搭来做"物证的质感"——朝堂没有嗅味，但朝臣能摸到的文书、铜印、刀柄都应该有质感。

#### 竞技/游戏专属：视觉+听觉混搭

```
✅ "Goal——！！" 全场炸了。他看到那球越过门将的手指飞进左上角。
→ 听觉（全场的"Goal"）+ 视觉（球越过手指）= 双重锚定进球瞬间

✅ 鼠标点击声停了。屏幕中央那个进度条从99%跳到100%。
→ 听觉（点击声停）+ 视觉（进度条）= 紧张在听觉消失的时刻达到最大
```

#### 都市专属：视觉+味觉混搭

```
✅ 咖啡浓得像酱油。他看着杯底那团未溶开的渣对着老板干笑。
→ 味觉（浓苦）+ 视觉（杯底渣）= 都市日常生活的感官锚定

✅ 女人高跟鞋咔咔走过去，留下一种甜得有点假的香水尾调。
→ 听觉（高跟鞋）+ 嗅觉（香水尾调）= 街头的双重锚定
```

### S.4 感官衰减律——为什么你的卷三失去嗅觉了

从169章全本诊断数据中发现的规律：

```
📉 嗅觉占比：卷一4% → 卷二2% → 卷三1%  （-75%）
📉 长句(>30字)：8.6% → 3.7% → 0.8%  （-91%）
📉 省略号/章：1.6 → 0.8 → 0.2  （-88%）

视觉占比（推算）：卷一45% → 卷二65% → 卷三80%
```

**感官衰减是AI写作的必然退化模式**：章节越多，视觉占比越膨胀，其余四感全部被压缩。到卷三，感官指纹变成"纯视觉"——这不是"整体优化了"——是**感官崩溃了**。

**反衰减策略**（每卷开头必做）：

```
① 重设感官预算（用S.2表格）
② 给嗅觉/味觉/触觉各分配最低保障额：
   嗅觉≥1次/章（无论品类）
   触觉≥1次/章（无论品类）
   味觉：玄幻/历史/体育可以跳过，其他品类≥0.5次/章
③ 每写完一章拉出感官计数：
   视觉信号数/总信号数 < 70%  → ✅
   视觉信号数/总信号数 > 70%  → ❌ 检查五感是否被视觉压缩
```

### S.5 特殊品类感官规则

#### 太空科幻：感官真空

```
规则：太空没有气味，没有声音，绝大多数是"信息的描述"而非"感官的描述"。
→ 感官分配中可以缺少嗅觉/味觉/触觉/听觉全缺——但视觉必须强化。
→ 但在有大气层的场景（舰内、基地、星球表面）——必须恢复全身感官。
→ 从太空到舱内的过渡必须显示感官切换：

✅ 舱门滑开，空气里有股臭氧味。
→ 从真空→有大气层的第一感觉 = 气味回归
```

#### 末世/废土：多感官必然

```
规则：末世=环境中始终有"身体层面的威胁"。
→ 触觉不隔离——角色不是在"看"废墟，是在"感受"废墟
→ 味觉不是在"品茶"——水的安全性和可饮用性是一个味觉判断
→ 嗅觉是生存工具——腐肉/烟/火药/化学剂

✅ 空气里飘着一股淡淡的煤油味——可能是燃料泄漏。
→ 嗅觉 = 危险预警（不是"感官享受"——是生存工具）
```

#### 仙侠：嗅觉是修道感的底层

```
规则：修炼的环境必须通过嗅觉锚定（丹房、灵药田、古战场、妖兽巢穴各有气味）。
→ 如果没有嗅觉，修炼="一堆人在空房间做呼吸运动"
→ 突破境界时需要气味锚定——"天地灵气"如果在文字上感知不到，就是概念而非体验

✅ 灵气像松脂一样浓，烧灼着鼻腔。
→ 修炼的嗅觉锚点——不是"他突破到了金丹期"——是"他闻到/感受到了天地灵气"
```

#### 历史：物证法则

```
规则：历史文的功能感官不是嗅觉/味觉——是触觉。
→ 历史的世界不靠气味——靠物证。触觉承载所有"古代的物质感"。
→ 刀、纸、铁、木、石、布——每一种物质都要有触觉出现。

✅ 竹简边缘有毛刺。他用指甲推了推，毛刺扎进去了一点。
→ 触觉=年代的质感——不是"这是汉代竹简"——是"你的手指能感觉到汉代的毛刺"
```

#### 美食末世：味觉+嗅觉 3:1 比例

```
规则：烹饪场景 = 味觉主角 + 嗅觉前导。
→ 一个完整烹饪段：嗅觉开路（香味飘来）→ 味觉高潮（入口瞬间）→ 触觉收尾（余味/触感）
→ 不要"闻到了香味"——要"从味道反推成分"

✅ 那股浓香钻进鼻子，他已经能尝到粥要搁多少盐了。
→ 嗅觉→味觉预估→不是"闻"是"推测味道"
```

### S.6 感官库检查清单

**写前预算**：

```
□ 确认本卷品类 → 查S.1表格选择"主导路线"
□ 设定每章感官总信号数（参考S.2表格）
□ 视觉信号上限 = 总信号×70%
□ 确保品类特有感官（仙侠嗅觉/末世触觉/历史触觉）有最低配额
□ 如果品类=太空科幻：标记从真空到大气层过渡点→那里必须是气味回归点
```

**每章审查**：

```
□ 视觉 < 总信号×70%？
□ 品类特有感官出现？（仙侠使用嗅觉≥1次? 末世使用触觉≥2次?）
□ 感官混搭至少1次？（品类专有组合技）
□ 感官分布不是均匀的——高潮场景有更多的感官轰炸？
□ 长对话段中是否插入了感官锚点？（长对话=感官缺席的高危区）
```

**每卷反衰减检查**：

```
□ 嗅觉占比 vs 上一卷（持平或上升？）
□ 非视觉感官总数 vs 上一卷（持平或上升？）
□ 如果有下降：下一章的感官总信号+2~3
□ 卷结尾=感官最丰富的章节（不是最贫乏的）
```

> **本章与协议其他模块的关系**
>
> - **品类叙事契约**（§X）→ 品类决定了主导感官路线
> - **时间锚定**（§Y）→ 不同时代的感官密度不同（例如现代都市的感官密度高于古典历史）
> - **省略号经济学**（§Z）→ 感官描写在留白句附近应该更多（省略号后的描写=读者的感知介入点）
> - **T1/T2/T3分级**→ T3的感官混搭应该更精细，T1可以有"感官直给"（直接描述气味/触感，不绕弯）
> - **福利库**→ 福利段落的感官密度应该是普通段落的2-3倍，且五感需要全开
