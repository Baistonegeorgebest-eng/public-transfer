> 这是v5.0 Human Protocol的P1-4模块：角色DNA体系升级。
> 升级自 v4.4 §五「角色语言DNA」（4张模板卡）→ 品类驱动的角色DNA参数生成器
> 数据基础：438篇手写叙事分析中的角色塑造模式 + 品类叙事契约 + 作者进化曲线
> 起草日期：2026-05-09

## 角色DNA——品类决定了角色的"说话方式"

**v4.4做了**：4张角色DNA卡（林无味/陈晓/林小溪/赵雪）——每张有"说话节奏+高频词+禁区词+口癖+情感出口+感官偏好+语言缺陷"。

**问题**：这些模板卡是为"美食末世"这一个品类手工设计的。你换到仙侠、换到都市、换到历史——角色DNA的"参数架构"完全不同。

**v5.0要做**：不是再写20张更多模板卡——是**给定品类 → 给定角色定位 → 自动生成角色DNA约束**。

### C.1 品类的"角色类型学"：每个品类能容纳的角色类型不同

不是所有品类都支持所有角色类型。从438篇分析中提取：

```
品类          能容纳的角色类型                              不能容纳的角色类型
═════════════════════════════════════════════════════════════════════════
仙侠/修真      独行天才、宗门老怪、叛逆弟子、无情剑修、        纯粹搞笑担当、无武力配角
              冷面炼丹师、天真小师妹、黑化师兄

都市/现实      社畜逆袭者、金手指打工仔、吐槽系女友、          江湖侠客、修炼者（除非都市修仙）
              冰山上司、退役兵王、舔狗兄弟

西幻           异界穿越者、骑士/魔法师学徒、失意王子、         朝堂权臣、科幻机甲驾驶员
              精灵/矮人/兽人、被诅咒者

科幻           星舰舰长、基因改造者、AI/合成人、               修仙者、古代官员、魔法师（除非混搭世界）
              末世幸存者（不是科幻专属）、科学家

末世/废土      生存主义者、母性/保护型领袖、叛变队员、         普通市民（末世没有"普通人"——逃亡者是职业）
              孤儿搭档（一老一少/一强一弱）、

              系统持有者

              对手/宿敌、团队吉祥物
```

**不是说你只能在这些列表中选**——而是：如果你的角色类型不在"能容纳"列表中，你需要**额外付出1-2章的篇幅来解释他为什么出现在这个品类中**。

### C.2 品类的"对话引擎"：不同品类的角色对话风格差异

基于品类grey和对话率数据：

| 品类 | 对话率 | 对话节奏 | 对话风格 | 适用句式 |
|------|--------|---------|---------|---------|
| 都市 | 30-45% | 快（2-3句交换） | 吐槽、反讽、现代语 | 短句、省略主语 |
| 竞技 | 30-40% | 中等（3-5句） | 激励、分析、嘲讽 | 中等句、专业术语 |
| 同人 | 25-35% | 中等 | 与原作一致的风格 | 灵活 |
| 游戏 | 25-35% | 快 | 战术、喊叫 | 极短 |
| 末世 | 20-30% | 慢（5+句） | 戒备、克制、生命思考 | 中长句 |
| 仙侠 | 20-25% | 慢 | 装逼、隐忍、道理论 | 中长句 |
| 科幻 | 20-25% | 中等 | 理性、分析、概念解释 | 中长句 |
| 恐怖 | 20-25% | 不均衡 | 紧张断句、正常→语无伦次 | 短句在恐惧中爆发 |
| 玄幻 | 15-25% | 中等 | 热血、装逼、打脸 | 中等句 |
| 西幻 | 15-25% | 慢 | 史诗、声明、预言 | 中长句 |
| 历史 | 15-20% | 慢 | 礼仪、暗讽、文言腔 | 中长句 |
| 体育 | 15-20% | 中等 | 加油、评论、策略 | 短中等句 |

**对话率×品类grey的联动**：

```
低grey品类（历史grey=25.8、体育grey=0）：
  → 对话中的模糊词（"可能""似乎""也许"）≈ 0
  → 历史人物说话 = "这天下，朕说了算"——不是"这天下，或许是朕的"

高grey品类（仙侠grey=202.8、科幻grey=120-180）：
  → 对话中允许模糊判断
  → 修仙人物说话 = "此物怕是被天机所遮蔽"——不是"此物被天机遮蔽"
```

### C.3 角色的"存在质量"：不是多写几个标签——是让角色在文本中有体感

v4.4的模板卡有14个字段——但**AI写出来的角色还是NPC**。因为模板卡是"关于角色的数据"，不是"角色在文字中的存在"。

v5.0用三个维度来衡量：

#### 维度A：语言指纹密度（每1000字对白中应该有多少个指纹信号）

```
角色语言指纹密度表：

角色层级    对话字数   指纹信号/千字    信号类型
════════════════════════════════════════════════
主角        全篇最高    8-12            口癖+句式+情感词+禁区突破+习惯动作
次级主角    高          5-8             口癖+句式+1-2个情感词
重要配角    中          3-5             口癖+句式
功能性NPC   低          1-2             1个句式或1个口癖
```

**信号定义**（每种都是一个"不是所有人都这样的"特征）：

```
口癖信号：—口头禅（每5-10句出现一次）—语气词（吧呢啊嘛）—无意义填充词（那个/这个/就是说）
句式信号：—碎句/长句/不成句—问句比例（偏多或偏少）—反写逻辑（先说结论再说理由）
情感词信号：—开心→____/生气→____/难过→____—不以"我X"作为情感载体
禁区信号：—不说的词—不让用的句式—不让做的语言行为
习惯信号：—摸刀/撩发/绞衣角/沉默
```

#### 维度B：社交距离波动率

```
角色间的关系不是固定的——社交距离应在1章之内至少1次改变：

距离类型      改变示例
────────────────────────────
远→近         敌人→不信任的盟友 / 陌生人→（一件事后）暂时同行
近→远         朋友→（一个误解后）冷淡 / 师徒→（一次质疑后）疏远
近→更近       盟友→（一次共同战斗后）体己 / 师徒→"叫你师父or叫你名字"
远→更远       敌人→死敌 / 竞争对手→（一次失败后）追悔
```

**禁止**：3章之内角色之间的距离没有变化 → 角色的关系是"死的"——这章不应该存在。

#### 维度C：角色-环境绑定

```
每个角色必须有一个"专属环境"——他/她在其中最有存在感的环境：

主角/美食末世 → 厨房（不是"烹饪场景"——是他能在厨房里自言自语/骂人/试味/磨刀）
主角/剑修   → 剑阁/断崖（不是在"修炼"——是"深夜一个人对着剑说话"）
配角/军师   → 地图室（不是在"分析"——是"蜡烛烧到手了三回"）

规则：  
1. 每个角色有1-2个专属环境  
2. 在专属环境中，角色的语言指纹密度自动+50%（读者在这场景中最"看见"他）
3. 专属环境必须每5-10章出现一次——否则角色在文本中"消失"
```

### C.4 角色的"品灰度"——角色自己的不确定性

一个关键发现：**不同品类的角色可以有不同的"不确定性"——不只是作者grey的问题。**

```
品类角色品灰值：

美食末世主角：grey=高——"什么都能吃"意味着"不知道要吃什么"
剑修主角：grey=低/0——"剑即一切"——没有犹豫的空间
历史军师：grey=极低——"策不可改"——一次性决定
网游竞技主角：grey=中等——"我不确定我能不能赢但我要说我能赢"
恐怖文主角：grey=极高——"那是什么东西？？"——恐怖在主角的感知模糊中产生
都市社畜主角：grey=中等——"这老板是真傻还是装傻"
```

**角色品灰值的操作**：

```
1. 主角自己的不确定（grey） = 叙事不确定（作者grey）× 0.3～0.7
2. 配角的不确定 = 叙事不确定 × 0.1～0.3
3. 反派的不确定 = 叙事不确定 × 0.0～0.1（反派几乎永远"知道自己在做什么"）
4. 不明角色的不确定 = 叙事不确定 × 1.0（纯粹的模糊——是敌是友？）
```

### C.5 角色DNA与进化曲线的联动

对照34条作者进化曲线：

```
规则：作者在成熟化时，角色的"确定性"会上升。

辰东（进化：史诗→沉稳）：
  神墓时期→角色的不确定来自"天地不公"
  深空彼岸→角色的不确定几乎是0——"我知道要做什么"

猫腻（进化：聪明→善良）：
  庆余年→角色的不确定来自"算计别人"
  将夜→角色的不确定来自"我要保护她但我不知道怎么保护好"

血红（进化：持续振荡）：
  所有作品→角色的不确定永远≥50——"这个世界本身不确定"
  血红的角色永远不能说"我确定"——这是他的品类DNA

土豆（不进化）：
  所有作品→主角的不确定=0——"我知道要做什么：打他脸"
  这是退婚流的核心——主角被压制，但主角没有任何自我怀疑
```

**操作**：

```
给定你的对标作者 → 查§E进化曲线 → 如果是成熟化型 → 你的主角的不确定应适合当前篇章数
  第1-50章：主角不确定偏多（初态）
  第50-200章：主角不确定减少（过渡态）
  第200章+：主角不确定稳定在低水平（成熟态）

如果对标的是血红/土豆型 → 主角的不确定是固定值——不需要随时间改变
```

### C.7 角色DNA检查清单

**一章内**：

```
□ 主角的对话指纹密度 ≥ 8/千字对话？
□ 有一个专属环境的信号出现？
□ 至少一个角色的社交距离发生了改变？
□ 不同角色的品灰值分布合理（主角中等、配角低、反派0）？
□ 没有两个角色用同一套语言系统？（→立刻修改其中一人的句长/口癖/词汇）
```

**跨章节**：

```
□ 每5章内：每个重要角色回到过专属环境一次？
□ 每10章内：角色的社交距离格局有实质改变？
□ 每20章内：主角的品灰值匹配当前篇章数的进化阶段？
□ 连续3章没有改变角色距离 → ❌ 这三章应该合并或删除
```
