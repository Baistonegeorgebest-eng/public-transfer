## 进化曲线——写参数不如写轨迹

**v4.4这样做了**：style-reference中有"这部小说的grey是XX"、"这部小说的省略号是YY"——**但这是静止的，像一个人在某一年的照片。**

**v5.0要做的**：给定一个作者，我不是告诉你"他当前的参数"——我是告诉你"他正朝哪个方向变"。因为你的小说在连载中——你需要的是一个**动态目标**，不是一个**快照**。

---

### E.1 三大进化学规律（34作者 → 通用规律）

#### 规律① 头部作者的"成熟化学习曲线"（15/34证）

```
规律：写完第4-6本书时，作者普遍经历"!↓ + 句长↓ + grey收敛"三降期

具体表现：
  ! 递减：从处女作的8-14/千字 → 成熟作的2-5/千字（-50%到-70%）
  句长缩短：从42-50字 → 27-33字（-25%到-40%）
  grey收敛：从广谱震荡（0↔668）→ 稳定区间（50↔250）
```

**15个证实作者**：辰东、猫腻、梦入神机、唐家三少、会说话的肘子、宅猪、西红柿、远瞳、山人有妙计、zhttty、文抄公、方想、滚开、猪头七、余云飞

**反例（但不违反规律）**：
- 土豆——不需要"成熟化"——他从第一本《魔兽剑圣》就锁定了"退婚→打脸"循环——他不需要进化，他只需要重复
- 血红——没有收敛，他保持了28年的grey震荡（22→44→89→92→155→192→251→668）——因为模糊本身就是他的叙事DNA
- 烽火戏诸侯——他从都市文品类跳槽到仙侠——"进化"是品类切换而非参数成熟

**为你的写作带来的操作建议**：
```
如果你的小说在连载（前50章）：
  → 参数应该偏右（!偏高、句长偏长、grey偏广）——这像作者的处女作

如果你的小说在连载（50-200章）：
  → 参数应该进入三降期（!➖、句长➖、grey➖）

如果你的小说在连载（200章+）：
  → 参数应该进入成熟态（!稳定在3-6、句长稳定在28-35、grey稳定在50-200）
```

#### 规律② 品类×作者的"不可能三角"

```
规律：一个作者不能同时拥有：高句长 + 高对话率 + 高频! 

品类的自然分配：
  仙侠/西幻：选择 高句长（35-50）+ 低对话率（15-20%）→ 放弃！
  都市/竞技：选择 高对话率（30-45%）+ 高频! → 放弃长句
  历史/古言：选择 中句长 + 极低! → 放弃对话率
```

操作含义：**给定品类→自动决定了作者要牺牲三角中的哪一个**——不需要凭感觉判断"这部该不该多写对话"。

---

#### 规律③ 省略号的二向性：永远是"留白工具"或者"停顿标记"——不可两者都是

```
规律：省略号在作者版图中极端分化：
  留白派（辰东神墓5.5、文抄公持续攀升）：... = 意境空白 → 读者自己填
  停顿派（滚开0.5、百里玺0.3）：...不存在 → 所有空白都是句号或无声
  
没有作者同时在高句长+高省略号——因为长句+省略号=读者的迷失感。
```

**操作推导**：给定你的品类+句长+对话率——自动推导你的省略号甜点区间（由§Z省略号经济学负责计算）。

### E.3 进化参考三句话

```
一句话一：如果你的品类是修仙/西幻 → 对标辰东或猫腻的进化路线
  （从"喊"到"安静" → grey从波动→稳定 → 句长从38→30出头）
  
一句话二：如果你的品类是都市/竞技 → 对标会说话的肘子或猪头七的进化路线
  （!从10→3 → 句长从40→30 → grey从高→收敛 ← 快节奏品类）

一句话三：如果你想"从不进化" → 对标土豆
  （锁定一个循环 → 将它写到极限 → 不需要进化 → 只需要重复）
```

### E.4 作者进化曲线集成到其他模块

**与省略号经济学（§Z）的联动**：

```
给定作者 → 查E.2矩阵 → 如果作者进化类型=成熟化
  → §Z的省略号预算要加入"随章节推进递减"的时间修正
  → 第1-50章用初态参数（!偏高）
  → 第51-200章用过渡态参数（!中等）
  → 第200+章用成熟态参数（!偏低）
```

**与感叹号预算制（§W）的联动**：

```
给定作者 → 查E.2的!轨迹
  → 如果轨迹是"从高→低"（多数作者）：§W的!预算应该高开低走
  → 如果轨迹是"高位保持"（风凌天下14.3）：§W的!预算固定高值
  → 如果轨迹是"低位保持"（百里玺1.1）：§W的!预算固定低值
```

**与品类叙事契约（§X）的联动**：

```
给定品类+给定章节数 → 用§X品类基准 × §E进化趋势修正
  仙侠基准! = 7 + "第200章修正"-30% = 最终!预算 = 4.9
  都市基准! = 4.5 + "第50章修正"+20% = 最终!预算 = 5.4
```

### E.5 进化曲线检查清单

**写前**：

```
□ 确认对标作者 → 查E.2找到最近的进化类型
□ 确定当前章节数 → 查E.1规律①找到当前阶段（初态/过渡/成熟）
□ 提取对标作者在"当前阶段"的参数（!密度、句长、grey）
□ 代入§Z和§W作为预算计算的输入
```

**写后**：

```
□ 章节参数是否匹配对标作者的"当前阶段"参数？
□ 是否出现了"过早成熟"？（前50章!已经低于3→调回初态参数）
□ 是否出现了"退化"？（200章后!回到8→暗示叙事退化到"喊"）
```

>
> - **品类叙事契约**（§X）→ 品类基准参数 = 进化曲线的起点
