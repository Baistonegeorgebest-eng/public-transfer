## 二、分析质量标准

### 参考标杆
- **斗破苍穹**（31KB）：标点指纹+进化突变+退婚流结构+严肃度曲线+五感权重+模糊度+斗技节奏+退婚流物种分析+协议参数建议
- **苟在妖武**（14.8KB）：开局结构对比+双世界穿梭+感叹省略双高+爽点密度矩阵+严肃度波动+犹豫型叙事

### 标准要素
1. **标点指纹**：感叹/省略/逗号/句号/问号千字比 + 均句长 + 段均 + 长短句率
2. **全书趋势**：按百分段/章组的情绪密度曲线
3. **场景级抽样**：开局/高潮/战斗/对话等不同叙事模式的标点差异
4. **叙事结构分析**：标点如何服务于叙事功能（不是跑数据，是解读数据）
5. **跨作者对比**：与已分析作品的结构级对标
6. **核心洞察**：从数据中发现的叙事规律（不是"感叹低"，而是"为什么低+低了有什么效果"）

### 质量等级
- **>15KB**：顶级（全面覆盖+深度解读+跨作品对比）
- **10-15KB**：高质量（标点+趋势+场景+洞察）
- **5-10KB**：良好（标点+基本洞察）
- **<5KB**：需要升级

## 五、操作备忘

### Git 推送
```bash
# SSH推送
GIT_SSH_COMMAND="ssh -i ~/.ssh/.github_miclaw -o StrictHostKeyChecking=no -o ConnectTimeout=30 -o ServerAliveInterval=10" git push origin HEAD:main

# 只add新增文件，不要git add -A
git add novel-corpus-analysis/analysis-新文件.md
```

### 工作目录
- master（小说原文+分析）：`/root/.openclaw/workspace/public-transfer-master-git/`
- main（分析+脚本+协议）：`/root/.openclaw/workspace/public-transfer-main-git/`
- main 是 master 的 worktree，共享 git 对象

### 分析流程
1. 从 master 的 `novel-txts/` 读小说原文
2. 跑标点统计（注意GBK编码需iconv转换）
3. 读章节内容，理解叙事结构
4. 写深度分析到 master 的 `novel-corpus-analysis/`
5. 复制到 main，commit + push
